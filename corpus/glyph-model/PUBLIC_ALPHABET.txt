# PUBLIC_ALPHABET — approved public glyph subset (default closed)
#
# One glyph slug per line. A glyph is published to the public GitHub mirror only
# if its slug appears here AND it is certified in the private ALPHABET.md. This
# file — not the private canon — is the source of truth for what is public.
#
# Empty (only comments) means nothing is published. To publish a glyph, add its
# slug, then run:
#
#   corpos-lab disclosure promote
#
# which copies only the approved, certified glyphs' AC-4 blocks into
# corpus/glyph-model/published/. The public-repo CI runs
#
#   corpos-lab disclosure verify
#
# and fails if published/ does not match this file exactly (an unapproved glyph
# present is a leak; an approved glyph absent means promotion did not run).
#
# Keep the public subset no broader than what a published paper needs a reader to
# verify. Widening it is a deliberate act, not a default.
