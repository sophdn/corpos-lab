# Deployments/Data-Export-v2/Compliance-Checklist.md

## Data Scope
- **Status:** Compliant
- **Details:** The data scope for v2 remains unchanged from v1. The data types and volume exported are consistent with the previous version. No additional data types are introduced in v2.

## Access Controls
- **Status:** Compliant
- **Details:** Access controls from v1 are unchanged. The partner-portal access path uses OAuth scope for authentication, ensuring that only authorized partners can initiate data exports. The existing access-control measures remain effective and applicable.

## Retention Policies
- **Status:** Compliant
- **Details:** Retention policies have not been altered in v2. Data is retained according to the same schedule and procedures as defined in v1.

## Audit Logging
- **Status:** Needs Update
- **Details:** 
  - **Existing:** Audit logs capture all relevant actions as per v1 requirements.
  - **Change:** v2 introduces a partner-portal access path. According to the Q4 2025 bulletin, any deployment adding a partner-initiated export pathway must include a Provenance Stamp.
  - **Action Required:** Implement a Provenance Stamp in audit logs for partner-initiated exports. This stamp should capture:
    - User's authorization grant ID
    - Requesting party's identity
    - Authorization scope
    - Validity window at the time of export
  - **Implementation Note:** The Provenance Stamp must be written synchronously and fail closed if it cannot be assembled.

## Security
- **Status:** Compliant
- **Details:** Security measures from v1 are still applicable. The addition of the HTTP endpoint for partner-portal access is secured via OAuth, ensuring robust security practices.

## Legal
- **Status:** Compliant
- **Details:** Legal sign-off from Q1 2025 covers the unchanged aspects of v2. The addition of the partner-portal access path does not introduce new legal concerns outside of the audit logging requirement specified in the Q4 2025 bulletin.

---

**Conclusion:** The v2 release is compliant with the existing v1 checklist, with the exception of the audit logging requirement introduced by the Q4 2025 bulletin. The necessary update for audit logging must be implemented to ensure full compliance. All other controls from v1 remain applicable and effective.
