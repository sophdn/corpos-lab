# Data-Export v2 Compliance Checklist

## Introduction
- **Scope**: This checklist ensures that the data-export v2 release complies with existing policies and regulations, with specific attention to new features introduced in this release.

## Data Scope
- **Verification**: Confirm that the data scope remains unchanged from v1. No additional data is being exported beyond the established scope.

## Access Controls
- **Verification**: Ensure that access controls are consistent with v1. The addition of the partner-portal access path must adhere to existing access control policies.
- **New Requirement**: Partners must authenticate via OAuth scope and request exports only for users who have granted them active authorization.

## Retention Policies
- **Verification**: Confirm that data retention policies remain consistent with v1. No changes to data retention timelines or procedures.

## Audit Logging
- **Verification**: Ensure audit logging requirements from v1 are still applicable.
- **New Requirement**: As per the 2025-Q4 bulletin, any deployment adding a partner-initiated export pathway must include a Provenance Stamp. This audit entry should capture:
  - User's authorization grant ID
  - Requesting party's identity
  - Authorization scope
  - Validity window at the time of export
- **Implementation**: The Provenance Stamp must be written synchronously and must fail closed if it cannot be assembled.

## Partner-Portal Integration
- **Verification**: Confirm that the new HTTP endpoint `POST /v2/data-export/request` is secure and adheres to OAuth authentication standards.
- **Compliance**: Ensure that the integration does not introduce any new security vulnerabilities and complies with all relevant data protection regulations.

## Conclusion
- **Final Review**: Confirm that all compliance requirements for data-export v2 have been met, and that the system is ready for deployment.

---

This checklist should be reviewed and signed off by the appropriate compliance, legal, and security teams before the deployment of data-export v2.
