### Release Notes for `filterpipe` v1.5.0

#### New Features
- **ChainedFilter Class**: Introduced a new `ChainedFilter` class that allows users to compose multiple filter functions together. This feature enhances the modularity and reusability of filtering logic by enabling the chaining of filters.

#### Bug Fixes
- **NullFilter AttributeError**: Resolved an issue where `NullFilter` was raising an `AttributeError` when processing empty input. This fix ensures that `NullFilter` can handle empty inputs gracefully without errors.

#### Versioning and Release
- The version in `filterpipe/__init__.py` and `pyproject.toml` has been updated to `v1.5.0`.
- All 47 tests have been executed and passed successfully.
- The release commit and tag `v1.5.0` have been pushed to the remote repository.

#### Changelog
The project's changelog at `CHANGELOG.md` has been updated to reflect these changes. The release is complete with all necessary updates and documentation.

This release enhances the functionality of `filterpipe` by introducing the ability to chain filters and improving the robustness of the `NullFilter` class.
