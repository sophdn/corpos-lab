 1. Open the `RELEASES.md` file in a text editor.

2. Scroll to the end of the file to find the 20th entry.

3. Copy that entry, as it serves as a template for the new entry.

4. Paste the copied template just below the last entry.

5. Replace all occurrences of "vX.X" (where X.X is the version number of the template) with "v4.0".

6. Save the file.

7. If the number of releases now exceeds 20, move one of the oldest entries from `RELEASES.md` to `RELEASES_ARCHIVE.md`.

8. Save both files.
