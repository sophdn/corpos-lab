 To add the v4.0 entry to the `RELEASES.md` file:

1. Open the `RELEASES.md` file in a text editor.

2. Find the last entry in the file, which should be the 20th release. This is the release that will be moved to the archive file.

3. Copy the format of the last entry and paste it just below the last entry.

4. Replace the placeholders (like "v3.9", "Release Date", and "Description") in the copied format with the appropriate values for the v4.0 release.

5. Save the file.

6. Since the `RELEASES.md` file is capped at 20 entries, move the last entry (which was the 20th before adding the v4.0 entry) to the `RELEASES_ARCHIVE.md` file.

7. Save the `RELEASES_ARCHIVE.md` file.

Now, the `RELEASES.md` file has been updated to include the v4.0 entry, and the `RELEASES_ARCHIVE.md` file has been updated to include the previous 20th release.
