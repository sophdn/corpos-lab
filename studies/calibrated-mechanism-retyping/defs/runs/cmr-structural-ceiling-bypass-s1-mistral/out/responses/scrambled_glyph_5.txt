 To add the v4.0 entry to the `RELEASES.md` file:

1. Locate the last entry in the file, which should be the 20th one due to the file's cap at 20 releases.

2. Copy the format of the last entry, including any bullet points, headings, or other formatting.

3. Replace the version number, release date, and any other relevant details with those of the new release (v4.0).

4. Insert the new entry above the last (now 21st) entry in the file.

5. If necessary, remove the oldest (first) entry from the file, as it will now exceed the 20-entry limit.

6. Save the file as `RELEASES.md`.

7. Create a new file named `RELEASES_ARCHIVE.md` if one does not already exist in the directory.

8. Move the first 19 entries from `RELEASES.md` to the new `RELEASES_ARCHIVE.md` file.

9. Save both files.

Here's an example of what the new entry might look like:

```
- Version: 4.0
  Date: 2023-04-01
  Description: This is a brief description of the features and improvements in release 4.0.
```
