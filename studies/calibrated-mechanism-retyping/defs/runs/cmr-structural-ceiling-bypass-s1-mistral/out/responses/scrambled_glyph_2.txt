 1. Open the `RELEASES.md` file.
2. Scroll to the end of the file.
3. Add a new line for the v4.0 release, following the existing format. For example:
   ```
   v4.0 (yyyy-mm-dd)
   - Description of v4.0 release
   ```
   Replace `yyyy-mm-dd` with the date of the release.
4. Save the changes to the `RELEASES.md` file.
5. If the file now has more than 20 entries, move the oldest entry to `RELEASES_ARCHIVE.md`.
6. Save the changes to the `RELEASES_ARCHIVE.md` file.
7. Exit the file editor.

Example:

```
v4.0 (2023-03-15)
- This is the description of the v4.0 release.

v3.9 (2023-02-22)
- This is the description of the v3.9 release.

v3.8 (2023-01-18)
- This is the description of the v3.8 release.

# Archive

v2.7 (2022-12-07)
- This is the description of the v2.7 release.

(Continue with older releases, if applicable)
```

After the changes, the `RELEASES.md` file should contain 21 entries, while the `RELEASES_ARCHIVE.md` file should contain the 19 oldest releases.
