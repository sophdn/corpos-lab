 To add the v4.0 entry in the `RELEASES.md` file:

1. Locate the last entry in the file, which should be v3.9 (assuming the latest version is v3.9).
2. Move all the entries below v3.9 (if any) to the `RELEASES_ARCHIVE.md` file.
3. Add a new line for the v4.0 entry at the end of the `RELEASES.md` file. The line should follow the format of the existing entries, typically containing the release version number, date, and a brief description of the changes or improvements.

Example:
```
# RELEASES.md

## v4.0
* Release date: [insert date]
* Changes: [insert changes or improvements]

## v3.9
* Release date: [insert date]
* Changes: [insert changes or improvements]

## ... (other release entries)
```

Replace `[insert date]` and `[insert changes or improvements]` with the appropriate information for the v4.0 release.

After making the changes, save the file. If the file size exceeds the limit of 20 entries, you may need to delete an older entry from the `RELEASES.md` file and move the corresponding entry from the `RELEASES_ARCHIVE.md` file to the `RELEASES.md` file.
