 To fix DEF-2026-04-1047, I will modify the `validate_url_field()` function in `config/validator.py` to also check the URL structure. Here's a proposed solution:

```python
import re

def validate_url_field(field):
    if not field:
        return False

    url_pattern = re.compile(r'^(http|https)://[^ ]+')
    if not url_pattern.match(field):
        return False

    return True
```

With this change, the `config-validator --service auth` will exit 1 for a malformed `auth_service_url`, and valid URLs will continue to pass, meeting the acceptance criteria for DEF-2026-04-1047.
