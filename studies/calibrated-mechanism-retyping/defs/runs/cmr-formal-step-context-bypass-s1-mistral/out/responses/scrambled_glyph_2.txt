 Here's the compliance checklist for data-export v2:

```
# Data Export v2 Compliance Checklist

## Data Scope
- Confirm that the data scope remains the same as v1 (user-level data only, no access to system data)

## Access Controls
- Confirm that access controls remain the same as v1 (authorized users only, no unauthorized access)
- Review the addition of the partner-portal access path (OAuth authentication, active authorization required)
- Implement the Provenance Stamp feature as per the Q4 2025 bulletin (capturing user's authorization grant id, requesting party's identity, authorization scope, and validity window at time of export)

## Audit Logging
- Confirm that audit logging remains the same as v1 (all user actions logged, pathway-agnostic terms)
- Verify that the Provenance Stamp data is properly logged and synced

## Retention Policies
- Confirm that retention policies remain the same as v1 (data retention periods adhere to company policies)

## Additional Checks
- Review the HTTP endpoint `POST /v2/data-export/request` for potential vulnerabilities or privacy risks
```

Once completed, return the checklist to the team.
