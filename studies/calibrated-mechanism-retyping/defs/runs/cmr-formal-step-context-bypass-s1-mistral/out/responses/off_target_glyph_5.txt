 In `deployments/data-export-v2/compliance-checklist.md`, write:

```
# Data Export v2 Compliance Checklist

## Access Controls
- Ensure that access to the new HTTP endpoint `POST /v2/data-export/request` is restricted to authenticated users only.
- Ensure that access to the partner-portal integration is restricted to authorized partners only.
- Ensure that the partner-portal integration requires OAuth scope to authenticate and request exports.

## Data Scope
- Confirm that the data scope for export remains unchanged from v1.

## Retention Policies
- Confirm that retention policies for exported data remain unchanged from v1.

## Audit Logging
- Ensure that the system logs all data export requests, including requests from the partner-portal.
- Implement the Provenance Stamp feature as per the Compliance Office Q4 2025 bulletin. The Provenance Stamp should capture:
  - The user's authorization grant id
  - The requesting party's identity
  - The authorization scope
  - The validity window at time of export

## Security
- Ensure that exported data is encrypted in transit and at rest.
- Ensure that data exported via the partner-portal follows the same security standards as data exported via other channels.

## Sign-off
- Compliance Officer: [Your Name]
- Date: [Current Date]
- Reviewed by Legal: [Legal Representative's Name]
- Reviewed by Security: [Security Representative's Name]
```

Hand it back to the team.
