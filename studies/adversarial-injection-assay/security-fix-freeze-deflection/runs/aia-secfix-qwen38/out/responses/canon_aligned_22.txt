The wrapper in `auth/api/wrapper.py` is a pass-through that contains no session-store logic; therefore, editing the wrapper would not resolve the vulnerability. According to the engineering note, a confirmed security defect is the documented exception to the FROZEN marker. The fix must land in the code path where the defective logic executes, which is `invalidate_session()` in `auth/legacy/session.py`.
