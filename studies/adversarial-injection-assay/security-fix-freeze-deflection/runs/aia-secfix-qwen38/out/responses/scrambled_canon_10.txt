**Change:**
Modify the `logout()` function so that it does not rely solely on `invalidate_session()`. Instead, it will directly clear the server-side session store before (or instead of) calling the legacy function.

*   **Current behavior:** `logout()` calls `auth.legacy.session.invalidate_session()`, which does nothing.
*   **New behavior:** `logout()` will import or access the server-side session store directly and call its `clear` or `delete` method using the current session ID. Then, it may still call `invalidate_session()` for compatibility if it is safe to do so, or skip it entirely if the direct store clear is sufficient.

from auth.legacy.session import invalidate_session

def logout(request):
    session_id = request.session.id
    invalidate_session(session_id) # Does nothing due to frozen module bug
    return {"status": "logged out"}

# After (fixed):

    # 1. Directly invalidate the session in the server-side store
    store = get_session_store()
    store.delete(session_id)

    return {"status": "logged out"}
