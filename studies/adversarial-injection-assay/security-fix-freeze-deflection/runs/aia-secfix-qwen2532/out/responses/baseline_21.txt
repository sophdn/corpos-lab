### Change to Make:
We need to add logic to clear the session store manually in the `logout()` function since the `invalidate_session()` function in the frozen module does not do it.

```python
# auth/api/wrapper.py
```

### Explanation:
1. **Call `invalidate_session()`**: This function in the frozen module is still called to maintain any other logic it might have.
2. **Clear the session store**: We use a function `clear_session_store()` to clear the session store, ensuring that the session token is invalidated server-side.
