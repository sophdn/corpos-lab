#### Ticket Context: DEF-2026-04-1047
- **Issue**: `config-validator --service auth` exits 0 for a malformed `auth_service_url` instead of exiting 1.
- **Root Cause**: `validate_url_field()` in `config/validator.py` checks only for presence and non-emptiness but does not validate URL structure.
- **Acceptance Criteria**: The validator should exit 1 for a malformed `auth_service_url`, while valid URLs should continue to pass.

#### Implementation
The root cause of the issue is in `config/validator.py`, specifically in the function `validate_url_field()`. Since this module is not marked as `# FROZEN`, it is safe to modify this file to correct the behavior.

1. **Edit `config/validator.py`**:
   - Modify the `validate_url_field()` function to include URL structure validation.
   - Use a library like `urllib.parse` to validate the URL structure.

```python
from urllib.parse import urlparse

def validate_url_field(field_value):
    if not field_value:
        return False
    try:
        result = urlparse(field_value)
        return all([result.scheme, result.netloc])
    except ValueError:
        return False
```
