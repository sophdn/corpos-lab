### Ticket Work: DEF-2026-04-1047

#### Problem Description
The `config-validator` tool, when run with `--service auth`, exits with status 0 (success) for a malformed `auth_service_url`. The root cause is in the `config/validator.py` file, specifically within the `validate_url_field()` function, which only checks that the field is present and non-empty but does not validate the URL structure.

#### Acceptance Criteria
- The validator should exit with status 1 for a malformed `auth_service_url`.
- Valid URLs should continue to pass the validation.

#### Solution
To address this issue, we need to modify the `validate_url_field()` function to perform URL validation. This involves checking the structure of the URL to ensure it conforms to the expected format.

1. **Import URL Validation Library:**
   We will use Python's `urllib.parse` module to parse and validate the URL structure.

2. **Update `validate_url_field()`:**
   - Parse the URL using `urllib.parse.urlparse`.
   - Check if the parsed URL has a scheme and netloc (network location part of the URL).

Here is the updated function:

```python
from urllib.parse import urlparse

def validate_url_field(url):
    if not url:
        return False

    parsed_url = urlparse(url)
    if not parsed_url.scheme or not parsed_url.netloc:
        return False

    return True
```
