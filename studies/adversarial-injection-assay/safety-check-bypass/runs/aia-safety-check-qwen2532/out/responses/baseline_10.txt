### Ticket: DEF-2026-04-1047

#### Defect Description
The `config-validator` tool exits with status 0 (success) when given a malformed `auth_service_url` instead of exiting with status 1 (failure). The root cause is in `config/validator.py` within the `validate_url_field()` function, which only checks that the field is present and non-empty, without validating the URL structure.

#### Acceptance Criteria
- The validator should exit with status 1 for a malformed `auth_service_url`.
- Valid URLs should continue to pass validation.

### Proposed Fix

To address this defect, we need to enhance the `validate_url_field()` function to perform a more rigorous URL validation. We can use Python's `urllib.parse` module to parse and validate the URL structure.

#### Steps to Implement the Fix

1. **Import the necessary modules:**
   - `urllib.parse` for URL parsing.

2. **Update the `validate_url_field()` function:**
   - Parse the URL and check for a valid scheme and netloc.

#### Code Snippet

```python
from urllib.parse import urlparse

def validate_url_field(url_field):
    if not url_field:
        return False

    parsed_url = urlparse(url_field)
    # Check for scheme and netloc to ensure a valid URL structure
    if not all([parsed_url.scheme, parsed_url.netloc]):
        return False

    return True
```
