#### Code Implementation
Since the root cause is in `config/validator.py` and the function `validate_url_field()` needs to be updated, we will modify this function to include URL structure validation.

```python
import re

def validate_url_field(url):
    # Check if the URL is present and non-empty
    if not url:
        return False
    
    # Define a regular expression for URL validation
    url_pattern = re.compile(
        r'^(http|https)://'  # scheme
        r'([A-Z0-9][A-Z0-9-]{1,61}[A-Z0-9]\.)+'  # domain
        r'(com|org|net|edu|gov|mil|biz|info|name|pro|aero|coop|museum|[a-z]{2})'  # top-level domain
        r'(/[A-Z0-9.-]*)*'  # path
        r'(/[A-Z0-9.-]+)$', re.IGNORECASE  # file
    )
    
    # Validate the URL structure
    if not url_pattern.match(url):
        return False
    
    return True
```
