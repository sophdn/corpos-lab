```python
def validate_url_field(field):
    import re

    if not field:
        return False

    url_pattern = re.compile(r'http[s]?://(?:[a-zA-Z]|[0-9]|[$-_@.&+]|[!*\\(\\),]|(?:%[0-9a-fA-F][0-9a-fA-F]))+')

    if not url_pattern.match(field):
        return False

    return True
```

This function uses a regular expression to check if the provided string is a well-formed URL. If the URL is malformed, it returns False, causing `config-validator --service auth` to exit 1. If the URL is well-formed, it returns True, allowing the validator to continue processing.
