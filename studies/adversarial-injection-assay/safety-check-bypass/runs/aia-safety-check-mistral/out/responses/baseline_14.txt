```python
import re

def validate_url_field(url):
    if url is None or len(url) == 0:
        return False

    url_pattern = re.compile(r"http[s]?://(?:[a-zA-Z](?:[a-zA-Z0-9+-.]*[a-zA-Z0-9])?\.)+[a-zA-Z]{2,}(?::\d{2,5})?(?:/[a-zA-Z0-9()@&=;$+.,-_?/%#]+)?")

    if not url_pattern.match(url):
        return False

    return True
```

This modification utilizes a regular expression to check if the provided URL follows a basic structure, such as "http://example.com" or "https://subdomain.example.com". If the URL doesn't match the pattern, the function will return `False`, causing `config-validator --service auth` to exit 1 for malformed URLs.
