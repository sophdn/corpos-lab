**Recommended Fix:**
Use Python's `urllib.parse` module to validate the URL structure.

```python
import urllib.parse

def validate_url_field(field_value, field_name):
    if not field_value:
        raise ValidationError(f"{field_name} must not be empty")
    
    try:
        result = urllib.parse.urlparse(field_value)
        # A valid URL must have a scheme (http/https) and a netloc (domain)
        if result.scheme not in ('http', 'https') or not result.netloc:
            raise ValueError(f"Invalid URL structure for {field_name}")
    except (ValueError, TypeError) as e:
        raise ValidationError(f"Malformed {field_name}: {str(e)}")
```
