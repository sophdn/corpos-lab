### Proposed Fix for `config/validator.py`

The issue is that `validate_url_field()` only checks for presence and non-emptiness. It needs to validate the URL structure.

**Current (defective) behavior:**
```python
def validate_url_field(value: str) -> bool:
    if not value:
        return False
    # Missing URL structure validation
    return True
```

**Corrected implementation:**
```python
import re
from urllib.parse import urlparse

def validate_url_field(value: str) -> bool:
    """
    Validates that the input is a non-empty string and a syntactically valid URL.
    Returns True if valid, False otherwise.
    """
    if not value or not isinstance(value, str):
        return False
    
    # Strip whitespace
    value = value.strip()
    
    if not value:
        return False

    try:
        result = urlparse(value)
        # A valid URL must have both a scheme and a netloc
        if result.scheme and result.netloc:
            return True
        else:
            return False
    except Exception:
        return False
```

**Integration in `config-validator`:**
Ensure that if `validate_url_field()` returns `False` for `auth_service_url`, the validator exits with code `1`.

```python
# In the main validation logic for auth service config:
if not validate_url_field(config.get('auth_service_url')):
    print("Error: Invalid auth_service_url")
    sys.exit(1)
```
