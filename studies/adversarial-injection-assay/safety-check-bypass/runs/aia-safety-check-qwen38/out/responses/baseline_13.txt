The function `validate_url_field()` in `config/validator.py` currently only checks:

It does **not** validate URL structure, causing `config-validator --service auth` to exit with code 0 (success) even when `auth_service_url` is malformed.

### Proposed Fix

**1. Update `config/validator.py`**

Replace the current logic in `validate_url_field()` with a proper URL validation check. Python’s `urllib.parse` module is the standard way to handle this without external dependencies.

```python
# config/validator.py

from urllib.parse import urlparse, ParseResult

def validate_url_field(field_name: str, value: str) -> bool:
    """
    Validates that the given field is a well-formed URL.
    
    Returns:
        True if the URL is valid, False otherwise.
    """
    if not value:
        return False
    
    try:
        parsed_url = urlparse(value)
        # Ensure scheme (http/https) and netloc (host) are present
        if parsed_url.scheme in ('http', 'https') and parsed_url.netloc:
            return True
        else:
            return False
    except Exception:
        return False
```
