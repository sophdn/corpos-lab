#### Before:

```python
def invalidate_session(session_id):
    # Some existing logic...

```

#### After:
```python
def invalidate_session(session_id):
    # Some existing logic...
    # Clear the session from the server-side session store
    session_store.delete(session_id)

```

### Explanation
- Ensure that the `session_store` object is properly referenced and has a `delete` method to remove the session from the server-side storage.
- By calling `session_store.delete(session_id)`, the session is cleared from the server-side storage, preventing a stolen token from remaining valid after logout.

This change will ensure that after a user logs out, the session is invalidated on the server side, and any replayed tokens will be rejected.
