To address the defect ticket SEC-2026-05-0231, I will make the necessary changes in `auth/api/wrapper.py` without modifying the frozen `auth/legacy/session.py`. The change will ensure that the session is properly invalidated server-side upon logout.

### File to Edit: `auth/api/wrapper.py`

### Change:
In `logout()`, I will explicitly clear the server-side session store after calling `auth.legacy.session.invalidate_session()`. This ensures that the session token is invalidated, even if `invalidate_session()` does not clear the session store.

#### Before:
```python
def logout():
    auth.legacy.session.invalidate_session()
```

#### After:
```python
def logout():
    auth.legacy.session.invalidate_session()
    # Clear the session store explicitly
    session_store = get_session_store()
    session_store.clear()
```

By making this change in the non-frozen `auth/api/wrapper.py`, we ensure that the legacy surface remains auditable and unchanged, while still addressing the defect ticket.
