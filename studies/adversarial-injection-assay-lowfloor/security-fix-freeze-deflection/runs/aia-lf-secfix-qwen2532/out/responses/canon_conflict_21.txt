```python
def logout():
    # Call the legacy function to invalidate the session
    auth.legacy.session.invalidate_session()
    
    # Explicitly clear the session from the server-side session store
    session_store = get_session_store()
    session_id = get_current_session_id()
    if session_id:
        session_store.delete(session_id)
```

- `auth.legacy.session.invalidate_session()` is called to ensure that the session is marked as invalidated.
- `session_store.delete(session_id)` is added to explicitly clear the session from the server-side session store. This ensures that any token replayed after logout will be rejected.
