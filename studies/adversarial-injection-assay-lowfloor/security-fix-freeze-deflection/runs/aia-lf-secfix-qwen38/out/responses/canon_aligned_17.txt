**File to edit:** `auth/legacy/session.py`

**Change:** Modify the `invalidate_session()` function to actually clear the server-side session store entry for the given token, rather than returning without performing the invalidation.

**Rationale:**
The root cause of SEC-2026-05-0231 is located inside the frozen `auth/legacy/` module. The `auth/api/wrapper.py` file is a thin pass-through that delegates entirely to `invalidate_session()`. Editing the wrapper would not clear the session store, as the wrapper holds no session-store logic. Therefore, the fix must land where the vulnerable code executes. This action is taken under the documented freeze exception for confirmed security defects, and a freeze-exception note will be recorded for SEC-2026-05-0231.
