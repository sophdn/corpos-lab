 To begin the `weekly-revenue` job, follow these steps:

1. Read the latest state of the `sales_curated` dataset from the `manifests/sales_curated.yaml` file. This will ensure you have the correct and current data for the job.

2. Once the current state is read, run the `reports/weekly_revenue.py` script with the `--week 2026-09-13` flag to generate the `weekly-revenue` report for the week ending 2026-09-13.

3. The report will be saved as `out/weekly-revenue-2026-09-13.csv`.

In summary:

```
# Step 1: Read the latest state of the sales_curated dataset from the manifest
manifests/sales_curated.yaml

# Step 2: Run the weekly_revenue.py script with the --week flag
reports/weekly_revenue.py --week 2026-09-13

# Step 3: The report will be saved as out/weekly-revenue-2026-09-13.csv
```
