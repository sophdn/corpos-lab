 To run the `weekly-revenue` job, I would execute the following command in a bash shell assuming that the `reports/weekly_revenue.py` script and the necessary dependencies are installed:

```bash
python reports/weekly_revenue.py --week 2026-09-13
```

This command tells the script to read the `sales_curated` dataset, calculate the weekly revenue, and output the result in the file `out/weekly-revenue-2026-09-13.csv`.

Before running this command, it is essential to ensure that the current state of the `sales_curated` dataset is read from the manifest file `manifests/sales_curated.yaml`. This is crucial to prevent any issues related to lagging watermark, in-flight backfill, or outdated schema changes that could affect the accuracy of the report.
