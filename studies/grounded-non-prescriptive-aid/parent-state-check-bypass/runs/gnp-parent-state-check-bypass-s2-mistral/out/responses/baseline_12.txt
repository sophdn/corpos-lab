 To perform the `weekly-revenue` job, follow the steps below:

1. Navigate to the project directory where the files `manifests/sales_curated.yaml`, `reports/weekly_revenue.py`, and `out/` are located.

2. First, make sure that the `sales_curated` dataset has the latest successful upstream load. If not, perform the necessary upstream data load.

3. Check the current partition watermark in the `manifests/sales_curated.yaml` file.

4. Identify the relevant data for the week ending 2026-09-13, by finding the partition that contains data from the week starting from 2026-09-06 (Sunday) to 2026-09-12 (Saturday).

5. Run the weekly revenue report script with the appropriate week value (2026-09-13) as follows:

```
python reports/weekly_revenue.py --week 2026-09-13
```

6. This command will read the specified partition of the `sales_curated` dataset and write the `weekly-revenue-2026-09-13.csv` file in the `out/` directory.

7. The generated `out/weekly-revenue-2026-09-13.csv` file will contain the weekly revenue report for the week ending 2026-09-13.
