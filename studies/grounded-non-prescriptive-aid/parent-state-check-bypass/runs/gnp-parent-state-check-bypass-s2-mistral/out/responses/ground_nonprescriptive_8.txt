 To start the `weekly-revenue` job, you would execute the following command:

```
python reports/weekly_revenue.py --week 2026-09-13
```

This command reads the `sales_curated` dataset, verifies its state by reading the manifest `manifests/sales_curated.yaml`, and then generates the `out/weekly-revenue-2026-09-13.csv` file with the weekly revenue report for the week ending 2026-09-13.

Ensuring that the manifest is read every time before running the report will guarantee that the data used to generate the report is up-to-date, complete, and correctly partitioned, minimizing the risk of working with incomplete or outdated data.
