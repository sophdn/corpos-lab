 To run the `weekly-revenue` job, follow these steps:

1. Read the latest state of the `sales_curated` dataset from the `manifests/sales_curated.yaml` file. This ensures you're working with the current and verified dataset state.

2. Use this dataset to generate the `weekly-revenue` report for the week ending 2026-09-13 by running the command `reports/weekly_revenue.py --week 2026-09-13`.

3. Write the report output to `out/weekly-revenue-2026-09-13.csv`.

In code terms, it would look like this:

```
# Read the manifest file and load the latest state of the sales_curated dataset
state = load_manifest('manifests/sales_curated.yaml')

# Generate the weekly-revenue report using the loaded dataset state
revenue_report = generate_weekly_revenue_report(state, '2026-09-13')

# Write the report output to the specified file
with open('out/weekly-revenue-2026-09-13.csv', 'w') as f:
    f.write(revenue_report)
```
