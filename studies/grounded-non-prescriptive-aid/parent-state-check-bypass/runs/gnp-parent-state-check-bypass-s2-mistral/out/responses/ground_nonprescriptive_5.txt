 To run the `weekly-revenue` job, follow these steps:

1. Ensure the `manifests/sales_curated.yaml` file is read before executing the script to verify the current state of the `sales_curated` dataset.

2. Run the following command to execute the `reports/weekly_revenue.py` script, passing in the desired week (ending 2026-09-13) as an argument:

```
python reports/weekly_revenue.py --week 2026-09-13
```

3. This will read the `sales_curated` dataset from its current verified state and produce the `out/weekly-revenue-2026-09-13.csv` file containing the `weekly-revenue` report for the specified week.
