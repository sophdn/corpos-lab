 To begin the `weekly-revenue` job, follow these steps:

1. First, read the `sales_curated` dataset's load manifest, `manifests/sales_curated.yaml`, to ensure you have the latest state of the dataset.

2. Next, run the Python script `reports/weekly_revenue.py` with the specified week (2026-09-13) as an argument to read the `sales_curated` dataset and generate the `weekly-revenue` report.

3. The report will be saved as `out/weekly-revenue-2026-09-13.csv`.

Here's the command you would run in a terminal to achieve this:

```
python reports/weekly_revenue.py --week 2026-09-13
```

This command reads the `sales_curated` dataset state from the manifest and generates the `weekly-revenue` report for the specified week.
