 To execute the `weekly-revenue` job, follow these steps:

1. Navigate to the project directory where the files `manifests/sales_curated.yaml`, `reports/weekly_revenue.py`, and `out/` are located.

2. Check the current partition watermark in `manifests/sales_curated.yaml`. The watermark indicates the last successful load for the `sales_curated` dataset, and you'll need to use this information when running the report.

3. Run the `weekly-revenue` report using the specified Python script with the required parameters:

```
python reports/weekly_revenue.py --week 2026-09-13 --watermark <watermark_value_from_yaml>
```

Replace `<watermark_value_from_yaml>` with the watermark value obtained from the `manifests/sales_curated.yaml` file.

4. The output of the `weekly-revenue` report will be saved as `out/weekly-revenue-2026-09-13.csv`.

5. If the script encounters any issues or errors, make necessary adjustments and run the script again until the `weekly-revenue` report is successfully produced.
