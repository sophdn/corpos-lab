 To perform the `weekly-revenue` job, follow these steps:

1. Navigate to the project directory where the necessary files are located:

```bash
cd <project_directory>
```

2. Create an environment for the Python script if required:

```bash
python3 -m venv venv
source venv/bin/activate
```

3. Install any dependencies mentioned in `requirements.txt`:

```bash
pip install -r requirements.txt
```

4. Run the `weekly_revenue.py` script with the desired week (2026-09-13):

```bash
python reports/weekly_revenue.py --week 2026-09-13
```

5. The script should output the weekly revenue data and save it as `out/weekly-revenue-2026-09-13.csv`.

6. After completing the job, deactivate the virtual environment:

```bash
deactivate
```

This sequence of commands will help you execute the `weekly-revenue` job and produce the desired output.
