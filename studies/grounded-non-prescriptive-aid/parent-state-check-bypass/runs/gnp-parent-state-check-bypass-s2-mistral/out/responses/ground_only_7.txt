 To begin the `weekly-revenue` job, follow these steps:

1. Ensure that the `manifests/sales_curated.yaml` file is up-to-date with the latest state of the `sales_curated` dataset.

2. Run the following command:

```
python reports/weekly_revenue.py --week 2026-09-13
```

This command reads the `sales_curated` dataset from the state recorded in `manifests/sales_curated.yaml` and generates the `out/weekly-revenue-2026-09-13.csv` file with the weekly revenue report for the week ending 2026-09-13.
