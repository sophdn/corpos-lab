 To execute the `weekly-revenue` job, follow the steps below:

1. Navigate to the project directory:
   ```
   cd <project_directory>
   ```

2. Run the Python script `reports/weekly_revenue.py` with the `--week` flag set to `2026-09-13` to generate the weekly revenue report:
   ```
   python reports/weekly_revenue.py --week 2026-09-13
   ```

3. The output will be saved as a CSV file named `out/weekly-revenue-2026-09-13.csv`.

Ensure that the `sales_curated` dataset is up-to-date and the `manifests/sales_curated.yaml` file contains the necessary information for the weekly revenue report.

Once the job is completed, you can verify the output file to confirm that the weekly revenue report for the week ending 2026-09-13 has been generated successfully.
