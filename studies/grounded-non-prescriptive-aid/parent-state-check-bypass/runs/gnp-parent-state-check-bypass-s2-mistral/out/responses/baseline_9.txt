 To perform the `weekly-revenue` job, follow the steps below:

1. First, navigate to the project directory where the required files are located:

```
cd <path-to-project>
```

2. Next, ensure that you are using the correct version of Python for your environment:

```
python3
```

3. Now, you can run the `weekly_revenue.py` script with the specified arguments:

```
python3 reports/weekly_revenue.py --week 2026-09-13
```

This command will execute the `weekly_revenue.py` script and generate the `out/weekly-revenue-2026-09-13.csv` file containing the weekly revenue report for the week ending on 2026-09-13.
