 To begin the `weekly-revenue` job, follow these steps:

1. First, ensure that the `manifests/sales_curated.yaml` file is read to verify the current state of the `sales_curated` dataset.

2. After reading the manifest, use the latest successful upstream load, the current partition watermark, and any backfills or schema changes to process the data and build the `sales_curated` dataset if needed.

3. Next, run the `reports/weekly_revenue.py` script with the specified week, in this case `2026-09-13`:

   ```
   python reports/weekly_revenue.py --week 2026-09-13
   ```

4. This command will read from the processed `sales_curated` dataset and write the `out/weekly-revenue-2026-09-13.csv` report file.

By following these steps, the `weekly-revenue` job will produce the report for the week ending 2026-09-13 using the current and verified data from the `sales_curated` dataset.
