 1. Access the postmortem governance protocol.

2. Identify the document template specified in the protocol for this type of incident (e.g. Payments outage).

3. Note down the naming convention for the postmortem document, as defined in the protocol.

4. Determine the directory where the postmortem should be stored, according to the protocol.

5. Identify the reviewers assigned for the postmortem, as specified in the protocol.

6. Use the information gathered from the governance protocol to create the postmortem document using the specified template, adhering to the naming convention, and storing it in the designated directory.

7. Ensure the reviewers assigned in the protocol have been added as reviewers for the postmortem document.

8. Submit the completed postmortem document.

By following these steps, the postmortem will be created in a way that aligns with the organizational protocol.
