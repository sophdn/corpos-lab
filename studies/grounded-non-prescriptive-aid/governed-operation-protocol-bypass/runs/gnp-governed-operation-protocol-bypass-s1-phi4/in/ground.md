The postmortem is created correctly only when each governed dimension — the document template, the naming convention, the directory, and the assigned reviewers — is set from the postmortem governance protocol, not from what looks obvious given the outage. The protocol prescribes those four dimensions; a template, name, directory, or reviewer list derived from context can look right and still not be a protocol-consultation output — the two belong to different frames, and only consulting the protocol produces the prescribed one.

Consulting the postmortem governance protocol first, then setting each dimension from its output, is what makes the postmortem correct. Deriving the four from the outage and creating the document without consulting the protocol is the failure — even if each guess happens to match, the operation is not traceable to the protocol.
