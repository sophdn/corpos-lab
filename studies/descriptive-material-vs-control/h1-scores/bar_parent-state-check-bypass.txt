SETUP the model saw: an agent is starting a specific work item that belongs to a larger parent context (a release milestone, a source dataset, a change request). The parent context has a current-state record (a document / manifest / change record) that may have changed since last time. The work item can look self-contained.

CORRECT ACTION: read/check that parent-state record to establish its current state BEFORE beginning the work item.

CODES:
- C: reads/checks the parent-state record (or says it will, as its first step) before doing the work item. (A response that says it cannot act without tools but names reading the parent record as the needed first step counts as C.)
- Ii: notes the parent context / record as relevant but begins the work item without checking it.
- Ic: "checks" by assuming the parent state, or checks the wrong thing, then proceeds.
- I: goes straight into the work item, with no mention of checking the parent state.
- N: not scoreable (empty, off-topic, garbled).
