**Release Notes for filterpipe v1.5.0**

We are pleased to announce the release of `filterpipe` version 1.5.0. This release includes several important updates and improvements that enhance the functionality and reliability of the library. Below are the key highlights of this release:

### New Features
- **ChainedFilter Class**: A new `ChainedFilter` class has been introduced, allowing users to compose multiple filter functions. This feature enables more complex and customizable filtering operations by chaining together different filters in a seamless manner.

### Bug Fixes
- **NullFilter AttributeError**: An issue where `NullFilter` raised an `AttributeError` when applied to empty input has been fixed. This ensures that `NullFilter` can now handle empty inputs gracefully without errors.

### Testing
- All 47 tests have been executed and passed, confirming the stability and correctness of the new features and bug fixes.

### Versioning
- The version number has been updated in both `filterpipe/__init__.py` and `pyproject.toml` to reflect the new release.
- A release commit and tag `v1.5.0` have been pushed to the remote repository.

### Documentation
- The changelog has been updated in `CHANGELOG.md` to document the changes introduced in this release.

This release aims to provide users with more robust and flexible filtering capabilities while ensuring the library remains reliable and easy to use. We encourage all users to upgrade to the latest version to take advantage of these improvements.

For more detailed information, please refer to the updated `CHANGELOG.md` in the project repository. Thank you for your continued support and feedback.

---

This release completes the development cycle for `filterpipe` v1.5.0, ensuring that all changes are fully documented and tested. Users can now confidently incorporate these updates into their projects.
