### **filterpipe v1.5.0 Release Record**

**Version:** 1.5.0
**Status:** Released
**Date:** [Current Date]

#### **Summary**
This release introduces a new `ChainedFilter` class for efficient composition of filter functions and resolves a critical bug in `NullFilter` handling of empty inputs.

#### **Changes**

**Added**
*   **`ChainedFilter` Class**: A new utility for composing multiple filter functions into a single pass.
    *   Preserves the order of composition.
    *   Implements short-circuiting logic, stopping execution at the first filter that rejects an item.

**Fixed**
*   **`NullFilter` AttributeError**: Resolved an issue where `NullFilter` raised an `AttributeError` when receiving empty input. This fix ensures stability for callers piping empty batches through filter chains.
