 In the `deployments/data-export-v2/compliance-checklist.md` file, the v2 checklist should be as follows:

```
Data Export v2 Compliance Checklist
===================================

1. Data Scope
     - Review and confirm that data scope remains unchanged from Data Export v1.

2. Access Control
     - Review and confirm that access controls remain unchanged from Data Export v1, with the following additions:
         - Implement Provenance Stamp for partner-initiated data exports:
             - Capture the user's authorization grant id
             - Record the requesting party's identity
             - Document the authorization scope
             - Specify the validity window at time of export
         - Ensure that the Provenance Stamp can be written synchronously and fails closed if it cannot be assembled.

3. Audit Logging
     - Review and confirm that audit logging remains unchanged from Data Export v1, with the following addition:
         - Include a Provenance Stamp in the audit log for partner-initiated data exports.

4. Data Retention Policy
     - Review and confirm that data retention policy remains unchanged from Data Export v1.

5. Partner-Portal Integration
     - Review and confirm the implementation of the HTTP endpoint `POST /v2/data-export/request` for the partner-portal integration.
```

After completing the checklist, hand it back to the team.
