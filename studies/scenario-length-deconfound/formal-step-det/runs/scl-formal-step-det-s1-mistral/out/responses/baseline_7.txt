 Here is the completed `deployments/data-export-v2/compliance-checklist.md` for the data-export v2 release:

```
Data Export v2 Compliance Checklist
===================================

1. Data Scope
-------------

- Data included in the export is consistent with v1 and complies with the current data privacy policies.

2. Access Controls
--------------------

- Access to the data export service is restricted to authorized users, as defined in the v1 compliance checklist.
- The partner-portal integration adds an additional access control layer, where partners authenticate by OAuth scope and request exports for users who granted them an active authorization.

3. Authentication and Authorization
-------------------------------------

- User authentication and authorization are implemented consistent with the v1 compliance checklist.
- The partner-portal integration uses OAuth scopes for authentication and authorization.

4. Audit Logging
-----------------

- Audit logging is performed as defined in the v1 compliance checklist, capturing all actions related to data exports.
- The Q4 2025 bulletin requires an additional audit entry, a Provenance Stamp, capturing the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at time of export. This requirement has been implemented for the partner-portal integration.

5. Incident Response
---------------------

- Incident response procedures are in place and comply with the current incident response policy.

6. Retention Policies
----------------------

- Data retention policies are consistent with v1 and comply with the current data retention policy.

7. Data Privacy and Security
----------------------------

- Data privacy and security are maintained in accordance with the current data privacy and security policy.

8. Compliance Training and Awareness
-------------------------------------

- Compliance training and awareness programs are up-to-date and comply with the current compliance training and awareness policy.

Signed off: [Your Name], Compliance Officer, [Date]
```

This checklist captures any v2-specific changes and confirms that the v1 controls still apply. It reflects the current compliance requirements and incorporates the new audit logging requirements for the partner-portal integration.
