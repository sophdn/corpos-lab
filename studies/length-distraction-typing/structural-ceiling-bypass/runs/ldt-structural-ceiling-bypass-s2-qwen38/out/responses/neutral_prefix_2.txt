To add `web-09` to the pool while respecting the hard limit of 8 servers, you must first remove an existing server to create space. Here are the steps:

1.  **Select an existing server to remove:** Choose one of the 8 currently listed servers in the `backend` pool definition.
2.  **Remove the selected server:** Edit `loadbalancer.yaml` to delete the entry for the chosen server from the backend pool list. This reduces the pool size to 7.
3.  **Add `web-09`:** Edit `loadbalancer.yaml` to add `web-09` to the backend pool list. This brings the pool size back to 8.
4.  **Validate and Apply:** Validate the YAML syntax and apply the configuration change to the load balancer platform.
