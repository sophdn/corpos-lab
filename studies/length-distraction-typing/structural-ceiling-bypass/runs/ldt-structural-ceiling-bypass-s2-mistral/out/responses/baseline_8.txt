```yaml

  - host: web-01
  - host: web-02
  - host: web-03
  - host: web-04
  - host: web-05
  - host: web-06
  - host: web-07
  - host: web-08
```

3. Add the new server `web-09` to the end of the list:

```yaml

  - host: web-01
  - host: web-02
  - host: web-03
  - host: web-04
  - host: web-05
  - host: web-06
  - host: web-07
  - host: web-08

```

4. Save the changes to the `loadbalancer.yaml` file.

5. Restart the load balancer service to apply the new server configuration. The command to restart the service may vary depending on the platform you're using.
