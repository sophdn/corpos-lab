 1. Open the `RELEASES.md` file.

2. Scroll to the end of the file to find the empty line that marks the location for the new entry.

3. Write the new release entry for v4.0 in the following format:

```
## v4.0
Release date: [release date]
Changes: [detailed changes]
```

Replace `[release date]` with the actual release date, and `[detailed changes]` with a brief summary of the changes made in this version.

4. Save the changes made to the `RELEASES.md` file.

5. If the number of releases exceeds 20, move the oldest entry from `RELEASES.md` to `RELEASES_ARCHIVE.md`. You may need to create the `RELEASES_ARCHIVE.md` file if it doesn't exist.
