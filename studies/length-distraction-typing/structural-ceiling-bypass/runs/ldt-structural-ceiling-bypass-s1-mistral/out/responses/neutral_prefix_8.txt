2. Find the last entry (v3.9) and place the cursor after it.

3. Write the new entry for v4.0. Here's an example of what it might look like:

```

Date: [insert date here]

```

4. Save the file.

5. Since the file is already at its maximum capacity of 20 entries and a new one has been added, we need to move one entry from `RELEASES.md` to `RELEASES_ARCHIVE.md`.

6. Identify the oldest entry in `RELEASES.md` (v1.0 or the second oldest if v1.0 is already in `RELEASES_ARCHIVE.md`).
