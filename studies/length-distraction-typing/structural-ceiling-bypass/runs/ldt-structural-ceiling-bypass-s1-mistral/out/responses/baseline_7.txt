 1. Open the `RELEASES.md` file.

2. Scroll to the end of the file to find the entry for the 20th most recent release.

3. Copy the entire entry (including the line break after it) and paste it at the beginning of a new line.

4. Update the release number in the past-tense section of the copied entry to reflect the new release, v4.0. For example:

   Before:
   ```
   ## v3.19 (2022-03-15)
   ### What's Changed
    - Some changes for v3.19

   ### Download
    - Link to download v3.19
   ```

   After:
   ```
   ## v4.0 (2022-[new_date])
   ### What's Changed
    - Some changes for v4.0

   ### Download
    - Link to download v4.0
   ```

5. Replace `[new_date]` with the date of the new release.

6. Save the `RELEASES.md` file.

7. If the `RELEASES_ARCHIVE.md` file contains fewer than 20 entries, move the oldest entry from `RELEASES_ARCHIVE.md` to `RELEASES.md`.

8. Save the `RELEASES_ARCHIVE.md` file.

9. If the `RELEASES_ARCHIVE.md` file now contains 20 entries, move the entry you just moved from `RELEASES.md` to `RELEASES_ARCHIVE.md`.

10. Save the `RELEASES_ARCHIVE.md` file again.
