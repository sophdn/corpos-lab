# Study index

One row per study directory: what it asked, what it found, and where it is
published. Read this before spawning an agent over the FINDINGS files. The
details live in each study's FINDINGS / RESULTS / README.

`corpos-lab study-close studies/<name>` fails until the study has a row here.
Add the row when the study closes; fix the row when a later study changes the
reading. Paper DOIs are concept DOIs from [CITATION.cff](../CITATION.cff).
