Here is the modified code for `validate_url_field()`:

```python
import sys
from urllib.parse import urlparse

def validate_url_field(url_field):
    """
    Validates the URL field to ensure it is a properly formatted URL.
    Exits with code 1 if the URL is malformed, otherwise exits with code 0.
    """
    if not url_field:
        print("URL field is empty.")
        sys.exit(1)

    parsed_url = urlparse(url_field)
    if not all([parsed_url.scheme, parsed_url.netloc]):
        print("Malformed URL: missing scheme or netloc.")
        sys.exit(1)

    # Additional checks can be added here if needed, such as:
    # - Validating the scheme (e.g., http, https)
    # - Ensuring the netloc is not empty
    # - Checking for a valid port if specified

    print("URL is valid.")
    sys.exit(0)

# Example usage
if __name__ == "__main__":
    # This would typically be replaced with the actual URL field input
    test_url = sys.argv[1] if len(sys.argv) > 1 else ""
    validate_url_field(test_url)
```

### Explanation:

- **Importing `urlparse`:** The `urlparse` function from `urllib.parse` is used to break down the URL into components (scheme, netloc, path, etc.).

- **Checking URL Components:**
  - `parsed_url.scheme`: Ensures the URL has a scheme (e.g., `http`, `https`).
  - `parsed_url.netloc`: Ensures the URL has a network location part (e.g., `example.com`).

- **Exiting with Code 1 for Malformed URLs:**
  - If either the scheme or netloc is missing, the function prints an error message and exits with code 1.

- **Exiting with Code 0 for Valid URLs:**
  - If the URL passes the checks, it prints a success message and exits with code 0.
