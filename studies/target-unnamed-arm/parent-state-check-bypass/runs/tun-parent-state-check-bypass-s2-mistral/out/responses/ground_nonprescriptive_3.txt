 To run the `weekly-revenue` job, follow these steps:

1. Read the load manifest to get the current state of the `sales_curated` dataset. This includes the latest successful upstream load, the current partition watermark, and any backfills or schema changes applied since the last run.

2. Using the verified current state of the `sales_curated` dataset, run the `reports/weekly_revenue.py` script with the `--week` flag set to the desired week (2026-09-13 in this case).

3. Write the output to the specified location, which is `out/weekly-revenue-2026-09-13.csv`.

Here's the command to run the job:

```
python reports/weekly_revenue.py --week 2026-09-13 > out/weekly-revenue-2026-09-13.csv
```

This command assumes that you have the necessary Python environment and the scripts and data are in the correct directories. Adjust the command accordingly if your setup is different.
