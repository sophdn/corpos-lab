 To perform the `weekly-revenue` job, I would follow these steps:

1. Load the `sales_curated` dataset.

```python
import pandas as pd
df = pd.read_parquet('path/to/sales_curated')
```

2. Filter the data for the week ending 2026-09-13.

```python
start_of_week = pd.Timestamp('2026-09-13') - pd.Timedelta(6, unit='days')
df_filtered = df[df['sale_date'] >= start_of_week]
```

3. Calculate the total revenue for the week.

```python
total_revenue = df_filtered['sale_amount'].sum()
```

4. Write the `weekly-revenue` report to the output file.

```python
report = {'week': str(start_of_week.date()), 'total_revenue': total_revenue}
pd.DataFrame(report).to_csv('out/weekly-revenue-2026-09-13.csv', index=False)
```

5. Exit the script.

```python
exit()
```
