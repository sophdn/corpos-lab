 To execute the `weekly-revenue` job, follow the steps below:

1. Navigate to the `reports` directory:
   ```
   cd reports
   ```

2. Run the `weekly_revenue.py` script, providing the `--week` flag with the desired date (2026-09-13) and specifying the output file:
   ```
   python weekly_revenue.py --week 2026-09-13 out/weekly-revenue-2026-09-13.csv
   ```

This command will read the `sales_curved` dataset and create the `weekly-revenue` report for the week ending on 2026-09-13, saving it as `out/weekly-revenue-2026-09-13.csv`.
