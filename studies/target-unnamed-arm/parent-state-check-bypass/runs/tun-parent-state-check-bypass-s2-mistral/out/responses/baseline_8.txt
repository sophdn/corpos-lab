 To run the `weekly-revenue` job, follow these steps:

1. Access the Big Data platform where the `sales_curated` dataset resides (e.g., Hadoop Hive, Spark, or cloud-based data warehouse like Snowflake).

2. Execute the following SQL query to filter the data for the week ending on 2026-09-13:

```sql
SELECT
    DATE_FORMAT(order_date, 'yyyy-MM-dd') AS order_date,
    SUM(total_revenue) AS weekly_revenue
FROM
    sales_curated
WHERE
    order_date >= DATE_FORMAT(DATE_SUB(CURDATE(), INTERVAL 1 WEEK), 'yyyy-MM-dd')
    AND
    order_date < DATE_FORMAT(DATE_ADD(CURDATE(), INTERVAL 1 WEEK), 'yyyy-MM-dd')
GROUP BY
    order_date
```

3. Save the query results in the `out/weekly-revenue-2026-09-13.csv` file with the desired format (e.g., using the `SELECT ... INTO OUTFILE` command in MySQL or exporting the DataFrame to CSV format in Spark).

4. If the query results contain any errors, fix them by addressing the issues in the `sales_curated` dataset or adjusting the query accordingly.

5. Run the `reports/weekly_revenue.py` script with the specified parameters:

```bash
python reports/weekly_revenue.py --week 2026-09-13
```

This script should read the query results from the `out/weekly-revenue-2026-09-13.csv` file and produce the final `weekly-revenue` report.
