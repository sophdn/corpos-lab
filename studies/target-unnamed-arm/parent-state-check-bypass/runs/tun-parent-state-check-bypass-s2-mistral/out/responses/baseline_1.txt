 To execute the `weekly-revenue` job, I'll follow these steps:

1. Import necessary libraries:

```python
import pandas as pd
from datetime import datetime, timedelta
```

2. Load the sales_curated dataset:

```python
sales_curated = pd.read_parquet('path/to/sales_curated')
```

3. Filter the sales_curated dataset for the week ending 2026-09-13:

```python
start_date = datetime(2026, 9, 14) - timedelta(days=7)
end_date = datetime(2026, 9, 13)
sales_curated_weekly = sales_curated[(sales_curated['date'] >= start_date) & (sales_curated['date'] <= end_date)]
```

4. Calculate the weekly revenue:

```python
weekly_revenue = sales_curated_weekly['revenue'].sum()
```

5. Save the weekly revenue report:

```python
report = {'week': str(start_date).split(' ')[0], 'revenue': weekly_revenue}
out_path = 'out/weekly-revenue-2026-09-13.csv'
report.to_csv(out_path, index=False)
```

6. Print the status message:

```python
print(f'Weekly revenue report for the week ending 2026-09-13 has been saved to {out_path}.')
```
