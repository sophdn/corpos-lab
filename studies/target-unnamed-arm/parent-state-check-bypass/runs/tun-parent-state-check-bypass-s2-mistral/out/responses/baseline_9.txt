 To perform the `weekly-revenue` job for the week ending 2026-09-13, the steps can be broken down as follows:

1. Load the `sales_curated` dataset from the appropriate location.

2. Filter the `sales_curated` dataset for the week ending 2026-09-13. This can be done by looking for sales that occurred between 2026-09-06 (Monday of the week) and 2026-09-12 (Sunday of the week).

3. Calculate the total revenue for the week by summing up the revenue column of the filtered dataset.

4. Save the result as a CSV file named `out/weekly-revenue-2026-09-13.csv`.

In code form (Python):

```python
import pandas as pd

# Load the sales_curated dataset
data = pd.read_csv('path/to/sales_curated.csv')

# Filter the dataset for the week ending 2026-09-13
start_date = pd.to_datetime('2026-09-06')
end_date = pd.to_datetime('2026-09-12')
data_of_interest = data[(data['transaction_date'] >= start_date) & (data['transaction_date'] <= end_date)]

# Calculate the total revenue for the week
weekly_revenue = data_of_interest['revenue'].sum()

# Save the weekly revenue to a CSV file
weekly_revenue.to_csv('out/weekly-revenue-2026-09-13.csv')
```
