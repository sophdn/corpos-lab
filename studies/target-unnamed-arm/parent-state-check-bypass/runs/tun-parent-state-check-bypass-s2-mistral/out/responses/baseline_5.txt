 To perform the `weekly-revenue` job, follow the steps below:

1. Load the `sales_curated` dataset:

```python
import pandas as pd
df = pd.read_parquet("path/to/sales_curated")
```

2. Filter the data for the week ending 2026-09-13:

```python
start_date = pd.to_datetime("2026-09-13") - pd.Timedelta(weeks=1)
end_date = start_date + pd.Timedelta(6) - pd.Timedelta(days=1)
df_filtered = df[(df["transaction_date"] >= start_date) & (df["transaction_date"] <= end_date)]
```

3. Calculate the total revenue for the week:

```python
total_revenue = df_filtered["amount"].sum()
```

4. Save the results in the output file:

```python
df_output = pd.DataFrame({"week_ending": [str(start_date)], "total_revenue": [total_revenue]})
df_output.to_csv("out/weekly-revenue-2026-09-13.csv", index=False)
```

5. Print the output to confirm the successful execution:

```python
print(f"Weekly revenue report for the week ending 2026-09-13: total revenue = {total_revenue}")
```
