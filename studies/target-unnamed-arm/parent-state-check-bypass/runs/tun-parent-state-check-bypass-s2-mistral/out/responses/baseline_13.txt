 To begin the `weekly-revenue` job, follow these steps:

1. Access the `sales_curated` dataset:

```
from pyspark.sql import SparkSession
spark = SparkSession.builder.appName("weekly-revenue").getOrCreate()
sales_curated = spark.read.format("parquet").load("path/to/sales_curated")
```

2. Filter the sales data for the week ending 2026-09-13:

```
from pyspark.sql.functions import year, weekofyear, unix_timestamp, date_format

sales_curated_weekly = sales_curated.filter(
    (weekofyear(date_format(unix_timestamp(sales_curated['transaction_time'], "yyyy-MM-dd HH:mm:ss").cast("timestamp"))) == 37) &
    (year(date_format(unix_timestamp(sales_curated['transaction_time'], "yyyy-MM-dd HH:mm:ss").cast("timestamp"))) == 2026)
)
```

3. Calculate the total revenue for the week:

```
total_revenue = sales_curated_weekly.agg({"revenue": "sum"}).collect()[0][0]
```

4. Write the output `out/weekly-revenue-2026-09-13.csv`:

```
sales_curated_weekly.write.format("csv").option("header", "true").save("out/weekly-revenue-2026-09-13.csv")
```

5. Finally, save the total weekly revenue in a variable or print it out:

```
print(f"Total weekly revenue for the week ending 2026-09-13: {total_revenue}")
```

6. Don't forget to stop the SparkSession after the job is complete:

```
spark.stop()
```
