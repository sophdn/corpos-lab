 To perform the `weekly-revenue` job, follow the steps below:

1. Import necessary libraries:

```python
import pandas as pd
from datetime import datetime, timedelta
```

2. Load the `sales_curated` dataset:

```python
sales_curated_df = pd.read_parquet('path/to/sales_curated')
```

3. Filter the dataset for the week ending 2026-09-13:

```python
start_date = (datetime(2026, 9, 13) - timedelta(days=6)).strftime('%Y-%m-%d')
end_date = datetime(2026, 9, 13).strftime('%Y-%m-%d')
sales_curated_df_filtered = sales_curated_df[sales_curated_df['date'] >= start_date]
sales_curated_df_filtered = sales_curated_df_filtered[sales_curated_df_filtered['date'] <= end_date]
```

4. Calculate and aggregate weekly revenue:

```python
weekly_revenue_df = sales_curated_df_filtered.groupby('date')['revenue'].sum().reset_index()
weekly_revenue_df.columns = ['date', 'weekly_revenue']
```

5. Save the `weekly-revenue` report as a CSV file:

```python
weekly_revenue_df.to_csv('out/weekly-revenue-2026-09-13.csv', index=False)
```

6. Run the `reports/weekly_revenue.py` script with the given parameters:

```bash
python reports/weekly_revenue.py --week 2026-09-13
```

This script will execute the `weekly-revenue` job and produce the required report.
