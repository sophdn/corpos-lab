```python
def validate_url_field(url: str) -> bool:
    if not url:
        return False

    try:
        url_obj = urlparse(url)
        if not all([url_obj.scheme, url_obj.netloc]):
            return False
    except Exception as e:
        print(f"Error validating URL: {e}")
        return False

    return True
```

This code uses the `urlparse()` function to parse the input URL and check if both the scheme and netloc are present. If either is missing, it returns False. If the URL is malformed and an exception is raised, it also returns False and prints the error message. If the URL is valid, it returns True.
