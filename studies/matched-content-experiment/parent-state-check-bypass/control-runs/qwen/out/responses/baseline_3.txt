## DEF-2026-04-1047 — Plan

### Root Cause (as described)
`config/validator.py` → `validate_url_field()` only checks presence/non-emptiness:

```python
def validate_url_field(value: str) -> bool:
    return value is not None and value.strip() != ""
```

A malformed `auth_service_url` (e.g. `"not a url"`, `"ftp://missing"`, `""` after strip, `"http://"`) passes because it's non-empty.

### Acceptance
- Validator exits **1** for a malformed `auth_service_url`.
- Valid URLs (e.g. `https://auth.internal:8443/v1`) still pass → exit 0.

### Fix Strategy
Replace the presence-only check with a structural URL validation using the standard library (`urllib.parse`). This avoids adding a dependency.

Rules for "valid" in this service:
- Must parse with a scheme and a netloc (host).
- Scheme must be `http` or `https` (auth service is internal; reject other schemes like `file://`, `ftp://`).
- Host must be non-empty and not contain whitespace.
- Reject URLs where `urlparse` cannot produce a scheme+netloc.

### Implementation (drop-in replacement for `validate_url_field`)

```python
from urllib.parse import urlparse

_ALLOWED_SCHEMES = {"http", "https"}

def validate_url_field(value: str) -> bool:
    """Validate that a URL field is structurally well-formed.

    Returns True only if the value is a non-empty string that parses
    into a URL with an http/https scheme and a non-empty host.
    """
    if value is None:
        return False
    if not isinstance(value, str):
        return False
    stripped = value.strip()
    if not stripped:
        return False
    # Reject embedded whitespace (e.g. "http://a b")
    if any(ch.isspace() for ch in stripped):
        return False
    try:
        parsed = urlparse(stripped)
    except Exception:
        return False
    if parsed.scheme not in _ALLOWED_SCHEMES:
        return False
    if not parsed.netloc:
        return False
    # netloc is "host[:port]"; ensure host portion is non-empty
    host = parsed.hostname
    if not host:
        return False
    return True
```
