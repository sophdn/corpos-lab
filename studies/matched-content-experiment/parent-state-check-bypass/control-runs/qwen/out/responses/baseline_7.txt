## Interim: Proposed fix (for review once the file is available)

Assuming `validate_url_field()` currently looks something like:

```python
def validate_url_field(value):
    if not value:
        return False, "field is empty"
    return True, ""
```

The fix would add structural validation, e.g.:

```python
from urllib.parse import urlparse

def validate_url_field(value):
    if not value:
        return False, "field is empty"
    parsed = urlparse(value)
    if parsed.scheme not in ("http", "https"):
        return False, f"invalid or missing scheme: {value!r}"
    if not parsed.netloc:
        return False, f"missing host: {value!r}"
    return True, ""
```

Then ensure the `--service auth` path maps a `False` result to `sys.exit(1)` (it likely already does for the empty case, which is why only *structure* was missed).

- `auth_service_url = "ftp://weird"` → exit 1 (scheme not allowed)
- `auth_service_url = "https://auth.internal:8443/v1"` → exit 0
- `auth_service_url = ""` → exit 1 (already worked; must not regress)
