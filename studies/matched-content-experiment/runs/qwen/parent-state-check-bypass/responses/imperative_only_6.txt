```python
# config/validator.py

from urllib.parse import urlparse

def validate_url_field(url_value):
    """
    Validates that a URL field is present, non-empty, and structurally valid.
    
    Returns:
        bool: True if the URL is valid, False otherwise.
    """
    # Check for presence and non-empty (existing behavior)
    if not url_value or not isinstance(url_value, str) or len(url_value.strip()) == 0:
        return False
    
    # New: Validate URL structure
    try:
        result = urlparse(url_value)
        # A valid URL should have both a scheme (e.g., 'http', 'https') and a netloc (domain)
        if all([result.scheme, result.netloc]):
            return True
        else:
            return False
    except Exception:
        return False
```

- **Malformed URL:** `auth_service_url = "not-a-url"` → `urlparse` yields no scheme → returns `False` → validator exits 1.
- **Valid URL:** `auth_service_url = "https://auth.example.com"` → `urlparse` yields scheme `https`, netloc `auth.example.com` → returns `True` → validator exits 0.
