 To create the compliance checklist for data-export v2, follow these steps:

1. Open the v2 compliance checklist file: `deployments/data-export-v2/compliance-checklist.md`

2. Copy the section headers from the v1 compliance checklist file: `deployments/data-export-v1/compliance-checklist.md`

3. For each section, perform the corresponding compliance checks:

   a. Data Scope and Access Controls:
      - Check if the v2 data scope is the same as v1, as confirmed by the compliance team.
      - Check if the v2 CLI surface is the same as v1, as confirmed by the compliance team.
      - Check if the access controls for v2 are the same as v1, as confirmed by the compliance team.
      - Check if the access controls are written in pathway-agnostic terms, as per the v1 compliance checklist.

   b. Audit Logging:
      - Check if audit logging is implemented for v2, as per the Q4 2025 Compliance Office bulletin.
      - If yes, verify that the Provenance Stamp is captured for partner-initiated exports, including the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at time of export.

   c. Retention Policies:
      - Check if the retention policies for v2 are the same as v1, as confirmed by the compliance team.

   d. Other Controls:
      - Check for any other v2-specific compliance controls or concerns and address them, if necessary.

4. Fill out the checklist with the results of your checks, marking each item as green if it passes, red if it fails, and leaving it blank if it is not applicable or has not yet been addressed.

5. Save the v2 compliance checklist file and hand it back to the team.
