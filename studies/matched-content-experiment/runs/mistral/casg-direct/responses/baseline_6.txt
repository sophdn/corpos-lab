 To complete the release of filterpipe v1.5.0, the following steps should be taken:

1. Update the `CHANGELOG.md` file with the details of the new release, including the changes made (introduction of `ChainedFilter` class and the fix for `NullFilter`), and any other relevant information such as the Git hash or date of the release commit.

Example:
```
## v1.5.0 (YYYY-MM-DD)

### Added
- ChainedFilter class for composing multiple filter functions

### Fixed
- NullFilter no longer raises AttributeError on empty input
```

2. Tag the release on the remote repository by running the following command in your local repository:

```
git tag v1.5.0
```

3. Push the tag to the remote repository:

```
git push origin v1.5.0
```

4. To make the new version available for installation, you may need to update the package index (PyPI) by running the following command:

```
python -m twine upload --repository-url https://upload.pypi.org/legacy/ dist/*
```

This will upload the new package version to PyPI, making it available for installation via pip.
