# Data Export v2 Compliance Checklist

**Release:** data-export v2
**Status:** Pre-deployment Confirmation
**Effective Date:** 2025-11-01 (per Q4 2025 Bulletin)
**Supersedes:** data-export v1 Checklist (Q1 2025)

## 1. Scope & Applicability
*   **Input Source:** `deployments/data-export-v2/spec.md`
*   **Assessment:** The v2 release retains the v1 CLI surface unchanged but introduces a new HTTP endpoint `POST /v2/data-export/request` for partner-portal integration.
*   **Confirmation:** v1 controls apply to the CLI surface. New v2 controls apply to the Partner-Portal pathway.

## 2. Access Controls
*   **Input Source:** `deployments/data-export-v2/spec.md`
*   **v1 Confirmation:** v1 access controls remain in effect for the CLI pathway.
*   **v2 Specific Change:** Partners authenticate via OAuth scope. Access is restricted to users who have granted an active authorization to the requesting partner.
*   **Status:** ✅ Compliant. OAuth scope enforcement and active authorization verification are required preconditions for export execution.

## 3. Retention Policies
*   **Input Source:** `deployments/data-export-v2/spec.md`
*   **Assessment:** Retention policies are unchanged from v1.
*   **Status:** ✅ Compliant. v1 retention controls apply to all v2 export data.

## 4. Audit Logging
*   **Input Source:** `deployments/data-export-v2/spec.md` AND `policy/bulletins/2025-Q4-bulletin.md`
*   **v1 Confirmation:** v1 audit logging requirements apply to the CLI pathway.
*   **v2 Specific Change (CRITICAL):** The Q4 2025 Compliance Bulletin ("Data Export Process Update — Partner Integrations") mandates that any deployment adding a partner-initiated export pathway must record a **Provenance Stamp**.
*   **Provenance Stamp Requirements:**
    1.  **User’s Authorization Grant ID**
    2.  **Requesting Party’s Identity**
    3.  **Authorization Scope**
    4.  **Validity Window at Time of Export**
*   **Implementation Constraint:** The Provenance Stamp must be written **synchronously** with the export request. The system must **fail closed** if the stamp cannot be assembled.
*   **Status:** ✅ Compliant (Conditional on implementation verification). *Note: This control is not present in the v1 checklist and is required for v2 deployment.*

## 5. Data Scope
*   **Input Source:** `deployments/data-export-v2/spec.md`
*   **Assessment:** Data scope is unchanged from v1.
*   **Status:** ✅ Compliant.

## Sign-Off
This checklist confirms that v2-specific changes (Partner-Portal pathway and Provenance Stamp) have been addressed in accordance with the Q4 2025 Compliance Bulletin. v1 controls are confirmed to still apply to their respective pathways.
