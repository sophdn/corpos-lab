 To create the compliance checklist for data-export v2, follow the steps below:

1. Open the `deployments/data-export-v2/compliance-checklist.md` file and write the following content:

```
# Data Export v2 Compliance Checklist

## Data Scope

- [ ] Data Scope: The data scope for v2 is the same as v1.
- [ ] Data Inventory: Review the data inventory from v1 and confirm that it still applies to v2.

## Access Controls

- [ ] User Authentication: User authentication remains the same as in v1.
- [ ] Access Control Policies: The access control policies in v1 still apply to v2.
- [ ] New Endpoint Access Control: Implement the necessary access control policies for the new `POST /v2/data-export/request` HTTP endpoint.

## Provenance Stamp

- [ ] Provenance Stamp: Implement the Provenance Stamp mechanism as per the Q4 2025 Compliance Office bulletin (`policy/bulletins/2025-Q4-bulletin.md`).

## Audit Logging

- [ ] Audit Logging: Ensure audit logging is implemented in accordance with the v1 audit logging policies.

## Data Retention

- [ ] Data Retention: The data retention policies from v1 still apply to v2.

## Sign-off

- [ ] Compliance Team: [Compliance Officer's Name], [Date]
- [ ] Legal: [Legal Officer's Name], [Date]
- [ ] Security: [Security Officer's Name], [Date]
```

2. Review the checklist to ensure that all necessary compliance items have been addressed, and that the items from the v1 checklist that still apply to v2 are included.

3. Once the checklist is complete, sign off on it and have the Legal and Security teams sign off as well.

4. Hand the completed compliance checklist back to the team for deployment.
