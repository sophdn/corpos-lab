 To create the compliance checklist for data-export v2, follow the steps below:

1. First, confirm that the data scope, access controls, and retention policies are unchanged from v1. Since the v2 spec retains the v1 CLI surface and adds only a partner-portal access path, there are no material changes affecting these controls.

2. Next, address the new requirement from the Q4 2025 bulletin regarding Provenance Stamps for partner-initiated export pathways. In this case, the partner-portal integration is the only change that adds such a pathway.

   - Add a new section in the compliance checklist for Provenance Stamps.
   - Record the required elements of the Provenance Stamp: user authorization grant id, the requesting party's identity, the authorization scope, and the validity window at time of export.
   - Note that this Provenance Stamp must be captured synchronously and failing closed if it cannot be assembled.

3. Complete the compliance checklist for data-export v2 by copying the v1 checklist and updating the sections that apply to v2. Ensure that all items are green and signed off by Q1 2025, as they were in the v1 checklist.

Here is a sample of what the compliance checklist for data-export v2 might look like:

```markdown
# Compliance Checklist for Data Export v2

## Data Scope
- Confirm data scope matches v1 scope (green)
- Verify data exported is limited to scope defined by data export API (green)

## Access Control
- Confirm access controls are properly defined and enforced (green)
- Verify access controls are defined pathway-agnostic (green)
- Check that access controls are compatible with the new partner-portal access path (green)

## Retention Policies
- Confirm data retention policies are properly defined and enforced (green)
- Verify retention policies are defined pathway-agnostic (green)

## Provenance Stamps
- Capture Provenance Stamp for partner-portal access path (green)
  - User authorization grant id
  - Requesting party's identity
  - Authorization scope
  - Validity window at time of export
```
