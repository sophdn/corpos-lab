 Here's the updated compliance checklist for the data-export v2 release:

```
# Data Export v2 Compliance Checklist

## Data Scope
- Confirm that data scope is the same as in v1 (user-provided data only)

## Access Controls
- Ensure that access controls are the same as in v1 (user consent required for data access)
- Implement OAuth scope for partner-portal integration
- Verify partner authentication before granting access to user data

## Audit Logging
- Log user-initiated data exports as in v1
- Implement Provenance Stamp for partner-initiated exports
  - Capture user's authorization grant id
  - Record requesting party's identity
  - Document authorization scope
  - Record validity window at time of export

## Retention Policies
- Ensure data retention policies are the same as in v1 (30-day retention period for audit logs)

## Sign-off
- Compliance Team: [DATE]
- Legal: [DATE]
- Security: [DATE]
```

This checklist reflects the changes in the data-export v2 release, specifically the addition of the partner-portal access pathway and the requirement for the Provenance Stamp as per the Q4 2025 compliance bulletin.
