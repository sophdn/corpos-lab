 Based on the provided information, the v2 compliance checklist for the data-export release should include the following items:

1. Data Scope
   - Verify that the data scope remains the same as in v1. (Since v2 is built on top of v1 with no material changes in data scope)

2. Access Controls
   - Verify that the access controls for partner-portal integration are implemented correctly. This includes the OAuth scope for partner authentication and user authorization.

3. Audit Logging
   - Confirm that the audit-logging items are written in pathway-agnostic terms and that the Provenance Stamp requirement from the Q4 2025 bulletin is added. The Provenance Stamp should capture the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at the time of export.

Here's a sample v2 compliance checklist:

```
# Data Export v2 Compliance Checklist

## Data Scope
- Data scope remains the same as in v1.

## Access Controls
- Partner-portal access control is implemented correctly.

## Audit Logging
- Audit logging items are written in pathway-agnostic terms.
- Provenance Stamp is implemented to capture the following information:
  - User's authorization grant id
  - Requesting party's identity
  - Authorization scope
  - Validity window at the time of export
```

The completed v2 compliance checklist should be saved at `deployments/data-export-v2/compliance-checklist.md`.
