```
# Data Export v2 Compliance Checklist

## Access Controls

- Users must authenticate with valid credentials to initiate a data export.
  (Applies from v1; still applicable)

- The CLI and HTTP endpoints enforce appropriate access controls based on the user's roles and permissions.
  (Applies from v1; still applicable)

## Data Scope

- Data exported conforms to the defined data scope.
  (Applies from v1; still applicable)

## Data Retention

- Data retention policies are adhered to.
  (Applies from v1; still applicable)

## Audit Logging

- A record is kept of all data export requests, including user information, request details, and timestamps.
  (Applies from v1; still applicable)

## Partner Integration Controls (v2-specific)

- A new HTTP endpoint `POST /v2/data-export/request` is added to facilitate partner-portal integrations.
  (v2-specific)

## Partner-initiated Export Provenance Stamp (v2-specific)

- The Provenance Stamp capturing the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at time of export is implemented.
  (v2-specific; required by Q4 2025 bulletin)
```

The checklist includes the v2-specific changes, such as the new partner-portal access path and the Provenance Stamp requirement, while confirming that the v1 controls still apply.
