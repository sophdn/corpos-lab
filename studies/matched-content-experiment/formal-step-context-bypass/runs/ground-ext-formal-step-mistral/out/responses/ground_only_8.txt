```
# Data Export v2 Compliance Checklist (November 2025)

## Access Control

- Ensure that access control policies are in place and enforce user authentication and authorization for all data export requests.
  - (Same as v1)

## Audit Logging

- Maintain comprehensive audit logs for all data export activities.
  - (Same as v1)

## Data Scope

- Define clear data scope for all data export activities.
  - (Same as v1)

## Data Retention

- Implement data retention policies in line with company standards.
  - (Same as v1)

## New: Partner-Portal Export Pathway

- Implement a new partner-portal access pathway for data export requests.
  - Partners authenticate via OAuth scope and can request exports for users who granted them an active authorization.

## New: Provenance Stamp for Partner-Initiated Exports

- Record a Provenance Stamp for each partner-initiated export request.
  - Capture the user's authorization grant ID, the requesting party's identity, the authorization scope, and the validity window at time of export.
  - Write synchronously and fail closed if it cannot be assembled.
```

This v2 checklist captures the new control added in v2 (partner-portal export pathway and Provenance Stamp for partner-initiated exports) and confirms that the v1 controls still apply.
