```
# Compliance Checklist v2 (Data Export)

## Access Control and Authorization

1. **Access Control Policy** (v1 applicable, unchanged)
   - Ensure access to the data-export system is properly controlled and managed according to the Access Control Policy.

2. **Authorization Grant** (v2 specific)
   - Implement the partner-portal access pathway with proper OAuth scopes for partner authentication.
   - Ensure that partners can request exports only for users who have granted them an active authorization.

## Audit Logging and Monitoring

3. **Audit Logging** (v1 applicable, unchanged)
   - Implement audit logging of all user actions in the data-export system according to the Audit Logging Policy.

4. **Provenance Stamp** (v2 specific)
   - Implement a Provenance Stamp for every partner-initiated export request.
   - Capture the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at the time of export.
   - Ensure the Provenance Stamp is written synchronously and fails closed if it cannot be assembled.

## Data Retention and Disposal

5. **Data Retention Policy** (v1 applicable, unchanged)
   - Retain user data in accordance with the Data Retention Policy.

6. **Data Disposal Policy** (v1 applicable, unchanged)
   - Dispose of user data in accordance with the Data Disposal Policy.

## Compliance Sign-off

7. **Compliance Sign-off**
   - Legal and Security sign-off required.
```

The v2 compliance checklist captures the v2-specific changes and confirms that the v1 controls still apply. This checklist ensures that the data-export v2 release is compliant with the Q4 2025 compliance bulletin and ready for deployment on Friday.
