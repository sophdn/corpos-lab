 Here is the v2 compliance checklist for the data-export v2 release, as requested:

```
# Compliance Checklist - Data Export v2

## Data Scope
- Confirm that the data scope is identical to v1, covering only necessary user data as defined in the Data Policy.

## Access Control
- Verify that access to the data-export v2 endpoint is restricted to authenticated and authorized partners.
- Confirm that partners can only request data for users who have granted them active authorization.

## Authentication and Authorization
- Ensure that partners authenticate via OAuth with the correct scopes to access the data-export v2 endpoint.

## Audit Logging
- Log all partner-initiated data export requests, including:
  - The user's authorization grant id
  - The requesting party's identity
  - The authorization scope
  - The validity window at time of export

## Data Retention
- Ensure that data retention policies remain the same as v1, with user data being securely stored for the minimum retention period as defined in the Data Policy.

## Provenance Stamp
- Implement a Provenance Stamp for partner-initiated exports, capturing the following information:
  - The user's authorization grant id
  - The requesting party's identity
  - The authorization scope
  - The validity window at time of export

## Data Privacy
- Confirm that all data handling procedures comply with applicable data privacy regulations, including GDPR, CCPA, and LGPD.

## Incident Response
- Ensure that an incident response plan is in place, outlining steps to be taken in the event of a data breach or unauthorized data access.
```

This checklist includes the new Provenance Stamp control required by the Q4 2025 bulletin for partner-initiated data exports. The remaining controls are carried over from the v1 checklist, as the v2 spec confirms that the data scope, access controls, and retention policies are unchanged from v1.
