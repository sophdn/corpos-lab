 Here's the completed v2 compliance checklist for the data-export v2 release:

```
# Deployments Data Export v2 Compliance Checklist

## Data Scope

- The data scope remains the same as in v1, covering user profile data, activity logs, and system configuration data. (Referenced from v1 checklist)

## Access Controls

- Ensure the access control policies for users, administrators, and partners are identical to those in v1. (Referenced from v1 checklist)
- Implement the OAuth 2.0 authorization flow for partners to request data exports on behalf of authorized users. (New for v2)

## Audit Logging

- Log all actions related to data export, including user actions, administrator actions, and partner actions. (Referenced from v1 checklist)
- Implement the Provenance Stamp requirement for partner-initiated data exports, capturing the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at time of export. (New for v2, per Q4 2025 bulletin)

## Data Retention and Disposal

- Follow the established data retention and disposal policies outlined in the v1 compliance checklist. (Referenced from v1 checklist)
```

This checklist captures the v2-specific changes and confirms the v1 controls still apply. It ensures the new partner-portal access pathway complies with the Q4 2025 bulletin's Provenance Stamp requirement. The completed checklist should be placed in the `deployments/data-export-v2/compliance-checklist.md` workspace.
