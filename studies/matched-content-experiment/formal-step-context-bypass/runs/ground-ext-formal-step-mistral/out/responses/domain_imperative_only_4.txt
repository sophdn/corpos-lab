# Data Export Compliance Checklist v2

## Access Control

1. User Authentication
   - Users must authenticate using secure methods to access the data export service.

2. Authorization
   - Users must have appropriate authorization to initiate a data export.

3. Partner Authentication
   - Partners must authenticate via OAuth for partner-portal access.

4. Partner Authorization
   - Partners must have active authorization from users to request a data export on their behalf.

## Audit Logging

1. Logging Requirements (v1 controls unchanged)
   - All actions performed on the data export service must be logged.
   - Logs must include the user's identity, action performed, and timestamps.

2. Provenance Stamp (new v2 requirement)
   - For partner-initiated exports, a Provenance Stamp must be included in the audit log.
   - The Provenance Stamp must capture the user's authorization grant id, the requesting party, the authorization scope, and the validity window at the time of export.

## Data Retention

1. Data Retention Policy (v1 controls unchanged)
   - Data retention policy must comply with company and regulatory standards.

## Data Security

1. Data Encryption (v1 controls unchanged)
   - Data in transit and at rest must be encrypted using industry-standard encryption methods.

2. Secure Data Export (v1 controls unchanged)
   - Data exports must be secure and protected using encryption and secure transfer protocols.

## Partner Portal

1. Partner Portal Access (new v2 requirement)
   - The data export service must provide a partner-portal integration for partners to request data exports.
