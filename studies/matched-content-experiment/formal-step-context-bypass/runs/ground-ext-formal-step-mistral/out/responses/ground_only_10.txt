 Here is the v2 checklist for the data-export release, as requested:

```
# Data Export v2 Compliance Checklist

## Access Control

- Access control policies remain the same as in v1 (pathway-agnostic)
- No new access control issues identified in the v2 spec

## Audit Logging

- Audit logging policies remain the same as in v1 (pathway-agnostic)
- No new audit logging issues identified in the v2 spec

## Data Scope

- Data scope remains the same as in v1 (unchanged)

## Data Retention

- Data retention policies remain the same as in v1 (unchanged)

## Partner-Portal Integration

- Partner-portal access pathway added for partner-initiated data exports
- OAuth scope for partner authentication implemented
- Provenance Stamp implemented for partner-initiated exports, capturing:
  - User's authorization grant id
  - Requesting party's identity
  - Authorization scope
  - Validity window at time of export
  - Synchronous and fail-closed if not assembled
```

The v2 checklist includes the new partner-portal access pathway and the Provenance Stamp requirement from the Q4 2025 bulletin. The existing controls from the v1 checklist remain in place unless otherwise noted.
