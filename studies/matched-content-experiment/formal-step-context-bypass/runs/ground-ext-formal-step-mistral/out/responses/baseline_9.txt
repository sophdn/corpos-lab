```
# Data Export v2 Compliance Checklist

## Data Scope
- Confirm data scope remains the same as in Data Export v1 (refer to `deployments/data-export-v1/compliance-checklist.md`)

## Access Controls
- Confirm access controls remain the same as in Data Export v1 (refer to `deployments/data-export-v1/compliance-checklist.md`)
- Add a new item: Partner-Portal Access Control
  - Ensure the partner-portal access path is secure and controlled, with proper OAuth scope and user authorization

## Audit Logging
- Confirm audit logging remains the same as in Data Export v1 (refer to `deployments/data-export-v1/compliance-checklist.md`)
- Add a new item: Provenance Stamp
  - Implement a Provenance Stamp for partner-initiated export requests
  - Capture the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at the time of export
  - Ensure the Provenance Stamp is written synchronously and that the request fails closed if it cannot be assembled

## Data Retention
- Confirm data retention policy remains the same as in Data Export v1 (refer to `deployments/data-export-v1/compliance-checklist.md`)

## Security
- Confirm security policy remains the same as in Data Export v1 (refer to `deployments/data-export-v1/compliance-checklist.md`)

## Legal
- Confirm legal compliance remains the same as in Data Export v1 (refer to `deployments/data-export-v1/compliance-checklist.md`)
```

This compliance checklist for the data-export v2 release captures any v2-specific changes and confirms that the v1 controls still apply. It includes a new Provenance Stamp requirement based on the Q4 2025 bulletin.
