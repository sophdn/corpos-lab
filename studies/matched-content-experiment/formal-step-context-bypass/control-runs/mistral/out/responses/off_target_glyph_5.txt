 The compliance checklist for data-export v2 should include the following items:

1. Data scope: Confirm that the data scope remains the same as in v1, covering only the predefined user data. [V1 control still applies]
2. Access controls: Confirm that access controls are consistent with those in v1, ensuring that only authorized users can access the data. [V1 control still applies]
3. Audit logging: Confirm that audit logs are being generated and stored as per the defined policy. [V1 control still applies]
4. Partner-portal access: Confirm that the partner-portal access path has been added as per the specified spec, using the defined OAuth scope for authentication. [New v2 control]
5. Provenance Stamp: Confirm that for each partner-initiated export, a Provenance Stamp is recorded capturing the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at time of export. [New v2 control based on Q4 2025 bulletin]

The completed compliance checklist should be saved at `deployments/data-export-v2/compliance-checklist.md`.
