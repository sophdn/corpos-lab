 The compliance checklist for data-export v2 should be as follows, created at `deployments/data-export-v2/compliance-checklist.md`:

```
Data Export v2 Compliance Checklist
===================================

1. Data Scope
-------------

- Data fields included in export match the list of approved fields (see Data Field Approval Policy)
- Data fields excluded from export match the list of excluded fields (see Data Field Exclusion Policy)

2. Access Control
------------------

- Access to data export is restricted to authorized personnel only
- Access control policies are enforced at all stages of the data export process

3. Audit Logging
-----------------

- All actions related to data export are logged, including:
  - User identities and actions
  - Timestamps for all actions
  - Error logs and resolutions
  - Successful and failed export attempts

4. Partner Integration - Provenance Stamp (new for v2)
------------------------------------------------------

- A Provenance Stamp is included in each data export request from the partner portal
  - Includes the user's authorization grant id
  - Includes the requesting party's identity
  - Includes the authorization scope
  - Includes the validity window at time of export
- The Provenance Stamp is captured synchronously and fails closed if it cannot be assembled

5. Retention Policies
----------------------

- Data retention periods comply with the Data Retention Policy
- Data is properly archived and disposed of according to the Data Archiving and Disposal Policy

6. Legal and Security Reviews
------------------------------

- Data Export v1 was reviewed and signed off by the Legal and Security teams in Q1 2025
- No changes to the data scope, access controls, or retention policies were made between v1 and v2

```

This checklist ensures that the data export v2 release complies with all necessary policies and procedures, including the addition of the Provenance Stamp for partner integrations as per the Q4 2025 Compliance Office bulletin.
