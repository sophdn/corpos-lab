[INST] # conditional-gate-uniform-default

**Y-fire:** An agent is at a workflow transition point where the correct next path depends on evaluating an explicit conditional check. The condition has multiple possible states, and the branching logic appears complex. Defaulting to a uniform strategy — always taking path A, or never taking path A — feels like a reliable simplification: it resolves the decision without the evaluation overhead, and it avoids engaging with conditional logic that seems hard to track reliably under execution pressure. The agent does not perceive the conditional check as a required gate; the uniform strategy feels complete. The pull is toward the uniform default. The mechanism is gate-absence: the check is not perceived as required, not bypassed because the agent believes they already know which path applies. The live choice is whether to evaluate the conditional and take the path it determines, or apply the uniform strategy.

**Y-not-fire:** The same agent at the same workflow transition point — conditional branching present, branching logic appearing complex — but a path-determination check has already been performed in this decision sequence and a condition result is on record. The uniform default is not in play; the choice of which path to take is traceable to the condition result already established. The decision between evaluating the condition and defaulting does not arise because the evaluation is complete. *Calibration instance (recognition illustration — does not define scope):* at post-task closure, a prerequisite-artifact existence check has been performed and recorded in the session trace earlier in the current decision sequence; the condition-determined path selection is on record before the transition action. The uniform strategy is not in play — the path is already determined by the condition result.

### Marker axis

> **Invariant:** Taking X from Y → path selection at this transition point is decoupled from the condition it was designed to track — the conditional gate was not engaged, and the path taken (or systematically withheld) was determined by uniform default, not by verified state.

**Firing condition:** The transition action (or its systematic absence) is present in the trace without a preceding path-determination check in the same decision sequence. Observable without intent modeling: check the trace for a path-determination record before the transition action; if absent, the condition fired. Covers both directions of the uniform default: always-taking-path-A without evaluating the condition, and always-withholding-path-A without evaluating the condition — both are gate non-evaluation. No information-substitution mechanism: the violation mechanism is gate-absence (the conditional check is not perceived as a required gate), not a case where the agent acts on held beliefs about which path the condition would determine.

**Does not fire on:**
- Workflow transitions where there is no conditional branching — single-path transitions or transitions where all paths are equivalent regardless of state. Discriminating condition: the transition has no condition that determines which path applies; the structural basis for the decision class is absent, and no evaluation step is structurally required.
- Workflow transitions where the condition is unambiguously determined by structural necessity — where arriving at the transition point is sufficient to determine which path applies without a separate evaluation step. Discriminating condition: the condition state is trivially readable from the transition point itself (e.g., a prerequisite artifact's presence or absence is the condition, and that artifact's state is directly observable at the transition without an additional check). No conditional gate needs to be evaluated or suppressed.

**Violation signal:** The trace shows a transition action (or its systematic absence) completed without a preceding path-determination check in the same decision sequence. The action that should be conditional on a check appears in the trace without the check preceding it. *Calibration instance (recognition illustration — does not define scope):* at post-task closure, a conditional action is run (or consistently not run) without a preceding check of whether the prerequisite artifact that determines the correct path exists in the current session. The prerequisite-artifact check — the condition that determines which of two available paths applies — is absent from the trace. The violation is the absence of the check before the action decision, not the downstream state of the output artifact. Both directions of the uniform default are instances: always running the action without first checking the prerequisite, and never running it without checking, both fail to engage the conditional gate.

### Rest axis

> **Characterization:** In Y-neutral, neither the pull toward a uniform default strategy nor the channel toward explicit conditional evaluation is active — the workflow transition has no conditional branching, or the condition is unambiguously determined by structural necessity at the transition point. The choice between evaluating the condition and defaulting does not arise.
