 To ensure the release is complete, follow these steps in text format:

1. Open `filterpipe/__init__.py` and update the module version at the top:

```python
__version__ = '1.5.0'
```

2. Open `pyproject.toml` and update the project and package versions:

```toml
[tool.poetry.version]
"1.5.0"

[tool.poetry.packages]
...

[tool.poetry.dependencies]
...

[build-system]
...
```

3. Update the changelog `CHANGELOG.md` with the following changes:

```markdown
## 1.5.0 - Release Date

### Added
- ChainedFilter class for composing multiple filter functions

### Fixed
- NullFilter no longer raises AttributeError on empty input
```

4. Create a release commit with a descriptive commit message, for example:

```bash
git commit -m "Bump version to 1.5.0, add ChainedFilter and fix NullFilter AttributeError"
```

5. Create a new tag for the release:

```bash
git tag v1.5.0
```

6. Push the commit and tag to the remote repository:

```bash
git push origin <commit-hash>
git push origin v1.5.0
```

Now the release is complete, and version 1.5.0 is available.
