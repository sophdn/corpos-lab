 To ensure the release is complete, follow these steps in text format:

1. Update the version number in the changelog (CHANGELOG.md) under the appropriate section (e.g., Unreleased, v1.4.x, or v1.5.x).

Example for v1.5.0:

```
## v1.5.0 (release date)
### Added
- ChainedFilter class for composing multiple filter functions

### Fixed
- NullFilter no longer raises AttributeError on empty input
```

2. Push the updated changelog to the remote repository.

3. Create a Git tag for the new release:

```
git tag v1.5.0
```

4. Push the tag to the remote repository:

```
git push origin v1.5.0
```

The release is now complete with the changelog updated and the new version tagged.
