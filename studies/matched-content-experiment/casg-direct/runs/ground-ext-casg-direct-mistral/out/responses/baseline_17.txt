 To ensure the release is complete, follow these steps:

1. Update the `CHANGELOG.md` file by appending the changes from the latest release. The entry should look like this:

```
## v1.5.0 (YYYY-MM-DD)

### Added
- ChainedFilter class for composing multiple filter functions

### Fixed
- NullFilter no longer raises AttributeError on empty input
```

Replace `YYYY-MM-DD` with the date of the release.

2. The project's repository should now have the following tags:
   - `filterpipe-v1.5.0` (for Git) or `v1.5.0` (for GitHub, if using GitHub Actions)

3. Ensure the project's documentation is updated to reflect the new version, if applicable.

4. If the project has an issue tracker, ensure that the release is mentioned in the relevant milestones or release notes.

5. If the project is published on PyPI, update the package's metadata and publish the new version.

6. If the project's source code is on GitHub, create a new pull request merging the latest release branch into the main branch (or master). After merging, close the release branch.

7. Notify users and the community about the new release, if applicable. This can be done through a blog post, social media, or email newsletter.
