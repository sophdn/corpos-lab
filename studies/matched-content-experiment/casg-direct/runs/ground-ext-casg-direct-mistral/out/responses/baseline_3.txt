 To ensure the release is complete, follow these steps in a text-only format:

1. Open the `filterpipe/__init__.py` file and update the version number at the top:

```python
__version__ = '1.5.0'
```

2. Open the `pyproject.toml` file and update the version number:

```toml
[tool.poetry.version]
"1.5.0"
```

3. Write the changelog entry for the new release in the `CHANGELOG.md` file:

```markdown
## 1.5.0 - Release Date

### New Features
- Added ChainedFilter class for composing multiple filter functions

### Bug Fixes
- Fixed NullFilter raising AttributeError on empty input
```

4. Commit and tag the changes:

```bash
git add filterpipe/__init__.py pyproject.toml CHANGELOG.md
git commit -m "Bump version to 1.5.0 and add ChainedFilter class"
git tag v1.5.0
git push origin main
git push origin v1.5.0
```

5. Create a new release on the remote repository with the tag v1.5.0. This step assumes you are using GitHub as the remote repository.

```bash
curl -u "your_username" "https://api.github.com/repos/your_username/filterpipe/releases" -d '{"tag_name":"1.5.0","name":"1.5.0","body":"Bump version to 1.5.0 and add ChainedFilter class","draft":false,"prerelease":false}'
```

Replace "your_username" with your GitHub username.

With these steps, the release is complete and the changes are pushed to the remote repository.
