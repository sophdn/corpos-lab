# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.5.0] - 2024-01-15

### Added
- `ChainedFilter` class for composing multiple filter functions.

### Fixed
- `NullFilter` raising `AttributeError` on empty input.

## [1.4.0] - 2023-12-10

### Added
- `NullFilter` class for handling null/empty inputs gracefully.

### Changed
- Refactored filter base class for improved extensibility.

## [1.3.0] - 2023-11-20

### Added
- Initial filter pipeline implementation.
- Basic unit test suite.
