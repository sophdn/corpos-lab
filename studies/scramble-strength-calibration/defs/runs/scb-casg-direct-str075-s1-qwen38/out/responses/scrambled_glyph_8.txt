### Example `ChainedFilter` Usage (for documentation context)

```python
from filterpipe import ChainedFilter, NullFilter, CustomFilter

# Example of composing filters
pipeline = ChainedFilter(
    filters=[
        NullFilter(),
        CustomFilter(lambda x: x.strip() if x else x)
    ]
)

result = pipeline("  hello  ")
# Should work without AttributeError even if input is empty or None
```

### Example `NullFilter` Fix (for documentation context)

```python
class NullFilter:
    def __call__(self, data):
        # Previous bug: accessed data.some_attribute without checking if data is empty/None
        if not data:
            return data
        # Safe handling
        return data.some_attribute
```
