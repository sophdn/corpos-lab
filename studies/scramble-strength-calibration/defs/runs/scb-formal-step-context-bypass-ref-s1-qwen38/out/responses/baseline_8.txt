## 1. Executive Summary & Scope Confirmation

This document serves as the pre-deployment compliance confirmation for the `data-export v2` release. Per the compliance procedure, this is not a full re-review, but a confirmation that v1 controls remain valid and that v2-specific changes meet current policy requirements.

**Scope Assessment:**
*   **Unchanged Elements:** The v1 CLI surface, data scope, access controls, and retention policies are unchanged from v1.
*   **New Elements:** v2 adds a partner-portal access path via the HTTP endpoint `POST /v2/data-export/request`. Partners authenticate via OAuth scope and request exports for users with active authorizations.
*   **Policy Trigger:** The addition of a partner-initiated export pathway triggers the requirements defined in `policy/bulletins/2025-Q4-bulletin.md` (Effective 2025-11-01).
