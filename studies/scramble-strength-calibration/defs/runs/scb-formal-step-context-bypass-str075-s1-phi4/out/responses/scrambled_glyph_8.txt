# Data-Export v2 Compliance Checklist

This checklist confirms compliance for the Data-Export v2 deployment, focusing on the newly added partner-portal access path. The checklist is based on the v1 compliance checklist, which remains relevant for unchanged aspects. The v2 deployment adds a new HTTP endpoint for partner-portal integration, requiring specific compliance attention as per the Q4 2025 Compliance Office bulletin.

## Access Control

- **Access Pathway**: The addition of the HTTP endpoint `POST /v2/data-export/request` for partner-portal access is compliant with existing access control measures.
- **Authentication**: Partners authenticate using OAuth scope, which is a secure method for verifying identities and ensuring only authorized parties can request data exports.
- **Authorization**: The system checks for active user authorizations, ensuring that data exports are only initiated by partners with explicit consent from the user.

## Audit Logging

- **Audit Trail**: The existing audit logging mechanism is extended to include the new partner-initiated export pathway.
- **Provenance Stamp**: As per the Q4 2025 bulletin, a Provenance Stamp must be recorded for each partner-initiated export. This includes:
  - User's authorization grant ID
  - Requesting party's identity
  - Authorization scope
  - Validity window at the time of export
- **Synchronous Logging**: The Provenance Stamp must be written synchronously, ensuring that any failure in logging results in the export request being rejected.

## Data Scope and Retention

- **Unchanged Scope**: The data scope for exports remains consistent with v1, ensuring no unauthorized data is accessible through the new endpoint.
- **Retention Policies**: Retention policies continue to apply as defined in v1, with no changes introduced by the v2 release.

## Security

- **Secure Communication**: All communications via the new HTTP endpoint are secured using HTTPS to protect data in transit.
- **Data Integrity**: Measures are in place to ensure data integrity during the export process, preventing unauthorized modifications.

## Compliance Confirmation

- **Review Confirmation**: The compliance team has reviewed the v2 specification and confirmed that all necessary controls are in place for the new partner-portal access path.
- **Signature**: This checklist is prepared and confirmed by the Compliance Office, ensuring all compliance requirements for the v2 release are met.
