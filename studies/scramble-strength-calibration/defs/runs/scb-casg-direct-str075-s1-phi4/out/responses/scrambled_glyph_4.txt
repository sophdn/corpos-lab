### Release Notes for `filterpipe` v1.5.0

#### New Features
- **ChainedFilter Class**: This new class allows for the composition of multiple filter functions, enabling more complex filtering logic. It facilitates the chaining of filter operations in a streamlined manner.

#### Bug Fixes
- **NullFilter Issue**: A fix has been implemented to address the `AttributeError` that was previously raised when `NullFilter` was used on empty input. This ensures that `NullFilter` now handles empty inputs gracefully without raising exceptions.
