# Compliance Checklist: Data-Export v2

**Status:** Pending Team Review
**Release Date:** Friday
**Reference:** v1 Checklist (Signed Off Q1 2025), 2025-Q4 Compliance Bulletin

## 1. Executive Summary
Data-Export v2 retains the v1 CLI surface and adds a partner-portal integration via `POST /v2/data-export/request`. The compliance team confirms that v2's core data scope, access controls, and retention policies are unchanged from v1. However, per the **2025-Q4 Compliance Bulletin** (effective 2025-11-01), the addition of a partner-initiated export pathway triggers a mandatory update to the audit-logging controls. Specifically, v2 must implement a **Provenance Stamp** for all partner-originated exports.

## 2. Verification of v1 Controls (Carry-Over)
The following v1 controls remain fully applicable to v2. No changes to implementation logic are required for these items, provided the v2 HTTP endpoint adheres to the same underlying service logic as the CLI.

## 3. v2-Specific Changes: Partner-Portal Integration
### 3.1 New Endpoint: `POST /v2/data-export/request`
- **Authentication:** OAuth scope-based.
- **Authorization:** Exports only for users who have granted an active authorization to the partner.
- **Compliance Requirement:** This pathway is subject to the **2025-Q4 Bulletin** "Data Export Process Update — Partner Integrations."
