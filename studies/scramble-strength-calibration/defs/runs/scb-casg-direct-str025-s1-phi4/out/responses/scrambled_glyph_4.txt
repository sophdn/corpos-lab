### Release Notes for `filterpipe` v1.5.0

#### New Features
- **ChainedFilter Class**: A new class called `ChainedFilter` has been introduced. This class allows users to compose multiple filter functions into a single chain. This feature provides a more flexible and powerful way to apply a series of filters to data, enhancing the modularity and reusability of filter functions.

#### Bug Fixes
- **NullFilter AttributeError Fix**: The `NullFilter` now correctly handles empty input without raising an `AttributeError`. This fix ensures that `NullFilter` operates smoothly even when given no data, improving the robustness of the filter.

#### Project Maintenance
- **Version Bump**: The version number has been updated to 1.5.0 in both `filterpipe/__init__.py` and `pyproject.toml`.
- **Testing**: All 47 tests have passed, confirming the stability and reliability of the release.
- **Release Commit and Tag**: The release commit and the tag v1.5.0 have been pushed to the remote repository.
- **Changelog Update**: The changelog at `CHANGELOG.md` has been updated to reflect the changes made in this release.

This release enhances the functionality of `filterpipe` by adding the ability to chain filters and by fixing a critical bug, ensuring better performance and reliability.
