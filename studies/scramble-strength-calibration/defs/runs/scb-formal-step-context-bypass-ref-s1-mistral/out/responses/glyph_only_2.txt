 To complete the compliance checklist for data-export v2, you should create a new file `deployments/data-export-v2/compliance-checklist.md` with the following content:

```
# Data Export v2 Compliance Checklist

## Access Control

- [ ] Access control policies are in place to ensure that only authorized users can initiate and receive data exports.
- [ ] Access control policies are written in pathway-agnostic terms.

## Audit Logging

- [ ] Audit logs are recorded for all data export operations, capturing user identity, operation details, and timestamps.

## Partner Portal Integration

- [ ] A Provenance Stamp is recorded for each partner-initiated data export, capturing the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at time of export.
- [ ] The Provenance Stamp is written synchronously and fails closed if it cannot be assembled.

## Retention Policy

- [ ] Data retention policies are in compliance with company guidelines.

## Sign-off

- Date: [Insert current date]
- Compliance Officer: [Your name]
- Legal Approval: [Insert Legal's approval if applicable]
- Security Approval: [Insert Security's approval if applicable]
```

Note that the v1 access control and audit logging items remain as is because they are unchanged in v2. The new Provenance Stamp item is added to account for the partner-portal integration. Once the checklist is complete, you should hand it back to the team.
