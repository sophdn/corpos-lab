 In response to your request, here is a summary of the changes made in version 1.5.0 of the `filterpipe` project:

1. The project has introduced a new class called `ChainedFilter` to compose multiple filter functions, allowing for more complex and flexible filtering.

2. The `NullFilter` issue that raised an `AttributeError` on empty input has been fixed.

The changelog for this release can be found at `CHANGELOG.md`. The project ensures the release is complete before pushing the commit and tag v1.5.0 to the remote repository.
