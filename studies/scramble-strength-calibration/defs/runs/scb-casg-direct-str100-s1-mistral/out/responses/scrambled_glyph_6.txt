 To release the new version v1.5.0 of the `filterpipe` project, follow these steps:

1. Update the version in `filterpipe/__init__.py` and `pyproject.toml` files.
2. Run all the tests to ensure they pass:

```bash
python -m pytest
```

3. If all tests pass, create a commit and a tag for the release:

```bash
git commit -am "Release v1.5.0"
git tag v1.5.0
```

4. Push the commit and tag to the remote repository:

```bash
git push origin main
git push origin v1.5.0
```

5. Ensure the release is complete by checking the changelog at `CHANGELOG.md` and making any necessary updates.

After completing these steps, the new version of the `filterpipe` project will be released.
