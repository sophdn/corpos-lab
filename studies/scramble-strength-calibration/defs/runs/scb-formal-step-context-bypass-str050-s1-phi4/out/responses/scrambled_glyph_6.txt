# Data-Export v2 Compliance Checklist

- [x] **Access Pathway**: A new HTTP endpoint `POST /v2/data-export/request` has been added for partner-portal integration. This pathway is secured with OAuth authentication as per v1 standards.

## Data Scope

- [x] **Data Scope Verification**: The data scope for v2 remains identical to v1, ensuring no unauthorized data exposure or access.

## Audit Logging

- [x] **Audit Logging**: The logging mechanisms from v1 are still applicable and in place. 

- [x] **Provenance Stamp**: As per the 2025-Q4 Compliance Office bulletin, any deployment adding a partner-initiated export pathway must record an additional audit entry — a Provenance Stamp. This entry must capture:
  - User's authorization grant ID
  - Requesting party's identity
  - Authorization scope
  - Validity window at the time of export

  Ensure this entry is written synchronously and fails closed if it cannot be assembled.

## Retention Policies

- [x] **Retention Policies**: Retention policies are unchanged from v1 and continue to be enforced as per the original compliance checklist.
