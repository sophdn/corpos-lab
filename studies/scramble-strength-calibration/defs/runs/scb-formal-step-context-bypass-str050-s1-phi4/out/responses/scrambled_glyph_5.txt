**Compliance Checklist for Data-Export v2 Release**

**Release Overview:**
- The data-export v2 release includes a new HTTP endpoint `POST /v2/data-export/request` for partner-portal integration.
- The v2 release retains all data scope, access controls, and retention policies from the previously reviewed v1 release.
- Partners authenticate via OAuth scope and request exports for users who have granted them active authorization.

**Compliance Checklist:**

1. **Data Scope:**
   - **Status:** Unchanged from v1
   - **Verification:** Confirmed that the data scope remains consistent with v1. No new data types are exported.
   - **Action:** None required

2. **Access Controls:**
   - **Status:** Unchanged from v1
   - **Verification:** Access controls are pathway-agnostic and applicable to the new HTTP endpoint.
   - **Action:** None required

3. **Retention Policies:**
   - **Status:** Unchanged from v1
   - **Verification:** Retention policies remain consistent with those defined in v1.
   - **Action:** None required

4. **Audit Logging:**
   - **Status:** Additional requirements for v2
   - **Verification:** 
     - The new HTTP endpoint requires an additional audit entry — a Provenance Stamp.
     - The Provenance Stamp must capture:
       - User's authorization grant ID
       - Requesting party's identity
       - Authorization scope
       - Validity window at the time of export
   - **Action:** Ensure that the system logs the Provenance Stamp synchronously and fails closed if it cannot be assembled.

5. **Partnership Integration:**
   - **Status:** New requirement for v2
   - **Verification:** Partners authenticate via OAuth and request exports only for users with active authorizations.
   - **Action:** Validate that OAuth scopes are correctly implemented and that only authorized partners can initiate exports.

6. **Security Review:**
   - **Status:** Confirmed with Legal and Security
   - **Verification:** Security and legal teams have reviewed and confirmed that v2 does not introduce new security risks.
   - **Action:** None required

**Conclusion:**
- The v2 compliance checklist confirms that all v1 controls remain applicable.
- New compliance requirements specific to the partner-portal integration have been addressed.
- The compliance team recommends proceeding with the deployment of data-export v2.
