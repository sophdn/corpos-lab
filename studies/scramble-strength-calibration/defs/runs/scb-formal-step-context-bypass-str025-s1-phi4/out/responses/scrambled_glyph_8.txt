# Data-Export v2 Compliance Checklist

This checklist confirms compliance for the Data-Export v2 deployment, ensuring it adheres to the existing compliance framework established in v1, with specific attention to the new partner-portal access path and the additional audit requirements as per the 2025-Q4 compliance bulletin.

## Access Control

- [ ] **Access Control Mechanisms**: Verify that access controls remain consistent with v1, ensuring that only authorized users can initiate or view data exports.
  - *Comment*: Access controls are unchanged from v1, as the new HTTP endpoint does not alter existing user permissions.

- [ ] **OAuth Authentication**: Ensure that partners authenticate via OAuth scope correctly and that the OAuth implementation adheres to security best practices.
  - *Comment*: OAuth scope validation should be rigorously tested to prevent unauthorized access.

- [ ] **Authorization Checks**: Confirm that users who granted partners an active authorization are the only ones whose data can be exported through the partner-portal.
  - *Comment*: User consent is crucial; ensure the system checks for valid and active authorizations.

## Audit Logging

- [ ] **Provenance Stamp Implementation**: Implement the Provenance Stamp as required by the 2025-Q4 bulletin for partner-initiated exports.
  - *Comment*: This includes capturing the user's authorization grant ID, the requesting party's identity, the authorization scope, and the validity window at the time of export.

- [ ] **Audit Entry Recording**: Ensure that the Provenance Stamp is recorded synchronously and that the system fails closed if it cannot be assembled.
  - *Comment*: Implement robust error handling to prevent incomplete or missing audit entries.

- [ ] **Audit Log Integrity**: Verify that audit logs are immutable and can be securely stored and retrieved for compliance audits.
  - *Comment*: Regularly review audit logs for completeness and accuracy.

## Data Scope and Retention Policies

- [ ] **Data Scope Consistency**: Confirm that the data scope for exports remains unchanged from v1.
  - *Comment*: No modifications to the data being exported; the scope is consistent with previous versions.

- [ ] **Retention Policy Compliance**: Ensure that data retention policies continue to comply with organizational and legal requirements.
  - *Comment*: No changes to retention policies; continue to follow established guidelines.
