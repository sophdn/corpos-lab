The function should:
1.  Attempt to parse the string using `urllib.parse.urlparse`.
2.  Verify that the `scheme` (e.g., `http`, `https`) and `netloc` (domain/host) are present. A URL without a scheme or host is generally considered malformed in service configuration contexts.

### Code Change

Below is the proposed replacement for the `validate_url_field` function in `config/validator.py`:

```python
import urllib.parse

def validate_url_field(field_name: str, value: str) -> bool:
    """
    Validates that the provided value is a structurally valid URL.
    
    Args:
        field_name: The name of the field being validated (for error reporting).
        value: The string value to validate.
        
    Returns:
        True if the value is a valid URL, False otherwise.
    """
    if not value or not isinstance(value, str):
        return False

    try:
        result = urllib.parse.urlparse(value)
        # A valid URL for service configuration must have a scheme and a netloc (host)
        if not result.scheme or not result.netloc:
            return False
        return True
    except Exception:
        return False
```
