# Data Export v2 Compliance Checklist

## Scope

- Data scope remains the same as v1.

## Access Controls

- Access controls remain the same as v1. (Pathway-agnostic)
- Audit logging remains the same as v1. (Pathway-agnostic)
- Implement the Provenance Stamp for partner-initiated export requests. (New for v2)
  - Capture the user's authorization grant id
  - Capture the requesting party's identity
  - Capture the authorization scope
  - Capture the validity window at time of export

## Retention Policies

- Retention policies remain the same as v1.

## Partner Portal Access

- Add an HTTP endpoint `POST /v2/data-export/request` for the partner-portal integration.

## Compliance Sign-off

- To be signed off by the compliance team and Legal and Security upon successful implementation and testing of the Provenance Stamp and the new HTTP endpoint.
