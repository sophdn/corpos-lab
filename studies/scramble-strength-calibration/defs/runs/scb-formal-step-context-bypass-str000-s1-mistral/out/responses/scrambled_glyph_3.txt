 To create the compliance checklist for the data-export v2 release, follow these steps:

1. First, make a copy of the v1 compliance checklist as the starting point for the v2 checklist.

```
cp deployments/data-export-v1/compliance-checklist.md deployments/data-export-v2/compliance-checklist.md
```

2. Next, update the v2 checklist with v2-specific changes and confirm the v1 controls still apply.

```
# Data Export v2 Compliance Checklist

## Scope

- Data Scope: Unchanged from v1 (see v1 compliance checklist)
- Access Controls: Unchanged from v1 (see v1 compliance checklist)
- Retention Policies: Unchanged from v1 (see v1 compliance checklist)

## Additions

- Partner-Portal Access Path: Added in v2 (see deployment/data-export-v2/spec.md)

## Requirements

- Partner-Portal Access Path: Implement Provenance Stamp (per policy/bulletins/2025-Q4-bulletin.md)

## Verification

- Partner-Portal Access Path: Verify Provenance Stamp implementation (per policy/bulletins/2025-Q4-bulletin.md)
```

3. Finally, ensure that the checklist is ready for the team.

```
# Compliance Review

Please review the Data Export v2 Compliance Checklist and ensure all items are addressed before deploying the v2 release.

Regards,
[Your Name]
Compliance Officer
```
