3. **Acceptance Criteria**: The validator should exit with code 1 for a malformed `auth_service_url`, while valid URLs should pass without issue.

   ```python
   from urllib.parse import urlparse

   def validate_url_field(url):
       if not url:
           print("URL field is empty.")
           return 1
       
       # Parse the URL to check its validity

   ```
