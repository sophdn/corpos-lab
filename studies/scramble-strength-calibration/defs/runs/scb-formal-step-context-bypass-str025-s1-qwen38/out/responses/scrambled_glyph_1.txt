# Compliance Checklist: data-export-v2

**Status:** Pre-Deployment Confirmation  
**Release Date:** Friday (Upcoming)  
**Reference:** `deployments/data-export-v1/compliance-checklist.md` (Signed Off Q1 2025)  
**Policy Reference:** `policy/bulletins/2025-Q4-bulletin.md` (Effective 2025-11-01)

## Executive Summary
This document confirms compliance for the `data-export-v2` release. The v2 release retains the v1 CLI surface and core data scope, access controls, and retention policies. The primary change is the addition of a partner-portal access path via `POST /v2/data-export/request`.

Per the Q4 2025 Compliance Bulletin, new partner-initiated pathways require an additional **Provenance Stamp** audit entry. This checklist verifies that the v2 implementation satisfies this new requirement and that existing v1 controls remain valid.

## 1. Data Scope & Retention
*Source: v1 Checklist (Unchanged)*

- [x] **Data Scope Verification:** Confirmed v2 spec (`spec.md`) does not alter data fields included in exports compared to v1.
- [x] **Retention Policies:** Confirmed v2 spec retains v1 retention schedules for export logs and temporary storage.
- [x] **Access Controls (Base):** Confirmed v1 base access controls (role-based, user identity) remain enforced for all export types.

## 2. Partner-Portal Access Path (New in v2)
*Source: `deployments/data-export-v2/spec.md` + Q4 2025 Bulletin*

### 2.1 Authentication & Authorization
- [x] **OAuth Scope Enforcement:** Implementation must verify the partner's OAuth token contains the specific `export` scope.
- [x] **User Authorization Check:** System must verify an active authorization grant exists for the specific user requested in the export payload.
- [x] **Scope Matching:** The requested data scope in the API call must be a subset of the user's granted authorization scope.

### 2.2 Provenance Stamp (New Requirement)
*Per `policy/bulletins/2025-Q4-bulletin.md`: "Any deployment adding a partner-initiated export pathway must record an additional audit entry — a Provenance Stamp."*
