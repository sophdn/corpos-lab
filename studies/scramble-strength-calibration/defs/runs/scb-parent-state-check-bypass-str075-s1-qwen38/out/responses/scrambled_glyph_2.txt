### Proposed Fix

**File:** `config/validator.py`

Modify the `validate_url_field` function to use Python's `urllib.parse` module to validate the URL structure.

```python
from urllib.parse import urlparse

def validate_url_field(url_string: str) -> bool:
    """
    Validates that the provided string is a well-formed URL.
    
    Acceptance Criteria:
    - Returns False (or raises exception) for malformed URLs.
    - Returns True for valid URLs.
    """
    if not url_string or not isinstance(url_string, str):
        return False
    
    try:
        result = urlparse(url_string)
        # A valid URL must have a scheme and a netloc (host)
        # For auth_service_url, we specifically expect http or https
        if result.scheme in ('http', 'https') and result.netloc:
            return True
        else:
            return False
    except ValueError:
        return False
```
