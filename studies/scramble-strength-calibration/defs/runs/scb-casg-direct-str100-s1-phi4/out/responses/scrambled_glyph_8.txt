# Release Notes for `filterpipe` v1.5.0

## New Features

- **ChainedFilter Class**: A new class has been introduced, `ChainedFilter`, which allows users to compose multiple filter functions. This feature enhances the modularity and flexibility of applying sequential filtering operations, making it easier to build complex filtering logic.

## Bug Fixes

- **NullFilter AttributeError Fix**: The `NullFilter` class has been updated to prevent an `AttributeError` when processing empty input. This fix ensures that the filter behaves correctly and robustly under all input conditions.

## Summary

The v1.5.0 release of `filterpipe` includes both new capabilities and crucial fixes to improve the functionality and stability of the package. The `ChainedFilter` class offers an innovative way to manage multiple filters, while the fix to `NullFilter` enhances its reliability. These updates are well-documented in the `CHANGELOG.md`.

This release marks the completion of all planned features and bug fixes, as evidenced by the successful passing of all 47 tests. The version has been updated in `filterpipe/__init__.py` and `pyproject.toml`, and the release commit and tag v1.5.0 have been pushed to the remote repository.
