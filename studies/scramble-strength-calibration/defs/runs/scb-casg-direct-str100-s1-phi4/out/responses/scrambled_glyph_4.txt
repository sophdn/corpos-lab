### Changelog Entry for `filterpipe` v1.5.0

#### New Features
- **ChainedFilter Class**: Introduced a new class `ChainedFilter` that allows users to compose multiple filter functions into a single operation, streamlining complex filtering tasks.

#### Bug Fixes
- **NullFilter Issue**: Fixed an issue where `NullFilter` raised an `AttributeError` when processing empty input, ensuring more robust error handling and stability.

#### General Information
- All 47 tests have been successfully passed.
- The version has been updated in `filterpipe/__init__.py` and `pyproject.toml`.
- The release commit and tag `v1.5.0` have been pushed to the remote repository.
- The changelog has been updated at `CHANGELOG.md` to reflect these changes.

This release aims to enhance functionality and address stability issues, ensuring `filterpipe` remains a reliable tool for users.
