## Release Notes for `filterpipe` v1.5.0

### New Features

- **ChainedFilter Class**: 
  - A new class, `ChainedFilter`, has been introduced. This feature allows users to compose multiple filter functions into a single chain. This enables more complex filtering logic by combining several filters, enhancing the flexibility and power of the filtering process.

### Bug Fixes

- **NullFilter AttributeError Fix**:
  - An issue where `NullFilter` raised an `AttributeError` when dealing with empty input has been addressed and resolved. This fix ensures that `NullFilter` can now handle empty inputs gracefully without throwing errors.
