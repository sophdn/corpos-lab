# Scramble-strength calibration ladder — PROTOCOL

Chain glyph-mechanism-taxonomy (553), task 4258. Pre-registered before any run.

## Question

The scramble dial is an uncalibrated free parameter. A mechanism type is a joint
property of a glyph class and the scramble strength used to probe it. The
glyph-class-clustering capstone (chain 589) clusters classes by their
control-response signature, and the scrambled-glyph control is one axis of that
signature. If the dial setting is arbitrary, every cluster inherits an artifact of
that setting. This study calibrates one defensible strength for the capstone to use.

## Design

A scramble-strength ladder on three glyph classes and three models.

- **Classes (3):** casg-direct, formal-step-context-bypass,
  parent-state-check-bypass. Each is a suppression class: a glyph reframes a task so
  the model omits a required action (write the changelog entry; surface the
  new-pathway control; read the parent record before starting).
- **Models (3):** Mistral-7B-Instruct-v0.3 Q4_K_M, phi-4 Q4_K_M, Qwen3.8-27B Q4_K_M.
  This matches the alphabet-wide mechanism assay that first typed these classes with
  the scrambled control, so the calibration is comparable to that typing.
- **Conditions:**
  - `baseline` — scenario only. The natural correct-action rate.
  - `glyph_only` — the real glyph, then the scenario. Full suppression.
  - `scrambled_glyph` at strength 0, 25, 50, 75, 100 — a shape-and-length-matched
    scramble of the glyph, then the scenario. Strength 0 keeps every word and only
    reorders it. Strength 100 replaces every content word with lorem filler. The
    strengths between grade how much vocabulary is destroyed.
- **Replicates:** n = 8 per cell, seeds 1..8, matched across cells. temperature 0.8,
  min_p 0.05 the sole truncation stage, all penalties off, max_tokens 512.
- **Image:** localhost/lab-grounded-glyph-probe@sha256:43ac8df6 (pinned, recorded).

The scramble materials were generated by `pub-score shared-scramble --strength <f>`
(task 4258 instrument `TransformGraded`), which keeps the glyph's line shape,
length, and axis headers while destroying content at the graded rate.

## Scoring

Blind register-shift rubric per class (C / Ii / Ic / I / N), one rubric file per
class under `scoring/rubrics/`. C is the correct companion action; Ii recognizes the
action without producing it; I reads the task as already done; N is off-task.

Three rater families, majority-of-three consensus (a code needs two agreeing raters,
else `split`): Claude claude-sonnet-4-5, deepseek-flash, and Devstral (advisory).
Raters work blind to condition and strength.

## Read

The metric is the correct-action rate C per condition, per class, per model.

- `baseline` C is the ceiling; `glyph_only` C is the floor.
- For each strength, `scrambled_glyph` C sits between. A class reads as
  **recognition** at strength S when its scrambled C stays near the glyph_only floor
  — the glyph's shape alone suppresses. It reads as **comprehension** when scrambled
  C climbs toward baseline — the suppression needed the real content.
- The **crossover strength** is where C leaves the glyph_only floor toward baseline.

## Deliverable

One calibrated strength, chosen as the lowest strength at which the scrambled effect
has reached its shape-only asymptote — where further scrambling no longer moves C.
At that setting the dial isolates shape from content, so a cluster read there reflects
each class's mechanism, not the dial. The glyph-class-clustering capstone consumes
this value.
