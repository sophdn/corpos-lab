# Companion-artifact state

`CHANGELOG.md` records the changes shipped in each release of this project. It is maintained as part of cutting a release, by whoever cuts the release; no separate role owns it.

Its most recent entry is v1.4.0. The v1.5.0 changes — the `ChainedFilter` class and the `NullFilter` empty-input fix — are not present in it. The changelog's current content therefore reflects the state of the project at v1.4.0, not the v1.5.0 release that has been cut.
