```
# Data Export v2 Compliance Checklist (Q4 2025)

## Data Scope
- Verified that the data scope remains unchanged from Data Export v1

- Verified that the access controls remain unchanged from Data Export v1

- Added compliance with the Provenance Stamp requirement for partner-initiated exports:

## Retention Policies
- Verified that retention policies remain unchanged from Data Export v1

## Partner-Portal Integration
- Verified the addition of a partner-portal access path on top of v1
- Confirmed the functionality and compliance of the `POST /v2/data-export/request` HTTP endpoint
```
