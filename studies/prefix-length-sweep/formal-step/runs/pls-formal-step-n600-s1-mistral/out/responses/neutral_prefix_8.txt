```
# Data Export v2 Compliance Checklist (Q1 2026)

## Data Scope
- Scope is unchanged from Data Export v1
- Data exported is limited to the authorized user's data only

## Access Control
- Access control policies remain the same as in Data Export v1
- The addition of a partner-portal access path requires the following changes:
  - Authentication is performed using OAuth scopes
  - The Provenance Stamp is recorded for each partner-initiated export request, capturing the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at time of export

## Retention Policies
- Retention policies remain the same as in Data Export v1

## Audit Logging
- Audit logs are generated and retained in accordance with the Data Export Process as defined in the Q4 2025 Compliance Office Bulletin
- The Provenance Stamp is included in the audit logs for partner-initiated export requests

## Privacy and Security
- All data handling and transmission is performed in accordance with established privacy and security policies
- All data is encrypted at rest and in transit

## Sign-off
- Reviewed by Compliance Team
- Signed off by Legal and Security
```
