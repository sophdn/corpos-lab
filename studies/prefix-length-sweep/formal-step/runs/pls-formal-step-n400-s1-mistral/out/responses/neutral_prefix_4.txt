 Based on the information provided, here is the updated compliance checklist for the data-export v2 release:

```
deployments/data-export-v2/compliance-checklist.md

# Data Scope
- Scope is unchanged from v1, covering only the data that was approved in the v1 release.

# Access Controls
- Access control policies are unchanged from v1, maintaining the same access controls for the CLI and the new partner-portal integration.
- The partner-portal integration requires OAuth scope for authentication and user authorization.

# User Authorization
- User authorization is in place for the partner-portal integration, ensuring that partners can only request exports for users who have granted them active authorization.

# Audit Logging
- Audit logging is in place and written in pathway-agnostic terms, capturing all relevant data for compliance purposes.

# New Requirement: Provenance Stamp
- For the partner-portal integration, a Provenance Stamp must be recorded for each export request, capturing the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at time of export.
```
