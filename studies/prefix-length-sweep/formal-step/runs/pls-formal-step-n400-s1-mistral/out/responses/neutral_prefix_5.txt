# Data Export v2 Compliance Checklist - Reviewed Q4 2025

## Data Scope
- [x] Data scope is limited to approved use cases and compliant data categories as defined by the Data Policy.
- [x] Data does not include sensitive personal data unless explicitly permitted by the Data Policy and the user.

## Access Control
- [x] Access to the data export function is controlled via CLI and HTTP endpoints, requiring authentication and authorization.
- [x] Access control policies are defined and enforced at the individual user level, ensuring each user's data is only accessible to them or authorized parties.
- [x] Access control logs are maintained and audited for compliance purposes.
- [x] (New) Partner-portal access pathway requires OAuth scope and active authorization from the user.
- [x] (New) Provenance Stamp must be recorded for each partner-initiated export, capturing user authorization grant id, requesting party identity, authorization scope, and validity window at time of export.

## Retention Policy
- [x] Data retention policies comply with legal and regulatory requirements, as well as the company's data retention policy.
- [x] Data is securely stored and protected according to the Data Security Policy.

## Audit Logging
- [x] All actions related to data export are logged and audited for compliance purposes.
- [x] Logs are retained and archived for the required retention period.
