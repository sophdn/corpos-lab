```
# Data Export v2 Compliance Checklist

## Scope
- The data scope remains the same as v1. (Refer to `deployments/data-export-v1/compliance-checklist.md`)

## Access Control
- Access control policies remain the same as v1. (Refer to `deployments/data-export-v1/compliance-checklist.md`)
- An additional control has been added to record a Provenance Stamp for partner-initiated exports. This includes the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at the time of export. (Refer to `policy/bulletins/2025-Q4-bulletin.md`)

## Retention Policy
- Retention policies remain the same as v1. (Refer to `deployments/data-export-v1/compliance-checklist.md`)

## Audit Logging
- Audit logging policies remain the same as v1. (Refer to `deployments/data-export-v1/compliance-checklist.md`)
- The Provenance Stamp for partner-initiated exports has been added to the audit log. (Refer to `policy/bulletins/2025-Q4-bulletin.md`)

## Partner Portal Integration
- A new HTTP endpoint `POST /v2/data-export/request` has been added for the partner-portal integration.
- Partners authenticate by OAuth scope and request exports for users who granted them an active authorization.
```

The v2 compliance checklist has been created and the team can proceed with the deployment.
