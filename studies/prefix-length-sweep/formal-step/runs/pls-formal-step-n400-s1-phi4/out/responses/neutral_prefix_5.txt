# Deployments - Data Export v2 Compliance Checklist

**Note:** This checklist confirms compliance for the Data Export v2 release, which retains the data scope, access controls, and retention policies from the v1 release with an additional partner-portal access path.

## 1. Data Scope Compliance
- **Confirm Scope:** The data scope remains unchanged from v1, ensuring compliance with existing data handling and processing policies.
- **Compliance Confirmation:** All data items continue to meet organizational and legal data scope requirements.

## 2. Access Controls
- **Access Pathways:** 
  - Retains the v1 CLI surface.
  - Adds `POST /v2/data-export/request` for partner-portal integration.
- **Authentication:**
  - Partners authenticate via OAuth scope.
  - User authorizations are required for export requests.
- **Access Control Confirmation:** Access control measures align with v1 standards and additional requirements for partner portal integration.

## 3. Retention Policies
- **Retention Consistency:** Retention policies remain unchanged from v1, ensuring compliance with organizational data retention standards.
- **Compliance Confirmation:** Data is retained according to defined policies and procedures.

## 4. Audit Logging
- **Logging Mechanism:** Audit logs capture necessary data access and export activities, as per v1 specifications.
- **Additional Audit Requirement:** 
  - Implement Provenance Stamp logging for partner-initiated export pathways.
  - Capture user authorization grant ID, requesting party's identity, authorization scope, and validity window at time of export.
  - Ensure logs are written synchronously and fail closed if not possible.

## 5. Provenance Stamp Implementation
- **Audit Entry:** Ensure that each export request via the partner portal includes a Provenance Stamp.
- **Compliance Confirmation:** The system records all necessary details for each export request and adheres to the synchronous logging requirement.

## 6. General Compliance
- **Overall Compliance:** Confirm that all components and processes meet the compliance requirements as outlined in the v1 checklist and additional requirements for v2.
- **Legal and Security Approval:** Checklist reviewed and signed off by the compliance team, ensuring readiness for deployment.

---

**Status:** All items reviewed and confirmed in compliance with organizational standards. The checklist is ready for deployment of the Data Export v2 release.
