## Section 4: Audit Logging
- **Status**: Updated
- **Details**: 
  - A new audit entry, the Provenance Stamp, is required for partner-initiated export pathways.
  - The Provenance Stamp must capture:
    - User's authorization grant ID
    - Requesting party's identity
    - Authorization scope
    - Validity window at time of export
  - Must be written synchronously and fail closed if it cannot be assembled.
- **Compliance Confirmation**: Updated to include Provenance Stamp as per Q4 2025 bulletin requirements.

## Section 5: Partner-Portal Access Path
- **Status**: New
- **Details**: 
  - A new HTTP endpoint `POST /v2/data-export/request` has been added for partner-portal integration.
  - Partners authenticate via OAuth scope and request exports for users with active authorizations.
- **Compliance Confirmation**: Compliant with the addition of the Provenance Stamp and OAuth-based access control.
