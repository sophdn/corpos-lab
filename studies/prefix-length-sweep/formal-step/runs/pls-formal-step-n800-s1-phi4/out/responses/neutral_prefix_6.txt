# Data-Export v2 Compliance Checklist

## General Overview
- **Data Scope**: Unchanged from v1.
- **Access Controls**: Unchanged from v1.
- **Retention Policies**: Unchanged from v1.
- **New Integration**: Introduction of a partner-portal access path via HTTP endpoint `POST /v2/data-export/request`.

## Access Control
- [ ] **Access Pathway**: The new HTTP endpoint for partner-portal integration uses OAuth scope for authentication.
- [ ] **Authorization**: Partners must request exports for users who have granted them an active authorization.

## Audit Logging
- [ ] **Existing Logging**: All existing audit-logging controls from v1 apply to v2.
- [ ] **Provenance Stamp**: 
  - Record an additional audit entry (Provenance Stamp) for partner-initiated export pathways.
  - Capture the user's authorization grant ID, the requesting party's identity, the authorization scope, and the validity window at the time of export.
  - Ensure this entry is written synchronously and fails closed if it cannot be assembled.

## Compliance Confirmation
- [ ] **Compliance with Bulletin**: Ensure compliance with the Policy Bulletin Q4 2025, specifically the "Data Export Process Update — Partner Integrations."
- [ ] **Review Completion**: This checklist confirms that v2's data scope, access controls, and retention policies remain unchanged from v1, with the addition of the partner-portal access path as specified.

This checklist should be reviewed and signed off by the relevant teams to ensure compliance with the updated requirements for data-export v2.
