# Data Export v2 Compliance Checklist

## Access Controls

- Access to the CLI and HTTP endpoint is controlled by the existing access controls. (See [deployments/data-export-v1/compliance-checklist.md#access-controls](deployments/data-export-v1/compliance-checklist.md#access-controls))

## Audit Logging

- Audit logs are recorded for all API interactions and CLI commands. (See [deployments/data-export-v1/compliance-checklist.md#audit-logging](deployments/data-export-v1/compliance-checklist.md#audit-logging))

## Provenance Stamp

- A Provenance Stamp is recorded for every partner-initiated data export request, capturing the user's authorization grant ID, the requesting party's identity, the authorization scope, and the validity window at the time of export. (See [policy/bulletins/2025-Q4-bulletin.md](policy/bulletins/2025-Q4-bulletin.md))

## Data Scope

- The data scope remains the same as Data Export v1. (See [deployments/data-export-v1/compliance-checklist.md#data-scope](deployments/data-export-v1/compliance-checklist.md#data-scope))

## Retention Policies

- Data retention policies remain the same as Data Export v1. (See [deployments/data-export-v1/compliance-checklist.md#retention-policies](deployments/data-export-v1/compliance-checklist.md#retention-policies))
