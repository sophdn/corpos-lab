# Deployments Data Export v2 Compliance Checklist

**Checked by**: Compliance Officer  
**Date**: [Current Date]  
**Review Status**: Pre-deployment Compliance Confirmation

## Overview

This checklist confirms the compliance status of the Data Export v2 release. The v2 release retains all the data scope, access controls, and retention policies from the Data Export v1 release, with the addition of a partner-portal access path. The v2 release has been reviewed to ensure it adheres to the updated compliance requirements, particularly concerning the addition of the partner-portal integration.

## Access Control

- **Data Scope**: Confirmed unchanged from v1. No additional data is being exported.
- **User Access**: Unchanged from v1. Users must authenticate via OAuth and have granted active authorization.
- **Partner Access**: 
  - Confirmed new HTTP endpoint `POST /v2/data-export/request` is added.
  - Partners authenticate via OAuth scope.
  - Access is restricted to users who have granted them active authorization.

## Audit Logging

- **Audit Entries**: 
  - Confirmed existing audit logging practices from v1 remain applicable.
  - New requirement: Record an additional audit entry — a Provenance Stamp — for partner-initiated export pathways.
    - Provenance Stamp must include:
      - User’s authorization grant ID
      - Requesting party’s identity
      - Authorization scope
      - Validity window at time of export
    - Must be written synchronously.
    - Must fail closed if unable to be assembled.

## Retention Policies

- **Data Retention**: Confirmed unchanged from v1. No changes to data retention periods or processes.

## Compliance with Policy Bulletins

- **Q4 2025 Bulletin Compliance**:
  - Confirmed that the addition of the partner-initiated export pathway aligns with the bulletin's requirements.
  - Provenance Stamp implementation is in place to meet the new audit entry requirements.

## Conclusion

The Data Export v2 release complies with all current compliance requirements and retains the controls established in the v1 release. The addition of the partner-portal access path has been evaluated and meets the necessary compliance standards, particularly concerning access control and audit logging.

**Next Steps**: Proceed with the deployment of Data Export v2. Further compliance verification will occur post-deployment.
