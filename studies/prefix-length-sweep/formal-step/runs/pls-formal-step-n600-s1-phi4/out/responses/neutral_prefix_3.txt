## Introduction

This compliance checklist confirms that the Data Export v2 release is aligned with the established compliance requirements. The v2 release builds upon the v1 release, which was reviewed and approved in Q1 2025, with the core compliance controls remaining unchanged. This checklist focuses on the new partner-portal access path introduced in v2.

### Overview of Changes

- **Access Path Addition:** The v2 release introduces an HTTP endpoint `POST /v2/data-export/request` for partner-portal integration.
- **Authentication:** Partners authenticate using OAuth scope and request exports for users with active authorizations.
- **Audit Logging Update:** In accordance with the Q4 2025 Compliance Office bulletin, additional audit logging requirements are implemented for partner-initiated export pathways.

## Compliance Checklist Sections

### 1. Data Scope

- **Compliance Requirement:** Ensure data exported is within the authorized scope.
- **v2 Specific Change:** No change from v1.
- **Verification:** Confirmed that the data scope remains unchanged.

### 2. Access Controls

- **Compliance Requirement:** Verify that access controls are robust and pathway-agnostic.
- **v2 Specific Change:** Introduction of partner-portal access path.
- **Verification:** Access controls are pathway-agnostic as per v1. The new partner-portal access path uses OAuth scope for authentication, ensuring compliance with access control requirements.

### 3. Retention Policies

- **Compliance Requirement:** Ensure data retention policies are enforced.
- **v2 Specific Change:** No change from v1.
- **Verification:** Retention policies remain unchanged from v1.

### 4. Audit Logging

- **Compliance Requirement:** Ensure all access and data export activities are logged.
- **v2 Specific Change:** Addition of Provenance Stamp for partner-initiated export pathways.
- **Verification:** Confirmed that the new Provenance Stamp captures:
  - User's authorization grant ID
  - Requesting party's identity
  - Authorization scope
  - Validity window at time of export
  - Written synchronously and failing closed if not possible

### 5. Security

- **Compliance Requirement:** Ensure data security during export.
- **v2 Specific Change:** No change from v1.
- **Verification:** Security measures remain consistent with v1.

## Conclusion

The Data Export v2 release complies with all relevant standards and policies as outlined in the v1 checklist, with necessary updates for the new partner-portal access path. All v1 controls remain applicable, and the new audit logging requirement has been addressed in accordance with the latest compliance bulletin.
