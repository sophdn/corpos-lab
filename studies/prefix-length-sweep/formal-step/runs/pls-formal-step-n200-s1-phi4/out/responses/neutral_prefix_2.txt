# Deployments/Data-Export-v2/Compliance-Checklist.md

## Introduction
This compliance checklist addresses the deployment of data-export v2, which retains the data scope, access controls, and retention policies of v1 but introduces a partner-portal access path. The checklist confirms that all existing controls remain valid and captures any v2-specific compliance requirements.

## Data Scope
- **Compliance Verification**: Confirmed unchanged from v1.
- **Action Items**: None.

## Access Controls
- **Compliance Verification**: Confirmed unchanged from v1.
- **New Requirement**: Partners authenticate via OAuth scope and request exports for users with active authorization.
- **Action Items**: Ensure OAuth scope-based authentication is properly implemented.

## Retention Policies
- **Compliance Verification**: Confirmed unchanged from v1.
- **Action Items**: None.

## Audit Logging
- **Compliance Verification**: Confirmed unchanged from v1.
- **New Requirement**: Implement Provenance Stamp for partner-initiated export pathways.
  - Capture user's authorization grant ID.
  - Capture requesting party's identity.
  - Capture authorization scope.
  - Capture validity window at time of export.
  - Ensure these entries are written synchronously and fail closed if unable to assemble.
- **Action Items**: Update audit logging mechanisms to include Provenance Stamps.

## Partner-Portal Integration
- **Compliance Verification**: New integration added via `POST /v2/data-export/request` endpoint.
- **Action Items**: 
  - Validate OAuth authentication for partners.
  - Verify correct handling of user authorization grants.

## Sign-off
- **Compliance Team Review**: Completed.
- **Legal and Security Review**: To be completed post-deployment.

---

This checklist ensures that the v2 release complies with all current policies and integrates the new requirements for partner-initiated export pathways. All v1 controls have been confirmed to still apply, and any new compliance needs specific to v2 have been addressed.
