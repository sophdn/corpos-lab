# Data Export v2 Compliance Checklist

## Introduction
This checklist confirms compliance for the data-export v2 release, focusing on the addition of a partner-portal access path. It verifies that all v1 controls remain applicable and addresses any new requirements introduced in v2.

## Data Scope
- **Status:** Unchanged from v1
- **Details:** The data scope remains consistent with the v1 release. No new data types or categories are being exported.

## Access Controls
- **Status:** Unchanged from v1
- **Details:** Access controls from v1 apply. The new HTTP endpoint for partner-portal integration uses OAuth scope for authentication, ensuring secure partner access.

## Retention Policies
- **Status:** Unchanged from v1
- **Details:** Retention policies remain as per v1 specifications, ensuring data is stored and deleted according to predefined guidelines.

## Audit Logging
- **Status:** Unchanged from v1 with additional requirement
- **Details:** 
  - Audit logs from v1 remain applicable.
  - New requirement: For partner-initiated exports via the new endpoint, a Provenance Stamp must be recorded. This includes:
    - User's authorization grant ID
    - Requesting party's identity
    - Authorization scope
    - Validity window at time of export
  - The Provenance Stamp must be written synchronously and fail closed if it cannot be assembled.

## Partner-Portal Integration
- **Status:** New requirement
- **Details:** 
  - The v2 release introduces a `POST /v2/data-export/request` endpoint for partner-portal integration.
  - Partners authenticate using OAuth scope and request exports for users with active authorizations.
  - Compliance with the Q4 2025 bulletin requirement for Provenance Stamp recording is confirmed.

## Sign-off
- **Compliance Team:** Confirmed all applicable v1 controls are in place and v2-specific changes are addressed.
- **Legal:** No new legal issues identified with the v2 release.
- **Security:** No new security concerns identified with the v2 release.

This checklist ensures that the data-export v2 release complies with all necessary regulations and incorporates the new requirements for partner-initiated export pathways.
