**Release Notes for filterpipe v1.5.0**

We are pleased to announce the release of `filterpipe` version 1.5.0. This version introduces new functionality and important bug fixes. Below is a summary of the changes:

### New Features
- **ChainedFilter Class**: A new `ChainedFilter` class has been added, allowing users to compose multiple filter functions. This feature enhances the flexibility and power of `filterpipe` by enabling complex filtering operations with ease.

### Bug Fixes
- **NullFilter Fix**: The `NullFilter` class has been corrected to prevent `AttributeError` when handling empty input. This ensures more robust behavior and reliability in all use cases.

### Testing
- Comprehensive testing has been conducted, with all 47 tests passing, ensuring the stability and reliability of this release.

### Version Information
- The version has been updated in `filterpipe/__init__.py` and `pyproject.toml`.
- A release commit and tag `v1.5.0` have been pushed to the remote repository.

### Changelog
For a detailed list of changes, refer to the `CHANGELOG.md` file maintained by the project.

This release enhances the functionality of `filterpipe` by providing more sophisticated filtering capabilities and ensuring stability with the fix to `NullFilter`. We encourage users to upgrade to this latest version to take advantage of these improvements.
