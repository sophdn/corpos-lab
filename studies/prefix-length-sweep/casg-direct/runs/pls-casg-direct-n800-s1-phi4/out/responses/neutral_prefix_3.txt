**Release Notes for filterpipe v1.5.0**

We are excited to announce the release of `filterpipe` v1.5.0. This version introduces a new feature and fixes an issue that has been identified in previous releases. Below are the details of the changes included in this release:

### New Features

- **ChainedFilter Class**:
  - A new `ChainedFilter` class has been added, allowing users to compose multiple filter functions seamlessly. This feature provides greater flexibility in filtering operations by enabling the chaining of filters, making it easier to apply complex filtering logic in a single, cohesive operation.

### Bug Fixes

- **NullFilter AttributeError**:
  - An issue where `NullFilter` raised an `AttributeError` when processing empty input has been addressed and resolved. This fix ensures that the `NullFilter` operates correctly with empty inputs without causing exceptions.

### Other Changes

- Version bump in `filterpipe/__init__.py` and `pyproject.toml`.
- All 47 tests have been verified and pass successfully.
- The release commit and tag v1.5.0 have been pushed to the remote repository.

### Maintaining the Changelog

The project maintains a `CHANGELOG.md` file to document all changes. Users are encouraged to review it for a comprehensive list of updates and modifications introduced in each version.

This release aims to enhance the usability and reliability of `filterpipe`, and we appreciate the community's feedback and contributions. Thank you for using `filterpipe`, and we look forward to bringing more improvements in future releases.
