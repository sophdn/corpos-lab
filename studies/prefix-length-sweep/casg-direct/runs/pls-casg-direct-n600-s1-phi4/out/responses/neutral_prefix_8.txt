**Release Notes for filterpipe v1.5.0**

We are pleased to announce the release of `filterpipe` version 1.5.0. This version introduces new functionality, improves existing features, and addresses an important bug. Here are the details:

### New Features

- **ChainedFilter Class**: A new class, `ChainedFilter`, has been added to allow for the composition of multiple filter functions. This class enables users to create complex filter pipelines by chaining together several filter functions, providing greater flexibility and control over data processing.

### Bug Fixes

- **NullFilter AttributeError**: The `NullFilter` has been fixed to prevent it from raising an `AttributeError` when it encounters empty input. This ensures smoother operation and enhances the robustness of the `filterpipe` package.

### Other Information

- **Testing**: All 47 tests have been executed and passed, confirming the stability and reliability of this release.
- **Version Update**: The version number has been updated in `filterpipe/__init__.py` and `pyproject.toml`.
- **Release Management**: The release commit and tag `v1.5.0` have been pushed to the remote repository.
- **Documentation**: The `CHANGELOG.md` has been updated to reflect these changes. Users are encouraged to review the changelog for detailed information on this release.

We hope you find these updates beneficial and look forward to your continued use of `filterpipe`. For any questions or feedback, please reach out to our support team. Thank you for choosing `filterpipe`!
