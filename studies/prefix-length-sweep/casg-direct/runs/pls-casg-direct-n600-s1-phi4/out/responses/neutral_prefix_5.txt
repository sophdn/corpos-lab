**Release Notes for Filterpipe v1.5.0**

We are pleased to announce the release of Filterpipe v1.5.0. This version introduces a new `ChainedFilter` class and addresses an issue with `NullFilter`. Below is a detailed overview of the changes included in this release:

### New Features

- **`ChainedFilter` Class**: 
  - This new feature allows users to compose multiple filter functions into a single filter operation. By using `ChainedFilter`, users can apply a sequence of filtering operations in a streamlined and efficient manner. This is particularly useful for complex data processing tasks where multiple conditions need to be applied to the data.

### Fixes

- **`NullFilter` Bug Fix**:
  - In previous versions, `NullFilter` would raise an `AttributeError` when handling empty input. This release resolves the issue, ensuring that `NullFilter` can gracefully handle empty inputs without raising exceptions. This improvement enhances the robustness and reliability of the filter operations in Filterpipe.

### Version Bump

- The version number has been updated from v1.4.x to v1.5.0 in `filterpipe/__init__.py` and `pyproject.toml`.

### Testing

- All 47 tests have been executed successfully, confirming the stability and correctness of the new features and fixes.

### Documentation

- The changelog at `CHANGELOG.md` has been updated to reflect these changes. Users are encouraged to review the changelog for detailed information about this release.

### Conclusion

Filterpipe v1.5.0 enhances the library's functionality and fixes a critical issue, making it a reliable choice for filtering tasks. We appreciate the community's support and feedback, which continues to help us improve the library.

For further details, please refer to the updated `CHANGELOG.md`. Thank you for using Filterpipe!
