**Release Notes for filterpipe v1.5.0**

We are excited to announce the release of `filterpipe` v1.5.0. This version brings new functionality and improvements that enhance the usability and robustness of the library. Below are the details of what's included in this release:

### New Features
- **`ChainedFilter` Class**: This new class allows users to compose multiple filter functions into a single operation. It simplifies the process of applying a series of transformations or filters to data, providing a more streamlined and efficient workflow.

### Bug Fixes
- **`NullFilter` Improvement**: The `NullFilter` now correctly handles empty input without raising an `AttributeError`. This fix ensures that the filter behaves as expected, even when no data is available to process.

### Testing
- All 47 tests have been successfully executed and passed, confirming the stability and reliability of the new features and fixes.

### Documentation
- The changelog has been updated to reflect these changes. Users can refer to `CHANGELOG.md` for a detailed account of what has been added and fixed in this release.

### Installation
- The version number has been updated in `filterpipe/__init__.py` and `pyproject.toml`. The release commit and tag `v1.5.0` have been pushed to the remote repository.

This release aims to provide developers with more powerful tools for data processing while ensuring robust error handling. We encourage users to upgrade to take advantage of these new features and improvements.

Thank you for your continued support of `filterpipe`. We look forward to your feedback and contributions to future releases.

For any questions or issues, please refer to our documentation or reach out to our support team.
