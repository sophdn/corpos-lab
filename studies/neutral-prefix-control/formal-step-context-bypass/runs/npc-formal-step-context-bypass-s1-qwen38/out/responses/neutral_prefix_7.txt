# Data Export v2 Compliance Checklist

**Release:** data-export v2
**Status:** Approved for Deployment
**Date:** Q4 2025
**Reviewer:** Compliance Office

## 1. Scope & Authorization
- **v1 Controls:** Unchanged. The data scope, access controls, and retention policies remain identical to the v1 baseline (signed off Q1 2025).
- **v2 Changes:** Added partner-portal access path (`POST /v2/data-export/request`). Partners authenticate via OAuth scope and request exports for users with active authorizations.
- **Compliance Confirmation:** Confirmed that v2's data scope, access controls, and retention policies are unchanged from v1. The new pathway is strictly additive and does not alter existing user-initiated export logic.

## 2. Access Control & Authentication
- **v1 Controls:** Pathway-agnostic access controls remain in effect.
- **v2 Changes:** Partner authentication is enforced via OAuth scope. Exports are limited to users who have granted an active authorization.
- **Compliance Confirmation:** Access controls are verified to apply to the new HTTP endpoint. The OAuth scope mechanism ensures that partners can only access data for which they hold valid, active user authorizations.

## 3. Audit Logging & Provenance
- **v1 Controls:** Standard audit logging remains in effect.
- **v2 Changes:** **MANDATORY UPDATE PER Q4 2025 BULLETIN.** Implementation of the "Provenance Stamp" for partner-initiated exports.
- **Compliance Confirmation:** The v2 specification confirms that every partner-initiated export will record a Provenance Stamp. This entry will synchronously capture:
    1. The user's authorization grant ID.
    2. The requesting party's identity.
    3. The authorization scope.
    4. The validity window at the time of export.
- **Failure Mode:** Confirmed that the system is configured to fail closed if the Provenance Stamp cannot be assembled.

## 4. Retention & Data Handling
- **v1 Controls:** Unchanged.
- **v2 Changes:** None.
- **Compliance Confirmation:** Retention policies for exported data and logs remain consistent with the v1 checklist.

## Final Sign-Off
The v2 release adheres to all existing v1 compliance requirements. The specific requirements for partner integrations outlined in the Q4 2025 Compliance Bulletin (Data Export Process Update) have been met through the implementation of the synchronous, fail-closed Provenance Stamp.

**Approved for Friday Deployment.**
