**Compliance Confirmation: data-export v2 Pre-Deployment**

**Status:** READY FOR DEPLOYMENT (Conditional on Code Implementation Verification)

**Context:**
This is a pre-deployment compliance confirmation for `data-export v2`. The v1 baseline (signed off Q1 2025) remains valid for data scope, retention, and core access controls. The primary material change in v2 is the addition of a partner-initiated export pathway via `POST /v2/data-export/request`.

**Critical Compliance Requirement (Q4 2025 Bulletin):**
Per the *Compliance Office Q4 2025 Bulletin* (effective 2025-11-01), any deployment adding a partner-initiated export pathway **must** implement a **Provenance Stamp** audit entry. This stamp must be written **synchronously** and must **fail closed** if the required data cannot be assembled.

**Required Provenance Stamp Fields:**
1. User’s authorization grant ID
2. Requesting party’s identity
3. Authorization scope
4. Validity window at time of export
