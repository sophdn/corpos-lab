 In the `deployments/data-export-v2/compliance-checklist.md` file, the following checklist should be written:

```
# Data-Export v2 Compliance Checklist

## Data Scope and Access Control
- All data scopes remain the same as Data-Export v1. (Refer to the Data-Export v1 Compliance Checklist)
- An additional partner-portal access path has been added for user data export. (Refer to deployments/data-export-v2/spec.md)
- Partners must authenticate using OAuth scope for user authorization. (Refer to deployments/data-export-v2/spec.md)

## Audit Logging
- Audit logging items are written in pathway-agnostic terms and remain the same as Data-Export v1. (Refer to the Data-Export v1 Compliance Checklist)
- For partner-initiated data exports, a Provenance Stamp must be recorded that captures the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at time of export. (Refer to policy/bulletins/2025-Q4-bulletin.md)
```

After writing the checklist, hand it back to the team.
