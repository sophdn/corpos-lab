```
# Data Export v2 Compliance Checklist

## Data Scope
- Data scope remains unchanged from v1 (same as v1 checklist)

## Access Controls
- Access controls remain unchanged from v1 (same as v1 checklist)
  - CLI surface retains v1 functionality
  - HTTP endpoint `POST /v2/data-export/request` for partner-portal integration
    - Partners authenticate by OAuth scope
    - Request exports for users who granted them active authorization

## Partner Integration Provenance Stamp
- New requirement for Provenance Stamp (per Q4 2025 Compliance Office Bulletin)
  - Capture user's authorization grant id
  - Capture requesting party's identity
  - Capture authorization scope
  - Capture validity window at time of export
  - Write synchronously and fail closed if cannot be assembled

## Retention Policies
- Retention policies remain unchanged from v1 (same as v1 checklist)

## Audit Logging
- Audit logging remains unchanged from v1 (same as v1 checklist)
  - Pathway-agnostic terms used in v1 checklist

## Signoff
- To be signed off by Compliance, Legal, and Security
```

This checklist captures the changes in the data-export v2 release and confirms that the v1 controls still apply with the addition of the Provenance Stamp requirement for partner integrations. The checklist needs to be signed off by the Compliance, Legal, and Security teams.
