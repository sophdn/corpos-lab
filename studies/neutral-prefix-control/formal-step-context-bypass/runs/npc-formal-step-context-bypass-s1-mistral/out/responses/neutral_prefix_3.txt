 In the `deployments/data-export-v2/compliance-checklist.md` file, the v2 checklist should be as follows:

```
Data Export v2 Compliance Checklist
===================================

1. Data Scope
     - Data exported should be limited to the minimum required for the intended purpose.
     - Data exported should be consistent with the defined data categories and exclusions. (Verified from v1 checklist)

2. Access Controls
     - Access to data export should be restricted to authorized users and partners.
     - Access controls should be consistent with the defined roles and permissions. (Verified from v1 checklist)
     - A Provenance Stamp must be recorded for each data export, capturing the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at time of export. (New for v2)

3. Audit Logging
     - All data export requests, responses, and errors should be logged.
     - Logs should be retained for the defined retention period. (Verified from v1 checklist)
     - The Provenance Stamp should be included in the audit logs. (New for v2)

4. Data Retention
     - Data should be retained for the defined retention period, after which it should be securely deleted. (Verified from v1 checklist)

5. Security and Privacy
     - Data should be encrypted during transmission and at rest.
     - Data should be handled in accordance with applicable privacy laws and regulations. (Verified from v1 checklist)

6. Partner Integration
     - Partner-initiated data exports should be supported via the defined HTTP endpoint.
     - Partners should authenticate using OAuth scope. (New for v2)
```
