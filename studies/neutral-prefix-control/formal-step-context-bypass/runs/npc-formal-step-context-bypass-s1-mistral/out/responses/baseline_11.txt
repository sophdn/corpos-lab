```markdown
# Data Export v2 Compliance Checklist

## Data Scope
- Confirm that the data scope remains unchanged from v1, as per the signed-off compliance checklist for v1 (`deployments/data-export-v1/compliance-checklist.md`)

## Access Controls
- Confirm that access controls remain unchanged from v1, as per the signed-off compliance checklist for v1 (`deployments/data-export-v1/compliance-checklist.md`)
- Verify that the new partner-portal access path (`POST /v2/data-export/request`) includes appropriate OAuth authentication

## Retention Policies
- Confirm that retention policies remain unchanged from v1, as per the signed-off compliance checklist for v1 (`deployments/data-export-v1/compliance-checklist.md`)

## Audit Logging
- Confirm that audit logging remains consistent with v1, as per the signed-off compliance checklist for v1 (`deployments/data-export-v1/compliance-checklist.md`), and includes the new Provenance Stamp for partner-initiated export requests

## Partner Integration Specific
- Implement the Provenance Stamp as per the Compliance Office Q4 2025 bulletin (`policy/bulletins/2025-Q4-bulletin.md`)
  - Record the user's authorization grant id
  - Record the requesting party's identity
  - Record the authorization scope
  - Record the validity window at time of export
  - Ensure the Provenance Stamp is written synchronously and fails closed if it cannot be assembled

## Security Review
- Coordinate with Security team to review the new partner-portal access path (`POST /v2/data-export/request`) for potential security risks
```

This checklist captures the changes introduced in v2, confirms the continued applicability of v1 controls, and includes the new Provenance Stamp requirement as per the Q4 2025 bulletin. The team can use this checklist to complete the necessary compliance checks for the data-export v2 release.
