```
# Compliance Checklist for Data Export v2 Release

## Data Scope
- Data exported adheres to defined data scope and excludes sensitive data as per the Data Scope Policy.
- (V1 control still applies)

## Access Controls
- Access to data export functionality is restricted to authorized personnel only.
- (V1 control still applies)

## Authentication and Authorization
- Data export is only allowed for users who have granted explicit authorization for partner-portal access.
- Provenance Stamp is recorded for every partner-initiated data export request, capturing the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at time of export.
- (V1 control does not apply)

## Audit Logging
- All data export activities, including partner-initiated requests, are logged with timestamps, user identities, and details of the exported data.
- (V1 control still applies)

## Retention Policy
- Data retention period for exported data adheres to the defined retention policy.
- (V1 control still applies)

## Security
- Data is encrypted during transmission and at rest, in compliance with the Data Security Policy.
- (V1 control still applies)

## Sign-off
- Compliance Officer (Name, Date)
- Legal (Name, Date)
- Security (Name, Date)

```
