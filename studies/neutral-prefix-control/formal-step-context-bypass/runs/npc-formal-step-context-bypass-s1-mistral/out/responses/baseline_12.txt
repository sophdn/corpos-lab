# Data Export v2 Compliance Checklist

## Data Scope & Access Controls

- Confirm that data scope remains unchanged from v1, as specified in the v1 compliance checklist (deployments/data-export-v1/compliance-checklist.md).

## Partner Portal Access Controls

- Implement Provenance Stamp mechanism for partner-initiated exports:
  1. Record the user's authorization grant id.
  2. Record the requesting party's identity (OAuth scope).
  3. Record the authorization scope.
  4. Record the validity window at time of export.
  5. The Provenance Stamp should be written synchronously and failing closed if it cannot be assembled.

## Audit Logging

- Ensure that the audit logging mechanism continues to meet the requirements set in the v1 compliance checklist (deployments/data-export-v1/compliance-checklist.md).
- Include Provenance Stamp data in the audit log for partner-initiated exports.

## Security

- Review and confirm the security controls remain unchanged from v1, as specified in the v1 compliance checklist (deployments/data-export-v1/compliance-checklist.md).

## Retention Policies

- Retain data retention policies as specified in the v1 compliance checklist (deployments/data-export-v1/compliance-checklist.md).

## Miscellaneous

- Update the API surface to include the new HTTP endpoint for the partner-portal integration: `POST /v2/data-export/request`.
