# Conformance Report for Learning Portal v2

**Date:** 2025-Q4

**Auditor:** Accessibility Compliance Officer

---

## Executive Summary

The Learning Portal v2 release has been evaluated for compliance with WCAG 2.1 AA standards. This evaluation builds on the successful audit of the v1 release, which was signed off by the Accessibility Board in Q1 2025. The v2 release retains all the accessibility features of v1, with the addition of a voice-command input path. This report confirms that v2 meets all applicable WCAG 2.1 AA criteria, including new requirements introduced in the latest accessibility bulletin.

## Scope and Methodology

The evaluation focused on the changes introduced in v2, specifically the addition of voice-command navigation. The existing accessibility features from v1 were reviewed to ensure continued compliance. The evaluation used the inputs and guidelines provided in the `releases/learning-portal-v2/change-summary.md` and the accessibility bulletin `policy/bulletins/2025-Q4-accessibility-bulletin.md`.

## Conformance Criteria

### Retained from v1

1. **Page Structure**
   - The v2 release maintains the page structure of v1, ensuring that all headings, landmarks, and structural elements remain accessible and correctly ordered.

2. **Color Palette**
   - The color palette has not changed from v1, continuing to meet contrast ratio requirements for text and interactive elements.

3. **Keyboard Navigation**
   - All functionalities accessible via keyboard in v1 remain fully operable in v2, with no regressions in keyboard navigation.

### New in v2

1. **Voice-Command Input Path**
   - Learners can issue spoken commands to navigate and submit answers, utilizing the browser's speech API for transcription.

2. **Modality Alternative Mapping**
   - As per the Q4 2025 accessibility bulletin, a Modality Alternative Mapping has been documented for each voice command. This mapping includes:
     - Equivalent non-voice control for each voice command.
     - A transcription-failure fallback mechanism.
     - A timeout feature that ensures learners are returned to a usable non-voice pathway.

3. **Transcription-Failure Fallback**
   - In cases where voice command transcription fails, learners are provided with clear instructions to switch to alternative input methods, ensuring continued accessibility.

4. **Timeout and Usable Pathways**
   - A timeout mechanism is implemented to return learners to a non-voice pathway if voice commands are not recognized within a specified period, ensuring the system fails safely.

## Findings

- **Success:** The Learning Portal v2 meets all WCAG 2.1 AA criteria, including the new requirements for voice-command inputs.
- **Voice-Command Integration:** The integration of voice-command inputs is seamless, with comprehensive alternative mappings and fallbacks ensuring accessibility.
- **Documentation:** All required documentation for voice-command mappings and fallback mechanisms is complete and aligned with the latest accessibility guidelines.

## Conclusion

The Learning Portal v2 has been thoroughly evaluated and meets all applicable WCAG 2.1 AA accessibility criteria. The addition of voice-command inputs has been successfully implemented with appropriate fallbacks and mappings, ensuring that the portal remains accessible to all users. This conformance report is submitted for review and approval by the Accessibility Board.
