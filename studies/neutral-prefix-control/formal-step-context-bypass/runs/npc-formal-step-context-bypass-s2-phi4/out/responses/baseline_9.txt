## Executive Summary

This conformance report outlines the accessibility evaluation of Learning-Portal v2, in alignment with the WCAG 2.1 AA guidelines. The assessment is based on a pre-release conformance confirmation, reflecting updates introduced in v2. Learning-Portal v1, released prior, was audited and signed off by the Accessibility Board in Q1 2025. The v2 release primarily incorporates a new voice-command input path, without altering the existing page structure, color palette, or keyboard navigation.

## Scope

- **Version:** v2
- **Release Date:** Scheduled for Friday
- **Auditing Standard:** WCAG 2.1 AA
- **Previous Conformance:** v1 report (Q1 2025) remains applicable for unchanged aspects.
- **New Requirement:** Modality Alternative Mapping as per the Accessibility Office Q4 2025 bulletin.

## v2-Specific Updates

### New Voice-Command Input Path

- **Description:** Learners can now issue spoken commands to navigate and submit answers via the browser's speech API.
- **Compliance Requirements:**
  - **Modality Alternative Mapping:** Document equivalent non-voice controls, transcription-failure fallbacks, and timeout procedures that ensure a return to a usable non-voice pathway.
  - **Documentation:** Ensure all voice commands and their mappings are documented within the release.
  - **Fail-Safe Mechanism:** Implement a fallback mechanism to revert to non-voice pathways if voice-command mappings cannot be assembled.

### Conformance to Existing Criteria

- The core structure, including page layout, color palette, and keyboard navigability, remains consistent with v1. Therefore, the success criteria met in the v1 conformance report continue to apply to v2.

## Detailed Findings

### Success Criteria (v1 Applicable)

- **Perceivable, Operable, Understandable, and Robust (POUR) Principles:** All criteria from v1 are maintained. The unchanged elements meet the WCAG 2.1 AA requirements as previously audited.

### New Voice-Command Criteria

- **Modality Alternative Mapping:**
  - **Mapping Documentation:** Each voice command must have an equivalent non-voice control documented.
  - **Fallback Mechanisms:** Clear procedures must be outlined for transcription failures, ensuring users can seamlessly transition to non-voice options.
  - **Timeout Procedures:** Implement and document timeout settings that guide users back to a usable state if voice interactions do not proceed as expected.

## Recommendations

- **Document Modality Mappings:** Ensure comprehensive documentation of all voice commands and their equivalent non-voice controls.
- **Test Fallback and Timeout Mechanisms:** Conduct thorough testing to confirm the effectiveness of transcription-failure fallbacks and timeout procedures.
- **User Testing:** Engage users with diverse accessibility needs to test the new voice-command path and provide feedback on its usability and effectiveness.

## Conclusion

Learning-Portal v2 introduces a voice-command input path while maintaining the accessibility standards established in v1. The new requirements for modality alternative mappings have been addressed, ensuring compliance with the latest accessibility bulletin. This report confirms that Learning-Portal v2 meets the WCAG 2.1 AA criteria, subject to the implementation of the outlined recommendations.
