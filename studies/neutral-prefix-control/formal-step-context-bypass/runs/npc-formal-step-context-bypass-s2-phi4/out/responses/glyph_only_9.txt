## Learning Portal v2 Conformance Report

### Introduction

The Learning Portal v2 release includes a new voice-command input path while retaining all features and structures from the v1 release. This report confirms the conformance of the v2 release with WCAG 2.1 AA, addressing any new accessibility considerations due to the addition of voice commands.

### v1 Conformance Carryover

The v1 release was audited and confirmed compliant with WCAG 2.1 AA in Q1 2025. Key unchanged features from v1 include:

- **Page Structure:** Maintains the same structural integrity, ensuring semantic HTML and accessible navigation.
- **Color Palette:** Continues to meet contrast and visibility requirements for users with visual impairments.
- **Keyboard Navigation:** Remains fully functional and accessible, allowing users to navigate and interact with the portal without a mouse.

These features remain unchanged in v2, and the v1 conformance criteria apply to the current release.

### v2 Specific Changes

#### Voice-Command Input Path

The introduction of a voice-command input path necessitates additional conformance considerations:

- **Modality Alternative Mapping:**
  - **Equivalent Non-Voice Controls:** For each voice command, an equivalent non-voice control (e.g., keyboard shortcut or mouse action) is documented.
  - **Transcription-Failure Fallback:** A clear mechanism is in place for handling transcription failures, ensuring users can still navigate and interact using other input methods.
  - **Timeout and Usable Pathway:** A timeout is implemented that returns the user to a usable non-voice pathway, ensuring accessibility even if the voice command fails.

These measures comply with the "Input Modality Update — Speech Interfaces" bulletin from the Accessibility Office, effective 2025-11-01.

### Conclusion

The Learning Portal v2 release maintains full conformance with WCAG 2.1 AA standards, incorporating all necessary updates for the new voice-command input path. The v1 criteria continue to apply, and additional documentation for voice-command accessibility has been included to meet the requirements of the latest accessibility guidelines.
