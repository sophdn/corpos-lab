# Learning Portal v2 Conformance Report

**Release Date:** [Insert Release Date]  
**Conformance Standard:** WCAG 2.1 AA

## Introduction

This report confirms the accessibility compliance of the learning-portal v2 release. The v2 release retains the page structure, color palette, and keyboard navigation from the previous v1 release, which was audited and signed off by the Accessibility Board in Q1 2025. In addition to these unchanged components, v2 introduces a voice-command input path. This document captures the new conformance requirements as per the Accessibility Office Q4 2025 bulletin.

## Conformance to WCAG 2.1 AA

The learning-portal v1 met all WCAG 2.1 AA success criteria, and this release inherits these criteria. The unchanged elements of v2, including page structure, color palette, and keyboard navigation, continue to comply with WCAG 2.1 AA.

## Voice Command Input Path

### Modality Alternative Mapping

In accordance with the "Input Modality Update — Speech Interfaces" bulletin, the addition of a voice-command input path requires the following documentation:

1. **Modality Alternative Mapping:**
   - **Voice Command to Non-Voice Control Mapping:**
     - Each voice command has an equivalent non-voice control documented.
     - Example: 
       - Voice Command: "Submit answer"
       - Equivalent Non-Voice Control: Click the "Submit" button.

2. **Transcription-Failure Fallback:**
   - In cases where the browser speech API fails to transcribe a command, a fallback mechanism is in place.
   - Example: 
     - If the command "Go to next question" is not transcribed, the learner is prompted to use the arrow keys to navigate.

3. **Timeout and Usable Non-Voice Pathway:**
   - A timeout mechanism ensures that if voice commands are not issued within a specified period, the system defaults to a usable non-voice pathway.
   - Example:
     - If no voice input is detected within 10 seconds, the portal defaults to keyboard navigation.

### Failing Safe

The system is designed to fail safely, ensuring that if the modality alternative mapping cannot be assembled, the learner is returned to a fully functional non-voice pathway.

## Conclusion

The learning-portal v2 release maintains compliance with WCAG 2.1 AA standards as per the v1 audit. The introduction of the voice-command input path has been documented with the necessary Modality Alternative Mapping, transcription-failure fallback, and timeout mechanisms to ensure accessibility. This report is submitted for review by the Accessibility Board.
