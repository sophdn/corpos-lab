# Learning Portal v2 Conformance Report

**Release Date:** Q4 2025  
**Audited Against:** WCAG 2.1 AA  
**Previous Version:** Learning Portal v1 (Audited Q1 2025)  

---

## Executive Summary

The Learning Portal v2 release introduces a new voice-command input path while retaining the existing pointer and keyboard navigation interfaces from v1. The core page structure, color palette, and keyboard navigation remain unchanged. This conformance report confirms the continued applicability of the v1 success criteria and documents compliance with the new Accessibility Office policy on speech interfaces.

## 1. Introduction

The Learning Portal v2 has been assessed to ensure it meets WCAG 2.1 AA standards, with additional compliance for the newly introduced voice-command input path as per the Accessibility Office bulletin effective 2025-11-01.

## 2. Conformance to WCAG 2.1 AA

### 2.1 Applicable Success Criteria

The Learning Portal v2 adheres to all WCAG 2.1 AA success criteria as established in the v1 release. The unchanged aspects of the portal ensure that all previously met criteria remain compliant.

### 2.2 Changes and New Features

- **Voice-Command Input Path:** A new input modality has been added, allowing learners to navigate and submit answers using spoken commands. This feature is transcribed by the browser speech API.

## 3. Modality Alternative Mapping

In accordance with the "Input Modality Update — Speech Interfaces" bulletin, the following mapping has been documented:

### 3.1 Voice Command Equivalents

For each voice command introduced in v2, an equivalent non-voice control has been established:

- **Voice Command:** "Navigate to next section"
  - **Equivalent Control:** Tab key navigation
- **Voice Command:** "Submit answer"
  - **Equivalent Control:** Enter key
- **Voice Command:** "Cancel"
  - **Equivalent Control:** Escape key

### 3.2 Transcription-Failure Fallback

In cases where voice command transcription fails, the system will:

- Provide an auditory or visual cue indicating the failure.
- Allow users to retry the command.
- Offer an option to switch to keyboard or pointer navigation.

### 3.3 Timeout and Safe Return

A timeout mechanism ensures that if a voice command is not successfully executed within a reasonable time frame, the system will:

- Return the user to a usable non-voice pathway.
- Maintain a state that allows the user to continue using pointer or keyboard controls without disruption.

## 4. Conclusion

The Learning Portal v2 has been reviewed and confirmed to meet WCAG 2.1 AA standards, with additional compliance for the new voice-command input path as per the latest accessibility bulletin. The portal maintains all previously met success criteria and introduces necessary documentation for the new input modality.

This report is submitted for review and approval by the Accessibility Board.
