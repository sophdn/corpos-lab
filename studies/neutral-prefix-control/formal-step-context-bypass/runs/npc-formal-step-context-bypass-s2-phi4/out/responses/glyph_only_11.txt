# Learning Portal v2 Conformance Report

## Introduction

This conformance report addresses the WCAG 2.1 AA requirements for the learning-portal v2 release. Based on the change summary and the accessibility bulletin issued in Q4 2025, we have evaluated the introduction of a voice-command input path and verified that the previous criteria for v1 continue to apply.

## Conformance Overview

- **Page Structure, Color Palette, and Keyboard Navigation:** As confirmed by the Accessibility Board, these aspects remain unchanged from v1, ensuring continued compliance with all relevant success criteria.
- **Voice Command Input Path:** A new feature introduced in v2 requires additional conformance measures, specifically a Modality Alternative Mapping.

## Voice Command Input Path

### Modality Alternative Mapping

In accordance with the Accessibility Office Q4 2025 bulletin, we have developed a Modality Alternative Mapping for the voice-command input path. This mapping includes:

1. **Equivalent Non-Voice Controls:**
   - For each voice command, an equivalent keyboard or pointer-based action has been identified to ensure that all functionality is accessible via non-voice input.

2. **Transcription-Failure Fallback:**
   - A mechanism is in place to handle transcription failures, providing clear feedback to the user and guiding them to retry or use alternative input methods.

3. **Timeout and Usable Non-Voice Pathway:**
   - A timeout feature is implemented to return the learner to a usable non-voice pathway if voice input is not completed within a reasonable timeframe. This ensures that users can continue their activities without disruption.

### Documentation

The Modality Alternative Mapping for all voice commands has been documented in detail, ensuring transparency and providing a clear reference for future audits or updates.

## Confirmation of v1 Criteria

All success criteria from the v1 conformance report remain applicable and are confirmed to be met in the v2 release. The unchanged aspects of the portal, including page structure, color palette, and keyboard navigation, continue to comply with WCAG 2.1 AA standards.

## Conclusion

The learning-portal v2 meets the WCAG 2.1 AA conformance requirements, incorporating the necessary updates for the new voice-command input path. The Modality Alternative Mapping ensures that the portal remains accessible to all users, regardless of input modality.
