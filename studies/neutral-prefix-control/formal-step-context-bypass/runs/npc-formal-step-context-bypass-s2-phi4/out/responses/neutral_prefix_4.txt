# Conformance Report for Learning Portal v2

**Report Issued:** Q4 2025

## Introduction

This report confirms the accessibility compliance of the Learning Portal v2 release. The v1 release was previously audited against WCAG 2.1 AA standards and was signed off by the Accessibility Board in Q1 2025. The v2 release retains the same page structure, color palette, and keyboard navigation as v1, with the addition of a voice-command input path. This report confirms that the v2 release meets all previously established accessibility criteria and introduces new criteria specific to the voice-command input path.

## WCAG 2.1 AA Conformance

### Page Structure
- **v1 Criteria:** All criteria met.
- **v2 Confirmation:** No changes to page structure. All criteria from v1 still apply.

### Color Palette
- **v1 Criteria:** All criteria met.
- **v2 Confirmation:** No changes to color palette. All criteria from v1 still apply.

### Keyboard Navigation
- **v1 Criteria:** All criteria met.
- **v2 Confirmation:** No changes to keyboard navigation. All criteria from v1 still apply.

### Voice-Command Input Path
- **v1 Criteria:** N/A (voice-command path was not part of v1).
- **v2 Specifics:**
  - **Modality Alternative Mapping:** Implemented for all voice commands.
  - **Equivalent Non-Voice Control:** For each voice command, an equivalent non-voice control has been documented.
  - **Transcription-Failure Fallback:** A fallback mechanism is in place for transcription errors.
  - **Timeout Mechanism:** A timeout feature returns the learner to a usable non-voice pathway if voice commands are not recognized within a specified period.
  - **Documentation:** The mapping and fallback mechanisms are documented for the release.

### Input and Error Handling
- **v1 Criteria:** All criteria met.
- **v2 Confirmation:** No changes to input and error-handling criteria. All criteria from v1 still apply.

## Policy Compliance

### Accessibility Bulletin 2025-Q4
- **Input Modality Update — Speech Interfaces:** Compliance with the bulletin requirement for a Modality Alternative Mapping is confirmed. The mapping includes:
  - **Voice Command to Non-Voice Control:** Each voice command has an equivalent non-voice control.
  - **Transcription-Failure Fallback:** A reliable fallback mechanism is in place.
  - **Timeout Mechanism:** A timeout feature ensures the learner can return to a non-voice pathway if necessary.

## Conclusion

The Learning Portal v2 has been confirmed to meet all WCAG 2.1 AA criteria, including new requirements for the voice-command input path as per the Accessibility Office Q4 2025 bulletin. The v2 release maintains the accessibility standards established in v1 and introduces necessary documentation and mechanisms to support the new voice-command functionality. The Accessibility Board has reviewed and confirmed this conformance report.
