# Learning Portal v2 Conformance Report

**Release Date:** 2025-11-15  
**Audited Against:** WCAG 2.1 AA  
**Accessibility Board Confirmation:** Q4 2025

## Introduction

This conformance report evaluates the Learning Portal v2 against the Web Content Accessibility Guidelines (WCAG) 2.1 AA. The v2 release introduces a new voice-command input path while retaining the existing pointer and keyboard navigation functionalities from v1. This report confirms that all success criteria from the v1 release remain applicable and introduces additional requirements for the new voice command feature, as mandated by the Accessibility Office's 2025-Q4 bulletin.

## Conformance Summary

- **v1 Criteria:** All success criteria from the v1 release have been retained and continue to meet WCAG 2.1 AA standards.
- **v2 Additions:** The introduction of a voice-command input path necessitates additional compliance measures, specifically the Modality Alternative Mapping.

## Detailed Criteria

### Pointer and Keyboard Navigation

- **Retention from v1:** The structure, color palette, and keyboard navigation have been confirmed unchanged from v1, ensuring continued compliance with all relevant WCAG 2.1 AA criteria.
  
### Voice Command Input Path

- **Implementation:** The voice-command input path allows learners to issue spoken commands for navigation and answer submission, transcribed by the browser's speech API.
- **Modality Alternative Mapping:** As per the 2025-Q4 Accessibility Bulletin, the following additional conformance items have been documented:

  1. **Equivalent Non-Voice Control:** For each voice command, an equivalent action using pointer or keyboard controls has been identified and documented.
  
  2. **Transcription-Failure Fallback:** In cases where voice commands are not transcribed accurately, a fallback mechanism ensures learners can continue using pointer or keyboard inputs without interruption.
  
  3. **Timeout and Usable Pathway:** A timeout feature is implemented to revert to a usable non-voice pathway if voice commands are not recognized within a specified duration. This ensures that users are not left in an unusable state.

- **Safety Measures:** The voice command system is designed to fail safely, ensuring that learners can always revert to a non-voice control pathway.

## Conclusion

The Learning Portal v2 has been audited and confirmed to meet WCAG 2.1 AA standards, with additional compliance measures for the newly introduced voice-command input path. All v1 criteria remain applicable, and the v2-specific changes have been documented and addressed in accordance with the latest accessibility policies.

This report is submitted to the Accessibility Board for final approval.
