# Conformance Report for Learning Portal v2

**Release Date:** [Insert Release Date]

## Executive Summary

The learning-portal v2 release adds a voice-command input path to the existing interface, which was previously compliant with WCAG 2.1 AA standards. This conformance report confirms that v2 retains all the accessibility features of v1 while introducing additional requirements to accommodate the new voice command functionality.

## Conformance to WCAG 2.1 AA

### Structure and Navigation

- **Page Structure:** The page structure remains unchanged from v1, ensuring continuity in accessibility standards.
- **Color Palette and Keyboard Navigation:** These elements are consistent with v1, maintaining compliance with established guidelines.

### Voice Command Input Path

The introduction of a voice-command input path necessitates additional conformance measures as outlined in the "Input Modality Update — Speech Interfaces" bulletin from Q4 2025.

#### Modality Alternative Mapping

For each voice command introduced in v2, the following must be documented:

1. **Equivalent Non-Voice Control:**
   - Every voice command must have a corresponding keyboard or pointer-based action that achieves the same function.

2. **Transcription-Failure Fallback:**
   - A clear fallback mechanism must be in place if voice command transcription fails. This ensures that users can continue to interact with the portal without disruption.

3. **Timeout and Usable Non-Voice Pathway:**
   - A timeout feature must return users to a usable non-voice pathway if the voice command is not completed within a reasonable time frame. This ensures users are not left in an unusable state.

#### Documentation and Fallback Mechanisms

- **Voice Command Mapping Documentation:**
  - A comprehensive mapping of voice commands to non-voice controls has been documented and included in this report.

- **Fallback Mechanisms:**
  - All voice commands have associated fallback mechanisms to ensure continuity of use in case of transcription errors or timeouts.

## Conclusion

The learning-portal v2 release maintains full compliance with WCAG 2.1 AA standards as per the v1 conformance report, with additional measures taken to accommodate the new voice-command input path. The Modality Alternative Mapping has been successfully documented, ensuring that all voice commands have equivalent non-voice controls, transcription-failure fallbacks, and timeout mechanisms.

This report is submitted for review and approval by the Accessibility Board.
