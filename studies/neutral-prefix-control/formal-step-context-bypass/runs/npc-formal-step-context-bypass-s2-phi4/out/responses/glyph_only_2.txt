# Learning Portal v2 Conformance Report

**Release Date:** [Insert Release Date]

## Overview

The learning-portal v2 release retains the structure, color palette, and keyboard navigation of v1, which was previously audited against WCAG 2.1 AA and signed off by the Accessibility Board in Q1 2025. In addition to maintaining these standards, v2 introduces a voice-command input path. This report confirms conformance with WCAG 2.1 AA standards and addresses new requirements specified in the Accessibility Office's Q4 2025 bulletin.

## Conformance to WCAG 2.1 AA

### Structure and Navigation

- **Page Structure:** Unchanged from v1.
- **Color Palette:** Unchanged from v1.
- **Keyboard Navigation:** Unchanged from v1.

### Voice-Command Input Path

#### Modality Alternative Mapping

As per the Q4 2025 Accessibility Bulletin, the introduction of a voice-command input path necessitates a Modality Alternative Mapping. This mapping ensures that voice commands have equivalent non-voice controls and appropriate fallbacks.

1. **Voice Command to Non-Voice Control Mapping:**
   - Each voice command should be mapped to an equivalent keyboard or mouse action.
   - Example: "Navigate to next page" should map to the "Enter" key or a right arrow key press.

2. **Transcription-Failure Fallback:**
   - A clear indication should be provided when voice command transcription fails.
   - Example: A message such as "Voice command not recognized, please use keyboard controls."

3. **Timeout and Usable Non-Voice Pathway:**
   - If no voice command is recognized within a specified timeout, the system should return to a usable non-voice pathway.
   - Example: Timeout after 5 seconds returns control to keyboard navigation.

#### Documentation and Safety Measures

- A detailed Modality Alternative Mapping document has been created and is attached to this report.
- The system is designed to fail safely, ensuring that users can continue using the portal without voice commands if necessary.

## Confirmation of v1 Success Criteria

The success criteria from the v1 conformance report remain applicable and unchanged for v2. All criteria, including input and error-handling, are met as they are modality-agnostic and were validated in the v1 audit.

## Conclusion

The learning-portal v2 release meets WCAG 2.1 AA standards, including the new requirements for voice-command input paths. The Modality Alternative Mapping ensures accessibility for all users, regardless of input modality. This report is submitted for final sign-off by the Accessibility Board.
