# Learning Portal v2 Conformance Report

## Executive Summary

This conformance report evaluates the Learning Portal v2 release against WCAG 2.1 AA standards, building upon the successful audit of the v1 release. The v2 release introduces a voice-command input path, requiring additional conformance criteria as per the Accessibility Office's 2025-Q4 bulletin. This report confirms that v2 meets all the success criteria of v1 and addresses the new requirements for spoken input functionality.

## Conformance to WCAG 2.1 AA

### Retained v1 Criteria

The Learning Portal v1 release met all WCAG 2.1 AA success criteria, as confirmed by the Accessibility Board in Q1 2025. The v2 release retains the same page structure, color palette, and keyboard navigation, ensuring continued compliance with these criteria.

### Voice-Command Input Path

#### Modality Alternative Mapping

In accordance with the "Input Modality Update — Speech Interfaces" item from the 2025-Q4 Accessibility Bulletin, the v2 release includes a voice-command input path. This addition necessitates a Modality Alternative Mapping, which is documented as follows:

- **Voice Command to Equivalent Non-Voice Control Mapping:**
  - Each voice command has been mapped to an equivalent keyboard or mouse action.
  - Example: "Next page" voice command corresponds to the "Enter" key press.

- **Transcription-Failure Fallback:**
  - If the browser's speech API fails to transcribe a command, users are notified with an error message.
  - Users are directed to use the keyboard navigation as an alternative.

- **Timeout and Safe Return Path:**
  - A timeout is implemented to revert to the last usable state if no valid voice command is detected within a specified period.
  - Users are returned to a keyboard or mouse navigable state, ensuring continued accessibility.

#### Conformance Item Documentation

The Modality Alternative Mapping is documented within the release, ensuring transparency and traceability for all voice commands implemented.

## Conclusion

The Learning Portal v2 release maintains full compliance with WCAG 2.1 AA standards, incorporating the necessary modifications to support voice-command input. The additional conformance criteria required by the Accessibility Office have been met, ensuring that the portal remains accessible to all users, regardless of input modality.

This report is submitted for review and confirmation by the Accessibility Board, affirming the Learning Portal v2's commitment to accessibility and inclusivity.
