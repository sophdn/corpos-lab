# Learning Portal v2 Conformance Report

**Release Date:** [Insert Release Date]

## Overview

This report confirms the conformance of the Learning Portal v2 release to WCAG 2.1 AA standards, building on the previously audited v1 release. The v1 release was successfully audited and signed off by the Accessibility Board in Q1 2025. The v2 release maintains all structural, visual, and navigational elements of v1, with the addition of a voice-command input path.

## Conformance to WCAG 2.1 AA

### Retained Criteria from v1

The following criteria, previously validated in the v1 release, remain applicable to v2:

- **Page Structure:** All headings, lists, and landmarks continue to be used correctly to ensure semantic structure and navigability.
- **Color Palette:** Contrast ratios meet the required standards for text and interactive elements.
- **Keyboard Navigation:** The portal remains fully navigable and functional using keyboard input alone, ensuring accessibility for users who cannot use a mouse.

### New Voice-Command Input Path

In addition to the existing input methods, v2 introduces a voice-command input path. This new feature has been evaluated for accessibility compliance as follows:

#### Modality Alternative Mapping

- **Voice Command to Non-Voice Control Mapping:** Each voice command has an equivalent non-voice control. For example, "Next" is mapped to the right arrow key, and "Submit" to the Enter key.
  
- **Transcription-Failure Fallback:** In cases where voice commands are not accurately transcribed, the system provides immediate feedback to the user, allowing them to use keyboard or pointer inputs as an alternative.
  
- **Timeout and Usable Non-Voice Pathway:** If voice commands are not recognized within a reasonable timeframe, the system automatically returns the user to a usable non-voice control pathway, ensuring continuous accessibility.

#### Additional Conformance Item

- **Documentation:** The Modality Alternative Mapping, including all voice commands, their equivalent non-voice controls, transcription-failure fallbacks, and timeouts, is thoroughly documented in the release notes and user guide.

## Conclusion

The Learning Portal v2 release meets all the WCAG 2.1 AA accessibility criteria, including the new requirements for the voice-command input path. The portal remains fully accessible to all users, with additional support for speech interfaces that have been carefully integrated to maintain accessibility standards.

The Accessibility Board is invited to review this report and confirm the conformance of the Learning Portal v2 release.
