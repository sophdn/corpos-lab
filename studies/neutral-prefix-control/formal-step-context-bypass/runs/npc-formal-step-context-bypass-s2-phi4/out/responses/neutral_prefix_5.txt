# Learning Portal v2 Conformance Report

## Overview
The Learning Portal v2 release retains the accessibility features of v1, with the addition of a voice-command input path. This report confirms that v2 complies with WCAG 2.1 AA standards and meets all criteria established in the previous conformance report for v1. This report includes specific considerations for the newly introduced voice-command functionality.

## Conformance to WCAG 2.1 AA
The Learning Portal v2 has been evaluated against the Web Content Accessibility Guidelines (WCAG) 2.1 AA. All success criteria from the v1 release remain applicable and have been met. The core accessibility features, including page structure, color palette, and keyboard navigation, have been maintained without alteration.

### Specific Considerations for Voice-Command Input Path
In accordance with the "Input Modality Update — Speech Interfaces" policy bulletin effective from November 1, 2025, the addition of a voice-command input path requires the documentation of a Modality Alternative Mapping. This mapping ensures that each voice command has an equivalent non-voice control, a transcription-failure fallback, and a timeout mechanism that returns the learner to a usable non-voice pathway.

#### Modality Alternative Mapping
- **Voice Command**: Specific spoken commands issued by learners to navigate and submit answers.
- **Equivalent Non-Voice Control**: Each voice command has an equivalent pointer or keyboard control that performs the same function.
- **Transcription-Failure Fallback**: If the browser's speech API fails to transcribe a voice command accurately, the system provides an alternative method for the user to complete the desired action using pointer or keyboard controls.
- **Timeout Mechanism**: A timeout is implemented to return the user to a usable non-voice pathway if the voice command input does not complete within a reasonable time frame. This ensures that users are not left in an inaccessible state.

## Documentation and Fallbacks
The voice-command input path has been thoroughly documented, ensuring that all voice commands are mapped to equivalent non-voice controls. The system's design includes robust fallback mechanisms to handle transcription failures and timeouts, maintaining accessibility for all users regardless of their chosen input modality.

## Conclusion
The Learning Portal v2 has been confirmed to meet WCAG 2.1 AA standards, including the new requirements for speech interfaces. The addition of the voice-command input path has been implemented with careful consideration of accessibility, ensuring that all users have equivalent access to the portal's features. The conformance report for v2 reflects these updates while confirming that all v1 criteria continue to be met.

This report is submitted for the Accessibility Board's review and approval.
