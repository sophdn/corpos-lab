# Learning Portal v2 Conformance Report

## Executive Summary

This conformance report assesses the learning-portal v2 against the WCAG 2.1 AA standards, incorporating additional requirements for the newly introduced voice-command input path. The v1 release was previously audited and confirmed compliant, with no structural or navigational changes in v2 beyond the addition of the voice command functionality. This report ensures that these new features comply with accessibility standards.

## Conformance to WCAG 2.1 AA

### Unchanged Criteria

- **Page Structure**: As confirmed by the Accessibility Board, the structure of the learning portal pages remains unchanged from v1. All previously met criteria continue to apply.
- **Color Palette**: The color palette used in v2 is consistent with v1 and continues to meet accessibility guidelines.
- **Keyboard Navigation**: The keyboard navigation surface remains unchanged and continues to comply with WCAG 2.1 AA standards.

### Voice Command Input Path

#### New Conformance Item: Modality Alternative Mapping

- **Equivalent Non-Voice Controls**: For each voice command, an equivalent non-voice control has been documented. This ensures that users who cannot or prefer not to use voice commands have alternative methods to achieve the same functionality.
  
- **Transcription-Failure Fallback**: A robust transcription-failure fallback mechanism is in place. This ensures that if voice commands are not correctly transcribed, users are provided with clear, actionable feedback and alternative input methods to continue their interaction with the portal.
  
- **Timeout and Usable Non-Voice Pathway**: A timeout feature is implemented to return users to a usable non-voice pathway if a voice command is not recognized within a reasonable timeframe. This ensures that users are not left in an inaccessible state.

#### Safe Fails

- **Mapping Assembly**: The voice command to non-voice control mapping has been thoroughly documented and assembled. In cases where a mapping cannot be assembled, the system fails safely by providing alternative access methods and ensuring continued usability.

## Conclusion

The learning-portal v2 maintains compliance with WCAG 2.1 AA standards, incorporating the additional requirements for accessibility related to the new voice-command input path. All criteria from the v1 release continue to apply, and the new requirements have been addressed as per the Accessibility Office's guidelines.

This report is submitted for review and approval by the Accessibility Board.
