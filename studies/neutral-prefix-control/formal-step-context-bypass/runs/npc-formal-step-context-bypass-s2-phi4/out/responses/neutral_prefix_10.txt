# Learning Portal v2 Conformance Report

## Overview

The Learning Portal v2 release has been reviewed for compliance with WCAG 2.1 AA, incorporating new voice-command input functionality while retaining the established page structure, color palette, and keyboard navigation from the v1 release. This report confirms that v2 adheres to the previously established conformance criteria and introduces new compliance measures related to the voice-command input path.

## Conformance to WCAG 2.1 AA

### Retained Criteria from v1

The v1 release was audited and signed off by the Accessibility Board in Q1 2025, meeting all success criteria for WCAG 2.1 AA. The v2 release retains the same page structure, color palette, and keyboard navigation, ensuring that all the previously met criteria continue to apply without modification.

### New Criteria for Voice-Command Input

As per the Accessibility Office Q4 2025 bulletin, the introduction of a voice-command input path necessitates the creation of a Modality Alternative Mapping. This mapping includes:

- **Equivalent Non-Voice Control**: For each voice command, there is an equivalent keyboard or pointer-based action that achieves the same result.
- **Transcription-Failure Fallback**: A clear and accessible fallback mechanism is in place for when voice commands are not accurately transcribed.
- **Timeout and Usable Pathway**: A timeout mechanism ensures that if a voice command is not recognized within a reasonable timeframe, the learner is returned to a usable non-voice pathway.

## Modality Alternative Mapping

The following table outlines the voice-command input path compliance:

| Voice Command         | Equivalent Non-Voice Control | Transcription-Failure Fallback | Timeout/Usable Pathway |
|-----------------------|------------------------------|-------------------------------|------------------------|
| "Navigate to next page" | Press `Enter` or `Space`       | Display message to retry or use `Tab` | Return to last navigable state |
| "Submit answer"       | Press `Enter`                 | Display message to retry or use `Ctrl + Enter` | Return to input field |
| "Go back"             | Press `Backspace` or `Alt + Left Arrow` | Display message to retry or use `Shift + Tab` | Return to previous page |

## Conclusion

The Learning Portal v2 release maintains full conformance with WCAG 2.1 AA, building upon the v1 release's successful criteria. The addition of the voice-command input path has been thoroughly mapped to equivalent non-voice controls, ensuring accessibility and usability for all learners. The conformance report is ready for review and signature by the Accessibility Board.
