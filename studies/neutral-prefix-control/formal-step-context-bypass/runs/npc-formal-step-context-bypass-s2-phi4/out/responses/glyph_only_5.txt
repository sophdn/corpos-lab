# Conformance Report: Learning Portal v2

## Executive Summary

The Learning Portal v2 release includes an additional voice-command input path on top of the existing keyboard and pointer navigation features. This report confirms that the Learning Portal v2 conforms to WCAG 2.1 AA standards. All success criteria met by the Learning Portal v1 remain applicable, and new requirements specific to the voice-command input path have been addressed in compliance with the Accessibility Board’s policies.

## Conformance to WCAG 2.1 AA

### Existing Success Criteria (Inherited from v1)

The Learning Portal v1 was audited against WCAG 2.1 AA standards, and all success criteria were met. The Learning Portal v2 retains the same page structure, color palette, and keyboard navigation as v1. Therefore, the existing success criteria from the v1 conformance report remain applicable:

- **1.1.1 Non-text Content**: All non-text content in Learning Portal v2 includes text alternatives.
- **1.3.1 Info and Relationships**: Information, structure, and relationships conveyed through presentation are preserved in text.
- **2.4.4 Link Purpose (In Context)**: The purpose of each link can be determined from the link text alone or the link text in context.
- **3.3.2 Labels or Instructions**: Labels or instructions are provided when content requires user input.
- **3.3.3 Error Identification**: Input errors are identified and described to the user in text.
- **4.1.2 Name, Role, Value**: All components of the user interface have accessible names, roles, and values.

### New Success Criteria for Voice-Command Input Path

In compliance with the Accessibility Office Q4 2025 bulletin, the following additional criteria have been evaluated for the voice-command input path:

- **Modality Alternative Mapping**: For every voice command, an equivalent non-voice control has been documented. The system provides a transcription-failure fallback and a timeout mechanism that returns the learner to a usable non-voice pathway.
  - Each voice command has been mapped to a corresponding keyboard or pointer action.
  - Transcription failures trigger a clear notification to the user, guiding them to use alternative input methods.
  - A timeout is implemented to ensure that if voice commands are not recognized within a reasonable period, the user is returned to a state where they can continue using other input methods.

## Conclusion

The Learning Portal v2 conforms to WCAG 2.1 AA standards, maintaining all previously met success criteria and introducing necessary compliance measures for the new voice-command input path. The Accessibility Board is requested to sign off on this conformance report.
