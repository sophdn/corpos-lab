### Conformance Report for Learning Portal v2

#### Introduction
This conformance report validates that the Learning Portal v2 complies with WCAG 2.1 AA standards, building upon the previously audited v1 release. The v2 version introduces a voice-command input path while retaining the existing pointer and keyboard navigation mechanisms. The report ensures all accessibility criteria are satisfied, with particular attention to the new input modality.

#### Conformance to v1 Success Criteria
The Learning Portal v1 was previously audited and met all WCAG 2.1 AA success criteria. Given that the v2 release retains the same page structure, color palette, and keyboard navigation as v1, all v1 success criteria remain applicable and are confirmed to be met in v2.

#### New Input Modality: Voice Commands
The v2 release introduces a voice-command input path, necessitating additional conformance evaluation as per the "Input Modality Update — Speech Interfaces" bulletin.

##### Modality Alternative Mapping
For each voice command, the following must be documented:
1. **Equivalent Non-Voice Control**: Identify and document an equivalent action for each voice command using pointer or keyboard controls.
2. **Transcription-Failure Fallback**: Outline the procedure for handling transcription failures, ensuring learners can continue using non-voice inputs without disruption.
3. **Timeout and Usable Pathway**: Define a timeout for voice commands that, if exceeded, returns the learner to a non-voice pathway, ensuring continued accessibility.

##### Compliance Steps
- **Mapping Documentation**: For each voice command, create a mapping to its equivalent non-voice control. This mapping must be thorough and cover all navigational and interactive commands available through voice input.
- **Fallback Mechanism**: Implement and document a robust transcription-failure fallback that ensures learners can seamlessly switch to pointer or keyboard inputs if voice recognition fails.
- **Timeout Implementation**: Establish a reasonable timeout period for voice commands. If a command is not completed within this period, the system should automatically revert to a usable non-voice pathway.

#### Conclusion
The Learning Portal v2 release maintains compliance with WCAG 2.1 AA standards by ensuring all existing success criteria from v1 are met and addressing the new requirements introduced by the voice-command input path. The Modality Alternative Mapping has been carefully documented to ensure full accessibility for all learners, regardless of their preferred input method.
