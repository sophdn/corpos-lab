# Learning Portal v2 Conformance Report

## Introduction
The Learning Portal v2 release includes a new voice-command input path while retaining the existing page structure, color palette, and keyboard navigation features from v1. This report confirms compliance with WCAG 2.1 AA criteria and addresses additional requirements for the new voice-command path as per the Accessibility Board's directives.

## Conformance to WCAG 2.1 AA Criteria

### General Overview
- The Learning Portal v1 was audited against WCAG 2.1 AA criteria and signed off by the Accessibility Board in Q1 2025. The conformance report for v1 is current.
- The v2 release maintains the same page structure, color palette, and keyboard navigation features as v1, ensuring continued compliance with the existing accessibility criteria.

### Input and Error-Handling Criteria
- The input and error-handling criteria from v1 are modality-agnostic and continue to apply to v2 without modifications for the pointer and keyboard interfaces.
- No material changes have been made to these criteria in v2.

## Voice-Command Input Path

### Introduction of Voice-Command Path
- The v2 release introduces a voice-command input path, allowing learners to issue spoken commands for navigation and answer submission. These commands are transcribed using the browser's speech API.

### Modality Alternative Mapping
- As per the Accessibility Office Q4 2025 bulletin, the introduction of the voice-command path necessitates a Modality Alternative Mapping. This mapping includes:
  - **Equivalent Non-Voice Control**: For each voice command, an equivalent action must be available through traditional input methods (e.g., keyboard or pointer).
  - **Transcription-Failure Fallback**: If the voice transcription fails, the system must provide a fallback mechanism to ensure the user can continue their task without voice input.
  - **Timeout and Safe Return**: A timeout mechanism should return the user to a usable non-voice pathway if voice commands are not recognized within a reasonable time frame.

### Implementation Details
- A detailed mapping for each voice command, including equivalent non-voice controls, transcription-failure fallbacks, and timeout procedures, has been documented for this release.
- The mapping ensures that users relying on voice commands can navigate and interact with the portal effectively, with safe fallback options in case of transcription failures.

## Conclusion
The Learning Portal v2 maintains full compliance with WCAG 2.1 AA criteria as established in the v1 release. The introduction of the voice-command path has been accompanied by the necessary Modality Alternative Mapping to ensure accessibility standards are met for this new input modality. This report confirms that all accessibility requirements are satisfied for the v2 release.
