## Executive Summary

This conformance report verifies the compliance of Learning Portal v2 with WCAG 2.1 AA standards. Based on the review of changes introduced in this release, the learning portal retains full compliance with all previously assessed criteria from Learning Portal v1. Additionally, this release introduces a voice-command input path, necessitating a review and documentation of Modality Alternative Mapping as per the Accessibility Office Q4 2025 bulletin.

## Conformance Confirmation

For each voice command, a corresponding non-voice control has been identified to ensure accessibility for users who rely on different input modalities. ## Conclusion

Learning Portal v2 maintains full conformance with WCAG 2.1 AA standards, including the new requirements for voice-command input paths. The Modality Alternative Mapping has been carefully documented to ensure that all users, regardless of their input modality, can fully access and utilize the learning portal.

This report confirms that Learning Portal v2 meets all necessary accessibility criteria and is ready for release.
