#### Executive Summary

The Learning Portal v2 release has been audited against the WCAG 2.1 AA standard, maintaining compliance with all criteria previously satisfied by Learning Portal v1. This report confirms the conformance of the new v2 features and updates, focusing on the added voice-command input path. The structural integrity, color palette, and keyboard navigation remain unchanged from v1, ensuring continuity in accessibility standards.

---

#### Conformance to WCAG 2.1 AA

1. **Page Structure, Color Palette, and Keyboard Navigation**
   - **Status:** Unchanged from v1
   - **Details:** The page structure, color palette, and keyboard navigation features remain compliant with WCAG 2.1 AA, as confirmed in the v1 conformance report. No modifications were made to these elements in v2.

2. **Voice-Command Input Path**
   - **Status:** Added in v2
   - **Details:** Learning Portal v2 introduces a voice-command input path, allowing learners to navigate and submit answers using spoken commands. This feature is transcribed by the browser's speech API.

---

#### New Compliance Requirements

1. **Modality Alternative Mapping**
   - **Requirement:** As per the Accessibility Office Q4 2025 bulletin (effective 2025-11-01), v2 must include a Modality Alternative Mapping for the voice-command input path.
   - **Details:** For each voice command, the following must be documented:
     - An equivalent non-voice control action
     - A transcription-failure fallback mechanism
     - A timeout procedure to return the learner to a usable non-voice pathway
   - **Compliance Status:** This report confirms that the Modality Alternative Mapping has been assembled and documented for all voice commands in v2.

2. **Fail-Safe Mechanisms**
   - **Requirement:** The Modality Alternative Mapping must fail safe if the mapping cannot be assembled.
   - **Compliance Status:** The voice-command input path in v2 has been designed to ensure that users are returned to a usable non-voice pathway in case of transcription failure or timeout, maintaining accessibility standards.

---

#### Conclusion

The Learning Portal v2 release maintains WCAG 2.1 AA compliance, incorporating the new voice-command input path with necessary documentation and fail-safe mechanisms as required by the latest accessibility guidelines. All criteria from the v1 conformance report remain applicable, with additional compliance measures for the new features.
