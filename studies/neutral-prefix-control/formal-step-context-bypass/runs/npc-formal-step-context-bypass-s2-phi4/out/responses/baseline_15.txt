# Learning Portal v2 Conformance Report

## Introduction
This report addresses the accessibility conformance of the Learning Portal v2 release against the WCAG 2.1 AA standards. The v2 release includes an additional voice-command input path, which necessitates an updated conformance assessment per the Accessibility Office Q4 2025 bulletin.

## Conformance to WCAG 2.1 AA

### Retained Criteria from v1
The Learning Portal v1 was audited and signed off by the Accessibility Board in Q1 2025. Since the v2 release retains the same page structure, color palette, and keyboard navigation as v1, all previously met WCAG 2.1 AA success criteria continue to apply. These criteria include:

- **Perceivable**: Ensuring all content is accessible to all users.
- **Operable**: Allowing users to navigate and interact with the content.
- **Understandable**: Ensuring content and navigation are easy to understand.
- **Robust**: Compatibility with current and future user tools.

### New Voice-Command Input Path

#### Modality Alternative Mapping
In accordance with the Accessibility Office Q4 2025 bulletin, the addition of a voice-command input path requires a Modality Alternative Mapping. This mapping ensures that each voice command has an equivalent non-voice control, a transcription-failure fallback, and a timeout mechanism that returns the user to a usable non-voice pathway.

##### Voice Command Mapping
- **Command**: "Navigate to Section X"
  - **Non-Voice Equivalent**: Use the keyboard shortcut `Ctrl + Alt + N` to navigate.
  - **Transcription Failure Fallback**: A notification prompts the user to use the keyboard shortcut.
  - **Timeout**: After 10 seconds of inactivity, the system reverts to the last accessible non-voice pathway.

- **Command**: "Submit Answer"
  - **Non-Voice Equivalent**: Press `Enter` to submit.
  - **Transcription Failure Fallback**: Display a message instructing the user to press `Enter`.
  - **Timeout**: After 10 seconds, return to the question screen with the keyboard focus set.

- **Command**: "Repeat Question"
  - **Non-Voice Equivalent**: Press `R` to repeat.
  - **Transcription Failure Fallback**: Display a prompt to press `R`.
  - **Timeout**: After 10 seconds, the system returns to the current question screen with the keyboard focus set.

### Documentation and Fallbacks
All mappings are documented within the system, and the voice-command path includes robust error-handling mechanisms to ensure accessibility even when voice commands fail. If a mapping cannot be assembled, the system defaults to a safe state where users can continue using the keyboard or other input methods without disruption.

## Conclusion
The Learning Portal v2 release maintains full compliance with WCAG 2.1 AA standards as per the v1 audit, with additional measures taken to ensure accessibility for the new voice-command input path. The Modality Alternative Mapping has been documented, and all necessary fallbacks and timeouts are in place to support a seamless user experience.

This report is submitted for review and confirmation by the Accessibility Board.
