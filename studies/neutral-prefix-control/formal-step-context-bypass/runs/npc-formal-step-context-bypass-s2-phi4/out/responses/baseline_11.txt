# Learning Portal v2 Conformance Report

## Executive Summary

This report provides a pre-release conformance confirmation for the Learning Portal v2, scheduled for release on Friday. The v2 update builds upon the WCAG 2.1 AA conformance achieved by the Learning Portal v1, which was audited and signed off by the Accessibility Board in Q1 2025. The v2 release introduces a voice-command input path while maintaining the existing page structure, color palette, and keyboard navigation. This report verifies that v2 meets the accessibility standards outlined in WCAG 2.1 AA, incorporating the additional requirements specified in the 2025 Q4 Accessibility Bulletin for speech interfaces.

## Conformance to WCAG 2.1 AA

### Structural and Visual Consistency

- **Page Structure**: The page structure remains unchanged from v1, ensuring continuity in accessibility features and compliance with WCAG 2.1 AA.
- **Color Palette**: The color palette is consistent with v1, maintaining color contrast ratios that meet WCAG 2.1 AA requirements.
- **Keyboard Navigation**: Keyboard navigation continues to function as in v1, providing a complete and accessible experience for users relying on keyboard input.

### Voice Command Input Path

The introduction of a voice-command input path necessitates additional considerations under the "Input Modality Update — Speech Interfaces" item from the 2025 Q4 Accessibility Bulletin. The following sections address these considerations:

#### Modality Alternative Mapping

For each voice command, the following elements have been documented:

1. **Equivalent Non-Voice Control**: Each voice command has a corresponding keyboard or pointer control that performs the same function, ensuring that all interactions are accessible via non-voice modalities.

2. **Transcription-Failure Fallback**: A clear and user-friendly error message or alternative pathway is provided if the voice command is not recognized or transcribed correctly, ensuring users are not left without options.

3. **Timeout and Usable Non-Voice Pathway**: A timeout mechanism is implemented to return the learner to a usable non-voice pathway if the voice interaction is not completed within a reasonable time frame. This ensures that users can continue their learning experience without interruption.

#### Safety and Usability

- **Fail-Safe Mechanism**: The system is designed to fail safely, reverting to a non-voice control pathway if the voice command input cannot be processed or mapped correctly. This ensures continuous accessibility and usability for all learners.

## Conclusion

The Learning Portal v2 maintains full conformance to WCAG 2.1 AA, incorporating the necessary updates for the addition of voice-command input as specified in the 2025 Q4 Accessibility Bulletin. The v2 release retains all accessibility features of v1 while enhancing accessibility through the introduction of voice commands, ensuring a comprehensive and inclusive learning experience for all users.

This report confirms that the Learning Portal v2 meets all required accessibility standards and guidelines. The Accessibility Board is invited to review this report for final confirmation before the release.
