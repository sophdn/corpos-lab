# Learning Portal v2 Conformance Report

**Release Date:** Friday

## Overview

The Learning Portal v2 builds upon the WCAG 2.1 AA conformance of the v1 release, which was audited and signed off by the Accessibility Board in Q1 2025. This report focuses on the additional voice-command input path introduced in v2, while confirming that the unchanged elements from v1 still meet all success criteria.

## Conformance to WCAG 2.1 AA

### Unchanged Elements from v1

- **Page Structure:** Retains the same structural design as v1, ensuring accessibility for screen readers and other assistive technologies.
- **Color Palette:** Continues to meet contrast and color accessibility requirements.
- **Keyboard Navigation:** Remains unchanged, supporting all navigation and interaction functions through keyboard controls.

### New Voice-Command Input Path

The introduction of a voice-command input path requires an additional conformance item as per the Accessibility Office Q4 2025 bulletin. This section details the Modality Alternative Mapping for the new feature.

#### Modality Alternative Mapping

For each voice command, the following must be documented:

1. **Equivalent Non-Voice Control:**
   - Every voice command has a corresponding keyboard or pointer control.
   - Example: A voice command to "Submit Answer" is equivalent to pressing the "Enter" key.

2. **Transcription-Failure Fallback:**
   - If the voice command is not recognized, the system provides feedback and allows the user to retry or use an alternative input method.
   - Example: A message appears prompting the user to try again or use the keyboard.

3. **Timeout and Non-Voice Pathway:**
   - If no voice input is detected within a reasonable timeframe, the system returns the user to a state where non-voice controls are accessible.
   - Example: The user is returned to the last active keyboard interface after a 10-second timeout.

#### Implementation Details

- **Voice Command Recognition:** Utilizes the browser speech API for transcribing spoken commands.
- **Fallback Mechanisms:** Designed to fail safely, ensuring users can always navigate and interact using non-voice methods.
- **Documentation:** All mappings and fallback procedures are documented within the system and included in this report.

## Conclusion

The Learning Portal v2 has been evaluated for WCAG 2.1 AA conformance, incorporating the new voice-command input path while maintaining the accessibility standards set by the v1 release. The additional conformance item, Modality Alternative Mapping, has been thoroughly documented to ensure compliance with the latest accessibility policies.

This report is submitted for review to the Accessibility Board.
