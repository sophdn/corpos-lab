## Executive Summary

The Learning Portal v2 release has been evaluated for accessibility compliance, building upon the WCAG 2.1 AA conformance previously achieved by the Learning Portal v1. This conformance report confirms the unchanged aspects of v1 and introduces assessments specific to the new voice-command input path as per the Accessibility Office Q4 2025 bulletin requirements.

### Conformance Status

- **Page Structure:** Unchanged from v1, remains compliant.
- **Color Palette:** Unchanged from v1, remains compliant.
- **Keyboard Navigation:** Unchanged from v1, remains compliant.
- **Voice-Command Input Path:** New addition in v2, assessed for compliance as per the latest policy bulletin.

## Detailed Conformance Assessment

### Unchanged Criteria from v1

The Learning Portal v2 retains all the success criteria from v1, which have been previously audited and signed off. The following criteria remain compliant:

1. **Page Structure:** Logical and consistent structure, using semantic HTML elements.
2. **Color Palette:** Sufficient contrast ratios and color usage that supports accessibility.
3. **Keyboard Navigation:** Full keyboard operability, including all interactive elements and navigation paths.
4. **Input and Error-Handling:** Written in modality-agnostic terms, applicable to all input methods, including voice.

### New Voice-Command Input Path

In accordance with the "Input Modality Update — Speech Interfaces" policy bulletin, the Learning Portal v2 introduces a voice-command input path. The following specific compliance items have been assessed:

1. **Modality Alternative Mapping:**
   - **Voice Command to Non-Voice Control Mapping:** Each voice command has been mapped to an equivalent non-voice control action. This ensures that all functionalities accessible via voice are also accessible via keyboard and other input methods.
   - **Transcription-Failure Fallback:** In cases where voice transcription fails, the system provides clear feedback to the user and suggests alternative input methods.
   - **Timeout Mechanism:** A timeout is implemented to return the user to a usable non-voice pathway if no valid voice command is detected within a reasonable time frame.

2. **Documentation and Fallback Safety:**
   - All mappings and fallback mechanisms are documented within the system and included in this report.
   - The system is designed to fail safely, ensuring users can continue to interact with the portal using non-voice inputs if the voice-command path encounters issues.

## Conclusion

The Learning Portal v2 has been assessed for accessibility compliance with WCAG 2.1 AA standards. The unchanged elements from v1 remain compliant, and the new voice-command input path has been evaluated and documented in accordance with the latest policy requirements. The conformance report confirms that the Learning Portal v2 meets the necessary accessibility criteria.

This report is submitted for review and approval by the Accessibility Board.
