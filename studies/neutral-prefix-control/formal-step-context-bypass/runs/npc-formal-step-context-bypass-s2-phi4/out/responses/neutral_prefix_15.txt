# Learning Portal v2 Conformance Report

**Release Version:** v2  
**Audit Date:** Q4 2025

## Introduction

This report confirms the conformance of the Learning Portal v2 release to WCAG 2.1 AA standards, building upon the successful audit of the v1 release in Q1 2025. The v2 release introduces a voice-command input path while retaining the existing page structure, color palette, and keyboard navigation from v1.

## Conformance to WCAG 2.1 AA

### Structure and Navigation

- **Page Structure:** The structure remains unchanged from v1, ensuring continued compliance with WCAG 2.1 AA success criteria related to page structure.
- **Color Palette:** The color palette has not been altered, maintaining compliance with contrast and color use requirements.
- **Keyboard Navigation:** Keyboard navigation remains fully functional and compliant, as established in the v1 audit.

### New Voice-Command Input Path

The v2 release introduces a voice-command input path, necessitating additional conformance considerations:

#### Modality Alternative Mapping

In accordance with the Accessibility Office Q4 2025 bulletin, the following Modality Alternative Mapping has been documented:

1. **Voice Commands and Equivalent Non-Voice Controls:**
   - Each voice command issued by learners has been mapped to an equivalent non-voice control action, ensuring accessibility for all users.

2. **Transcription-Failure Fallback:**
   - A clear fallback mechanism is in place for instances where voice transcription fails, allowing users to continue using non-voice pathways without interruption.

3. **Timeout Mechanism:**
   - A timeout feature has been implemented to return learners to a usable non-voice pathway if voice input does not succeed within a specified period.

4. **Documentation and Fail-Safe:**
   - The mapping and associated mechanisms are fully documented within the release documentation. A fail-safe ensures users are not left without accessible options if the voice command system encounters issues.

## Conclusion

The Learning Portal v2 release maintains full conformance with WCAG 2.1 AA standards, including the successful integration of a voice-command input path. All success criteria from the v1 release continue to apply, and the additional requirements for the new input modality have been met.

This report is submitted for review by the Accessibility Board.
