## Introduction

This conformance report evaluates the Learning Portal v2 against WCAG 2.1 AA standards, based on the pre-release conformance confirmation process. The v2 release maintains the accessibility features of v1 while adding a voice-command input path. The v1 release was audited and signed off by the Accessibility Board in Q1 2025. This report confirms that all criteria from the v1 report continue to apply and documents the additional requirements introduced by the new voice-command functionality.

## v1 Conformance Criteria

The Learning Portal v1 was audited and confirmed to meet all success criteria of WCAG 2.1 AA. These criteria include, but are not limited to:

- **Page Structure:** Proper use of headings, lists, and landmarks.
- **Color Palette:** Sufficient color contrast for text and images of text.
- **Keyboard Navigation:** Full operability through keyboard controls.
- **Input and Error-Handling:** Modality-agnostic criteria ensuring accessible input methods and clear error messages.

Since the v2 release retains the page structure, color palette, and keyboard navigation from v1, these criteria continue to apply without modification.

## v2 Specific Changes

### Voice Command Input Path

The v2 release introduces a voice-command input path, allowing learners to navigate and submit answers using spoken commands. This addition requires compliance with the "Input Modality Update — Speech Interfaces" as outlined in the Accessibility Office Q4 2025 bulletin.

#### Modality Alternative Mapping

For each voice command, the following mappings have been documented:

- **Equivalent Non-Voice Control:** For every voice command, an equivalent keyboard or pointer control is provided to ensure that users relying on other input methods can achieve the same outcome.
  
- **Transcription-Failure Fallback:** In cases where voice commands are not recognized or transcribed accurately, the system provides clear feedback and allows users to revert to a non-voice control method without losing context or progress.
  
- **Timeout and Usable Non-Voice Pathway:** A timeout mechanism ensures that if the voice command does not complete within a reasonable time frame, the system returns the learner to a usable non-voice pathway, maintaining accessibility and usability.

#### Documentation and Safety Measures

- **Mapping Documentation:** Detailed documentation of the voice-command mappings is included in the release notes and accessible to developers and accessibility reviewers.
  
- **Failing Safe:** The system is designed to fail safely, ensuring that any issues with voice command recognition do not disrupt the user experience or accessibility of the portal.

## Conclusion

The Learning Portal v2 meets WCAG 2.1 AA standards, maintaining the accessibility features of v1 and successfully integrating the new voice-command input path in compliance with the latest accessibility policies. This report confirms the continued applicability of v1 criteria and documents the additional measures taken to ensure the accessibility of the voice-command functionality.
