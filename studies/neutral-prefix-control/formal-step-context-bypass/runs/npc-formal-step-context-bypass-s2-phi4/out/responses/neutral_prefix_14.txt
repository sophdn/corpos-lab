# Learning Portal v2 Conformance Report

## Executive Summary
The Learning Portal v2 release builds upon the successful conformance of the v1 release, maintaining its adherence to WCAG 2.1 AA standards. This version introduces a new voice-command input path, which necessitates an updated conformance item specific to spoken input.

## Accessibility Standards
The Learning Portal v2 has been assessed against WCAG 2.1 AA criteria, ensuring that all users, regardless of their abilities, have equitable access to the learning materials.

## Conformance Items

### Input and Error Handling
- **Keyboard Navigation**: The keyboard navigation and error-handling criteria from v1 remain unchanged and continue to be compliant.
- **Color Palette and Page Structure**: These aspects have also been retained from v1, ensuring consistent visual and structural accessibility.

### Voice Command Input Path
- **Modality Alternative Mapping**: As per the Accessibility Office Q4 2025 bulletin, the following new conformance item has been added:
  - **Equivalent Non-Voice Controls**: For every voice command, an equivalent non-voice control has been documented.
  - **Transcription-Failure Fallback**: A clear fallback mechanism is in place for transcription failures, ensuring users can continue using non-voice pathways.
  - **Timeout and Usable Pathway**: A timeout is implemented that returns the learner to a usable non-voice pathway if voice commands are not recognized within a specified period.

### Safety and Usability
- **Fail-Safe Mechanism**: The system is designed to fail safely by returning to non-voice pathways if the modality alternative mapping cannot be assembled or if voice recognition fails.

## Conclusion
The Learning Portal v2 retains all the accessibility features of its predecessor while introducing a new voice-command input path. The addition of the Modality Alternative Mapping ensures that this new feature meets the necessary accessibility standards. The conformance report confirms that the Learning Portal v2 meets all WCAG 2.1 AA criteria, including the newly added requirements for spoken input.

This report is prepared for review and confirmation by the Accessibility Board. All changes and new conformance items have been documented to ensure transparency and accountability in maintaining high accessibility standards.
