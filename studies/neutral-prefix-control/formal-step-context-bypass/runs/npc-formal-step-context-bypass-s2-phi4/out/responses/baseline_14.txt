# Learning Portal v2 Conformance Report

**Report Date:** [Insert Date]  
**Release Version:** Learning Portal v2

## Executive Summary

This conformance report verifies the compliance of Learning Portal v2 with WCAG 2.1 AA standards, building upon the successful audit of the Learning Portal v1 release, which was signed off by the Accessibility Board in Q1 2025. This report focuses on the additions and modifications introduced in v2, specifically the integration of a voice-command input path, while confirming that the criteria previously met by v1 remain applicable.

## Conformance with WCAG 2.1 AA

### Retained Criteria from v1

The Learning Portal v2 retains the same page structure, color palette, and keyboard navigation as v1. As such, all WCAG 2.1 AA criteria met in v1 remain applicable and satisfied in v2. For detailed verification of these criteria, please refer to the v1 conformance report.

### New Criteria for Voice-Command Input Path

In accordance with the "Input Modality Update — Speech Interfaces" bulletin effective from 2025-11-01, the following additional conformance item has been documented for Learning Portal v2:

#### Modality Alternative Mapping

- **Voice Command to Non-Voice Control Mapping:**
  - For each voice command available in v2, an equivalent non-voice control action has been identified and documented. This ensures that all functionalities accessible via voice are also accessible through traditional input methods, maintaining accessibility for users who may not use voice input.

- **Transcription-Failure Fallback:**
  - A robust fallback mechanism is in place for instances where voice command transcription fails. This includes:
    - Providing clear error messages indicating the failure.
    - Offering alternative input methods to continue interaction without disruption.

- **Timeout Mechanism:**
  - A timeout feature ensures that if a voice command is not recognized within a specified period, the user is automatically returned to a usable non-voice pathway. This prevents indefinite waiting and ensures seamless navigation.

- **Documentation and Fallback Safety:**
  - The mappings and mechanisms described above have been thoroughly documented within the development and user support materials.
  - The system is designed to fail safe, ensuring that any failure in the voice-command path does not impede overall accessibility or user experience.

## Conclusion

The Learning Portal v2 has been reviewed and confirmed to meet WCAG 2.1 AA standards, with additional considerations for the newly introduced voice-command input path. The criteria from v1 remain applicable and satisfied, and the new requirements for modality alternative mapping have been addressed in accordance with the latest accessibility guidelines.

This report is submitted to the Accessibility Board for review and approval.
