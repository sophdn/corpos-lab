# Learning Portal v2 Conformance Report

**Audited Against**: WCAG 2.1 AA  
**Release Version**: v2  
**Signed Off By**: Accessibility Board  
**Effective Date**: Q4 2025  

## Conformance Overview

The learning-portal v2 release has been reviewed for accessibility conformance against WCAG 2.1 AA standards. This report confirms that the v2 release maintains all the conformance criteria established in the previous v1 release, with additional considerations introduced by new features.

### Retained Conformance from v1

The v2 release retains the following from the v1 release, which was audited and confirmed in Q1 2025:

- **Page Structure**: The underlying structure of the pages remains unchanged, ensuring continued conformance with established accessibility standards.
- **Color Palette**: The color palette from v1 remains unchanged, supporting sufficient contrast ratios for text and visual elements.
- **Keyboard Navigation**: The existing keyboard navigation capabilities are retained, ensuring that all interactive elements are accessible via keyboard.

### New Feature: Voice-Command Input Path

The v2 release introduces a voice-command input path, allowing learners to navigate and submit answers using spoken commands. This feature is transcribed by the browser's speech API. The following new conformance item has been added to address this enhancement:

#### Modality Alternative Mapping

To ensure accessibility for users of the new voice-command feature, a Modality Alternative Mapping has been created. This mapping includes:

- **Voice Commands and Equivalent Non-Voice Controls**: For each voice command, an equivalent non-voice control has been identified, allowing users to perform the same actions using traditional input methods.
  
- **Transcription-Failure Fallback**: A robust fallback mechanism is in place for instances where voice transcription fails. This ensures that users can continue to interact with the portal using alternative input methods without disruption.
  
- **Timeout Mechanism**: A timeout has been implemented to return the learner to a usable non-voice pathway if voice input is not detected within a reasonable timeframe. This ensures that users are not indefinitely stuck in a voice-input mode.

### Conformance Confirmation

The Accessibility Board has reviewed the changes introduced in the v2 release and confirmed that:

- The v2 release retains all successful criteria from the v1 release.
- The new voice-command feature has been adequately addressed with the Modality Alternative Mapping.
- The portal continues to meet WCAG 2.1 AA standards, including the new requirements introduced by the accessibility policy bulletin.

## Conclusion

The learning-portal v2 release has been thoroughly audited and confirmed to meet WCAG 2.1 AA accessibility standards. The introduction of the voice-command input path has been successfully integrated with appropriate accessibility considerations, ensuring that the portal remains inclusive and accessible to all users.
