# Learning Portal v2 Conformance Report

## Introduction
This conformance report addresses the accessibility compliance of the Learning Portal v2 release. The report confirms adherence to WCAG 2.1 AA guidelines, building upon the successful audit of the Learning Portal v1 release.

## Confirmation of v1 Conformance
The Learning Portal v1 was audited and signed off by the Accessibility Board in Q1 2025. The following points from the v1 conformance report are confirmed to remain unchanged in v2:

- **Page Structure**: The page structure remains consistent with v1.
- **Color Palette**: No changes have been made to the color palette.
- **Keyboard Navigation**: The keyboard navigation surface remains unchanged.

## Changes in v2
The primary change in v2 is the introduction of a voice-command input path, utilizing the browser speech API to allow learners to issue spoken commands for navigation and answer submission.

### New Accessibility Requirements for Voice Command Path

#### Modality Alternative Mapping
In compliance with the "Input Modality Update — Speech Interfaces" item from the Accessibility Office Q4 2025 bulletin, the following mapping requirements are documented for the voice-command path:

- **Voice Command to Non-Voice Control Mapping**: For each voice command, an equivalent non-voice control must be documented. This ensures that all functionality accessible via voice commands is also accessible through traditional input methods.

- **Transcription-Failure Fallback**: A clear fallback mechanism must be in place for scenarios where speech transcription fails. This ensures that users can continue to interact with the portal without interruption.

- **Timeout and Usable Non-Voice Pathway**: A timeout must be established to return the learner to a usable non-voice pathway if the voice-command input is inactive for a specified duration. This ensures that users are not locked into a single input modality.

## Conclusion
The Learning Portal v2 retains the accessibility features of v1 while introducing a new voice-command input path. The additional requirements for modality alternative mapping have been addressed to ensure compliance with WCAG 2.1 AA standards. The Accessibility Board is requested to review and sign off on this conformance report.
