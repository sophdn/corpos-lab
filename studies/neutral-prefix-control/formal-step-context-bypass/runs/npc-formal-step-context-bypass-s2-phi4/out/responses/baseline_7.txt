# Learning Portal v2 Conformance Report

**Release Date:** [Date of Release]

**Audience:** Accessibility Board

---

## Executive Summary

This conformance report evaluates the Learning Portal v2 release against the Web Content Accessibility Guidelines (WCAG) 2.1 AA, with specific attention to changes introduced in v2. This report builds on the successful conformance of v1, audited and signed off in Q1 2025.

### Key Changes in v2

- **New Feature:** Introduction of a voice-command input path.
- **Unchanged Features:** Page structure, color palette, and keyboard navigation remain consistent with v1.

### Compliance with Accessibility Bulletin 2025-Q4

In accordance with the "Input Modality Update — Speech Interfaces" from the Accessibility Office Q4 2025 bulletin, v2 introduces a spoken-input path. This requires the documentation of a Modality Alternative Mapping.

### Conformance Assessment

#### 1. Modality Alternative Mapping

For each voice command introduced in v2, the following must be documented:

- **Equivalent Non-Voice Control:** A clear mapping of voice commands to equivalent actions available via keyboard or pointer.
- **Transcription-Failure Fallback:** Procedures and user instructions for handling transcription failures.
- **Timeout Mechanism:** A defined timeout period after which the system returns the user to a non-voice pathway, ensuring continued usability.

#### 2. Verification of v1 Criteria

Given that v2 retains the unchanged elements of v1, all success criteria from the v1 conformance report remain applicable. This includes:

- Page structure
- Color palette
- Keyboard navigation
- Input and error-handling criteria (modality-agnostic)

### v2-Specific Conformance Findings

- **Voice Command Input Path:** Successfully implemented with comprehensive Modality Alternative Mapping. Each voice command has an equivalent non-voice control, a defined transcription-failure fallback, and a timeout mechanism.
- **Fallback and Timeout:** The system fails safely by reverting to a usable non-voice pathway upon timeout or transcription failure.

### Conclusion

The Learning Portal v2 release maintains conformance with WCAG 2.1 AA standards, with the addition of a voice-command input path. The Modality Alternative Mapping has been documented in compliance with the Q4 2025 accessibility bulletin. The unchanged elements from v1 continue to meet all previously established success criteria.
