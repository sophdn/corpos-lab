### Conformance Report: Learning Portal v2 Release

**Release Date:** Friday (2025-11-01)

#### Introduction

The Learning Portal v2 release maintains its conformance to WCAG 2.1 AA standards, building upon the foundation established by the Learning Portal v1 release, which was audited and signed off by the Accessibility Board in Q1 2025. This report confirms that the v2 release complies with existing accessibility criteria and introduces necessary updates to accommodate the new voice-command input path.

#### Conformance to WCAG 2.1 AA

**1. Structural Integrity**
- **Page Structure:** The page structure remains consistent with v1, ensuring all structural elements continue to meet accessibility standards.
- **Color Palette:** The color palette is unchanged, maintaining compliance with contrast and color differentiation criteria.

**2. Keyboard Navigation**
- **Unchanged Keyboard Surface:** The keyboard navigation paths and functionalities remain as in v1, ensuring continued compliance with all relevant criteria.

#### New Voice-Command Input Path

**Introduction of Voice-Command Path:**
- The v2 release introduces a voice-command input path, allowing learners to issue spoken commands for navigation and submission of answers. This input path is transcribed using the browser speech API.

**Modality Alternative Mapping:**
- In accordance with the Accessibility Office Q4 2025 bulletin, the following Modality Alternative Mapping has been documented for the v2 release:

  - **Voice Command Equivalents:** For each voice command, an equivalent non-voice control has been identified and documented.
  - **Transcription-Failure Fallback:** A robust transcription-failure fallback mechanism is in place, ensuring users can continue using the portal without voice input if necessary.
  - **Timeout Mechanism:** A timeout feature has been implemented to return the learner to a usable non-voice pathway if voice input is not recognized within a specified time frame.

**Fallback and Safety Measures:**
- The voice-command path includes a fail-safe mechanism that ensures learners can revert to non-voice interactions seamlessly, maintaining accessibility and usability.

#### Confirmation of v1 Criteria

All success criteria from the v1 conformance report remain applicable and met in the v2 release. The addition of the voice-command path does not alter the compliance status of existing input and error-handling criteria, which were written in modality-agnostic terms.

#### Conclusion

The Learning Portal v2 release is confirmed to be in conformance with WCAG 2.1 AA standards, including the additional requirements for the new voice-command input path. This report provides assurance to the Accessibility Board that all necessary accessibility criteria have been met and documented.

**Next Steps:**
- The conformance report is ready for review and signature by the Accessibility Board.
