### Learning Portal v2 Conformance Report

**Release Date:** [Insert Date]

**Version:** Learning Portal v2

**Conformance Standard:** WCAG 2.1 AA

---

#### Executive Summary

This conformance report addresses the accessibility compliance of the Learning Portal v2 release, building upon the successful WCAG 2.1 AA conformance of Learning Portal v1. The v2 release introduces a voice-command input path while retaining the unchanged structure, color palette, and keyboard navigation from v1. In accordance with the Accessibility Office Q4 2025 bulletin, this report includes a Modality Alternative Mapping to ensure comprehensive accessibility.

---

#### Conformance to WCAG 2.1 AA Criteria

1. **Page Structure and Color Palette**
   - **Status:** Unchanged from v1
   - **Details:** The Learning Portal v2 retains the page structure, color palette, and keyboard navigation as validated in the v1 conformance report. These elements continue to meet all WCAG 2.1 AA criteria.

2. **Keyboard Navigation**
   - **Status:** Unchanged from v1
   - **Details:** The keyboard navigation capabilities remain consistent with the previous version, ensuring all interactive elements are accessible via keyboard.

3. **Voice-Command Input Path**
   - **Status:** New feature
   - **Details:** The Learning Portal v2 introduces a voice-command input path, allowing learners to navigate and submit answers using spoken commands. This feature is transcribed by the browser's speech API.

4. **Modality Alternative Mapping**
   - **Status:** Newly implemented
   - **Details:** In compliance with the Accessibility Office Q4 2025 bulletin, a Modality Alternative Mapping has been developed. This mapping includes:
     - **Voice Command Equivalence:** Each voice command has an equivalent non-voice control.
     - **Transcription-Failure Fallback:** A clear fallback mechanism is in place for transcription failures.
     - **Timeout and Usable Pathway:** A timeout feature ensures users are returned to a usable non-voice pathway if necessary.

---

#### Detailed Conformance Assessment

1. **Perceivable**
   - **Text Alternatives:** All non-text content continues to have text alternatives.
   - **Time-based Media:** Captions and audio descriptions are provided as required.
   - **Adaptable:** Content is structured to be presented in different ways without losing information or structure.
   - **Distinguishable:** Color is not used as the sole visual means of conveying information.

2. **Operable**
   - **Keyboard Accessible:** All functionalities are accessible via keyboard.
   - **Enough Time:** Users have sufficient time to read and use content.
   - **Seizures and Physical Reactions:** Content does not cause seizures or physical reactions.
   - **Navigable:** Navigation mechanisms are clear and consistent.

3. **Understandable**
   - **Readable:** Text content is readable and understandable.
   - **Predictable:** Web pages operate in predictable ways.
   - **Input Assistance:** Errors are clearly identified, described, and suggested corrections are provided.

4. **Robust**
   - **Compatible:** Content can be interpreted reliably by a wide variety of user agents, including assistive technologies.

---

#### Modality Alternative Mapping

- **Voice Command:** "Next"
  - **Equivalent Non-Voice Control:** Press the "Tab" key.
  - **Transcription-Failure Fallback:** Visual focus moves to the next element.
  - **Timeout:** If no voice command is detected within 5 seconds, navigation defaults to keyboard control.

- **Voice Command:** "Submit"
  - **Equivalent Non-Voice Control:** Press the "Enter" key.
  - **Transcription-Failure Fallback:** Visual confirmation of submission attempt.
  - **Timeout:** If no voice command is detected within 5 seconds, submission defaults to keyboard control.

- **Voice Command:** "Cancel"
  - **Equivalent Non-Voice Control:** Press the "Esc" key.
  - **Transcription-Failure Fallback:** Visual indication of cancellation attempt.
  - **Timeout:** If no voice command is detected within 5 seconds, cancellation defaults to keyboard control.

---

#### Conclusion

The Learning Portal v2 meets all WCAG 2.1 AA criteria, with the addition of a voice-command input path and corresponding Modality Alternative Mapping. The unchanged elements from v1 continue to comply with accessibility standards, ensuring a robust and inclusive user experience.
