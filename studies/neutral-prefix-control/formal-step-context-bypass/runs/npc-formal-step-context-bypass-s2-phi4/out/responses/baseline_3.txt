# Learning Portal v2 Conformance Report

## Executive Summary
The Learning Portal v2 release has been reviewed for accessibility compliance against WCAG 2.1 AA standards. This report confirms that all criteria from the Learning Portal v1 release, which was signed off by the Accessibility Board in Q1 2025, continue to be met. Additionally, the v2 release introduces a voice-command input path, which necessitates compliance with the new "Input Modality Update — Speech Interfaces" policy effective 2025-11-01.

## Conformance to WCAG 2.1 AA
The Learning Portal v2 retains the page structure, color palette, and keyboard navigation features from v1, ensuring continued compliance with the previously met WCAG 2.1 AA criteria. The successful criteria from the Learning Portal v1 conformance report remain applicable to v2.

## Voice-Command Input Path Compliance
### Introduction
The Learning Portal v2 introduces a voice-command input path, allowing learners to issue spoken commands for navigation and answer submission. This feature is implemented using the browser speech API for transcription.

### Modality Alternative Mapping
In accordance with the "Input Modality Update — Speech Interfaces" policy, the following Modality Alternative Mapping has been documented for the voice-command path:

1. **Equivalent Non-Voice Control:**
   - For each voice command, an equivalent keyboard or pointer interaction is provided. For example:
     - Voice Command: "Go to next question"
     - Equivalent Non-Voice Control: Press the "Tab" key or click the "Next" button

2. **Transcription-Failure Fallback:**
   - In the event of transcription failure, the system provides clear feedback to the user and allows them to retry the voice command or switch to a non-voice input method.

3. **Timeout and Usable Pathway:**
   - A timeout mechanism is implemented to return the learner to a usable non-voice pathway if no voice command is detected within a specified time frame.

### Safe Failure
The system is designed to fail safely by ensuring that any failure in the voice-command path does not prevent access to content or functionality. Users can seamlessly switch to keyboard or pointer interactions if needed.

## Conclusion
The Learning Portal v2 release maintains full compliance with WCAG 2.1 AA standards, as previously established in v1. The addition of the voice-command input path has been thoroughly documented to meet the requirements of the new accessibility policy. The Accessibility Board is invited to review and sign off on this conformance report.
