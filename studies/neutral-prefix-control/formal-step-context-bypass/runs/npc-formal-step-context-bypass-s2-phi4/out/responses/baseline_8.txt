# Conformance Report for Learning Portal v2

## Introduction

This report provides a pre-release conformance confirmation for the Learning Portal v2, which introduces a voice-command input path in addition to the existing pointer and keyboard navigation options. The Learning Portal v1 was previously audited and signed off by the Accessibility Board in Q1 2025. The v1 conformance report remains current, and the board has confirmed that v2 retains the same page structure, color palette, and keyboard navigation as v1. This report focuses on the new voice-command feature and confirms that v1 criteria still apply.

## WCAG 2.1 AA Conformance

### 1. Perceivable

- **Success Criteria:** All criteria from the v1 conformance report are met and remain applicable to v2.
- **Additional Considerations:** Ensure that voice-command feedback is perceivable through auditory means, providing clear and accessible auditory cues.

### 2. Operable

- **Success Criteria:** All criteria from the v1 conformance report are met and remain applicable to v2.
- **Voice Command Path:**
  - **Modality Alternative Mapping:** Each voice command has an equivalent non-voice control (e.g., keyboard shortcut or pointer action).
  - **Transcription-Failure Fallback:** If voice commands are not transcribed correctly, provide a clear notification and allow the user to switch to a non-voice control.
  - **Timeout Mechanism:** Implement a timeout that returns the learner to a usable non-voice pathway if the voice command is not completed within a reasonable time.

### 3. Understandable

- **Success Criteria:** All criteria from the v1 conformance report are met and remain applicable to v2.
- **Additional Considerations:** Ensure that voice-command instructions and feedback are clear and understandable, avoiding technical jargon.

### 4. Robust

- **Success Criteria:** All criteria from the v1 conformance report are met and remain applicable to v2.
- **Compatibility:** Ensure that the voice-command feature is compatible with various browsers and assistive technologies.

## Additional Conformance Item: Modality Alternative Mapping

In accordance with the Accessibility Office Q4 2025 bulletin, the following mappings have been documented for each voice command:

- **Command:** "Navigate to next slide"
  - **Equivalent Non-Voice Control:** Arrow key right or "Next" button
  - **Transcription-Failure Fallback:** Notify user of error and suggest using arrow key right
  - **Timeout Mechanism:** Return focus to "Next" button after 5 seconds

- **Command:** "Submit answer"
  - **Equivalent Non-Voice Control:** Enter key or "Submit" button
  - **Transcription-Failure Fallback:** Notify user of error and suggest using Enter key
  - **Timeout Mechanism:** Return focus to "Submit" button after 5 seconds

- **Command:** "Repeat instructions"
  - **Equivalent Non-Voice Control:** "Repeat" button
  - **Transcription-Failure Fallback:** Notify user of error and suggest using "Repeat" button
  - **Timeout Mechanism:** Return focus to "Repeat" button after 5 seconds

## Conclusion

The Learning Portal v2 maintains conformance with WCAG 2.1 AA standards, incorporating the new voice-command input path while ensuring all v1 success criteria remain applicable. The Modality Alternative Mapping has been documented for each voice command, with transcription-failure fallbacks and timeout mechanisms in place. This report confirms that the Learning Portal v2 meets the necessary accessibility requirements as outlined by the Accessibility Board and the Q4 2025 bulletin.
