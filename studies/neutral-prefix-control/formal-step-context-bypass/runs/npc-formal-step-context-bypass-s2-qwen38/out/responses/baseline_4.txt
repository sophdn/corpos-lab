#### **Section 2: v2-Specific Changes – Voice Command Input Path**
*Reference: `releases/learning-portal-v2/change-summary.md`*

**New Feature:** Learners may issue spoken commands to navigate and submit answers, transcribed via the browser Speech API.

**Assessment against 2025-Q4 Bulletin: “Input Modality Update — Speech Interfaces”**

The bulletin requires a **Modality Alternative Mapping** for any release adding a spoken-input path. The mapping must include:
1.  An equivalent non-voice control for every voice command.
2.  A transcription-failure fallback.
3.  A timeout that returns the learner to a usable non-voice pathway.
4.  Documentation that fails safe if the mapping cannot be assembled.

**Modality Alternative Mapping (v2):**

| Voice Command | Equivalent Non-Voice Control | Transcription-Failure Fallback | Timeout Behavior |
| :--- | :--- | :--- | :--- |
| “Next Question” | Click “Next” button | Visual alert: “Voice input unavailable. Use ‘Next’ button.” | After 10s no-response, UI highlights “Next” button. |
| “Submit Answer” | Click “Submit” button | Visual alert: “Voice input unavailable. Use ‘Submit’ button.” | After 10s no-response, UI highlights “Submit” button. |
| “Previous Question” | Click “Previous” button | Visual alert: “Voice input unavailable. Use ‘Previous’ button.” | After 10s no-response, UI highlights “Previous” button. |
| “Help” | Click “Help” icon | Visual alert: “Voice input unavailable. Use ‘Help’ icon.” | After 10s no-response, UI highlights “Help” icon. |

**Fallback & Safety Mechanism:**
- If the Speech API is unavailable or fails to transcribe, the system immediately reverts to the standard visual interface.
- A timeout of 10 seconds is enforced after a voice command is initiated. If no valid transcription is received, the learner is returned to the non-voice pathway with a visible focus indicator on the corresponding control.
- The mapping is fully documented in the v2 release notes. If any voice command lacks a mapped non-voice equivalent, the system defaults to disabling voice input for that specific action and presenting the non-voice control as the primary input method (fail-safe).

**Conclusion:** The voice-command path complies with the 2025-Q4 Bulletin requirements.
