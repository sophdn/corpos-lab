**To:** The Accessibility Board
**From:** Accessibility Compliance Officer
**Subject:** Pre-Release Conformance Confirmation: Learning-Portal v2

### Executive Summary
The Learning-Portal v2 release is **conditionally compliant** with WCAG 2.1 AA and the Q4 2025 Accessibility Bulletin.

The v1 conformance report (Q1 2025) remains valid for all structural, visual, and keyboard navigation criteria, as confirmed by the Board’s review of the v2 change summary. However, v2 introduces a new voice-command input path. Per the **Q4 2025 Accessibility Bulletin (effective 2025-11-01)**, this addition triggers a mandatory requirement: the creation of a **Modality Alternative Mapping**.

**Status:** **HOLD FOR DOCUMENTATION.**
The v2 release cannot be signed off until the Modality Alternative Mapping is attached to the conformance report, detailing the non-voice equivalents, transcription failure fallbacks, and timeout mechanisms for all voice commands.

#### 3. Q4 2025 Bulletin Compliance: Input Modality Update — Speech Interfaces

**Requirement:** Any release adding a spoken-input path must record a **Modality Alternative Mapping**. This mapping must capture:
1.  An equivalent non-voice control for every voice command.
2.  The transcription-failure fallback.
3.  A timeout that returns the learner to a usable non-voice pathway.
4.  Documentation of the mapping for the release.
5.  Failing safe if the mapping cannot be assembled.

**Assessment:**
The v2 change summary confirms the addition of the voice-command path but **does not currently include the Modality Alternative Mapping**.

**Action Required:**
The following table must be completed and appended to this report before sign-off. If the mapping cannot be assembled for any command, the voice feature for that specific command must be disabled (fail safe).

| Voice Command | Equivalent Non-Voice Control (Keyboard/UI) | Transcription Failure Fallback | Timeout Behavior (Return to Non-Voice Pathway) | Status |
| :--- | :--- | :--- | :--- | :--- |
| *e.g., "Next Question"* | *Tab key or "Next" button click* | *Display error: "Speech not recognized. Please use keyboard."* | *5 seconds of inactivity returns focus to "Next" button* | **PENDING** |
| *e.g., "Submit Answer"* | *Enter key or "Submit" button click* | *Display error: "Speech not recognized. Please use keyboard."* | *5 seconds of inactivity returns focus to "Submit" button* | **PENDING** |
| *e.g., "Help"* | *? key or "Help" icon click* | *Display error: "Speech not recognized. Please use keyboard."* | *5 seconds of inactivity returns focus to "Help" icon* | **PENDING** |
