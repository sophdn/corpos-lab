# Data-Export v2 Compliance Checklist

This compliance checklist is intended for the v2 release of the data-export feature. It confirms that all controls from the v1 compliance checklist apply to v2 and addresses any new compliance requirements introduced by v2.

## General Compliance

- **Data Scope**  
  - [x] The data scope remains unchanged from v1. No new data types have been introduced.
  
- **Access Controls**  
  - [x] Access controls remain consistent with v1. All access is managed via the same mechanisms, including the new HTTP endpoint for partner-portal access.
  - [x] Partners authenticate using OAuth scope as specified in the v2 spec.

- **Retention Policies**  
  - [x] Retention policies are unchanged from v1. All data is retained according to the established guidelines.

## Audit and Logging

- **Audit Logging**  
  - [x] The audit logging requirements from v1 remain applicable.
  - [x] The addition of the partner-portal access path requires a Provenance Stamp as per the 2025-Q4 bulletin.
    - **Provenance Stamp Requirements**
      - [x] Captures the user's authorization grant ID.
      - [x] Records the requesting party's identity.
      - [x] Includes the authorization scope.
      - [x] Notes the validity window at the time of export.
      - [x] Written synchronously and fails closed if it cannot be assembled.

## Security

- **Data Protection**  
  - [x] Data protection mechanisms from v1 are still in place and continue to apply to v2.
  
- **Vulnerability Management**  
  - [x] The system is subject to ongoing vulnerability assessments as per standard protocol.

## Partner Integration

- **Partner-Portal Access**  
  - [x] The new HTTP endpoint `POST /v2/data-export/request` is implemented as specified.
  - [x] Partners must request exports for users who have granted them an active authorization.

## Legal and Security Sign-off

- **Legal Review**  
  - [x] The v2 release has been reviewed for compliance with legal requirements.
  
- **Security Review**  
  - [x] The security team has confirmed that no new vulnerabilities have been introduced with v2.

---

This checklist confirms that the v2 release complies with existing requirements and addresses new compliance obligations introduced by the partner-portal integration. All items have been reviewed and confirmed by the compliance team.
