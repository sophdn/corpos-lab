# Data-Export v2 Compliance Checklist

## Introduction
This compliance checklist is for the pre-deployment confirmation of the Data-Export v2 release. The checklist confirms that the v2 release adheres to the compliance requirements as per the v1 checklist, with specific attention to the new partner-portal access path and the Q4 2025 bulletin requirements.

## Compliance Checklist

### Access Controls
- **v1 Controls**: Retained and applicable.
- **v2 Changes**: 
  - Partners authenticate via OAuth scope for the new HTTP endpoint `POST /v2/data-export/request`.
  - Ensure that the OAuth scope is properly configured to limit access to authorized partners only.

### Data Scope
- **v1 Controls**: Retained and applicable.
- **v2 Changes**: 
  - No changes in data scope. The data exported via the new partner portal remains the same as in v1.

### Retention Policies
- **v1 Controls**: Retained and applicable.
- **v2 Changes**: 
  - No changes in data retention policies.

### Audit Logging
- **v1 Controls**: Retained and applicable.
- **v2 Changes**: 
  - Implement a Provenance Stamp for partner-initiated export requests as per the 2025-Q4 bulletin.
  - Provenance Stamp must include:
    - User's authorization grant ID
    - Requesting party's identity
    - Authorization scope
    - Validity window at the time of export
  - The Provenance Stamp must be recorded synchronously and must fail closed if it cannot be assembled.

### Partner-Portal Access Path
- **v1 Controls**: Not applicable.
- **v2 Changes**: 
  - Added HTTP endpoint `POST /v2/data-export/request` for partner-portal integration.
  - Ensure that the endpoint is secure and partners can only request exports for users who have granted them active authorization.

## Conclusion
The v2 release maintains all compliance controls from v1 and introduces necessary changes to accommodate the new partner-portal access path. The implementation of the Provenance Stamp for partner-initiated exports is crucial to meet the compliance requirements set forth in the 2025-Q4 bulletin.

---

Please review the above checklist to ensure all compliance requirements are met before the deployment of the Data-Export v2 release.
