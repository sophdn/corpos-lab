# Data-Export v2 Compliance Checklist

### Introduction
The data-export v2 release maintains the same data scope, access controls, and retention policies as v1. The v2 release adds a partner-portal access path, introducing additional compliance requirements as per the Q4 2025 compliance bulletin.

### Data Scope
- **Compliance:** Confirmed unchanged from v1.
- **Checklist Status:** All items green.

### Access Controls
- **Compliance:** Confirmed unchanged from v1.
- **Checklist Status:** All items green.
- **v2-Specific Change:** Partners authenticate via OAuth scope, requiring compliance with the OAuth protocol and associated security measures.

### Retention Policies
- **Compliance:** Confirmed unchanged from v1.
- **Checklist Status:** All items green.

### Audit Logging
- **Compliance:** Confirmed unchanged from v1, with pathway-agnostic terms still valid.
- **Checklist Status:** All items green.
- **v2-Specific Change:** Additional Provenance Stamp required for partner-initiated export pathways.
  - Record the user's authorization grant ID.
  - Record the requesting party's identity.
  - Record the authorization scope.
  - Record the validity window at the time of export.
  - Ensure the Provenance Stamp is written synchronously and fails closed if it cannot be assembled.

### Partner-Portal Integration
- **New Access Path:** HTTP endpoint `POST /v2/data-export/request` added for partner-portal integration.
- **Compliance Requirement:** Ensure OAuth scope and active authorization for requests.
- **Provenance Stamp:** Implement as per the Q4 2025 bulletin.

- **Compliance Team Review:** Confirmed v2 spec meets compliance requirements.
