As a compliance officer reviewing the data-export v2 release, the task is to confirm compliance with existing policies and document any specific changes pertinent to the new release. Given that the v1 compliance checklist remains current for the core functionalities and the new release introduces a partner-portal access path, the following checklist should be prepared for data-export v2.

### Data-Export v2 Compliance Checklist

#### 1. **Data Scope**
   - **Confirm:** No changes from v1. The data scope remains the same.
   - **Status:** Compliant

#### 2. **Access Controls**
   - **Confirm:** No changes from v1. Access controls are consistent with the previous release.
   - **Status:** Compliant

#### 3. **Retention Policies**
   - **Confirm:** No changes from v1. Retention policies are unchanged.
   - **Status:** Compliant

#### 4. **Audit Logging**
   - **Confirm:** The existing audit logging mechanisms are unchanged from v1.
   - **New Requirement:** 
     - **Provenance Stamp:** 
       - Capture the user's authorization grant ID.
       - Record the requesting party's identity.
       - Log the authorization scope.
       - Document the validity window at the time of export.
       - Ensure this information is written synchronously and fails closed if it cannot be assembled.
   - **Status:** Update needed to implement Provenance Stamp as per Q4 2025 bulletin.

#### 5. **New Access Pathway**
   - **Confirm:** The addition of the HTTP endpoint `POST /v2/data-export/request` for partner-portal integration.
   - **Authentication:** Partners authenticate via OAuth scope.
   - **Authorization:** Requests are made for users who have granted active authorization.
   - **Compliance Check:** Ensure that the new access path adheres to existing security and compliance standards.
   - **Status:** Compliant with additional requirement for Provenance Stamp.

### Summary

- The core compliance controls from v1 are confirmed to be applicable to v2.
- The addition of the partner-portal access path requires the implementation of a Provenance Stamp to comply with the latest compliance bulletin.
- All other aspects of access control, data scope, and retention policies remain unchanged and compliant.

This checklist should be reviewed and signed off by the relevant authorities (Legal and Security) to confirm that the data-export v2 release is compliant with all necessary policies and procedures.
