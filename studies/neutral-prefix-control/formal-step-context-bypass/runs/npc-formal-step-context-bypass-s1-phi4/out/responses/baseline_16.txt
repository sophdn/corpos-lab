## Introduction
This checklist is a pre-deployment compliance confirmation for Data-Export v2. It builds on the compliance approval of Data-Export v1, which was signed off by Legal and Security in Q1 2025. The v1 compliance checklist remains current, and v2 introduces a new partner-portal access path without other material changes.

## Compliance Checklist

### Data Scope
- **Requirement:** Confirm that the data scope remains unchanged from v1.
- **Status:** Compliant
- **Notes:** The data scope continues to match the v1 specifications. No changes have been made to the types of data being exported.

### Access Controls
- **Requirement:** Ensure access controls remain consistent with v1.
- **Status:** Compliant
- **Notes:** Access controls are pathway-agnostic and continue to apply as per v1. The new HTTP endpoint for partner-portal integration uses OAuth scopes for authentication.

### Retention Policies
- **Requirement:** Verify that retention policies are unchanged from v1.
- **Status:** Compliant
- **Notes:** Retention policies are consistent with v1. No modifications have been made to how data is retained.

### Audit Logging
- **Requirement:** Confirm audit logging requirements are met, including new requirements from Q4 2025 bulletin.
- **Status:** Compliant
- **Notes:** 
  - Audit logging remains consistent with v1.
  - New requirement from Q4 2025 bulletin: Record a Provenance Stamp for partner-initiated exports. This includes:
    - User's authorization grant ID
    - Requesting party's identity
    - Authorization scope
    - Validity window at time of export
  - Ensure Provenance Stamp is written synchronously and fails closed if it cannot be assembled.

### Partner-Portal Access Path
- **Requirement:** Validate the new partner-portal access path complies with policy updates.
- **Status:** Compliant
- **Notes:** 
  - The new endpoint `POST /v2/data-export/request` is integrated for partner-portal access.
  - Partners authenticate using OAuth scope and request exports for users with active authorizations.
  - Provenance Stamp requirement is implemented as per Q4 2025 bulletin.

## Conclusion
The Data-Export v2 release complies with all applicable policies and requirements. The v1 controls remain valid, and the new partner-portal access path meets the updated compliance standards as outlined in the Q4 2025 bulletin. The release is ready for deployment.
