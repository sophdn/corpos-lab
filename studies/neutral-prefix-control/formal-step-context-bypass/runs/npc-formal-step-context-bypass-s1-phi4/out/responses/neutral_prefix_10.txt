# Data-Export v2 Compliance Checklist

## Data Scope

- [x] Confirm that the data scope for v2 remains unchanged from v1.  
  - *Rationale*: v2 retains the same data scope as v1, with no new data types or categories being exported.

## Access Controls

- [x] Verify that access controls remain consistent with v1 specifications.  
  - *Rationale*: v2 maintains the same CLI access controls as v1, with the addition of the partner-portal access path.
- [x] Ensure that partners authenticate using OAuth scope for the new HTTP endpoint.  
  - *Rationale*: Partners must authenticate using OAuth scope to request exports, ensuring that only authorized users can initiate data exports.

## Audit Logging

- [x] Confirm audit logging requirements from v1 still apply.  
  - *Rationale*: v1's audit logging requirements are pathway-agnostic and thus apply to the new v2 partner-portal access path.
- [x] Implement the Provenance Stamp for the new partner-initiated export pathway.  
  - *Rationale*: Per the Compliance Office Q4 2025 bulletin, any deployment adding a partner-initiated export pathway must record an additional audit entry capturing specific details such as the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at the time of export.

## Retention Policies

- [x] Confirm that data retention policies remain unchanged from v1.  
  - *Rationale*: v2 does not alter the data retention policies established in v1.

## Additional Considerations

- [x] Ensure the HTTP endpoint `POST /v2/data-export/request` is secured and complies with existing security protocols.  
  - *Rationale*: The new partner-portal access path must adhere to the same security standards as the existing CLI interface.

---

This checklist confirms that the v2 release maintains compliance with existing standards while incorporating necessary changes for the new partner-portal access path. All applicable controls from v1 continue to apply, with specific attention given to the new audit logging requirements as mandated by the latest compliance bulletin.
