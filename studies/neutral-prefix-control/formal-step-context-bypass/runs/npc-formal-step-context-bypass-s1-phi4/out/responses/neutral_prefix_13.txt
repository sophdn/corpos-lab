# Data-Export v2 Compliance Checklist

## Signed Off By: [Your Name], Compliance Officer  
## Date: [Current Date]

### Data Scope
- **Status:** Green
- **Details:** The data scope for v2 remains unchanged from v1. No new data types or fields are being exported.

### Access Controls
- **Status:** Green
- **Details:** Access controls remain consistent with v1. The introduction of the partner-portal access path through `POST /v2/data-export/request` uses OAuth for authentication, ensuring that partners authenticate with the necessary scope and only request exports for users who have granted them active authorization.

### Retention Policies
- **Status:** Green
- **Details:** Retention policies remain unchanged from v1. Data is retained according to the existing policy without any alterations.

### Audit Logging
- **Status:** Green
- **Details:** 
  - The audit logging mechanism remains unchanged from v1.
  - In accordance with the "Data Export Process Update — Partner Integrations" from the Q4 2025 bulletin, v2 introduces a new requirement: an additional audit entry known as a Provenance Stamp.
  - **Provenance Stamp Requirements:**
    - Must capture the user's authorization grant ID.
    - Must record the requesting party's identity.
    - Must include the authorization scope.
    - Must log the validity window at the time of export.
    - Must be written synchronously and fail closed if it cannot be assembled.

### Security
- **Status:** Green
- **Details:** Security measures remain consistent with v1. The introduction of the partner-portal access path adheres to existing security protocols, ensuring that OAuth scopes are properly managed.

### Regulatory Compliance
- **Status:** Green
- **Details:** No changes in regulatory compliance requirements. All operations remain within the legal framework established for v1.

### Documentation
- **Status:** Green
- **Details:** Documentation has been updated to include the new partner-portal access path and the requirements for the Provenance Stamp.

### Overall Compliance
- **Status:** Green
- **Details:** All compliance requirements for data-export v2 have been reviewed and confirmed. The v2 release aligns with existing controls and incorporates necessary updates as per the latest compliance bulletin.
