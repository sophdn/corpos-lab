 # Learning-Portal v2 Conformance Report

## Introduction

This report confirms the conformance of Learning-Portal v2 to WCAG 2.1 AA guidelines as of the pre-release conformance confirmation date. This report is not a full re-audit, but rather a confirmation of the changes made from v1 to v2 and an assessment of the new voice-command input path.

## Overview

The Learning-Portal v2 retains the page structure, color palette, and keyboard navigation from v1, which were audited and signed off by the Accessibility Board in Q1 2025. The v2 release introduces a voice-command input path in addition to the existing input and keyboard surfaces.

## Success Criteria Met (from v1 report, all still applicable)

### Perceivable

1.1 Text Alternatives: Provide text alternatives for any non-text content so that it can be changed into other forms people need, such as large print, braille, speech, symbols, or simpler language.

1.2 Time-based Media: Provide alternatives for time-based media.

1.3 Adaptable: Create content that can be presented in different ways (for example simpler layout) without losing information or structure.

1.4 Distinguishable: Make it easier for users to see and hear content including separating foreground from background.

### Operable

2.1 Keyboard Accessible: Make all functionality available from a keyboard.

2.4 Navigable: Provide ways to help users navigate, find content, and determine where they are.

### Understandable

3.1 Make Content Readably: Make text content readable and understandable.

3.2 Predictable: Make Web pages appear and operate in predictable ways.

3.3 Input Assistance: Help users avoid and correct mistakes.

### Robust

4.1 Maximize Compatibility: Maximize compatibility with current and future user tools.

## New Success Criteria for Voice-Command Input Path (Modality Alternative Mapping)

### Input Modality Alternative Mapping

- Spoken Command Equivalents: A mapping of each voice command to an equivalent non-voice control.
- Transcription Failure Fallback: A mechanism to provide the user with an alternative method of control in case of transcription failure.
- Timeout and Fail-Safe Mechanism: A timeout that returns the learner to a usable non-voice pathway, and a mechanism that fails safely if the mapping cannot be assembled.

## Conclusion

The Learning-Portal v2 meets all the success criteria from the v1 report, and introduces a new Modality Alternative Mapping for the voice-command input path. This report confirms the conformance of Learning-Portal v2 to WCAG 2.1 AA guidelines.
