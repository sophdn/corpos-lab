Learning Portal v2 Conformance Report
=====================================

Date: 2025-11-01

Conformance Level: WCAG 2.1 AA

Overview
--------

The Learning Portal v2 has been reviewed for conformance against WCAG 2.1 AA standards. This report covers new elements and features introduced in v2, compared to the v1 release which was audited and signed off by the Accessibility Board in Q1 2025.

Changes from v1 to v2
----------------------

- Voice-command input path: Learners can now issue spoken commands to navigate and submit answers, transcribed by the browser speech API.

Success Criteria (WCAG 2.1 AA)
-------------------------------

### Perceivable

1.1.1 Non-text Content: A text alternative is provided for all non-text content. [V1 criteria met]
1.2.1 Audio-only and Video-only (Prerecorded): All prerecorded audio content has synchronized equivalent visual content. [V1 criteria met]
1.2.2 Captions (Live): Captions are provided for all live audio content in sync with the content. [New criteria]

### Operable

2.1.1 Keyboard: All functionality can be operated from a keyboard. [V1 criteria met]
2.4.7 Focus Visible: Focus is always visible. [V1 criteria met]
2.5.3 Label in Name: For user interface components with labels, the name from the label can be programmatically determined. [V1 criteria met]

### Understandable

3.1.1 Language: The default human language of each web page can be programmatically determined. [V1 criteria met]
3.1.2 Language of Parts: The human language of each part of the content can be programmatically determined even if they are not part of the default human language. [V1 criteria met]
3.2.2 On Input: The purpose of each user input is identified. [V1 criteria met]

### Robust

4.1.1 Parsing: The content can be parsed. [V1 criteria met]
4.1.2 Name, Role, Value: Information about the elements and their values can be programmatically determined. [V1 criteria met]
