Learning Portal v2 Conformance Report
=====================================

Date: November 1, 2025

Audited Against: WCAG 2.1 AA

Signed Off By: Accessibility Board

This report covers the Learning Portal v2 release, effective November 1, 2025. The v1 conformance report remains current and can be found at `releases/learning-portal-v1/conformance-report.md`.

Overview
--------

The Learning Portal v2 retains the page structure, color palette, and keyboard navigation from v1, which were found to be compliant with WCAG 2.1 AA in Q1 2025 (see `releases/learning-portal-v1/conformance-report.md`). In addition, v2 introduces a voice-command input path, which builds upon the existing input and error-handling criteria written in modality-agnostic terms.

Voice Command Input Path
-------------------------

Voice command input is now available in Learning Portal v2. The voice-command path allows learners to issue spoken commands to navigate and submit answers, transcribed by the browser speech API. The Accessibility Office Q4 2025 bulletin (`policy/bulletins/2025-Q4-accessibility-bulletin.md`) requires that any release adding a spoken-input path also documents a Modality Alternative Mapping.

Modality Alternative Mapping
-----------------------------

For each voice command, we provide an equivalent non-voice control, a transcription-failure fallback, and a timeout that returns the learner to a usable non-voice pathway. The mapping is documented for the Learning Portal v2 release and fails safe if the mapping cannot be assembled.

Conclusion
----------

The Learning Portal v2 release is compliant with WCAG 2.1 AA, as confirmed by the Accessibility Board. The v2 conformance report has been updated to account for the new voice-command input path and associated Modality Alternative Mapping.
