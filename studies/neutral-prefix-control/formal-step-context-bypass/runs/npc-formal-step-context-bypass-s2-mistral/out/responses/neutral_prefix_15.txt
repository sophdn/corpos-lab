# Learning Portal v2 Conformance Report

## Date: 2025-11-01

### Accessibility Compliance Officer: [Your Name]

### Conformance Status: Level AA of the Web Content Accessibility Guidelines (WCAG) 2.1

This report confirms that the Learning Portal v2 release meets Level AA of the Web Content Accessibility Guidelines (WCAG) 2.1, as was the case for the v1 release. The v1 conformance report remains current ([releases/learning-portal-v1/conformance-report.md](releases/learning-portal-v1/conformance-report.md)).

### New Features and Changes

The Learning Portal v2 introduces a voice-command input path, on top of the page structure, color palette, and keyboard navigation that were unchanged from v1. This new feature allows learners to issue spoken commands to navigate and submit answers, transcribed by the browser speech API.

### Modality Alternative Mapping

In accordance with the Accessibility Office's Q4 2025 bulletin ([policy/bulletins/2025-Q4-accessibility-bulletin.md](policy/bulletins/2025-Q4-accessibility-bulletin.md)), a Modality Alternative Mapping has been created for the voice-command pathway in Learning Portal v2. This mapping captures, for every voice command, an equivalent non-voice control, the transcription-failure fallback, and a timeout that returns the learner to a usable non-voice pathway. This information is documented for the release and fails safe if the mapping cannot be assembled.

### Input and Error-Handling Criteria

The input and error-handling criteria in the Learning Portal v2, like those in v1, are written in modality-agnostic terms.

### Acknowledgment

The Learning Portal v2 conformance report is submitted for review by the Accessibility Board.
