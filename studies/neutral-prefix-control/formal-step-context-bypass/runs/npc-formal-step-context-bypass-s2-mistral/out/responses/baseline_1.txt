```markdown
Learning Portal v2 Conformance Report
=====================================

Issued: 2025-11-01

Audit Date: 2025-10-31

Audit Team: Accessibility Board

Conformance Level: WCAG 2.1 AA

**Summary**

This report confirms the conformance of Learning Portal v2 to the WCAG 2.1 AA standards. The v1 release was previously audited and signed off in Q1 2025, and the v2 release retains the v1's page structure, color palette, and keyboard navigation while adding a voice-command input path.

**Success Criteria Met**

All success criteria from the v1 report (`releases/learning-portal-v1/conformance-report.md`) have been met in v2. The input and error-handling criteria were written in modality-agnostic terms, ensuring that they remain applicable to the new voice-command input path.

**Modality Alternative Mapping**

In accordance with the Accessibility Office Q4 2025 bulletin (`policy/bulletins/2025-Q4-accessibility-bulletin.md`), a Modality Alternative Mapping has been recorded for the voice-command input path. The mapping captures an equivalent non-voice control, a transcription-failure fallback, and a timeout that returns the learner to a usable non-voice pathway for each voice command.

**V2-Specific Changes**

The addition of a voice-command input path is the primary change in v2. The voice-command path allows learners to issue spoken commands to navigate and submit answers, which are transcribed by the browser speech API.

**Acknowledgment**

The Accessibility Board acknowledges the successful implementation of the voice-command input path in Learning Portal v2 while ensuring that the WCAG 2.1 AA conformance remains intact.
```
