```
# Learning-Portal v2 Conformance Report

## Overview

The Learning-Portal v2 release has been tested against the Web Content Accessibility Guidelines (WCAG) 2.1 AA standards, built upon the conformance-tested Learning-Portal v1 release. This report documents the conformance status of Learning-Portal v2, which includes the addition of a voice-command input path on top of the existing page structure, color palette, and keyboard navigation from v1.

## WCAG 2.1 AA Success Criteria

The following criteria have been met from the Learning-Portal v1 Conformance Report, signed off in Q1 2025, and are still applicable to Learning-Portal v2.

### Perceivable
1.1 Text Alternatives (1.1.1 Non-text Content, 1.4.5 Images of Text)
1.2 Time-based Media (1.2.2 Captions (Prerecorded), 1.2.2 Captions (Live))
1.3 Adaptable
1.4 Distinguishable

### Operable
2.1 Keyboard Accessible (2.1.1 Keyboard)
2.2 Enough Time (2.2.1 Timing Adjustable)
2.4 Navigable (2.4.3 Focus Order)

### Understandable
3.1 Make Content Readable and Predictable (3.1.1 Language of Page)
3.2 Make Content Operable (3.2.3 Consistent Navigation)
3.3 Input Assistance (3.3.1 Error Identification)

### Robust
4.1 Compatible

## New Modality Alternative Mapping Criteria (per Accessibility Office Q4 2025 Bulletin)

### Input Modality Update — Speech Interfaces

The following criteria have been met for the new voice-command input path in Learning-Portal v2:

1. Each voice command has an equivalent non-voice control.
2. A transcription-failure fallback is in place, which returns the learner to a usable non-voice pathway.
3. A timeout is defined, which, upon failure of the voice-command input path, returns the learner to a usable non-voice pathway within a reasonable timeframe.
```

This report confirms the applicability of the v1 criteria to Learning-Portal v2 while documenting the new voice-command input path and adhering to the Accessibility Office Q4 2025 bulletin guidelines. The report should be handed back to the board for review and approval.
