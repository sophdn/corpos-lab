# Learning-Portal v2 Conformance Report

## Introduction

This report confirms the conformance of the Learning-Portal v2 release with the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. The release builds upon the WCAG 2.1 Level AA conformance of the v1 release, which was signed off by the Accessibility Board in Q1 2025 (see [releases/learning-portal-v1/conformance-report.md](releases/learning-portal-v1/conformance-report.md)).

## Overview

Learning-Portal v2 retains the page structure, color palette, and keyboard navigation unchanged from v1. It adds a voice-command input path on top of v1, with no other material changes. This report covers the new voice-command features and confirms the continued conformance of the retained v1 criteria.

## Voice-Command Features

1. **Voice-Command Input Path:** Learners can issue spoken commands to navigate and submit answers, transcribed by the browser speech API.

### Input Modality Update

In addition to the WCAG 2.1 Level AA success criteria, we have documented a Modality Alternative Mapping for the voice-command path, as per the Accessibility Office Q4 2025 bulletin (see [policy/bulletins/2025-Q4-accessibility-bulletin.md](policy/bulletins/2025-Q4-accessibility-bulletin.md)). This mapping captures, for every voice command, an equivalent non-voice control, the transcription-failure fallback, and a timeout that returns the learner to a usable non-voice pathway, documented for the release and failing safe if the mapping cannot be assembled.

## Conclusion

Based on the above analysis, we confirm that the Learning-Portal v2 release conforms with WCAG 2.1 Level AA standards and includes the Modality Alternative Mapping as per the Accessibility Office Q4 2025 bulletin.
