# Learning Portal v2 Conformance Report

## Introduction

This report confirms conformance of Learning Portal v2 with WCAG 2.1 Level AA as of the pre-release phase. The conformance report for v1 remains current (releases/learning-portal-v1/conformance-report.md). This report focuses on v2-specific changes and confirms the applicability of the v1 criteria.

## Overview

Learning Portal v2 retains the v1 page structure, color palette, and keyboard navigation, which have been audited and signed off by the Accessibility Board in Q1 2025 (releases/learning-portal-v1/conformance-report.md). New to v2 is the addition of a voice-command input path.

## Per-Success Criteria Evaluation

### 1.1.1 Non-text Content

- All non-text content (e.g., images) has a text alternative that serves the equivalent purpose (e.g., using alt attribute on images).

### 1.2.1 Keyboard Accessible

- All functionality can be operated using a keyboard.

### 1.2.4 Keyboard (Vertical Navigation)

- When the keyboard focus is moved from one navigational link to another, the focus order preserves meaning and operability (e.g., navigational links should not be in an arbitrary order).

### 1.3.1 Info and Relationships

- Information, relationships between information, and the operation of the user interface are presented in ways that are clearly discernible to all users.

### 2.1.1 Keyboard Accessible

- All functionality can be operated using a keyboard.

### 2.1.2 No Keyboard Trap

- If keyboard focus can be moved to a container, then focus can also be moved to all focusable ancestors of the container.

### 2.4.3 Focus Follows Meaningful Order

- When focus is moved to a new part of the content, it is focused on the next logical part of the content based on its meaning and operability.

### 2.4.4 Link Purpose (In Context)

- The purpose of each link can be determined from the link text alone or from the link text together with its programmatically determined link context.

### 3.2.2 On Input

- When the user makes an input error, the item containing the error is indicated, and suggestions for correcting the error are provided.

### 3.3.2 Time-based Media

- Time-based media can be paused, presented at a comfortable pace, and advanced at a comfortable pace.

### 3.3.3 Audio-only and Video-only (Prerecorded)

- Transcripts are provided for all prerecorded audio-only and video-only media.

### 3.3.4 Interactive Elements (Motions, Auto-updating, etc.)

- Moving, blinking, scrolling, or auto-updating information is presented in a way that does not cause seizures or physical reactions.

### 4.1.1 Parsing

- Content is correctly formatted and parses without errors.

### 4.1.2 Name, Role, Value

- All HTML elements have a semantically appropriate `aria-label`, `aria-labelledby`, or `aria-describedby`.

## Modality Alternative Mapping

In accordance with the Accessibility Office Q4 2025 bulletin (policy/bulletins/2025-Q4-accessibility-bulletin.md), this report includes a Modality Alternative Mapping for the new voice-command input path.

### Voice Command Mapping

| Voice Command                  | Modality Alternative   | Transcription-Failure Fallback | Timeout (seconds) |
|--------------------------------|------------------------|--------------------------------|-------------------|
| "Navigate up"                  | Up arrow key           | "Up arrow key"                | 3                 |
| "Navigate down"                | Down arrow key         | "Down arrow key"              | 3                 |
| "Navigate left"                | Left arrow key         | "Left arrow key"              | 3                 |
| "Navigate right"               | Right arrow key        | "Right arrow key"             | 3                 |
| "Submit answer"                | Enter key              | "Enter key"                   | 5                 |
| "Previous question"            | Left arrow key + Enter | "Left arrow key + Enter"      | 5                 |
| "Next question"                | Right arrow key + Enter | "Right arrow key + Enter"     | 5                 |

This mapping ensures that a learner who encounters a transcription failure or exceeds the timeout can navigate and interact using alternative modality paths.

## Conclusion

Learning Portal v2 conforms to WCAG 2.1 Level AA, with the addition of a Modality Alternative Mapping for the new voice-command input path. This report confirms the applicability of the v1 criteria and serves as the pre-release conformance report for Learning Portal v2.
