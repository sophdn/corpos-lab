 To create the Learning-Portal v2 conformance report, follow these steps:

1. Enter the prerequisite sub-step for the v2 conformance report creation from its defined entry condition. This sub-step is creating a blank template with the same section headers as the v1 report.

2. Enter the prerequisite sub-step for referencing the v1 conformance report. This sub-step uses the file `releases/learning-portal-v1/conformance-report.md` and confirms that all success criteria were met and the Accessibility Board signed off in Q1 2025.

3. Enter the prerequisite sub-step for reviewing the v2 change summary. This sub-step uses the file `releases/learning-portal-v2/change-summary.md` and confirms that the page structure, color palette, and keyboard navigation are unchanged from v1, while a voice-command input path was added.

4. Enter the prerequisite sub-step for reviewing the Accessibility Office Q4 2025 bulletin. This sub-step uses the file `policy/bulletins/2025-Q4-accessibility-bulletin.md` and confirms the requirement for a Modality Alternative Mapping when a release adds a spoken-input path.

5. Enter the substantive step for creating the v2 conformance report. This step captures any v2-specific changes and confirms the v1 criteria still apply.

6. Record the v2 report at `releases/learning-portal-v2/conformance-report.md`.

7. Hand the report back to the Accessibility Board.

After completing these steps, the Learning-Portal v2 conformance report should be ready for the Accessibility Board's review and signature.
