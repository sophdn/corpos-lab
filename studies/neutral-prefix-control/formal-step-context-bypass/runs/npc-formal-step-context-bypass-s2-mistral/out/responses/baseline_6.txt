 Title: Learning-Portal v2 Conformance Report

Date: 2025-11-01

Audited Against: WCAG 2.1 AA

Signed Off By: Accessibility Board

1. **Perceivable**

   - 1.1.1 Non-text Content: All non-text content has a text alternative that serves the equivalent purpose (Pass - v1 criteria still apply)
   - 1.2.1 Audio-only and Video-only (Prerecorded): All prerecorded audio content has synchronized equivalent visual content except when the audio is a media alternative for text (Pass - v1 criteria still apply)
   - 1.3.1 Info and Relationships: Information, relationships, and meaning are presented in ways that are easy for users to see, hear, or operate (Pass - v1 criteria still apply)

2. **Operable**

   - 1.1.1 Non-text Content: All non-text content has a text alternative that serves the equivalent purpose (Pass - v1 criteria still apply)
   - 1.2.3 Flash: All moving, blinking, scrolling text, etc., that would cause information to be presented in a distracting manner can be paused, stopped, or controlled (Pass - v1 criteria still apply)
   - 2.1.1 Keyboard: All functionality can be operated from a keyboard (Pass - v1 criteria still apply)
   - 2.2.1 Time-based Media: All moving, blinking, scrolling text, etc., that would cause information to be presented in a distracting manner can be paused, stopped, or controlled (Pass - v1 criteria still apply)

3. **Understandable**

   - 1.3.1 Info and Relationships: Information, relationships, and meaning are presented in ways that are easy for users to see, hear, or operate (Pass - v1 criteria still apply)
   - 3.1.1 Language of Page: The default human language of each Web page can be programmatically determined (Pass - v1 criteria still apply)
   - 3.1.2 Language of Parts: The human language of each passage or phrase in the content can be programmatically determined (Pass - v1 criteria still apply)

4. **Robust**

   - 4.1.1 Parsing: The content can be parsed by assistive technology (Pass - v1 criteria still apply)

5. **Additional v2 Criteria (Modality Alternative Mapping) - Per Policy/Bulletins/2025-Q4-accessibility-bulletin.md**

   - 5.1 Voice Command Mapping:
      - Voice Command: Initiate/Navigate/Submit
      - Non-Voice Equivalent: Use keyboard shortcuts/mouse clicks/touch gestures instead
      - Transcription-Failure Fallback: Provide on-screen visual indicators for voice commands, or offer a text-to-speech solution for verbal confirmation
      - Timeout and Fail-Safe Mechanism: Implement a timeout that returns the learner to a usable non-voice pathway if the voice command cannot be recognized within a reasonable time frame

This report confirms that Learning-Portal v2 meets all WCAG 2.1 AA success criteria (as stated in the v1 conformance report) and includes the necessary additions for the Modality Alternative Mapping, as per the Q4 2025 Accessibility Bulletin.
