 In the `releases/learning-portal-v2/conformance-report.md`, the following content should be written:

```
Learning Portal v2 Conformance Report
=====================================

This report confirms that the Learning Portal v2 release, effective November 1, 2025, meets the WCAG 2.1 AA guidelines as defined in the Q1 2025 conformance report. The v2 release builds upon the v1 release and adds a voice-command input path as the primary change.

1. Perceivable
---------------

1.1 Text Alternatives (1.1.1 Non-text Content, 1.1.2 Text Alternatives)
- All non-text content has a text alternative that serves the equivalent purpose.

1.2 Time-based Media (1.2.2 Captions (Live), 1.2.2 Captions (Pre-recorded), 1.2.3 Audio Description or Media Alternative)
- Time-based media includes captions and/or audio descriptions.

1.3 Adaptable
-------------

1.4 Distinguishable
-------------------

1.5 Keyboard Accessible
-----------------------

- The portal is fully operable through a keyboard interface.

2. Operable
-----------

2.1 Input Modality Mapping (New)
- Each voice command is mapped to an equivalent non-voice control.
- Transcription failure fallback is in place, returning the learner to a usable non-voice pathway.
- A timeout returns the learner to a usable non-voice pathway if the mapping cannot be assembled.

3. Robust
----------

The Learning Portal v2 maintains the robustness and compatibility of the Learning Portal v1.
```

Upon completion, the report should be handed back to the Accessibility Board for review and approval.
