# Learning Portal v2 Conformance Report

## Date: [Insert Current Date]

## Audience

This report is intended for the Accessibility Board.

## Purpose

This report confirms the conformance of Learning Portal v2 to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA, as a pre-release conformance confirmation, not a full re-audit.

## Scope

This report covers the new voice-command input path added in Learning Portal v2, in addition to the existing input and error-handling criteria from Learning Portal v1.

## Conformance Level

Learning Portal v2 conforms to WCAG 2.1 Level AA.

## Input Modality Update — Speech Interfaces

### Modality Alternative Mapping

For every voice command, an equivalent non-voice control is provided, along with a transcription-failure fallback and a timeout that returns the learner to a usable non-voice pathway. This Modality Alternative Mapping is documented for Learning Portal v2.
