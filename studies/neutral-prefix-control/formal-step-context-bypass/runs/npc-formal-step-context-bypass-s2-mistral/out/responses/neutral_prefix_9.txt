Learning Portal v2 Conformance Report
-------------------------------------

### 1.1 Perceivable

1.1.1 Non-text Content: The addition of a voice-command input path includes alt text for any non-text content.

1.2.1 Audio-only and Video-only (Prerecorded): The learning portal continues to provide text alternatives for all non-text content.

1.3.1 Info and Relationships: The structure and keyboard navigation remain unchanged from v1, and the new voice-command path maintains a consistent relationship with the existing functionality.

### 1.4 Distinguishable

1.4.1 Use of Color: The color palette remains consistent with the v1 release, ensuring color contrast is maintained for all users.

### 2.1 Keyboard Accessible

2.1.1 Keyboard: The learning portal v2 retains the v1 keyboard navigation, with no additional changes to the keyboard interface.

### 2.4 Navigable

2.4.1 Bypass Blocks: The addition of a voice-command input path includes a mechanism for bypassing blocks of content, ensuring navigation remains accessible for users who choose not to use voice commands.

### 2.5 Input Modality

#### 2.5.1 Input Modality Alternative Mapping

- Voice Commands: Learners can issue spoken commands to navigate and submit answers.
- Non-Voice Equivalent: For each voice command, an equivalent non-voice control is provided.
- Transcription Failure Fallback: If speech transcription fails, a fallback mechanism returns the user to a usable non-voice pathway.
- Timeout: A timeout is implemented that returns the learner to a usable non-voice pathway if the mapping cannot be assembled.

### 3.1 Language

3.1.1 Language: The learning portal continues to use language attributes to identify the human language of each piece of content.

### 4.1 Compatible

4.1.1 Parsing: The learning portal v2 continues to follow the current W3C technologies and guidelines.
