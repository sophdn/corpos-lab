## Overview:
The Learning Portal v2 release builds upon the v1 release, which was audited against WCAG 2.1 AA and signed off by the Accessibility Board in Q1 2025. The v2 change summary confirms that the page structure, color palette, and keyboard navigation are unchanged from v1, with the addition of a voice-command input path.

### New Modality Alternative Mapping (per Accessibility Office Q4 2025 bulletin):
- Voice Command: Equivalent non-voice control, transcription-failure fallback, and timeout that returns the learner to a usable non-voice pathway, documented for the release and failing safe if the mapping cannot be assembled.

## Conformance:
The Learning Portal v2 release conforms to WCAG 2.1 AA, meeting all success criteria from the v1 conformance report, and includes a new Modality Alternative Mapping for the voice-command input path, as per the Accessibility Office Q4 2025 bulletin.

## Signoff:
The Accessibility Board has reviewed this conformance report and confirms that the Learning Portal v2 release conforms to WCAG 2.1 AA and includes the necessary Modality Alternative Mapping for the voice-command input path.
