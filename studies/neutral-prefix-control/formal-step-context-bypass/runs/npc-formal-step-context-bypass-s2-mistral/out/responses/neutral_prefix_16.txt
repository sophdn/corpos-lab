Learning Portal v2 Conformance Report
=====================================

Date: November 1, 2025
Conformance Level: WCAG 2.1 AA

1. Perceivable

1.1 Text Alternatives (1.1.1 Non-text Content, 1.1.2 Text on Images)
The learning portal maintains its use of text alternatives for all non-text content and ensures that text is provided for all images.

1.2 Time-based Media (1.2.2 Captions (Live), 1.2.3 Audio Description or Media Alternative)
The learning portal does not currently contain any time-based media.

1.3 Adaptable

1.4 Distinguishable

2. Operable

2.1 Keyboard Accessible (2.1.1 Keyboard)
The learning portal maintains its keyboard navigation and ensures that all functionality can be accessed via the keyboard.

2.2 Enough Time (2.2.1 Timing Adjustable)
The learning portal does not currently contain any time-limited content.

2.3 Seizures (2.3.1 Three Flashes or Below Thresholds)
The learning portal does not contain content that may trigger seizures.

3. Content (3.1 Reading Order, 3.2 Language of Parts)

3.1 Reading Order (3.1.1 Linear Reading Order)
The learning portal maintains its linear reading order, ensuring that content is presented in a clear and consistent manner.

3.2 Language of Parts (3.2.1 Language of Parts)
The learning portal maintains its use of appropriate language markup for all content parts.

4. Input Modality Mapping

4.1 Voice Command Mapping
The learning portal introduces a new input modality for voice commands, using the browser speech API. For each voice command, an equivalent non-voice control is provided, along with a transcription-failure fallback and a timeout that returns the learner to a usable non-voice pathway.

This conformance report has been prepared in accordance with the Accessibility Board's guidelines and the Q4 2025 Accessibility Office bulletin.
