```
Release Date: [INSERT RELEASE DATE]

Overview
--------

The Learning Portal v2 is an extension of v1, with the addition of a voice-command input path. This report confirms the conformance of the Learning Portal v2 to WCAG 2.1 AA standards, covering both the existing v1 criteria and the new voice-command criteria as per the Accessibility Office Q4 2025 bulletin.

### Existing v1 Criteria

The Learning Portal v1 was audited against WCAG 2.1 AA and conformed to all success criteria, as detailed in the [v1 Conformance Report](releases/learning-portal-v1/conformance-report.md).

### New v2 Criteria - Modality Alternative Mapping

In compliance with the Accessibility Office Q4 2025 bulletin, the following Modality Alternative Mapping is provided for the voice-command input path in Learning Portal v2:

| Voice Command | Equivalent Non-Voice Control | Transcription-Failure Fallback | Timeout (seconds) |
|---------------|------------------------------|--------------------------------|-------------------|
| Navigation Command 1 | Navigation Key 1 | On-screen prompt to repeat command | 10 |
| Navigation Command 2 | Navigation Key 2 | On-screen prompt to repeat command | 10 |
| Submit Answer | Enter Key | On-screen prompt to re-speak answer | 15 |
| ... | ... | ... | ... |

In case the Modality Alternative Mapping cannot be assembled, the system will safely return the learner to a usable non-voice pathway.

### Conformance Verdict

The Learning Portal v2 meets the WCAG 2.1 AA conformance level, including the new Modality Alternative Mapping criteria for the voice-command input path.
```

This report captures the v2-specific changes and confirms the v1 criteria still apply while also adhering to the Accessibility Office Q4 2025 bulletin's requirements. The report is now ready to be handed back to the board.
