=====================================

Date: November 1, 2025

Conformance Level: WCAG 2.1 AA

1.4.1 Use of Color: Information is not conveyed through color alone. (Met)

### Modality Alternative Mapping

In this release, a voice-command input path has been added. The following table captures the equivalent non-voice control, the transcription-failure fallback, and a timeout for each voice command:

| Voice Command | Non-Voice Equivalent | Transcription-Failure Fallback | Timeout (sec) |
|--------------|----------------------|-------------------------------|---------------|
| Navigate Home | Click Home Button      | Display Home Button and Focus | 5            |
| Next Question | Click Next Button     | Display Next Button and Focus | 5            |
| Previous Question | Click Previous Button | Display Previous Button and Focus | 5 |
| Submit Answer | Click Submit Button    | Display Submit Button and Focus | 5 |

This mapping ensures that learners can navigate and submit answers using both voice and keyboard commands, and that the system safely reverts to the keyboard pathway if speech transcription fails or times out.
