Audit Date: [insert current date]

Audited Against: WCAG 2.1 AA

Signed off by the Accessibility Board: [Q1 2025]

This report documents the conformance of the Learning Portal v2 release against WCAG 2.1 AA accessibility guidelines. The Learning Portal v2 release is built on top of the v1 release, which has been previously audited and signed off by the Accessibility Board in Q1 2025.

The Learning Portal v2 release retains the v1 page structure, color palette, and keyboard navigation unchanged, and adds a voice-command input path on top of the existing keyboard surface.

**Voice Command Input Path**

The Learning Portal v2 release introduces a voice-command input path, allowing learners to issue spoken commands to navigate and submit answers. The voice-command path is implemented using the browser speech API.

**Modality Alternative Mapping**

In accordance with the Accessibility Office Q4 2025 bulletin, the Learning Portal v2 release includes a Modality Alternative Mapping for the voice-command path. The mapping captures, for every voice command, an equivalent non-voice control, the transcription-failure fallback, and a timeout that returns the learner to a usable non-voice pathway.
