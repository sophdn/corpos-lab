Learning Portal v2 Conformance Report (WCAG 2.1 AA)
----------------------------------------------------

### Introduction

This report confirms that Learning Portal v2 conforms to Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. The v1 report (released Q1 2025) remains current, with additional conformance items added due to the v2's voice-command input path.

### Page Structure

The page structure remains unchanged from v1 and conforms to success criteria 1.3.1 Info and Relationships, 1.3.2 Meaningful Sequence, and 1.3.3 Sensory Characteristics.

### Color Palette

The color palette remains unchanged from v1 and conforms to success criteria 1.4.1 Use of Color, 1.4.3 Contrast (Minimum), and 1.4.4 Use of Color for Foreground and Background (except for color-blind users, for which success criterion 1.4.6 Contrast (Enhanced) is also met).

### Keyboard Navigation

Keyboard navigation remains unchanged from v1 and conforms to success criteria 2.1.1 Keyboard, 2.1.2 No Keyboard Trap, and 2.2.1 Timing Adjustable.

### Voice-Command Input Path

The new voice-command input path has been added to the Learning Portal, conforming to the following additional conformance items:

- **Modality Alternative Mapping** (per Accessibility Office Q4 2025 bulletin):
  - For every voice command, an equivalent non-voice control has been documented.
  - A transcription-failure fallback has been documented.
  - A timeout that returns the learner to a usable non-voice pathway has been documented.

### Input and Error-Handling

All input and error-handling criteria remain unchanged from v1 and conform to WCAG 2.1 AA success criteria, written in modality-agnostic terms.
