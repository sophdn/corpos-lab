Learning Portal v2 Conformance Report
=====================================

This report covers the Learning Portal v2 release, effective [Date]. The Learning Portal v1 was audited against WCAG 2.1 AA and signed off by the Accessibility Board in Q1 2025. This report confirms that v2 meets all success criteria from the v1 report, with an additional conformance item documenting the Modality Alternative Mapping for the voice-command input path introduced in v2.

Per WCAG 2.1 AA, the Learning Portal v2 meets the following criteria:

1. Perceivable
   1.1 Text Alternatives: Provided for all non-text content.
   1.2 Time-based Media: Provided with captions.
   1.3 Audio-only and Video-only (Prerecorded): Transcripts provided.
   1.4 Adaptable: Content can be presented in different ways, including by changing text size, background color, color contrast, speech rates, and fonts.
   1.5 Distinguishable: Enough contrast exists between foreground and background.
   1.6 Keyboard Accessible: All functionality is operable through a keyboard.

2. Operable
   2.1 Keyboard: All functionality is operable through a keyboard.
   2.2 Enough Time: For each time limit that is relevant to the user's interaction, at least 5 seconds of time is provided after completing part of the interaction.
   2.3 Seizures: Nothing flashes more than three times at a rate faster than three times per second.

3. Understandable
   3.1 Readable: Text is readable and understandable.
   3.2 Predictable: Navigation is predictable.
   3.3 Input Modality: The user interface includes components for multiple input modalities, including voice, keyboard, and mouse.

4. Robust
   4.1 Name, Role, Value: Information about the nature and status of content is programmatically determined.
   4.2 Language of Parts: The language of each part of the content can be programmatically determined.
