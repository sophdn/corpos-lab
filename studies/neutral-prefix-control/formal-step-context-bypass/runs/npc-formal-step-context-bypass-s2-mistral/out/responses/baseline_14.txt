 Title: Learning-Portal v2 Conformance Report

Date: November 1, 2025

Signatories: Accessibility Compliance Officer

1. **Prerequisites**
   - The Learning-Portal v1 has been previously audited and confirmed to meet WCAG 2.1 AA standards (Q1 2025).
   - The Learning-Portal v2 retains the v1's page structure, color palette, and keyboard navigation while adding a voice-command input path.
   - Reference documents: `releases/learning-portal-v1/conformance-report.md`, `releases/learning-portal-v2/change-summary.md`, `policy/bulletins/2025-Q4-accessibility-bulletin.md`

2. **Overview**
   - The Learning-Portal v2 is built upon the accessible foundation of v1 and introduces a voice-command input path.

3. **Success Criteria**
   - All success criteria from the Learning-Portal v1 (refer to `releases/learning-portal-v1/conformance-report.md`) still apply as the v1 page structure, color palette, and keyboard navigation remain unchanged in v2.

4. **New Requirements (Modality Alternative Mapping)**
   - In accordance with the Accessibility Office Q4 2025 bulletin, any voice command in Learning-Portal v2 must be accompanied by an equivalent non-voice control, transcription-failure fallback, and a timeout that returns the learner to a usable non-voice pathway. This Modality Alternative Mapping will be documented for the release and will fail safe if the mapping cannot be assembled (refer to `policy/bulletins/2025-Q4-accessibility-bulletin.md`).

5. **Conformance**
   - The Learning-Portal v2 conforms to WCAG 2.1 AA standards, with the addition of the new Modality Alternative Mapping requirements.

6. **Signoff**
   - This report confirms that the Learning-Portal v2 meets the required accessibility standards as outlined in the prerequisites and success criteria. The Learning-Portal v2 conformance report is now complete.

7. **Recommendations**
   - It is recommended to maintain regular accessibility audits and updates to ensure ongoing conformance with WCAG 2.1 AA standards and any future updates to accessibility guidelines.
