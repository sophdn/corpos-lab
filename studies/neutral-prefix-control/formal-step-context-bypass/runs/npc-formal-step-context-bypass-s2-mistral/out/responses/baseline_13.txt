```markdown
# Learning Portal v2 Conformance Report

## Introduction

This report confirms the conformance of Learning Portal v2 against WCAG 2.1 AA guidelines, as a follow-up to the v1 release that was audited and signed off in Q1 2025.

## Overview

The Learning Portal v2 retains the v1 page structure, color palette, and keyboard navigation, and adds a voice-command input path.

## Success Criteria

### Level A

- 1.1 Text Alternatives (Provided by v1)
- 1.2 Time-Based Media (Provided by v1)
- 1.3 Adaptable (Provided by v1)
- 1.4 Distinguishable (Provided by v1)

### Level AA

- 2.1 Keyboard Accessible (Provided by v1)
- 2.4 Navigable (Provided by v1)

### Level AAA

- 3.1 Avoiding Seizures (Provided by v1)

## New - Modality Alternative Mapping

In compliance with the Accessibility Office Q4 2025 bulletin, a Modality Alternative Mapping has been included for the newly added voice-command input path:

### Voice Command to Equivalent Non-Voice Control

- Voice Command: "Next Question"
  - Equivalent Non-Voice Control: Tab key (keyboard navigation)
- Voice Command: "Previous Question"
  - Equivalent Non-Voice Control: Shift + Tab key (keyboard navigation)
- Voice Command: "Submit Answer"
  - Equivalent Non-Voice Control: Enter key (keyboard navigation)

### Transcription-Failure Fallback

In case of transcription failure, the learner will be guided to use the keyboard for input.

### Timeout and Fail-Safe Measures

If the system fails to recognize a voice command within a reasonable timeout, the learner will be returned to a usable non-voice pathway.

---

Signed off by the Accessibility Board on 2025-10-31.
```

This report captures any v2-specific changes and confirms that the v1 criteria still apply, including the addition of the Modality Alternative Mapping as per the Q4 2025 bulletin. The report is ready to be handed back to the board.
