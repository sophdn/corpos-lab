 Title: Learning-Portal v2 Conformance Report (WCAG 2.1 AA)

Date: November 1, 2025

Signed Off By: Accessibility Board

1. **Perceivable**
   - 1.1 Text Alternatives: Provided for all non-text content, as in v1.
   - 1.2 Time-based Media: Captions are available for all video and audio content, as in v1.
   - 1.3 Adaptable: Content can be presented in different ways, including by changing color contrast, motion, and size, as in v1.

2. **Operable**
   - 2.1 Keyboard Accessible: All functionality is operable from a keyboard, as in v1.
   - 2.2 Enough Time: For all user input, there is a sufficient time for users to read and use the interface, as in v1.
   - 2.4 Navigable: All functionality and content is navigable sequentially using a keyboard, as in v1.
   - **Additional v2 Operable Criteria**
     - 2.5 Input Modality Mapping:
       - Voice Command: Navigating and submitting answers using spoken commands, transcribed by the browser speech API.
       - Non-Voice Control Equivalent: Navigating and submitting answers using keyboard or other assistive technology, as a fallback for transcription failure or timeouts.
       - Transcription-Failure Fallback: When speech transcription fails, the system will return the learner to a usable non-voice pathway.
       - Timeout: If speech transcription is not successful after a reasonable time, the system will return the learner to a usable non-voice pathway.

3. **Understandable**
   - 3.1 Readable: Text is readable and understandable, as in v1.
   - 3.2 Language of Page: The language of the page is specified, as in v1.
   - 3.3 Input Assistance: Help is available when users make errors, as in v1.

4. **Robust**
   - 4.1 Name, Role, Value: Information and structure can be interpreted reliably by assistive technologies, as in v1.

This report confirms that Learning-Portal v2 adheres to WCAG 2.1 AA standards, including the additional criteria for input modality mapping as outlined in the Accessibility Office Q4 2025 bulletin. The v1 conformance report remains current for all unchanged criteria.
