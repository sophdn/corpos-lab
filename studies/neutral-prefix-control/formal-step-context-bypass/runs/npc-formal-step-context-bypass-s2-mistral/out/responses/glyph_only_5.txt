# Learning Portal v2 Conformance Report

## Overview

The Learning Portal v2 release has been assessed against the Web Content Accessibility Guidelines (WCAG) 2.1 AA standards. This report outlines conformance for the additional voice-command input path added in v2, in accordance with the Accessibility Office Q4 2025 bulletin.

- 1.3.2 Meaningful Sequence (Level A)
- 2.4.1 Bypass Blocks (Level A)

Keyboard navigation remains unchanged from Learning Portal v1, meeting the following success criteria:

- 1.3.6 Identify Purpose (Level A)
- 2.1.1 Keyboard (Level A)
- 2.1.2 No Keyboard Trap (Level A)
- 2.1.4 Character Keyboard Shortcuts (Level A)
- 2.2.1 Timing Adjustable (Level A)
- 4.1.2 Name, Role, Value (Level A)

## Voice-Command Input Path

The Learning Portal v2 introduces a voice-command input path. To comply with the Accessibility Office Q4 2025 bulletin, we have added a Modality Alternative Mapping for voice commands:

- For every voice command, an equivalent non-voice control is provided, ensuring that learners can navigate and submit answers using either modality.
- A transcription-failure fallback is in place, ensuring that learners can revert to a usable non-voice pathway if voice transcription fails.
- A timeout is set, returning the learner to a usable non-voice pathway if the mapping cannot be assembled.

## Input and Error Handling

Input and error handling in Learning Portal v2 is written in modality-agnostic terms, meeting the following success criteria:

- 3.2.1 On Input (Level A)
- 3.2.2 On Input Focus (Level A)
- 3.2.3 Consistent Identification (Level A)
- 3.3.1 Error Identified (Level A)
- 3.3.2 Labels or Instructions (Level A)

## Conformance

The Learning Portal v2 has been developed to conform to WCAG 2.1 Level AA standards, with the addition of a Modality Alternative Mapping for the voice-command input path.
