```
Learning Portal v2 Conformance Report (WCAG 2.1 AA)
--------------------------------------------------

Date: November 1, 2025

Signed off by the Accessibility Board

### 1.1 Perceivable

1.1.1 Non-text Content: The new voice command feature includes audio content, but it is accompanied by text transcriptions and all non-text content is described appropriately.

### 1.2 Operable

1.2.1 Keyboard Accessible: Keyboard navigation remains unchanged and functions as expected, with no new issues.

### 1.3 Understandable

1.3.1 Info and Relationships: All information and relationships are presented in a way that can be easily understood, including the new voice command feature.

### 1.4 Robust

1.4.1 Parsing: The learning portal remains robust with the addition of the voice command feature, and the HTML is properly structured and parses correctly.

### Modality Alternative Mapping

In accordance with the Accessibility Office Q4 2025 bulletin, here is the Modality Alternative Mapping for the voice command feature:

- For every voice command, an equivalent non-voice control is provided.
- Transcription-failure fallback is in place, and the learner is returned to a usable non-voice pathway if the transcription fails.
- A timeout is implemented that returns the learner to a usable non-voice pathway if the mapping cannot be assembled or if the voice command is not recognized within a reasonable time.
```

This report confirms that the Learning Portal v2 meets WCAG 2.1 AA standards, with the addition of a voice command feature that includes a Modality Alternative Mapping as required by the Accessibility Office's Q4 2025 bulletin. The report can be handed back to the Accessibility Board for their review and approval.
