```
Learning Portal v2 Conformance Report
=====================================

Date: 2025-10-31

Sign-off: The Accessibility Board

Audit Scope
-----------

This conformance report covers the Learning Portal v2 release, focusing on the changes introduced compared to v1. The report is structured according to the WCAG 2.1 AA success criteria, as defined in the [v1 conformance report](../learning-portal-v1/conformance-report.md).

Changes from v1 to v2
----------------------

### Addition of a Voice Command Input Path

The Learning Portal v2 introduces a voice command input path in addition to the existing keyboard and pointer input methods. This path allows learners to issue spoken commands to navigate and submit answers, transcribed by the browser speech API.

### Modality Alternative Mapping

In accordance with the Accessibility Office Q4 2025 bulletin, a Modality Alternative Mapping has been documented for the Learning Portal v2. This mapping captures, for every voice command, an equivalent non-voice control, the transcription-failure fallback, and a timeout that returns the learner to a usable non-voice pathway.

### Unchanged Components

The page structure, color palette, and keyboard navigation of the Learning Portal v2 remain unchanged from v1.

Success Criteria Met
---------------------

### Perceivable

- 1.1 Text Alternatives: Provided for all non-text content, except when the non-text content is a media element that is purely decorative.
- 1.2 Time-based Media: Provided captions for all media content with synchronized captions (e.g., videos).
- 1.3 Adaptable: Content can be presented in different ways without losing information or structure.
- 1.4 Distinguishable: Enough contrast is maintained between foreground and background content.

### Operable

- 2.1 Keyboard Accessible: All functionality can be operated from a keyboard.
- 2.2 Enough Time: For any auto-advancing or auto-updating content, at least 2 seconds can be paused, or the rate can be adjusted.
- 2.4 Navigable: A clear and consistent navigation mechanism is provided.
- 2.5 Input Modality: Alternative input methods are available, including voice input.

### Understandable

- 3.1 Readable: Text is easily readable and understandable.
- 3.2 Predictable: Navigation and interaction behavior is predictable and consistent.

### Robust

- 4.1 Parse-able: Content can be interpreted correctly by assistive technologies.

Conformance Validated
----------------------

The Learning Portal v2 has been validated as conforming to WCAG 2.1 AA standards. The v1 conformance report remains current and provides a comprehensive overview of the success criteria, input and error-handling criteria written in modality-agnostic terms.

Sign-off: The Accessibility Board
```
