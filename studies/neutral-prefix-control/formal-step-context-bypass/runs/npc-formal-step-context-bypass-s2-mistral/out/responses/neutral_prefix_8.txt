Learning-Portal v2 Conformance Report
=======================================

This report confirms that the Learning-Portal v2 release meets the WCAG 2.1 AA success criteria, as outlined in the Q1 2025 conformance report for Learning-Portal v1.

The following sections detail the conformance of Learning-Portal v2, highlighting any v2-specific changes and confirming the applicability of the v1 criteria.

1. **Perceivable**
   - 1.1 Text Alternatives: All non-text content has a text alternative that serves the equivalent purpose. (Success Criterion 1.1.1)
   - 1.2 Time-based Media: All time-based media has synchronous equivalents (Success Criterion 1.2.2)
   - 1.3 Adaptable: Content can be presented in different ways, including by changing text sizes, background colors, and font families (Success Criterion 1.4.3)
   - 1.4 Distinguishable: Text and graphics are easily distinguishable against the background (Success Criterion 1.4.6)

2. **Operable**
   - 2.1 Keyboard Accessible: All functionality can be operated from a keyboard (Success Criterion 2.1.1)
   - 2.4 Navigable: Pages have clear and consistent navigation mechanisms (Success Criterion 2.4.5)
   - 2.5 Input Modalities: Users can operate all functionality using various input modalities, including voice (Success Criterion 2.5.3)

3. **Understandable**
   - 3.1 Language of Page: The language of each part of the content can be programmatically determined (Success Criterion 3.1.1)
   - 3.2 Predictable: Information is organized in a predictable manner (Success Criterion 3.2.1)
   - 3.3 Input Assistance: All user input can be followed visually and audibly (Success Criterion 3.3.1)

4. **Robust**
   - 4.1 Use of WAI-ARIA: WAI-ARIA roles and properties are used to improve the accessibility of web content and applications (Success Criterion 4.1.2)
   - 4.2 Name, Role, Value: Elements have content that conveys their identity and purpose (Success Criterion 4.1.4)

In addition to meeting the v1 criteria, Learning-Portal v2 introduces a voice-command input path. In accordance with the Accessibility Office Q4 2025 bulletin, this release also includes a Modality Alternative Mapping for every voice command. This mapping provides equivalent non-voice controls, transcription-failure fallbacks, and a timeout that returns the learner to a usable non-voice pathway, as detailed in the release documentation.

This report has been reviewed and is signed off by the Accessibility Board. The v1 conformance report remains current unless otherwise noted.
