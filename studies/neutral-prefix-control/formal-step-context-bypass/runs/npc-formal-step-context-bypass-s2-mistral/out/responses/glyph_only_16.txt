```markdown
# Learning Portal v2 Conformance Report

## Introduction

This report confirms the conformance of the Learning Portal v2 release to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA as of November 1, 2025. The Learning Portal v1 release was previously audited and conformed to these guidelines, and the v2 release builds upon the v1 foundation with the addition of a voice-command input path.

## Conformance Criteria

### Perceivable

1.1 Text Alternatives: ✔️ (same as v1)
1.2 Time-based Media: ✔️ (same as v1)
1.3 Adaptable: ✔️ (same as v1)
1.4 Distinguishable: ✔️ (same as v1)

### Operable

2.1 Keyboard Accessible: ✔️ (same as v1)
2.2 Enough Time: ✔️ (same as v1)
2.3 Seizures: ✔️ (same as v1)
2.4 Navigable: ✔️ (same as v1)

### Understandable

3.1 Readable: ✔️ (same as v1)
3.2 Predictable: ✔️ (same as v1)

### Robust

4.1 Name, Role, Value: ✔️ (same as v1)

## Modality Alternative Mapping

In addition to the above criteria, the Learning Portal v2 release includes a voice-command input path. The Modality Alternative Mapping for this path is as follows:

- For each voice command, an equivalent non-voice control is provided.
- In case of transcription failure, a fallback to a usable non-voice pathway is triggered.
- A timeout returns the learner to a usable non-voice pathway if the mapping cannot be assembled.
```
