```markdown
# Learning Portal v2 Conformance Report

## Date
November 1, 2025

## Audited Release
Learning Portal v2

## Conformance Level
WCAG 2.1 AA

## Conformance Report Status
Pre-release conformance confirmation (not a full re-audit)

## Previous Conformance Report
[Learning Portal v1 Conformance Report](releases/learning-portal-v1/conformance-report.md) (Q1 2025)

## Overview
Learning Portal v2 introduces a voice-command input path on top of the v1 keyboard navigation, with no other material changes to the page structure, color palette, or keyboard navigation.

## Success Criteria

### Perceivable

#### 1.1.1 Non-text Content:
Text alternatives are provided for all non-text content, including images, video, and audio. [V1 compliant]

#### 1.3.1 Info and Relationships:
Info and relationships between heading and body text are marked up so they can be presented to the user in an appropriate manner. [V1 compliant]

#### 1.4.1 Use of Color:
Color is not used as the only visual means of conveying information, indicating an active state, prompting a response, or distinguishing a purpose. [V1 compliant]

#### 1.4.3 Contrast (Minimum):
Text and images of text have a contrast ratio of at least 4.5:1 against the background. [V1 compliant]

### Operable

#### 2.1.1 Keyboard:
All functionality of the content can be operated from a keyboard. [V1 compliant]

#### 2.2.1 Timing Adjustable:
Time limits for completion of tasks can be turned off or adjusted. [V1 compliant]

#### 2.4.1 Bypass Blocks:
A mechanism is available to bypass blocks of content that are repeated on multiple pages. [V1 compliant]

#### 2.4.3 Focus Order:
When a focusable element receives focus, it is focused in an order that makes sense and is predictable. [V1 compliant]

### Understandable

#### 3.1.1 Language:
The default human language for every web content can be programmatically determined. [V1 compliant]

#### 3.3.1 Understandable:
Instructions are clear enough to be understood by users with a wide range of reading and language skills. [V1 compliant]

#### 3.3.2 Labels or Instructions:
Labels or instructions are provided when content requires user input. [V1 compliant]

### Robust

#### 4.1.1 Parsing:
Valid HTML is used, conforming to the latest HTML specification. [V1 compliant]

#### 4.1.2 Name, Role, Value:
Elements have complete and relevant attributes. [V1 compliant]

### New - Modality Alternative Mapping

#### Modality Alternative Mapping:
A mapping is provided for each voice command, specifying an equivalent non-voice control, the transcription-failure fallback, and a timeout that returns the learner to a usable non-voice pathway. This mapping is documented for the release and fails safe if the mapping cannot be assembled. [V2 compliant]

## Sign-off

This report confirms that the Learning Portal v2 release conforms to WCAG 2.1 AA standards.
```

This report ensures that the learning-portal v2 release meets the WCAG 2.1 AA accessibility standards, including the new Modality Alternative Mapping requirement for voice-command inputs. The report is based on the pre-release conformance confirmation process and references the v1 conformance report for comparison.
