 To create the conformance report for learning-portal v2, follow these steps:

1. Enter the prerequisite sub-step of creating a Modality Alternative Mapping for the voice command input path, as per the Accessibility Office Q4 2025 bulletin. The entry conditions for this sub-step would include the release addition of a voice-command path and the bulletin's requirement for a Modality Alternative Mapping.

2. Since the v1 conformance report remains current and the page structure, color palette, and keyboard navigation are unchanged in v2, you can copy the success criteria from the v1 conformance report (`releases/learning-portal-v1/conformance-report.md`) and paste them into the v2 report (`releases/learning-portal-v2/conformance-report.md`).

3. Add a new section for the Modality Alternative Mapping, including details on each voice command, the equivalent non-voice control, the transcription-failure fallback, and the timeout that returns the learner to a usable non-voice pathway. This information should be documented for the learning-portal v2 release.

4. Sign off the v2 conformance report with the current date and the Accessibility Board's name.

5. Hand back the v2 conformance report to the board.

The completed v2 conformance report should contain the following sections:

- Introduction
- Success Criteria (copied from v1 report)
    - Perceivable
    - Operable
    - Understandable
    - Robust
- Modality Alternative Mapping (new section)
    - Voice commands and their equivalent non-voice controls
    - Transcription-failure fallbacks
    - Timeouts and fail-safes
- Conclusion and Sign-off (with current date and Accessibility Board's name)
