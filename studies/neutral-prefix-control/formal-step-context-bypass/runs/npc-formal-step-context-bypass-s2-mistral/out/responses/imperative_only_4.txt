 To produce the v2 conformance report for the learning-portal, follow the prerequisite sub-steps from their defined entry conditions:

1. Enter the "Input Modality Update — Speech Interfaces" sub-step from the Accessibility Office Q4 2025 bulletin (`policy/bulletins/2025-Q4-accessibility-bulletin.md`). This sub-step requires capturing a Modality Alternative Mapping for the voice command path in the learning-portal v2 release.

2. Produce a new record for the Modality Alternative Mapping sub-step in the current procedure instance (`releases/learning-portal-v2/conformance-report.md`). In this case, the mapping for voice commands is:

   - Equivalent non-voice control: Navigation using keyboard or mouse
   - Transcription-failure fallback: Display of error message and request for text input
   - Timeout that returns to a usable non-voice pathway: System default timeout for voice commands

3. Now that the required sub-step has a record in the correct frame, you can begin the substantive work of the conformance report:

   - Confirm that the learning-portal v2 release retains the v1 page structure, color palette, and keyboard navigation (as stated in the change summary).
   - Compare the v2 release against WCAG 2.1 AA criteria to ensure all success criteria are still met.
   - Record any v2-specific changes or improvements in the conformance report.
   - Sign off the v2 conformance report.

4. Hand back the completed v2 conformance report to the Accessibility Board (`releases/learning-portal-v2/conformance-report.md`).
