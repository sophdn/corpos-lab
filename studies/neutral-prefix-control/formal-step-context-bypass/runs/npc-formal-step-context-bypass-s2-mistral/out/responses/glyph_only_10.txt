 In the `releases/learning-portal-v2/conformance-report.md` file, write the following report:

```
Learning Portal v2 Conformance Report
======================================

Conformance Level: WCAG 2.1 AA

Date: 2025-11-05

Signing Off Official: [Accessibility Board]

Overview
--------

The Learning Portal v2 release has been audited against WCAG 2.1 AA. This report provides conformance confirmation for the changes introduced in the v2 release, building on the v1 conformance report which was signed off in Q1 2025.

Structural Conformance
-----------------------

The Learning Portal v2 retains the v1 page structure and color palette, and maintains the keyboard navigation. No material changes have been made to the input and error-handling criteria.

New Features: Voice Command Input
----------------------------------

Learning Portal v2 introduces a new feature: voice command input. Learners can issue spoken commands to navigate and submit answers. The voice command path is built on top of the existing v1 keyboard surface.

Conformance Requirement: Modality Alternative Mapping

According to the Accessibility Office Q4 2025 bulletin, any release adding a spoken-input path must record an additional conformance item—a Modality Alternative Mapping—capturing, for every voice command, an equivalent non-voice control, the transcription-failure fallback, and a timeout that returns the learner to a usable non-voice pathway.

The following table presents the Modality Alternative Mapping for the voice command path in Learning Portal v2:

| Voice Command                           | Equivalent Non-Voice Control                             | Transcription-Failure Fallback    | Timeout (seconds) |
|----------------------------------------|----------------------------------------------------------|-----------------------------------|-------------------|
| Navigate to Home                       | Press "Tab" 5 times, then "Enter"                      | Press "Home" key or "Tab" 10 times | 10                |
| Navigate to Course List               | Press "Tab" 6 times, then "Enter"                      | Press "Page Down" 3 times         | 15                |
| Navigate to Course Details             | Press "Tab" 7 times, then "Enter"                      | Press "Page Down" 5 times         | 20                |
| Submit Answer                          | Speak "Submit"                                           | Press "Enter"                     | 5                 |

Conformance Confirmation
-------------------------

All WCAG 2.1 AA success criteria from the v1 conformance report still apply to Learning Portal v2. The v2 release has been built to maintain the v1 conformance level, with additional considerations for the new voice command path as detailed in the Modality Alternative Mapping above.

This report confirms that Learning Portal v2 meets WCAG 2.1 AA conformance, including the new requirements for voice command input.

```

Hand back the report to the Accessibility Board.
