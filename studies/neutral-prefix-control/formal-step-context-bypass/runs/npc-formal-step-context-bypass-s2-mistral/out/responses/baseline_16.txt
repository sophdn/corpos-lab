Learning Portal v2 Conformance Report (WCAG 2.1 AA)
---------------------------------------------------

Issued: November 1, 2025

This report confirms that the Learning Portal v2 release conforms to WCAG 2.1 Level AA accessibility guidelines, as it is a continuation and enhancement of v1, which was audited and signed off by the Accessibility Board in Q1 2025.

### Overview

The Learning Portal v2 retains the v1 page structure, color palette, and keyboard navigation. It adds a voice-command input path on top of v1, allowing learners to navigate and submit answers via spoken commands, transcribed by the browser speech API.

### Success Criteria Met (v1 criteria remain applicable)

1. Perceivable:
   - 1.1 Text Alternatives: Provide text alternatives for any non-text content so that it can be understood when the non-text content cannot be rendered.
   - 1.2 Time-based Media: Provide alternatives for all time-based media.
   - 1.3 Adaptable: Create content that can be presented in different ways, including by assistive technologies, without losing information or structure.
   - 1.4 Distinguishable: Make it easier for users to see and hear content including separating foreground from background.
   - 1.5 Keyboard Accessible: Make all functionality available from a keyboard.
   - 2.1 Keyboard: All functionality can be operated from a keyboard.
   - 2.4 Navigable: Provide ways to help users navigate, find content, and determine where they are.
   - 4.1 Parse: The content is clear in structure, markup, and meaning.

2. Operable:
   - 2.2 Enough Time: Provide users enough time to read and use content.
   - 2.3 Seizures: Do not design content in a way that is known to cause seizures.
   - 2.5 Input Modalities: Make it easier for users to operate functionality using various inputs beyond a keyboard.

3. Understandable:
   - 3.1 Language of Page: The default human language of each web page can be programmatically determined.
   - 3.2 Consistent Identification: Use the same identifier for the same information or function.
   - 3.3 Input Assistance: Help users avoid and correct mistakes.

4. Robust:
   - 4.1 Compatible: Maximize compatibility with current and future user tools, including assistive technologies.

### Additional Conformance Item - Modality Alternative Mapping (new for v2)

In compliance with the Accessibility Office Q4 2025 bulletin, we document the Modality Alternative Mapping for the voice-command input path in Learning Portal v2:

For every voice command, an equivalent non-voice control is provided, along with a transcription-failure fallback and a timeout that returns the learner to a usable non-voice pathway. The mapping is documented for the release and fails safe if the mapping cannot be assembled.
