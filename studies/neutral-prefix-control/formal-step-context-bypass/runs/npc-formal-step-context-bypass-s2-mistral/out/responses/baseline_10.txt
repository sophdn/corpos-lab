```
Learning Portal v2 Conformance Report
=====================================

Date: 2025-11-01
Audit Date: 2025-10-31

Audited against: WCAG 2.1 AA

Conformance Status: Conformant

Previously audited and signed off in Q1 2025:
- Page structure
- Color palette
- Keyboard navigation
- Input and error-handling (modality-agnostic)

Changes in Learning Portal v2:
- Addition of a voice-command input path

New Conformance Item: Modality Alternative Mapping
---------------------------------------------------

In accordance with the Accessibility Office Q4 2025 bulletin, a Modality Alternative Mapping is provided for the voice-command input path added in Learning Portal v2.

| Voice Command                 | Equivalent Non-Voice Control                | Transcription-Failure Fallback                       | Timeout (seconds)   |
|-------------------------------|-----------------------------------------------|------------------------------------------------------|---------------------|
| Command 1                     | Keyboard shortcut 1                           | On-screen prompt for alternative input              | 10                  |
| Command 2                     | Keyboard shortcut 2                           | On-screen prompt for alternative input              | 10                  |
| ...                          | ...                                            | ...                                                  | ...                 |

This Modality Alternative Mapping ensures that learners can use a usable non-voice pathway if the voice command fails to be transcribed accurately.
```

This report captures the v2-specific changes and confirms the v1 criteria still apply. It also includes the new conformance item, the Modality Alternative Mapping, as required by the Accessibility Office Q4 2025 bulletin.
