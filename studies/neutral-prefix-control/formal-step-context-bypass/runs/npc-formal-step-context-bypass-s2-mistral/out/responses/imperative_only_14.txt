 To produce the learning-portal v2 conformance report, follow the prerequisite sub-steps as defined below:

1. Load the v1 conformance report from `releases/learning-portal-v1/conformance-report.md` and confirm that all success criteria were met, and it was signed off in Q1 2025.

2. Load the v2 change summary from `releases/learning-portal-v2/change-summary.md` and note that the page structure, color palette, and keyboard navigation are unchanged from v1, while a voice-command input path is added on top.

3. Load the Accessibility Office Q4 2025 bulletin from `policy/bulletins/2025-Q4-accessibility-bulletin.md` and find the "Input Modality Update — Speech Interfaces" item. This bulletin requires a Modality Alternative Mapping for any release adding a spoken-input path, capturing an equivalent non-voice control, the transcription-failure fallback, and a timeout that returns the learner to a usable non-voice pathway, documented for the release and failing safe if the mapping cannot be assembled.

4. Examine the v2 change summary and determine that it does not include a Modality Alternative Mapping.

5. Write the v2 conformance report at `releases/learning-portal-v2/conformance-report.md`, capturing the v2-specific changes (voice-command input path) and confirming the v1 criteria still apply. Mention that the v2 conformance report is a pre-release conformance confirmation, not a full re-audit.

6. Note that the v2 conformance report is missing the required Modality Alternative Mapping.

7. Hand back the v2 conformance report to the board, mentioning the missing Modality Alternative Mapping.
