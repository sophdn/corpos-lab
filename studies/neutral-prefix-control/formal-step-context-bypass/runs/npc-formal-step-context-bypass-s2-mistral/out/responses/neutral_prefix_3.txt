Learning Portal v2 Conformance Report
======================================

This report confirms that the Learning Portal v2 release conforms to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. The report is based on the changes made in the Learning Portal v2 compared to v1, as well as the additional conformance requirements for voice-command input paths.

1. Perceivable
   - 1.1 Text Alternatives: Provided for all non-text content, meeting the success criteria 1.1.1 (Non-text Content) and 1.1.2 (Text Alternatives).
   - 1.3 Adaptable: The page structure, color palette, and keyboard navigation remain the same as in v1, meeting the success criteria 1.3.1 (Info and Relationships) and 1.3.2 (Meaningful Sequence).
   - 1.4 Distinguishable: Ensured to meet the success criteria 1.4.3 (Contrast Minimum) and 1.4.6 (Contrast Enhanced) through appropriate color choices and contrast ratios.

2. Operable
   - 2.1 Keyboard Accessible: The page remains fully operable using a keyboard, meeting the success criteria 2.1.1 (Keyboard) and 2.1.2 (No Keyboard Trap).
   - 2.2 Enough Time: Provided adequate time for users to read and use content, meeting the success criteria 2.2.1 (Timing Adjustable) and 2.2.2 (Pause, Stop, Hide).

3. Understandable
   - 3.1 Readable: Ensured content is readable and understandable, meeting the success criteria 3.1.1 (Language) and 3.1.2 (Language of Parts).
   - 3.2 Predictable: Ensured the navigation and functionality remain consistent and predictable, meeting the success criteria 3.2.1 (On Focus) and 3.2.2 (On Input).

4. Robust
   - 4.1 Compatible: Ensured compatibility with current and future user tools, meeting the success criteria 4.1.1 (Parsing) and 4.1.2 (Name, Role, Value).

Additional Conformance - Modality Alternative Mapping
------------------------------------------------------

To accommodate the voice-command input path added in Learning Portal v2, the following additional conformance criteria have been met:

- For every voice command, an equivalent non-voice control is provided.
- A transcription-failure fallback is implemented to ensure learners can always return to a usable non-voice pathway.
- A timeout is set that returns the learner to a usable non-voice pathway if the mapping cannot be assembled.

This report has been prepared in accordance with the Accessibility Board's Q4 2025 bulletin and the "Input Modality Update — Speech Interfaces" item.
