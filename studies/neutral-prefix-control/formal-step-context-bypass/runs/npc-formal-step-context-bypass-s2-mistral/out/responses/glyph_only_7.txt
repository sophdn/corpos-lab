# Learning-Portal v2 Conformance Report

## WCAG 2.1 AA Compliance

This conformance report covers the Learning-Portal v2 release. The v1 release was audited against WCAG 2.1 AA and signed off by the Accessibility Board in Q1 2025. The v2 release retains the page structure, color palette, and keyboard navigation unchanged from v1 and adds a voice-command input path on top of v1.

### Perceivable

- Text Alternatives: Provided for all non-text content, including images, graphs, and diagrams.
- Audio-only and Video-only content: Not present in the Learning-Portal.
- Captions (Prerecorded): Not applicable.
- Captions (Live): Not applicable.
- Audio Descriptions or Media Alternatives: Not applicable.
- Adaptable: The Learning-Portal is adaptable to different types of assistive technologies.

### Operable

- Keyboard Accessible: The Learning-Portal can be accessed and operated using a keyboard.
- Enough Time: No time limits are imposed on interaction that causes an error or loses data when the user does not respond within the time limit.
- Seizures: The Learning-Portal does not trigger seizures.
- Navigable: The Learning-Portal can be navigated in a logical order.
- Focus Visible: Keyboard focus is visible.
- Content Does Not Move: The Learning-Portal does not move the page content during interactions.

### Understandable

- Readable: The Learning-Portal is readable and understandable.
- Use of Language: The Learning-Portal uses clear and simple language.
- Input Modalities: The Learning-Portal supports multiple input modalities, including keyboard and voice commands.

### Robust

- Name, Role, Value: The Learning-Portal uses meaningful names, roles, and values for all interface components.
- Language of Parts: The language of all parts of the Learning-Portal can be programmatically determined.

## Modality Alternative Mapping

As per the Accessibility Office Q4 2025 bulletin, a new conformance item is required for any release adding a spoken-input path. The Learning-Portal v2 adds a voice-command input path on top of v1. The following Modality Alternative Mapping is provided:

1. For every voice command, an equivalent non-voice control is provided.
2. In case of transcription failure, the learner is returned to a usable non-voice pathway.
3. A timeout is implemented that returns the learner to a usable non-voice pathway if the mapping cannot be assembled.
