 To create the conformance report for the learning-portal v2 release, follow these steps:

1. Enter the prerequisite sub-step for creating a Modality Alternative Mapping for the voice command input path according to the Q4 2025 Accessibility Bulletin.
   - Define the Modality Alternative Mapping for each voice command, including the equivalent non-voice control, transcription-failure fallback, and a timeout that returns the learner to a usable non-voice pathway.

2. Enter the prerequisite sub-step for reviewing the v2 change summary to confirm that the page structure, color palette, and keyboard navigation are unchanged from v1.

3. Enter the substantive step for reviewing the v2 report template and confirming that it has the same section headers as v1.

4. Enter the substantive step for confirming that the v1 conformance report (`releases/learning-portal-v1/conformance-report.md`) still applies to the v2 release, as the v2 changes only add a voice-command input path on top of v1.

5. Write the v2 conformance report in the `releases/learning-portal-v2/conformance-report.md` file, including the Modality Alternative Mapping, and any v2-specific changes, as well as the confirmation that the v1 criteria still apply.

6. Hand the v2 conformance report back to the Accessibility Board.
