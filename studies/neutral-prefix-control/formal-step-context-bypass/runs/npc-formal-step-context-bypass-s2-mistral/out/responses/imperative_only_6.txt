 To produce the conformance report for the learning-portal v2 release, follow these steps:

1. Enter the prerequisite sub-step for creating a Modality Alternative Mapping, using the defined entry conditions from the Accessibility Office Q4 2025 bulletin:
   - Record each voice command with an equivalent non-voice control.
   - Document the transcription-failure fallback.
   - Set a timeout that returns the learner to a usable non-voice pathway if the mapping cannot be assembled.

2. Record the results of this sub-step in the correct procedural frame (v2 conformance report).

3. Confirm the v1 criteria still apply by checking the v1 conformance report (`releases/learning-portal-v1/conformance-report.md`) and ensuring that the page structure, color palette, and keyboard navigation are unchanged in v2.

4. Record the v2-specific changes (the addition of a voice-command input path) in the v2 conformance report (`releases/learning-portal-v2/conformance-report.md`).

5. Hand the v2 conformance report back to the Accessibility Board.

Here is a sample of what the v2 conformance report should look like after completing these steps:

releases/learning-portal-v2/conformance-report.md

# Learning Portal v2 Conformance Report
