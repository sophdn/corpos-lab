Learning Portal v2 Conformance Report
=====================================

Release: Learning Portal v2
Release Date: [Friday]
Conformance Level: WCAG 2.1 AA
Conformance Sign-Off Date: [Q1 2025]

Overall Conformance
--------------------

The Learning Portal v2 meets the WCAG 2.1 AA success criteria as defined in the Learning Portal v1 Conformance Report. The v1 report remains the current conformance reference.

The following sections detail any v2-specific changes and confirm the v1 criteria still apply.

### Page Structure

The page structure remains unchanged and continues to meet the success criteria as defined in the Learning Portal v1 Conformance Report.

### Color Palette

The color palette remains unchanged and continues to meet the success criteria as defined in the Learning Portal v1 Conformance Report.

### Keyboard Navigation

The keyboard navigation surface remains unchanged and continues to meet the success criteria as defined in the Learning Portal v1 Conformance Report.

### Voice Command Input (New)

The Learning Portal v2 introduces a voice command input path in addition to the existing keyboard navigation. The voice command input conforms to the following:

1. Learners can issue spoken commands to navigate and submit answers.
2. The browser speech API transcribes the spoken commands.
3. In the event of a transcription failure, the system provides a fallback mechanism that returns the learner to a usable non-voice pathway.
4. A timeout is implemented that returns the learner to a usable non-voice pathway if the mapping of spoken commands to non-voice controls cannot be assembled.

The Modality Alternative Mapping for each voice command is documented for the release and fails safe if the mapping cannot be assembled, as per the Accessibility Office Q4 2025 bulletin.

### Input and Error-handling

Input and error-handling criteria are written in modality-agnostic terms and continue to meet the success criteria as defined in the Learning Portal v1 Conformance Report.
