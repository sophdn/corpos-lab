
2. Mention the changes from v1 to v2, focusing on the new voice-command input path:

```markdown
This report covers the Learning-Portal v2 release, which introduces a voice-command input path in addition to the existing keyboard navigation from v1.
```

3. Describe the conformance criteria for the new voice-command input path as per the Accessibility Office Q4 2025 bulletin (Modality Alternative Mapping):

```markdown
- **Modality Alternative Mapping:**
  - For each voice command, an equivalent non-voice control is provided.
  - In case of transcription failures, a fallback path is available to ensure learners can continue using a non-voice control.
  - A timeout is set to return learners to a usable non-voice pathway if the mapping cannot be assembled.
```

4. Confirm the v1 criteria still apply, as the v2 page structure, color palette, and keyboard navigation are unchanged from v1:

```markdown

  - All success criteria listed in the Learning-Portal v1 Conformance Report ([releases/learning-portal-v1/conformance-report.md]) have been met, and the input and error-handling criteria have been written in modality-agnostic terms.
```

5. End the report with a conclusion and date:

```markdown
This report confirms that the Learning-Portal v2 release meets WCAG 2.1 AA standards, including the new Modality Alternative Mapping criteria.

[Current Date]
```
