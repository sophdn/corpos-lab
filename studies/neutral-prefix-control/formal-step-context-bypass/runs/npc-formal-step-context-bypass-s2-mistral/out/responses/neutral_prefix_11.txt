Learning-Portal v2 Conformance Report
=======================================

This report confirms that Learning-Portal v2 meets the WCAG 2.1 AA accessibility standards as defined in the Q1 2025 conformance report.

Page Structure and Color Palette
----------------------------------

All success criteria for page structure and color palette have been met as they are unchanged from v1.

Keyboard Navigation
--------------------

All success criteria for keyboard navigation have been met as the keyboard surface remains unchanged from v1.

Voice Command Input Path
-------------------------

The Learning-Portal v2 adds a voice-command input path on top of v1. To meet the requirements specified in the Accessibility Office Q4 2025 bulletin, a Modality Alternative Mapping must be created and documented for this release.

The mapping will capture an equivalent non-voice control for every voice command, a transcription-failure fallback, and a timeout that returns the learner to a usable non-voice pathway. The mapping will fail-safe if the required components cannot be assembled.

The Modality Alternative Mapping for Learning-Portal v2 is yet to be created and documented.

Once completed, this report will be updated to include the Modality Alternative Mapping.

Upon completion of the Modality Alternative Mapping, this report will be submitted back to the Accessibility Board for final approval.
