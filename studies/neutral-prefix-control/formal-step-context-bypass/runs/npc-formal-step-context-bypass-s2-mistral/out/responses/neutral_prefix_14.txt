Voice Command Input Modality Alternative Mapping
------------------------------------------------

In accordance with the Accessibility Office Q4 2025 bulletin, the following Modality Alternative Mapping has been documented for the Learning Portal v2 release:

- For every voice command, an equivalent non-voice control has been provided.
- In case of transcription failure, a fallback option that returns the learner to a usable non-voice pathway is in place.
- A timeout that returns the learner to a usable non-voice pathway has been documented for the release.

The Modality Alternative Mapping is designed to ensure that the Learning Portal v2 release remains compliant with WCAG 2.1 AA accessibility guidelines, even with the addition of the voice-command input path.
