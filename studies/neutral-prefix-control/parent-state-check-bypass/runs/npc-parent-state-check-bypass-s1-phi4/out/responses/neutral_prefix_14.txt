2. **Choose a URL Validation Method**:

3. **Implement URL Validation**:
   - Modify `validate_url_field()` to include a check for the URL's scheme (e.g., `http`, `https`), netloc (domain), and optionally path, to ensure it's a well-formed URL.

   ```python
   from urllib.parse import urlparse
   import sys

   def validate_url_field(url):
       # Check if the field is present and non-empty
       if not url:
           print("Error: URL field is empty.")
           sys.exit(1)
       
       # Parse the URL
       parsed_url = urlparse(url)
       
       # Validate the URL structure
       if not parsed_url.scheme or not parsed_url.netloc:
           print("Error: Malformed URL.")
           sys.exit(1)
       
       # If the URL is valid, continue
       return True

   # Example usage

   ```
