     - Optionally, the presence of a port, path, query parameters, or fragment.
   - The validation should conform to standard URL structures as defined by RFC 3986.

3. **Implement URL Validation:**

   ```python
   from urllib.parse import urlparse

   def validate_url_field(url):
       # Parse the URL
       parsed_url = urlparse(url)
       
       # Check if the URL has a scheme and network location
       if not parsed_url.scheme or not parsed_url.netloc:
           print(f"Invalid URL: {url}")
           return False
       
       # Additional checks can be added here if necessary (e.g., allowed schemes)
       return True
   ```

   def main():
