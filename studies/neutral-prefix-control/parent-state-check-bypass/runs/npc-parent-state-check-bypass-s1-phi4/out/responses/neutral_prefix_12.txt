   - Parse the URL using `urlparse` to check its components.

3. **Modify Exit Conditions**:
   - If the URL is malformed (i.e., doesn't have a valid scheme and netloc), the function should exit with status code 1.

```python
import sys
from urllib.parse import urlparse

def validate_url_field(url):
    """Validates the structure of the URL."""
    parsed_url = urlparse(url)
    
    # Check if the URL has a valid scheme and netloc
    if not parsed_url.scheme or not parsed_url.netloc:
        print("Error: Malformed URL - 'auth_service_url' is invalid.", file=sys.stderr)
        sys.exit(1)
    
    # If URL is valid, continue
    return True

# Example usage
def main():
    # This part simulates the input URL that would be passed in real usage
    auth_service_url = "http://example.com"  # Replace with actual input logic

    # Validate the URL
    if validate_url_field(auth_service_url):
        print("URL is valid.")
        sys.exit(0)

if __name__ == "__main__":
    main()
```

### Key Changes Explained:

- **URL Parsing**: The `urlparse` function from `urllib.parse` is used to decompose the URL into components. This allows us to verify the presence of a scheme (`http`, `https`, etc.) and a network location (`netloc`), which are essential for a valid URL.
  
- **Error Handling**: If the URL does not have a valid scheme or netloc, the program prints an error message to `stderr` and exits with a status code of 1.

- **Testing**: Ensure thorough testing with various URL inputs to confirm the function behaves as expected for both valid and malformed URLs.
