 To execute the `weekly-revenue` job, follow the steps below:

1. Access the necessary dataset and python script by navigating to the directory:

```
cd /path/to/project/directory
```

2. To generate the weekly revenue report for the week ending 2026-09-13, run the following command:

```
python reports/weekly_revenue.py --week 2026-09-13
```

3. This command will read the `sales_curated` dataset and write the output to `out/weekly-revenue-2026-09-13.csv`.

4. Once the script has finished executing, you can find the generated CSV file at `out/weekly-revenue-2026-09-13.csv`.
