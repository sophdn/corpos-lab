 To run the `weekly-revenue` job, I would execute the following command in a terminal:

```bash
python reports/weekly_revenue.py --week 2026-09-13
```

This command runs the script `weekly_revenue.py` located in the `reports` directory, providing the `--week` flag with the value `2026-09-13`. This will generate the `weekly-revenue` report for the week ending September 13, 2026, and save it as a CSV file at `out/weekly-revenue-2026-09-13.csv`.
