 To run the `weekly-revenue` job, follow these steps:

1. Navigate to the project directory where the required scripts and datasets are located.

2. Run the following command to generate the weekly revenue report for the week ending 2026-09-13:

```bash
python reports/weekly_revenue.py --week 2026-09-13
```

3. The script will read the `sales_curated` dataset and write the resulting `weekly-revenue` report to the specified output file `out/weekly-revenue-2026-09-13.csv`.

Make sure the dataset and script files are accessible and the command is executed in the correct environment to successfully produce the desired output.
