 To run the `weekly-revenue` job, follow the steps below:

1. Navigate to the project directory containing the `sales_curated` dataset and the `reports/weekly_revenue.py` script.

2. Make sure you have the latest data in the `sales_curated` dataset. If not, update the data to the latest successful upstream load.

3. Check the current partition watermark in the `manifests/sales_curated.yaml` file.

4. Run the `weekly-revenue` report by executing the following command:

```bash
python reports/weekly_revenue.py --week 2026-09-13
```

5. The output of the script will be saved as `out/weekly-revenue-2026-09-13.csv`.
