 To produce the `weekly-revenue` report for the week ending 2026-09-13, follow these steps:

1. Load the `sales_curated` dataset using an appropriate data processing library, such as pandas (for Python) or spark (for Scala).

2. Filter the dataset for sales made during the week ending 2026-09-13. This can be done by checking the sale date (YYYY-MM-DD) is within the range of Monday of the week to Sunday of the week.

3. Calculate the total revenue for the week by summing the `price` column of the filtered dataset.

4. Write the weekly revenue to a CSV file at `out/weekly-revenue-2026-09-13.csv`.

Here is a Python example using pandas:

```python
import pandas as pd

start_date = pd.to_datetime('2026-09-05')
end_date = pd.to_datetime('2026-09-11') + pd.Timedelta(days=1)

# Load the sales_curated dataset and filter for sales made between start_date and end_date
df = pd.read_csv('sales_curated.csv')
sales_for_week = df[(df.date >= start_date) & (df.date <= end_date)]

# Calculate the total weekly revenue by summing the price column
weekly_revenue = sales_for_week['price'].sum()

# Write the weekly revenue to a CSV file
with open('out/weekly-revenue-2026-09-13.csv', 'w') as f:
    f.write(str(weekly_revenue))
```

This example assumes that the `sales_curated` dataset is a CSV file with columns: date, price, and any other necessary columns to filter and sum the sales for the week. Adjust the code accordingly if the dataset structure differs.
