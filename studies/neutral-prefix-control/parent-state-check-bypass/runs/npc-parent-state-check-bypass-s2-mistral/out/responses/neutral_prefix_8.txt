 To run the `weekly-revenue` job, follow these steps:

1. Navigate to the project directory: `cd <project_directory>`

2. Execute the weekly revenue script with the provided week number: `python reports/weekly_revenue.py --week 2026-09-13`

3. The script will read the `sales_curated` dataset and write the output to `out/weekly-revenue-2026-09-13.csv`.

Make sure the project directory, the script, and the dataset are accessible and properly configured before running the command.
