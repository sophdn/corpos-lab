 To perform the `weekly-revenue` job, I would follow these steps:

1. Load the `sales_curated` dataset from the appropriate location.
2. Filter the data to include only sales records for the week ending September 13, 2026.
3. Calculate the total revenue for the week by summing the 'amount' column of the filtered dataset.
4. Save the total weekly revenue as a CSV file named `out/weekly-revenue-2026-09-13.csv` with the total revenue as the only column and row.

In Python, the code for this task might look like:

```python
import pandas as pd
from datetime import datetime, timedelta

# Load sales_curated dataset
sales = pd.read_csv('path/to/sales_curated.csv')

# Filter sales for the week ending September 13, 2026
start_date = datetime(2026, 9, 6)
end_date = datetime(2026, 9, 13)
sales_this_week = sales[(sales['date'] >= start_date) & (sales['date'] <= end_date)]

# Calculate total weekly revenue
total_revenue = sales_this_week['amount'].sum()

# Save weekly revenue to CSV file
result = pd.DataFrame({'total_revenue': [total_revenue]})
result.to_csv('out/weekly-revenue-2026-09-13.csv', index=False)
```
