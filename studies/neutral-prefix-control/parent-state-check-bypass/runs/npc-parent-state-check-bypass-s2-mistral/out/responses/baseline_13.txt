 To begin the `weekly-revenue` job, follow these steps:

1. Navigate to the project directory:

```
cd /path/to/your/project
```

2. Run the weekly revenue script:

```
python reports/weekly_revenue.py --week 2026-09-13
```

3. The script will read data from the `sales_curated` dataset and write the output to `out/weekly-revenue-2026-09-13.csv`.
