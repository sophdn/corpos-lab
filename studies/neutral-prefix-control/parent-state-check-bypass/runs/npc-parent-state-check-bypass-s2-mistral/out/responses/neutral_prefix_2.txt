 To run the `weekly-revenue` job, follow these steps:

1. Navigate to the project directory containing the `sales_curated` dataset, the `reports` folder, and the `manifests` folder.

2. Run the following command to produce the `weekly-revenue` report for the week ending 2026-09-13:

```
python reports/weekly_revenue.py --week 2026-09-13
```

3. The command will read the `sales_curated` dataset, use the latest successful upstream load, the current partition watermark, and any backfills or schema changes applied since the last run, as recorded in the load manifest `manifests/sales_curated.yaml`.

4. The output will be written to the file `out/weekly-revenue-2026-09-13.csv`.

That's it! The `weekly-revenue` job has been initiated.
