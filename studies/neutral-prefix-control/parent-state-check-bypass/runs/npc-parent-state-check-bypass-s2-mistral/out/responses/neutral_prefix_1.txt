 To execute the `weekly-revenue` job, follow these steps:

1. Navigate to the project directory: `cd path/to/project`

2. Run the weekly revenue script with the specified week: `python reports/weekly_revenue.py --week 2026-09-13`

3. The script will read the `sales_curated` dataset and write the output to `out/weekly-revenue-2026-09-13.csv`.

Ensure that the `sales_curated` dataset is up-to-date and the specified `weekly_revenue.py` script is accessible before running the command.
