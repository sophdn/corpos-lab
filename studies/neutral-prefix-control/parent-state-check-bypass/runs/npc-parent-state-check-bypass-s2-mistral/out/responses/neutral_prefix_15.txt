 To generate the `weekly-revenue` report for the week ending 2026-09-13, I would execute the following command:

`python reports/weekly_revenue.py --week 2026-09-13`

This command invokes the weekly_revenue script located in the reports directory, passing in the week parameter with the value 2026-09-13. The script should then read the `sales_curated` dataset and write the resulting report to `out/weekly-revenue-2026-09-13.csv`.
