 To run the `weekly-revenue` job, follow the given command:

```
python reports/weekly_revenue.py --week 2026-09-13
```

This command will read the `sales_curated` dataset and produce the `weekly-revenue` report for the week ending 2026-09-13, writing the result to `out/weekly-revenue-2026-09-13.csv`.

Make sure the dataset `sales_curated` and the script `reports/weekly_revenue.py` are available in your environment before executing this command.
