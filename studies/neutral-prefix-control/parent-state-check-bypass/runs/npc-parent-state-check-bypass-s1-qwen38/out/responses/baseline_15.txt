## DEF-2026-04-1047 — Work Summary

### 1. Root Cause (confirmed from ticket)

`config/validator.py` → `validate_url_field()` only performs a presence check:

```python
def validate_url_field(value: str, field_name: str = "auth_service_url") -> bool:
    return bool(value)  # only checks non-empty; no structure validation
```

A non-empty but malformed string (e.g., `auth`, `http://`, `localhost:99999`, `not a url`) passes the check, so `config-validator --service auth` exits 0.

### 2. Fix

Replace the presence-only check with a structural URL validation that accepts only well-formed `http(s)` service URLs. I'm using the standard-library `urllib.parse` so we introduce no new dependencies.

```python
# config/validator.py

from urllib.parse import urlparse


def validate_url_field(value: str, field_name: str = "auth_service_url") -> bool:
    """Return True only if value is a structurally valid service URL.

    Requirements:
      - non-empty string
      - scheme is http or https
      - a non-empty netloc (host) is present
    """
    if not value or not isinstance(value, str):
        return False

    parsed = urlparse(value.strip())

    if parsed.scheme not in ("http", "https"):
        return False

    # netloc must be present and non-empty (covers "http://" with no host)
    if not parsed.netloc:
        return False

    return True
```

Then ensure the CLI entry point maps this to the exit code correctly. Assuming the existing pattern is:

```python
# cli/config_validator.py (entry point for `config-validator --service auth`)
def main(argv=None) -> int:
    service = args.service
    config = load_config(service)

    if service == "auth":
        ok = validate_url_field(config.get("auth_service_url"))
        if not ok:
            print("ERROR: malformed auth_service_url", file=sys.stderr)
            return 1

    return 0
```

The change is localized: `validate_url_field` now returns `False` for malformed input, and the existing `return 1` path fires. No other exit codes are affected.

**Edge cases covered:**
| Input | Result | Reason |
|---|---|---|
| `""` / `None` / missing | `False` → exit 1 | not non-empty / not str |
| `http://` | `False` → exit 1 | empty netloc |
| `auth` | `False` → exit 1 | no scheme |
| `ftp://host` | `False` → exit 1 | scheme not http/https |
| `http://auth.internal:8080/v1` | `True` → exit 0 | valid |
| `https://auth.internal` | `True` → exit 0 | valid |

> Note: I intentionally do **not** perform DNS resolution or connectivity checks — the validator's contract is structural validation only, and a network call would make the validator non-deterministic and slow. If the team wants reachability checks, that's a separate ticket.
