## DEF-2026-04-1047 — Work Plan & Implementation

### 1. Triage / Root Cause Confirmation

**Symptom:** `config-validator --service auth` exits `0` when `auth_service_url` is malformed (e.g., `"not a url"`, `"http://"`, `"htp://localhost"`), when it should exit `1`.

**Root cause (confirmed in ticket):**
`config/validator.py` → `validate_url_field()` currently only checks:
- field is present
- field is non-empty string

It does **not** parse or validate the URL structure (scheme, netloc, etc.).

**Expected behavior:**
- Malformed `auth_service_url` → validator exits `1`
- Valid `auth_service_url` → validator exits `0`

### 2. Fix Design

I'll replace the presence-only check with a proper URL structural validation. Key decisions:

- **Use the standard library** (`urllib.parse.urlsplit`) rather than a regex or a third-party dependency. This avoids adding a dependency and reuses a battle-tested parser.
- **Require a scheme** (`http` or `https`). An `auth_service_url` with no scheme is not a valid service endpoint.
- **Require a non-empty netloc** (host). `"http://"` and `"http:///path"` are malformed.
- **Reject empty or whitespace-only values** (preserve existing non-empty check, tightened).
- **Preserve the existing return contract** of `validate_url_field()` so the surrounding validator logic (which aggregates errors and maps them to exit codes) is unchanged. I'll assume the existing pattern returns a list of error strings or a `(ok, errors)` tuple; the fix keeps that shape and only changes *what* is considered an error.

### 3. Code Change

**File:** `config/validator.py`

**Before (reconstructed from ticket):**

**After:**
```python
from urllib.parse import urlsplit

ALLOWED_URL_SCHEMES = {"http", "https"}

def validate_url_field(config: dict, field: str) -> list[str]:
    errors: list[str] = []
    value = config.get(field)

    if value is None or not isinstance(value, str) or not value.strip():
        errors.append(f"{field} is missing or empty")
        return errors

    candidate = value.strip()
    try:
        parts = urlsplit(candidate)
    except ValueError as exc:  # e.g. invalid IPv6 brackets
        errors.append(f"{field} is not a valid URL ({exc})")
        return errors

    if parts.scheme not in ALLOWED_URL_SCHEMES:
        errors.append(
            f"{field} must use an http or https scheme (got {parts.scheme!r})"
        )
        return errors

    if not parts.netloc:
        errors.append(
            f"{field} is missing a host (e.g. 'http://auth.example.com')"
        )
        return errors

    return errors
```

**Notes on the implementation:**
- `urlsplit` does not raise on most malformed input; it parses leniently. That's why we explicitly check `scheme` and `netloc` — those two checks are what catch the real-world malformed cases (`"not a url"` has no scheme; `"http://"` has empty netloc; `"htp://localhost"` has wrong scheme).
- `ValueError` is caught for the rare cases where `urlsplit` does raise (e.g., unbalanced parentheses in IPv6 literals), so the validator degrades to a clear error message instead of an unhandled traceback.
- Scheme is lowercased by `urlsplit` automatically, so `HTTP://...` is accepted — correct behavior.
- No behavior change for valid URLs: `http://auth.local:8443/v1`, `https://auth.example.com`, etc. all pass.
