 To fix the issue with the `config-validator --service auth` exiting 0 for a malformed `auth_service_url`, I suggest adding URL validation in the `validate_url_field()` function in `config/validator.py`. Here's a simple way to do that using Python's built-in `re` module for regular expressions:

```python
import re

def validate_url_field(field):
    if not field:
        return False

    url_pattern = re.compile(r'^(http|https)://[a-zA-Z0-9./]+$')
    if not url_pattern.match(field):
        return False

    return True
```

With this modification, the `validate_url_field()` function checks if the `auth_service_url` is a valid URL. If it's malformed, the function will return False, causing the validator to exit with status 1. Valid URLs will continue to pass, as intended.
