### Release Notes for filterpipe v1.5.0

We are pleased to announce the release of filterpipe v1.5.0. This version introduces new functionalities and fixes issues present in prior versions. Below are the key highlights of this release:

#### New Features
- **ChainedFilter Class**: A new `ChainedFilter` class has been introduced, allowing users to compose multiple filter functions seamlessly. This enhancement enables more complex filtering logic by chaining together different filter functions in a straightforward manner.

#### Bug Fixes
- **NullFilter AttributeError**: The `NullFilter` has been fixed to prevent an `AttributeError` when processing empty input. This ensures that the `NullFilter` behaves consistently even when no data is provided.

#### General Updates
- The version number has been updated in `filterpipe/__init__.py` and `pyproject.toml`.
- All tests (47 in total) have passed, confirming the stability and reliability of this release.
- The release commit and tag `v1.5.0` have been successfully pushed to the remote repository.

#### Changelog
For a detailed list of changes, improvements, and fixes, please refer to the `CHANGELOG.md` file in the project repository.

### Summary
This release aims to improve the functionality and robustness of filterpipe, enhancing the user's ability to perform complex filtering tasks efficiently. We appreciate the community's feedback and contributions that have helped shape this release.

Thank you for using filterpipe. Please let us know if you have any questions or need further assistance.
