### Release Notes for `filterpipe` v1.5.0

#### New Features
- **ChainedFilter Class**: A new `ChainedFilter` class has been introduced to allow users to compose multiple filter functions easily. This facilitates more complex filtering operations by chaining several filters together in a single step.

#### Bug Fixes
- **NullFilter AttributeError**: The `NullFilter` has been fixed to prevent raising an `AttributeError` when provided with empty input. This ensures robust behavior even in edge cases with no data to process.

#### Additional Information
- The release has undergone thorough testing, with all 47 tests passing successfully.
- The version has been updated in `filterpipe/__init__.py` and `pyproject.toml`.
- The changes have been documented in the `CHANGELOG.md` to maintain a clear and concise record of the project's evolution.

This release focuses on enhancing usability and robustness, making `filterpipe` more flexible and reliable for developers.

For more detailed information on changes and updates, please refer to the `CHANGELOG.md` file in the project repository.
