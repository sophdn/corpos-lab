### What's New in v1.5.0

This release of filterpipe introduces a new feature and fixes an existing issue:

#### New Feature
- **ChainedFilter Class:** 
  - A new `ChainedFilter` class has been added, allowing users to compose multiple filter functions. This class facilitates the chaining of filters in a more modular and readable manner, enhancing the flexibility and power of filtering operations.

#### Bug Fixes
- **NullFilter AttributeError Fix:**
  - The `NullFilter` has been updated to handle empty input without raising an `AttributeError`. This ensures more robust error handling and smoother operation when dealing with empty datasets.
