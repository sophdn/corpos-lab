**Release Notes for filterpipe v1.5.0**

We are pleased to announce the release of `filterpipe` version 1.5.0. This version introduces new functionality, improves existing features, and addresses a known issue. Here are the details:

### New Features

- **ChainedFilter Class**: A new class, `ChainedFilter`, has been added to allow for the composition of multiple filter functions. This class enables users to create complex filtering pipelines by chaining together individual filter functions, enhancing the flexibility and power of data processing within `filterpipe`.

### Bug Fixes

- **NullFilter AttributeError**: An issue where `NullFilter` was raising an `AttributeError` on empty input has been fixed. This correction ensures that `NullFilter` behaves consistently and correctly when processing empty data, improving the reliability of the library.

### Other Changes

- **Version Bump**: The version number has been updated in `filterpipe/__init__.py` and `pyproject.toml` to reflect the new release.
- **Testing**: All 47 tests have been executed and passed successfully, confirming the stability and correctness of the new release.

### Changelog

The complete changelog for `filterpipe` is maintained in `CHANGELOG.md`. For a detailed history of changes, please refer to this file.

This release marks a significant enhancement to the `filterpipe` library, making it more robust and versatile for users. We encourage users to update to the latest version to take advantage of these improvements.

Thank you for your continued support of `filterpipe`.
