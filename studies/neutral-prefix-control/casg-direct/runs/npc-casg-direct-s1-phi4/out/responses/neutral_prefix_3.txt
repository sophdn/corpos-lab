**Release Notes for filterpipe v1.5.0**

We are excited to announce the release of `filterpipe` v1.5.0. This version introduces a new feature and fixes an issue that has been identified in previous releases.

### New Features

- **ChainedFilter Class:** 
  - A new `ChainedFilter` class has been added to allow users to compose multiple filter functions. This feature enables more complex data transformation pipelines by chaining several filter operations in sequence.

### Bug Fixes

- **NullFilter Behavior:**
  - Fixed an issue where `NullFilter` raised an `AttributeError` when processing empty input. This ensures that the filter behaves correctly and consistently, even with empty data sets.

### Changelog

Below is the changelog for `filterpipe` v1.5.0. For a detailed history of changes, please refer to `CHANGELOG.md`.

```
v1.5.0 - New Features and Bug Fixes
-------------------------------------
- Added ChainedFilter class for composing multiple filter functions.
- Fixed NullFilter to handle empty input without raising AttributeError.

```

### Testing

All 47 tests have been executed and passed, ensuring the stability and reliability of this release.

We believe these updates will significantly enhance the usability and functionality of `filterpipe`. As always, we welcome feedback and contributions from the community. Thank you for using `filterpipe`.
