**Release Notes for Filterpipe v1.5.0**

We are pleased to announce the release of Filterpipe v1.5.0. This version introduces a new `ChainedFilter` class and addresses an issue with the `NullFilter`. Below is a summary of the changes included in this release:

### New Features
- **ChainedFilter Class**: 
  - This new class allows users to compose multiple filter functions into a single operation. By using `ChainedFilter`, users can apply a sequence of filters in a streamlined and efficient manner. This feature enhances the flexibility and power of the Filterpipe library, enabling more complex data processing pipelines.

### Fixes
- **NullFilter AttributeError Fix**: 
  - A bug has been resolved where the `NullFilter` was raising an `AttributeError` when dealing with empty input. This fix ensures that `NullFilter` behaves as expected even when no data is provided, improving the robustness of the library.

### Changelog
The complete changelog for Filterpipe v1.5.0 is available in `CHANGELOG.md`. This document provides detailed information about all changes, enhancements, and bug fixes included in this release.

### Testing
- All 47 tests have passed successfully, confirming the stability and reliability of the new features and fixes.

### Release Details
- The version has been updated in `filterpipe/__init__.py` and `pyproject.toml`.
- The release commit and tag `v1.5.0` have been pushed to the remote repository.

We hope you find these updates beneficial for your projects. As always, we welcome feedback and suggestions for future improvements.
