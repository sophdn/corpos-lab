### `TTLCache`

A cache implementation that expires entries after a configurable time-to-live (TTL) interval.

#### Constructor

```python
gridcache.TTLCache(maxsize: int, ttl: float)
```

*   **`maxsize`**: The maximum number of items the cache can hold. When the limit is reached, the least recently used item is evicted.
*   **`ttl`**: The time-to-live in seconds. Entries older than this duration are considered expired and will be removed upon access or eviction.

#### Methods

*   **`get(key)`**: Retrieves the value associated with `key`. Returns `None` if the key does not exist or if the entry has expired.
*   **`set(key, value)`**: Stores `value` in the cache under `key`, resetting the expiration timer.
*   **`pop(key)`**: Removes and returns the value associated with `key`. Returns `None` if the key does not exist or is expired.
*   **`clear()`**: Removes all items from the cache.

#### Example

```python
from gridcache import TTLCache

cache = TTLCache(maxsize=100, ttl=60.0)  # 60-second expiration
cache.set("user:1", {"name": "Alice"})

# Immediate retrieval
print(cache.get("user:1"))  # Output: {"name": "Alice"}

# After 60 seconds, the entry expires
import time
time.sleep(61)
print(cache.get("user:1"))  # Output: None
```
