## v2.3.0 (Release Date: YYYY-MM-DD)

### New Features

#### `TTLCache` Class
A new cache implementation that expires entries after a configurable time-to-live (TTL) interval.

**Class Signature:**
```python
class gridcache.TTLCache(capacity: int, ttl: float):
    """
    A cache with time-based expiration.

    Args:
        capacity: The maximum number of items the cache can hold.
        ttl: The time-to-live in seconds after which an item expires.
    """
    def get(self, key: Any) -> Any:
        """Retrieve an item. Returns None if the item is missing or expired."""
        
    def put(self, key: Any, value: Any) -> None:
        """Insert or update an item, resetting its TTL."""
        
    def pop(self, key: Any) -> Any:
        """Remove and return an item. Returns None if missing or expired."""
        
    def __contains__(self, key: Any) -> bool:
        """Check if a key is present and not expired."""
```

### Bug Fixes

#### `LRUCache.pop`
Fixed a race condition where `LRUCache.pop` could return a stale value if a concurrent eviction occurred between the lookup and the removal. The method now atomically checks for existence and removes the entry, ensuring consistency under concurrent access.

### Migration Notes
No breaking changes. `TTLCache` is additive. Users relying on `LRUCache` behavior should verify that their concurrent access patterns do not depend on the previous (buggy) non-atomic `pop` behavior, though correct code should not be affected.
```
