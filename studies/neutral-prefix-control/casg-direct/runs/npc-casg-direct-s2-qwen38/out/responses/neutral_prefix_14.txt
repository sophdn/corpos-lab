## Classes

### TTLCache

A cache that expires entries after a configurable time-to-live (TTL).

**Signature:**
```python
class TTLCache(maxsize: int, ttl: float)
```

**Parameters:**
- `maxsize` (int): The maximum number of items the cache can hold.
- `ttl` (float): The time-to-live in seconds for each entry. Entries older than this duration are considered expired.

**Methods:**
- `get(key, default=None)`: Returns the value for `key` if present and not expired. If the entry has expired, it is removed and `default` is returned.
- `set(key, value)`: Adds `value` to the cache under `key`. Resets the expiration timer for this key.
- `delete(key)`: Removes `key` from the cache.

**Example:**
```python
from gridcache import TTLCache

cache = TTLCache(maxsize=100, ttl=30.0) # 30 second expiration
cache.set("user:1", {"name": "Alice"})
print(cache.get("user:1")) # Returns {"name": "Alice"}

# After 30 seconds:
print(cache.get("user:1")) # Returns None (expired)
```

# Conceptual reference for TTLCache in gridcache
import time
from collections import OrderedDict

class TTLCache:
    def __init__(self, maxsize, ttl):
        self.maxsize = maxsize
        self.ttl = ttl
        self.cache = OrderedDict() # key -> (value, expiry_time)

    def _is_expired(self, expiry_time):
        return time.time() > expiry_time

    def get(self, key, default=None):
        if key not in self.cache:
            return default
        value, expiry_time = self.cache[key]
        if self._is_expired(expiry_time):
            del self.cache[key]
            return default
        # Move to end to mark as recently used
        self.cache.move_to_end(key)
        return value

    def set(self, key, value):
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = (value, time.time() + self.ttl)
        if len(self.cache) > self.maxsize:
            self.cache.popitem(last=False) # Evict oldest

    def pop(self, key, default=None):
        if key not in self.cache:
            return default
        value, expiry_time = self.cache.pop(key)
        if self._is_expired(expiry_time):
            return default
        return value
```
