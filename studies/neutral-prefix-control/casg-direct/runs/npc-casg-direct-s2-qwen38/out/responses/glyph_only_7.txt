## TTLCache

`TTLCache` is a cache implementation that automatically expires entries after a configurable time-to-live (TTL) interval.

### Class Signature

```python
class TTLCache(maxsize: int, default_ttl: float = 60.0):
    """
    A cache that expires entries after a configurable interval.

    Args:
        maxsize: Maximum number of items to store.
        default_ttl: Default time-to-live in seconds for entries not specified individually.
    """
    def get(self, key: str, default=None)
    def set(self, key: str, value, ttl: float = None)
    def pop(self, key: str, default=None)
```

### Behavior
- Entries are automatically removed from the cache once their TTL expires.
- If `ttl` is not provided in `set`, the `default_ttl` is used.
- Evictions are lazy (checked upon access) or proactive depending on internal policy, ensuring stale data is never returned.

### Example

```python
cache = TTLCache(maxsize=100, default_ttl=10.0)
cache.set("key1", "value1")
# After 10 seconds, cache.get("key1") returns None
```

## LRUCache

`LRUCache` is a Least Recently Used cache implementation.

### Fixes in v2.3.0
- **Fixed:** `LRUCache.pop` now correctly returns the current value associated with the key, even if a concurrent eviction occurred between the `pop` call and the internal lookup. Previously, a race condition could cause `pop` to return a stale value or raise an error if the item was evicted concurrently.
