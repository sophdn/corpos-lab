## Cache Classes

### `LRUCache`

A Least Recently Used cache implementation.

#### `pop(key, default=None)`

Removes and returns the value associated with `key` from the cache.

**Note (v2.3.0):** Fixed a bug where `pop` could return a stale value if the entry was concurrently evicted by another thread prior to the `pop` call. Now, if the key is not present (including due to concurrent eviction), the `default` value is returned instead of a stale entry.

### `TTLCache` *(New in v2.3.0)*

A cache that expires entries after a configurable time-to-live (TTL) interval.

#### `__init__(maxsize=128, ttl=60.0)`

Initializes the `TTLCache`.

- `maxsize` (int): The maximum number of items the cache can hold. Defaults to `128`.
- `ttl` (float): The time-to-live interval in seconds after which an entry expires. Defaults to `60.0`.

#### `set(key, value)`

Sets the `value` for `key` with the current timestamp. If the key already exists, the value and expiration time are updated.

#### `get(key, default=None)`

Retrieves the value associated with `key`.

- If the key exists and has not expired, the value is returned.
- If the key does not exist or has expired, `default` is returned.
- Expired entries are lazily removed when accessed.

#### `pop(key, default=None)`

Removes and returns the value associated with `key`.

- If the key exists and has not expired, the value is removed and returned.
- If the key does not exist or has expired, `default` is returned.

#### `clear()`

Removes all items from the cache.

#### `__len__()`

Returns the number of non-expired items currently in the cache.
