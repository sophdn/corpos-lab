## TTLCache

`TTLCache` is a new class introduced in v2.3.0 that extends cache functionality with time-to-live (TTL) expiration.

### Class Definition

```python
class TTLCache(capacity: int, ttl: int, clock: Callable[[], float] = time.time):
    ...
```

### Parameters

- **capacity** (`int`): The maximum number of items the cache can hold.
- **ttl** (`int`): The time-to-live duration in seconds after which an entry is considered expired.
- **clock** (`Callable[[], float]`): An optional callable that returns the current time. Defaults to `time.time`. Useful for testing.

### Behavior

- Entries are automatically expired when accessed if the time since insertion exceeds `ttl`.
- Expired entries are treated as cache misses and are removed from the cache.
- The cache respects the `capacity` limit, evicting the least recently used item (or the oldest expired item, depending on implementation specifics) when full.

### Example Usage

```python
from gridcache import TTLCache
import time

cache = TTLCache(capacity=10, ttl=60)  # 60-second TTL
cache['key'] = 'value'

print(cache['key'])  # Returns 'value'

time.sleep(61)
print(cache['key'])  # Returns None (expired)
```
