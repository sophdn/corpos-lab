### TTLCache

A cache with Time-To-Live (TTL) expiration.

Entries in a `TTLCache` are automatically expired after a configurable interval. When an entry is accessed or iterated, if its TTL has elapsed, it is considered missing and will be removed from the cache.

#### Parameters

*   `maxsize` (int): The maximum number of items the cache can hold. If exceeded, the least recently used item is evicted.
*   `ttl` (float): The time-to-live in seconds for each entry. Default is `None` (no expiration).
*   `timer` (callable, optional): A function returning the current time. Defaults to `time.monotonic`.

#### Example

```python
from gridcache import TTLCache
import time

cache = TTLCache(maxsize=2, ttl=1.0)

cache["key1"] = "value1"
time.sleep(1.1)

print(cache.get("key1"))  # None (expired)
```
