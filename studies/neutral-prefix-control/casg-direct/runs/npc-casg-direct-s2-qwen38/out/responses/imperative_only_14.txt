    ## TTLCache

    A cache that expires entries after a configurable interval.

    ### Class Signature
    ```python
    class TTLCache(capacity: int, ttl: float)
    ```

    ### Parameters
    - `capacity` (int): The maximum number of items the cache can hold.
    - `ttl` (float): The time-to-live in seconds for each entry.

    ### Methods
    - `set(key: str, value: any)`: Adds an item to the cache with the current timestamp.
    - `get(key: str)`: Retrieves an item from the cache. Returns `None` if the key does not exist or if the entry has expired.
    - `pop(key: str)`: Removes and returns the item associated with the key. Returns `None` if the key does not exist or if the entry has expired.

    ### Example
    ```python
    from gridcache import TTLCache

    cache = TTLCache(capacity=10, ttl=60.0)
    cache.set("key", "value")
    print(cache.get("key"))  # "value"
    # After 60 seconds
    print(cache.get("key"))  # None
    ```
    ```
