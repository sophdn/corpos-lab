```markdown
## TTLCache

A dictionary-like cache that expires entries after a configurable time-to-live (TTL) interval.

### Class Signature

`gridcache.TTLCache(capacity: int, ttl: float, default: Any = None)`

- **capacity** (`int`): The maximum number of items the cache can hold before evicting the oldest entry.
- **ttl** (`float`): The time in seconds after which an entry is considered expired. Expired entries are treated as if they do not exist.
- **default** (`Any`, optional): The value returned when a key is not found or has expired. Defaults to `None`.

### Methods

- **`__getitem__(key: Hashable) -> Any`**: Retrieves the value associated with `key`. Raises `KeyError` if the key is not present or has expired and no `default` was provided.
- **`__setitem__(key: Hashable, value: Any) -> None`**: Sets the value for `key` and updates its expiration timestamp.
- **`get(key: Hashable, default: Any = None) -> Any`**: Returns the value for `key` if present and not expired, otherwise returns `default`.
- **`pop(key: Hashable, default: Any = None) -> Any`**: Removes and returns the value for `key`. If the key is not present or expired, returns `default`. If `default` is not provided and the key is not present/expired, raises `KeyError`.

### Behavior Notes
- Entries are checked for expiration upon access (`__getitem__`, `get`, `pop`).
- Eviction of expired entries occurs lazily on access or during capacity-based eviction.
- This class is not thread-safe by default; use external locking for concurrent access.
```
