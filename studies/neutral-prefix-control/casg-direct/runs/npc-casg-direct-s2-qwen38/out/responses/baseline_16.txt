## TTLCache

Added in v2.3.0

A cache implementation that expires entries after a configurable interval (Time-To-Live, or TTL).

### Class Signature

```python
class gridcache.TTLCache(maxsize: int, ttl: float)
```

### Parameters

- **maxsize** (`int`): The maximum number of items the cache can hold. If the cache is full, the least recently used item is evicted.
- **ttl** (`float`): The time-to-live for each entry in seconds. Entries older than this duration are considered expired and will be removed upon access or eviction.

### Description

`TTLCache` combines the functionality of a standard LRU cache with time-based expiration. Each entry stored in the cache is associated with a timestamp. When an entry is accessed, if the current time exceeds the entry's timestamp by more than `ttl` seconds, the entry is considered expired and will be removed from the cache, resulting in a cache miss.

This is useful for scenarios where cached data becomes stale over time and should not be served after a certain period, even if it has not been explicitly evicted due to capacity constraints.

### Example

```python
from gridcache import TTLCache
import time

# Create a cache with a max size of 100 and a TTL of 5 seconds
cache = TTLCache(maxsize=100, ttl=5.0)

# Store an item
cache['key'] = 'value'

# Access immediately (cache hit)
print(cache['key'])  # Output: 'value'

# Wait for TTL to expire
time.sleep(6)

# Access after expiration (cache miss)
print(cache.get('key', default='Not Found'))  # Output: 'Not Found'
```

### Methods

#### `get(key, default=None)`
Retrieves the value associated with `key`. If the key does not exist or the entry has expired, returns `default`.

#### `set(key, value)`
Stores `value` in the cache under `key`. Resets the expiration timer for this key.

#### `pop(key, default=None)`
Removes and returns the value for `key`. If `key` is not found or the entry has expired, returns `default`.

#### `clear()`
Removes all items from the cache.
