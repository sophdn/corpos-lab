## TTLCache

A cache with time-to-live (TTL) expiration. Entries are automatically removed after a specified interval.

### Class Signature

```python
class TTLCache(capacity: int, ttl: float)
```

### Parameters

- `capacity` (int): The maximum number of items the cache can hold.
- `ttl` (float): The time-to-live in seconds. After this duration, entries are considered expired and will be removed on access or eviction.

### Methods

- `get(key)`: Retrieves the value associated with `key`. Returns `None` if the key is not found or if the entry has expired.
- `set(key, value)`: Sets the value for `key`. If the cache is full, the least recently used (or expired) entry is evicted.
- `pop(key)`: Removes and returns the value associated with `key`. Returns `None` if the key is not found or expired.

### Notes
- Expired entries do not count toward the cache capacity until they are explicitly accessed or evicted.
- Thread-safety depends on the underlying implementation details; consult source code for concurrent usage patterns.
