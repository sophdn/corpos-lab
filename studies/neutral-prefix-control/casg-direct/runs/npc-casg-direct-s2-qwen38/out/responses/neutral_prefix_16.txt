## TTLCache

A cache implementation that expires entries after a configurable time-to-live (TTL) interval.

### Constructor

```python
class TTLCache(capacity: int, ttl: float, clock: Callable[[], float] = time.time):
    """
    Initialize the TTLCache.

    Args:
        capacity: The maximum number of items the cache can hold.
        ttl: The time-to-live in seconds for each entry.
        clock: A callable that returns the current time. Defaults to `time.time`.
              Can be overridden for testing purposes.
    """
```

### Methods

#### `get(key, default=None)`
Retrieves the value associated with `key` if it exists and has not expired. If the entry has expired, it is removed from the cache and `default` is returned.

#### `set(key, value)`
Stores the value under `key`, resetting the TTL for this entry.

#### `__contains__(key)`
Returns `True` if `key` is in the cache and has not expired. Expired keys are lazily deleted.

#### `__len__()`
Returns the number of non-expired items currently in the cache.
