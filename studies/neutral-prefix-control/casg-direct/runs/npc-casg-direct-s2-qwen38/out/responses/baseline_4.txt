# gridcache API Reference

### TTLCache

New in version 2.3.0.

A cache that expires entries after a configurable time-to-live (TTL) interval.

```python
from gridcache import TTLCache

# Create a TTL cache with entries expiring after 60 seconds
cache = TTLCache(ttl=60)

cache["key"] = "value"

# Retrieve value before expiry
print(cache["key"])  # Output: "value"

# After TTL expires, key is considered missing
# (Behavior depends on specific implementation details of expiration check)
```

**Parameters:**
*   `ttl` (int | float): The time-to-live interval in seconds. Entries are considered expired after this duration has passed since insertion or last update.

**Methods:**
*   `__getitem__(key)`: Retrieves the value associated with `key`. Raises `KeyError` if the key does not exist or has expired.
*   `__setitem__(key, value)`: Sets the value for `key`, resetting its expiration timer.
*   `__contains__(key)`: Returns `True` if the key exists and has not expired.
*   `pop(key, default=None)`: Removes and returns the value associated with `key`. Returns `default` if the key is missing or expired.

### LRUCache

**Changes in version 2.3.0:**
*   **Bug Fix**: `LRUCache.pop` previously returned a stale value in cases of concurrent eviction. It now correctly returns `None` (or the specified `default`) if the key has been evicted or does not exist.

```python
from gridcache import LRUCache

cache = LRUCache(maxsize=100)
cache["key"] = "value"

# Pop returns the value and removes the entry
val = cache.pop("key")
print(val)  # Output: "value"

# Subsequent pop returns None
val = cache.pop("key")
print(val)  # Output: None
```
