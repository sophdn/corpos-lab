## TTLCache

A cache implementation that expires entries after a configurable time-to-live (TTL) interval.

### Class Definition

```python
class TTLCache:
    """
    A thread-safe cache that evicts entries after a specified time interval.
    
    Arguments:
        maxsize (int): The maximum number of items to hold in the cache.
        ttl (float): The time-to-live in seconds for each entry. Entries 
                     older than this will be considered expired and removed 
                     on access or during eviction.
    """
    def __init__(self, maxsize: int, ttl: float = 60.0):
        ...
    
    def get(self, key: str, default: Any = None) -> Any:
        """
        Retrieve an item from the cache.
        
        If the key is present and not expired, its value is returned.
        Otherwise, `default` is returned.
        """
        ...
    
    def set(self, key: str, value: Any) -> None:
        """
        Store a value in the cache with the current timestamp.
        
        If the key already exists, the value is updated and the TTL is reset.
        If the cache is at capacity, the least recently used (or oldest, 
        depending on strategy) non-expired entry is evicted.
        """
        ...
    
    def pop(self, key: str, default: Any = None) -> Any:
        """
        Remove and return an item from the cache.
        
        Returns `default` if the key is not present or if the entry is expired.
        """
        ...
    
    def clear(self) -> None:
        """Remove all items from the cache."""
        ...
```

### Notes

- `TTLCache` is thread-safe.
- Expired entries are lazily evicted upon access (`get` or `pop`) or when space is needed for new entries (`set`).
- This class complements `LRUCache` by adding time-based expiration, useful for scenarios where data freshness is critical.
