### `TTLCache`

A cache implementation that expires entries after a configurable time-to-live (TTL).

```python
class gridcache.TTLCache(maxsize: int, ttl: float)
```

**Parameters:**

*   `maxsize` (int): The maximum number of items the cache can hold before evicting the least recently used items.
*   `ttl` (float): The time in seconds after which an entry expires.

**Methods:**

*   `get(key)`: Returns the value for `key` if it exists and has not expired. Returns `None` if the key is absent or expired.
*   `set(key, value)`: Sets `value` for `key` with the current timestamp.
*   `pop(key)`: Removes and returns the value for `key`. Raises `KeyError` if `key` is not present or has expired.
*   `clear()`: Removes all entries from the cache.

**Note:** Entries are lazily checked for expiration upon access. Expired entries are removed when accessed or when the cache exceeds its maximum size.
