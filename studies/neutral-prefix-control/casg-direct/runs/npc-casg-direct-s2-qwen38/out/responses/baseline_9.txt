## Changes in v2.3.0

### New: `TTLCache`
A new cache class that expires entries after a configurable time-to-live (TTL) interval.

```python
class gridcache.TTLCache(maxsize: int, ttl: float)
```

**Parameters:**
- `maxsize` (int): The maximum number of items the cache can hold before evicting the least recently used item.
- `ttl` (float): The time-to-live for each entry in seconds. Entries not accessed within this duration are considered expired and are removed upon access or eviction.

**Example:**
```python
from gridcache import TTLCache

cache = TTLCache(maxsize=100, ttl=60.0)  # Entries expire after 60 seconds
cache['key'] = 'value'
# ...
# After 61 seconds, cache['key'] will raise a KeyError (or return None, depending on implementation details)
```

### Bug Fix: `LRUCache.pop`
Fixed an issue in `LRUCache.pop` where it could return a stale value after a concurrent eviction occurred. The method now correctly handles race conditions during eviction to ensure consistency.
