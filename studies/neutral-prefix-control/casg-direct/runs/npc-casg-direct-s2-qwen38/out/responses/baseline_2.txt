```markdown
## TTLCache

A Time-To-Live cache that automatically expires entries after a configurable interval.

### Constructor

`TTLCache(maxsize, ttl)`

*   **`maxsize`** (`int`): The maximum number of items the cache can hold.
*   **`ttl`** (`float`): The time-to-live for each entry in seconds. Entries older than this interval are considered expired and will be removed on access or during internal cleanup.

### Methods

#### `get(key, default=None)`
Retrieves the value associated with `key`. If the key exists but has expired, it is removed from the cache and `default` is returned.

#### `set(key, value)`
Inserts or updates the value for `key`. Resets the TTL for this entry.

#### `pop(key, default=None)`
Removes and returns the value associated with `key`. If the key has expired or does not exist, returns `default`.

#### `clear()`
Removes all items from the cache.

#### `__len__()`
Returns the number of non-expired items currently in the cache.

#### `__contains__(key)`
Returns `True` if `key` exists and has not expired, otherwise `False`.
```
