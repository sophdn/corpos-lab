### New in v2.3.0

#### `TTLCache`

Added the `TTLCache` class, which extends caching functionality by allowing entries to expire after a configurable time-to-live (TTL) interval.

```python
class TTLCache(capacity: int, ttl: float):
    """
    A cache that evicts entries after a specified time interval.
    
    Args:
        capacity: The maximum number of items the cache can hold.
        ttl: The time-to-live for each entry in seconds.
    """
    def __init__(self, capacity: int, ttl: float):
        ...

    def get(self, key: Any) -> Optional[Any]:
        """
        Retrieve a value from the cache. Returns None if the key is absent 
        or the entry has expired.
        """
        ...

    def put(self, key: Any, value: Any) -> None:
        """
        Insert or update a key-value pair. The entry will expire after `ttl` seconds.
        """
        ...

    def pop(self, key: Any, default: Optional[Any] = None) -> Optional[Any]:
        """
        Remove and return the value for the given key. Returns `default` if 
        the key is absent or expired.
        """
        ...
```

#### `LRUCache.pop` Behavior Change

Fixed a bug where `LRUCache.pop` could return a stale value if a concurrent eviction occurred during the operation. Now, `pop` guarantees that it returns the current value if the key exists and is not evicted, or `None` (or the specified default) if the key has been evicted or does not exist.
