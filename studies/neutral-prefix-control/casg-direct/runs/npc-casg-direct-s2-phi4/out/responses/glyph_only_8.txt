**Gridcache v2.3.0 Release Summary**

The release of `gridcache` version 2.3.0 introduces a new `TTLCache` class and a fix for an issue in the `LRUCache.pop` method. Here are the key details:

### New Features
- **TTLCache Class**: This new class provides a time-to-live (TTL) caching mechanism, allowing cache entries to expire after a configurable time interval. This feature is useful for scenarios where cached data needs to be refreshed periodically.

### Bug Fixes
- **LRUCache.pop Fix**: The `LRUCache.pop` method previously returned stale values if a concurrent eviction occurred. This issue has been resolved to ensure that the returned value is always up-to-date.

### Versioning
- The version number has been updated in `gridcache/__init__.py` and `pyproject.toml` to reflect the new release.

### Testing
- All 63 tests have passed, confirming the stability and correctness of the new features and fixes.

### Documentation
- The release includes an API reference available at `docs/api-reference.md`, providing detailed information on the usage and capabilities of the updated library.

### Release Process
- The release commit and tag `v2.3.0` have been pushed to the remote repository, marking the completion of the release process.

This release enhances the functionality of `gridcache` by adding time-based cache expiration and improving the reliability of the `LRUCache.pop` method. Users are encouraged to review the updated API reference for detailed instructions on utilizing the new `TTLCache` feature.
