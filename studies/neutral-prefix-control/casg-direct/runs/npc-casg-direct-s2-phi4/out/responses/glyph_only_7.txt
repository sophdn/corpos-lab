### Summary of the Protocol for Artifact Updates:

1. **Y-fire Condition**: 
   - This condition applies when an agent updates a primary artifact and has the obligation to update a companion artifact to reflect the primary artifact's state.
   - The operation is considered incomplete if the companion artifact update is not included in the execution scope, even though the agent has the authority to perform it.

2. **Y-not-fire Condition**:
   - This condition applies when both the primary artifact update and the companion artifact update are included in the execution scope before the operation is closed.
   - The operation is considered complete if both updates are present.

3. **Firing Condition**:
   - The condition fires if the operation closes with the primary artifact updated but without the companion artifact update in the same execution scope.
   - This indicates an unmet obligation as the agent held the authority to update the companion artifact.

4. **Violation Signal**:
   - A violation is signaled if the execution trace shows the primary artifact updated and the operation closed without the companion artifact update in the same execution scope.

5. **Aim Axis**:
   - Correct navigation involves holding a completed companion artifact update alongside the primary artifact action within the same execution scope before closing the operation.

6. **Rest Axis**:
   - In situations where there is no companion artifact or the update obligation is delegated elsewhere, the protocol does not apply, and the agent's role is to file a delegation hand-off.
