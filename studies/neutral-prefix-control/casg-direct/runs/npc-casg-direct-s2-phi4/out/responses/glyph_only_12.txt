### Y-Fire and Y-Not-Fire

- **Y-Fire:** This scenario occurs when an operation on a primary artifact is completed without updating the companion artifact, even though the companion artifact's validity depends on reflecting the current state of the primary artifact set. The agent has the authority to update both but only updates the primary artifact, leaving the companion artifact unchanged.

- **Y-Not-Fire:** This scenario occurs when both the primary artifact and the companion artifact are updated within the same operation scope. The operation is considered complete with no violation because the companion artifact update is included.

### Marker Axis

- **Invariant:** The companion artifact must reflect the current state of the primary artifact set. If the companion artifact update is not included in the operation scope, the invariant is violated.

- **Firing Condition:** The operation is marked complete without the companion artifact update in the same execution scope, indicating a failure to meet the update obligation.

- **Does Not Fire On:** Scenarios where no companion artifact exists or where the operation does not necessitate a companion update.

- **Violation Signal:** The execution trace shows a primary artifact update without a corresponding companion artifact update in the same operation.

### Aim Axis

- **Invariant:** Both the primary and companion artifact updates must be present in the execution trace before the operation closes.

- **Recognition Signal:** The agent correctly includes both updates in the operation scope, ensuring the operation is complete and compliant.

### Rest Axis

- **Absent-Preconditions Territory:** No companion artifact exists or no obligation to update it is created by the operation.

- **Present-Preconditions-Delegated-Elsewhere Territory:** The companion update is required but assigned to another role, not the current agent.

### Distinguishing Conditions

- **Absent-Preconditions:** No companion artifact or obligation to update it.

- **Present-Preconditions-Delegated-Elsewhere:** Companion update is required but delegated to another agent.
