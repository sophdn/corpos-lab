### Y-Fire and Y-Not-Fire Concepts

**Y-Fire:**
- **Scenario:** An agent completes an operation on a primary artifact and has direct authority to update a companion artifact.
- **Condition:** The companion artifact's update, which reflects the primary artifact's state, is not included in the operation's scope.
- **Firing Condition:** The operation closes with the primary artifact updated but without the companion artifact update in the same execution scope.
- **Violation Signal:** The execution trace shows the primary artifact updated without the companion artifact update in the same scope, indicating an unmet obligation.

**Y-Not-Fire:**
- **Scenario:** Similar to Y-Fire, but the companion artifact update is included in the operation's execution scope.
- **Condition:** Both the primary artifact action and the companion artifact update are co-present within the operation's scope before it closes.
- **Non-Firing Condition:** The operation includes both updates, fulfilling the obligation, so the condition does not fire.

### Marker Axis

- **Invariant:** The companion artifact's state should reflect the primary artifact set's current state. If not, the companion artifact update was not executed within the operation's scope.
- **Firing Condition:** The primary artifact is updated, and the operation closes without the companion artifact update in the same scope.
- **Does Not Fire On:** Operations where no companion artifact exists or the primary artifact update does not trigger a companion update obligation.
- **Violation Signal:** The trace shows a primary artifact update without a corresponding companion artifact update in the same execution block.

### Aim Axis

- **Invariant:** The agent must hold a completed companion artifact update co-present with the primary artifact action within the operation's scope.
- **Recognition Signal:** Both updates are present in the trace within the same operation's scope before closure.

### Rest Axis

- **Absent-Preconditions Territory:** No companion artifact update obligation arises because either no companion artifact exists or the operation does not affect the primary artifact in a way that triggers an update.
- **Present-Preconditions-Delegated-Elsewhere Territory:** The companion update obligation exists, but it is assigned to another role, so the current agent must delegate the update.
