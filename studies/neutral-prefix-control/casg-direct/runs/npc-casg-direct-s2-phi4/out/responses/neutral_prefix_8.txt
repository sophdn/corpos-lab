**Release Notes for gridcache v2.3.0**

We are pleased to announce the release of `gridcache` version 2.3.0. This version introduces new features, fixes, and enhancements to improve the overall functionality and performance of the cache system.

### Key Features

- **TTLCache Class**: A new `TTLCache` class has been added, allowing cache entries to expire after a configurable time-to-live (TTL) interval. This feature is particularly useful for applications that require automatic cache invalidation based on time.

### Fixes

- **LRUCache.pop Behavior**: An issue has been resolved where `LRUCache.pop` could return a stale value if a concurrent eviction occurred. This fix ensures that the returned value is always up-to-date.

### Other Information

- All 63 tests have passed, confirming the stability and reliability of this release.
- The version number has been updated in `gridcache/__init__.py` and `pyproject.toml`.
- The release commit and tag `v2.3.0` have been pushed to the remote repository.
- The project continues to publish an API reference at `docs/api-reference.md`.

We hope these updates enhance your experience with `gridcache`. As always, we appreciate your feedback and contributions to the project.
