### Release Notes for `gridcache` v2.3.0

**Version:** v2.3.0

**Key Features:**

- **New Feature:** Introduction of `TTLCache` class.
  - The `TTLCache` class allows entries to expire after a configurable interval. This feature provides a mechanism for automatically removing stale cache entries, improving cache management and potentially enhancing performance by ensuring that outdated data does not persist longer than necessary.

- **Bug Fix:**
  - A fix has been implemented for the `LRUCache.pop` method. Previously, this method could return a stale value after a concurrent eviction. The fix ensures that `pop` always returns the correct value, even if an eviction occurs concurrently, thereby maintaining the integrity and reliability of the cache operations.

**Testing:**
- All 63 tests have been executed and passed, confirming the stability and correctness of the new feature and the bug fix.

**Documentation:**
- The project continues to provide an API reference, which can be accessed at `docs/api-reference.md`. This documentation is crucial for users to understand the functionalities and usage of the new `TTLCache` class and other components of the library.

**Release Process:**
- The version has been updated in `gridcache/__init__.py` and `pyproject.toml`.
- The release commit and tag `v2.3.0` have been pushed to the remote repository, marking the completion of this release.

---

This release enhances the `gridcache` library by adding a new feature for time-to-live cache management and addressing a concurrency issue in the `LRUCache` implementation. The successful completion of all tests ensures that these changes are robust and reliable.
