### Summary of Changes in `gridcache` v2.3.0

The release of `gridcache` v2.3.0 introduces several enhancements and fixes:

1. **New Feature: `TTLCache` Class**
   - A new class named `TTLCache` has been added. This class allows cache entries to expire after a configurable time interval. This feature is useful for managing cache entries that should only be valid for a certain period.

2. **Fix: `LRUCache.pop`**
   - A fix has been implemented for the `LRUCache.pop` method. Previously, this method could return a stale value after a concurrent eviction. The fix ensures that the returned value is current and valid.

3. **Version Bump**
   - The version number has been incremented in both `gridcache/__init__.py` and `pyproject.toml` to reflect the new release, version 2.3.0.

4. **Testing**
   - All 63 tests have been executed and passed, ensuring that the new feature and the fix do not introduce any regressions or new issues.

5. **Documentation**
   - The project continues to publish an API reference at `docs/api-reference.md`. Users are encouraged to review this document for detailed information on the API, including the new `TTLCache` class.

6. **Release Management**
   - The release commit and the tag `v2.3.0` have been pushed to the remote repository, marking the completion of this release.

### Conclusion

The `gridcache` v2.3.0 release focuses on improving the functionality and reliability of the caching system by introducing a time-to-live feature and resolving an issue with stale values in the `LRUCache.pop` method. Users of `gridcache` should update to this version to benefit from these enhancements.
