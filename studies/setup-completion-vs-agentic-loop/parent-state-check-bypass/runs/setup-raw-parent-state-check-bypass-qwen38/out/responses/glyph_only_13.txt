    *   Attempt to parse the string as a URL.
    *   Verify that the parsed URL has a valid scheme (e.g., `http`, `https`) and a valid netloc (host).

**Code Change (Conceptual):**

In `config/validator.py`:

```python
import urllib.parse
from urllib.parse import ParseError

def validate_url_field(field_name, value):
    # Existing check: field is present and non-empty
    if not value:
        raise ValidationError(f"Field '{field_name}' must not be empty.")
    
    # New check: validate URL structure
    try:
        result = urllib.parse.urlparse(value)
        # Check for scheme and netloc
        if not result.scheme or not result.netloc:
            raise ValueError(f"Invalid URL structure: missing scheme or host")
    except (ValueError, ParseError) as e:
        raise ValidationError(f"Field '{field_name}' contains a malformed URL: {e}")
    
    return True # or whatever success signal the function uses
```
