### Root Cause Analysis
The function `validate_url_field()` in `config/validator.py` currently only checks:
1.  Field presence.
2.  Non-empty value.

It does **not** validate the syntactic structure of the URL. Therefore, a string like `"not-a-url"` passes validation, causing the validator to exit with code `0`.

### Proposed Fix

Update `validate_url_field()` in `config/validator.py` to use Python’s standard library `urllib.parse` to verify that the string is a well-formed URL.

```python
# config/validator.py

from urllib.parse import urlparse
import sys

def validate_url_field(field_name: str, value: str) -> bool:
    """
    Validates that the provided value is a syntactically correct URL.
    Returns True if valid, False otherwise.
    """
    if not value:
        return False

    try:
        parsed = urlparse(value)
        # A valid URL must have a scheme (e.g., http, https) and a netloc (domain)
        if parsed.scheme not in ('http', 'https') or not parsed.netloc:
            return False
        return True
    except Exception:
        return False
```
