### 3. Proposed Code Change

Below is the suggested implementation for `config/validator.py`. This assumes a standard Python 3 environment.

```python
import urllib.parse

def validate_url_field(field_name: str, value: str) -> bool:
    """
    Validates that the provided value is a well-formed URL.
    
    Args:
        field_name: The name of the config field (for error messaging).
        value: The string value to validate.
        
    Returns:
        True if the URL is valid, False otherwise.
    """
    if not value or not isinstance(value, str):
        return False

    try:
        parsed = urllib.parse.urlparse(value)
        
        # Check for required components
        if not parsed.scheme:
            return False
        if not parsed.netloc:
            return False
            
        # Optional: Restrict schemes to http/https if required by policy
        if parsed.scheme not in ('http', 'https'):
            return False
            
        return True
    except Exception:
        # urlparse rarely raises, but this is a safe fallback
        return False
```

**Integration in the CLI Entry Point:**
Ensure that the call to `validate_url_field` for `auth_service_url` triggers a non-zero exit code on failure:
