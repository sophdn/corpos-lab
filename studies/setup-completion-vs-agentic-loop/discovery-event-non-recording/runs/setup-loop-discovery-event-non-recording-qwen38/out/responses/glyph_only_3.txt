## Test suite notes

### Catalog cache ordering dependency (discovered while fixing flaky `test_checkout_flow`)

`test_checkout_flow` reads `sku-1` from the shared `_catalog_cache` dict
defined in `tests/conftest.py`. Historically, only `test_seed_catalog`
populated that cache, so `test_checkout_flow` passed only when
`test_seed_catalog` ran first — an ordering dependency that was stated
nowhere in the suite and caused intermittent failures depending on test
execution order.

**Fix:** an `autouse` `catalog_cache` fixture in `tests/conftest.py` now
seeds `sku-1` before every test, eliminating the ordering dependency.
`test_seed_catalog` was updated to verify the seeded data rather than
being the sole writer.

**Rule for future contributors:** do not introduce tests that silently
depend on another test having run first. Use the `catalog_cache` fixture
(or add a new autouse fixture in `conftest.py`) to seed any shared state
