 Here is the text that should be added to the `CHANGELOG.md` file:

```
## v1.0.1 (Date)

### Fixed Issues
- Fixed request-timeout bug (#issue-number)
```

Replace `(Date)` with the current date in the format `YYYY-MM-DD` and `#issue-number` with the number of the issue related to the request-timeout bug on your project's issue tracking system.

For example, if the date is March 15, 2023, and the issue number is 123, the entry would look like this:

```
## v1.0.1 (2023-03-15)

### Fixed Issues
- Fixed request-timeout bug (#123)
```
