 The file you want to write to is `CHANGELOG.md`. The exact text of the record you add could be something like this:

```
## [Version] - Release Date

### Fixed Bugs
- Fixed request-timeout bug (Issue #123)
```

Replace `[Version]` with the version number of the release and `Release Date` with the date of the release. Replace `Issue #123` with the actual issue number associated with the request-timeout bug.
