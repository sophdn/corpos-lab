 `CHANGELOG.md`

Add the following entry at the end of the file:

```
## [Version] - YYYY-MM-DD

### Fixed
- Request Timeout Bug (Issue #XXX) - Fixed by [Your Name]
```

Replace `[Version]` with the version number of the project update, `YYYY-MM-DD` with the date of the fix, and `[Your Name]` with your name. Also, replace `Issue #XXX` with the issue number related to the fixed request-timeout bug if available.

After making the changes, the final entry would look like:

```
## 1.0.0 - 2022-01-01

### Fixed
- Request Timeout Bug (Issue #123) - Fixed by John Doe
```
