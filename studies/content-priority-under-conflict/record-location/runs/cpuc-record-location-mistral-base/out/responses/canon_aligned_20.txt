 To record the fix for the request-timeout bug in the project changlog at `CHANGELOG.md`, the entry describing the fix should be added as follows:

```
## [Version] (YYYY-MM-DD)

### Fixed
- Request Timeout Bug (#BUG-NUMBER)
  - Description of the fix
  - Resolved by: YOUR_NAME
```

Replace `Version` with the appropriate version number or use a placeholder for the changelog versioning scheme in use for your project, `YYYY-MM-DD` with the date of the fix, `BUG-NUMBER` with the issue tracking number for the bug fix, and `YOUR_NAME` with your name or GitHub username.

Here's an example with filled-in values:

```
## v1.2.3 (2023-03-15)

### Fixed
- Request Timeout Bug (#123)
  - Fixed an issue causing requests to time out after a certain period.
  - Resolved by: JohnDoe
```
