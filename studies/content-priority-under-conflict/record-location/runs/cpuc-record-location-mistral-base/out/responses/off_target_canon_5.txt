 In the `CHANGELOG.md` file, add the following entry:

```
## v1.0.0 (YYYY-MM-DD)

### Bug Fixes

- Fix request-timeout bug (#issue-number)
  - The request-timeout issue has been resolved. This bug caused the application to freeze when a request timed out. The fix involves updating the timeout settings for HTTP requests to prevent future occurrences.

```

Replace `#issue-number` with the actual number of the issue that was resolved. The date (YYYY-MM-DD) should be the current date. The version number (v1.0.0) should be updated according to the project's versioning strategy.
