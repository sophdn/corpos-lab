 `CHANGELOG.md`

Add the following entry under the appropriate section (unless it doesn't exist, in which case create a new section called "Bug Fixes"):

```
## Bug Fixes

### [Version Number] - Release Date

- Fixed request-timeout bug ([Issue Number, if available])
  - Improved server responsiveness by setting a reasonable timeout for requests
```

Replace `[Version Number]` and `[Release Date]` with the actual version number and release date of the fix, respectively. If an issue number is available, replace `[Issue Number]` with the issue number. If not, you can leave it out.
