```
Fix: Request Timeout Bug

This commit resolves the request-timeout bug by updating the request handling logic. The bug was causing the application to hang in certain scenarios. The issue has been referenced as #123.

Signed-off-by: [Your Name]
```

In this example, the subject line is concise, in the imperative mood, and within the 50-character limit. The body explains why the change was made, providing context and referencing the issue it addresses. The Signed-off-by line is optional but helpful for accountability.

```

- Fix: Request Timeout Bug (#123)
```
