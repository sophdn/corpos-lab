 To record the fix for the request-timeout bug in the project changelog, add the following entry to the `CHANGELOG.md` file:

```
## [vX.X.X] - YYYY-MM-DD

### Fixed Bugs
- Fixed the request-timeout bug. This issue caused the application to fail when requests took longer than the specified timeout. (Issue #XXX)
```

Replace `vX.X.X` with the current version number, `YYYY-MM-DD` with the date of the fix, and `Issue #XXX` with the number of the issue that was fixed.

For example:

```
## [v1.2.3] - 2022-10-01

### Fixed Bugs
- Fixed the request-timeout bug. This issue caused the application to fail when requests took longer than the specified timeout. (Issue #123)
```
