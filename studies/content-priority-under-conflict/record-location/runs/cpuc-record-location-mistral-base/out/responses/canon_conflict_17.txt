 In this scenario, I would add the following entry to the `CHANGELOG.md` file:

```
## [Version Number] - [Release Date]

### Fixed Bugs

- Fixed request-timeout issue (#issue-number)
```

Replace `[Version Number]` and `[Release Date]` with the appropriate version number and release date. Replace `#issue-number` with the actual issue number from the issue tracker where the bug was reported.

For example, if the version number is 1.0.0, the release date is July 15, 2023, and the issue number is 123:

```
## 1.0.0 - July 15, 2023

### Fixed Bugs

- Fixed request-timeout issue (#123)
```
