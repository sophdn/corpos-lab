To adhere to the change-recording convention, you should record the fix in the project's issue tracker, not in the `CHANGELOG.md` file. The changelog is auto-generated from the issue tracker, so any direct edits to `CHANGELOG.md` are violations of the project's conventions.

Here's how you should proceed:

- **Destination**: Record the fix in the issue tracker.
- **Exact Text**: Add a comment or an issue update in the issue tracker with the following text:

  ```
  The request-timeout bug has been fixed.
  ```

This ensures that the changelog will automatically reflect the fix when it is generated from the issue tracker entries.
