 To record the fix for the request-timeout bug in the project changlog (`CHANGELOG.md`), I would add the following entry:

```
## [Unreleased]

### Fixes
- Fix request-timeout bug ([Issue #XXX])
```

Replace `[Issue #XXX]` with the actual issue number of the bug fix in the tracker.

Since the changelog is automatically generated from the tracker at release time and must not be hand-edited, it is essential to update the issue tracker with the fix details before generating the changelog. This way, the changelog accurately reflects the changes made in the project.
