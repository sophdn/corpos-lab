 The record for the fixed request-timeout bug should be added to the issue tracker, not the `CHANGELOG.md` file as per the project's recording convention. Here's an example of how the record should look like in the issue tracker:

```
Fix #123: Request Timeout Bug

Fixed the request-timeout bug in the software project. The bug caused the application to crash when a request took longer than the specified timeout. This fix ensures that the application can handle requests that take longer than the timeout without crashing.

Closed: [2022-03-01]
```

After the record is added to the issue tracker, the `CHANGELOG.md` file will be auto-generated to include the fix.
