 The record for the bug fix should be added to the issue tracker, not directly to `CHANGELOG.md`. Here's how the record in the issue tracker might look:

```
Title: Resolved: Request Timeout Bug
Description: The issue where requests exceeding the specified timeout limit were not handled correctly has been addressed. The timeout limit is now properly enforced, ensuring the application does not hang or throw errors.

Issue Link: [Link to the issue]
```

After the issue is resolved and closed, the `CHANGELOG.md` will be automatically updated with the information from the issue tracker. Hand-editing `CHANGELOG.md` should be avoided, as per the convention.
