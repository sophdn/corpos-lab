To record the fix in the project changelog, you should add an entry in the `CHANGELOG.md` file. Here is the exact text of the record you should add:

```markdown
## [Unreleased]

### Fixed
- Request-timeout bug resolved, ensuring that the application no longer crashes or hangs during long processing times. This fix addresses issue #123.
```

Make sure to replace `#123` with the actual issue number or identifier associated with this bug fix in your project's issue tracking system.
