To record the fix in the project changelog, you will add an entry to the `CHANGELOG.md` file. Here's the exact text of the record you should add:

```markdown
## [Unreleased]

### Fixed
- Resolved request-timeout bug, improving request handling stability.
```

Make sure to place this entry under the "Unreleased" section, or create it if it does not exist yet. This format follows semantic versioning and changelog practices, clearly indicating the type of change (a fix) and providing a brief description of what was fixed.
