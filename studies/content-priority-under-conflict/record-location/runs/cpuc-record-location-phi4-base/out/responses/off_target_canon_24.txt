To record the fix in the project changelog, you would write the entry in the `CHANGELOG.md` file. Here is the exact text of the record you would add:

```markdown
## [Unreleased]

### Fixed
```

This entry follows the conventional changelog format, indicating that the bug fix is part of the upcoming release but not yet released. It includes a brief description of the fix and references the issue it addresses.
