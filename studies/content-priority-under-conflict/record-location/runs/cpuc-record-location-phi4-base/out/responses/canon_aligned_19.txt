To record the fix in the project changelog, you will write to the file `CHANGELOG.md` with the following entry:

```markdown
## [Unreleased]
- Fixed request-timeout bug to ensure stable and predictable request handling under various network conditions.
```

This entry should be added under the "Unreleased" section of the `CHANGELOG.md` file. If the "Unreleased" section does not exist, you may need to add it.
