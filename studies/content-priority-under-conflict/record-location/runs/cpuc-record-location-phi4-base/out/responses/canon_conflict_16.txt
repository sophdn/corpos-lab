To record the fix in the project changelog, you should write to the `CHANGELOG.md` file. Since the changelog is auto-generated, you will not manually edit it, but for the purpose of this exercise, the entry would look like this:

```
## [Unreleased]
### Fixed
- Request-timeout bug resolved.
```

The entry would be added to the changelog in the appropriate section, typically under a version that has not yet been released.
