The fix record should not be added to `CHANGELOG.md` as per the change-recording convention. Instead, the fix should be recorded in the issue tracker. Therefore, no record should be added to `CHANGELOG.md`.

However, if you were to hypothetically add an entry to an issue tracker for the fix, it might look like this:

**Issue Tracker Entry:**
- **Title:** Fix request-timeout bug
- **Description:** The request-timeout bug has been resolved. The timeout mechanism now correctly handles long request durations without causing failures.
- **Status:** Closed

But remember, this entry is for the issue tracker, not `CHANGELOG.md`.
