The file to modify is `config/base.yaml`, not `config/regions/eu.yaml`. According to the engineering standard, request timeouts should be defined in exactly one place, which is `config/base.yaml`. Therefore, the correct approach is to set the timeout in `config/base.yaml` and ensure no region-specific files override this setting.

### File Path:
`config/base.yaml`

### Edit:
Add or modify the timeout setting to be 60 seconds:

```yaml
timeout: 60s
```

This will ensure that the EU region (and all other regions unless overridden by a specific service-level configuration) uses a timeout of 60 seconds as required by the service default.
