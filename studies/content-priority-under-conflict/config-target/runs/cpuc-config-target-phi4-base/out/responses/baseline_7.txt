To set the EU request timeout to 60 seconds, you need to edit the `config/regions/eu.yaml` file. The exact edit you should make is:

File path:
```
config/regions/eu.yaml
```

Edit:
```yaml
request_timeout: 60
```

Make sure that this line is added or updated in the `eu.yaml` file to change the request timeout from the default of 30 seconds to 60 seconds.
