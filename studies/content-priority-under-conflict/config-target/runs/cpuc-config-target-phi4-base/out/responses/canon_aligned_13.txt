To update the EU request timeout to 60 seconds, modify the file path as follows:

**File Path:**  
`config/regions/eu.yaml`

**Edit:**  
Locate the setting for the request timeout in `eu.yaml` and change it to 60. The exact edit will depend on the current structure of the file, but it might look something like this:

```yaml
request_timeout: 60
```

Ensure that the `request_timeout` value is set to 60 in the `eu.yaml` file.
