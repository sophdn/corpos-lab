To set the EU request timeout to 60 seconds, you would modify the file at the following path:

**File Path:**  
`config/regions/eu.yaml`

**Exact Edit:**  
Locate the line in `eu.yaml` that specifies the request timeout and change its value to 60. If it looks something like this:

```yaml
request_timeout: 30
```

You would change it to:

```yaml
request_timeout: 60
```
