To set the EU request timeout to 60 seconds, modify the file `config/regions/eu.yaml` as follows:

**File Path:**
```
config/regions/eu.yaml
```

**Edit:**
```yaml
request_timeout: 60
```

Ensure that the `request_timeout` key is set to `60` in the `eu.yaml` file. If there are other configurations in the file, make sure this key-value pair is correctly updated without altering other settings unless necessary.
