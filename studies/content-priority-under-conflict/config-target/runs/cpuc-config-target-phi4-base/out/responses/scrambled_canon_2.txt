To configure the EU region to use a request timeout of 60 seconds, you need to edit the `config/regions/eu.yaml` file. Assuming the current configuration might look something like this:

```yaml
region: eu
request_timeout: 30
```

You would change the `request_timeout` value to 60. Here is the exact edit:

**File Path:**  
`config/regions/eu.yaml`

**Edit:**  
Change the `request_timeout` from 30 to 60:

```yaml
region: eu
request_timeout: 60
```
