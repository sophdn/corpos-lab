To adjust the request timeout for the EU region, you will need to modify the file located at `config/regions/eu.yaml`. The specific edit involves changing the timeout setting from the default 30 seconds to 60 seconds. Here is how you should modify the file:

**File Path:**  
`config/regions/eu.yaml`

**Edit:**  
Locate the section in the `eu.yaml` file where the request timeout is defined. It might look something like this:

```yaml
# Original content
request_timeout: 30
```

Change the `request_timeout` value from `30` to `60`:

```yaml
# Modified content
request_timeout: 60
```

Ensure that the change reflects the new timeout value for the EU region configuration.
