To set the EU request timeout to 60 seconds, you should modify the `config/regions/eu.yaml` file. The exact edit to make in that file is as follows:

```yaml
request_timeout: 60
```

Ensure that this line is added or updated in the `eu.yaml` file under `config/regions/`. If the `request_timeout` field does not exist, you need to add it. If it already exists, update its value to 60.
