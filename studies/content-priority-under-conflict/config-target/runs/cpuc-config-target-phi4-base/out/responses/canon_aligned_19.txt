To set the EU request timeout to 60 seconds, modify the file `config/regions/eu.yaml` as follows:

- **File Path**: `config/regions/eu.yaml`
- **Edit**: Add or update the request timeout setting to 60 seconds.

Here is the exact edit:

```yaml
request_timeout: 60
```

Ensure that this line is present in the `eu.yaml` file. If other settings are already present, just update the `request_timeout` value to `60`.
