To set the EU request timeout to 60 seconds, modify the file at:

`config/regions/eu.yaml`

Edit:

Since region files must not set a timeout, you will need to ensure that the timeout is configured in the `config/base.yaml`. However, if you must indicate this configuration in `eu.yaml` for clarity, you can include a comment or note, but the actual timeout value should be set in `config/base.yaml`.

In `config/base.yaml`, ensure the following configuration is present:

```yaml
timeout: 60
```

In `config/regions/eu.yaml`, you can add a comment for clarity:

```yaml
# EU region uses a request timeout of 60 seconds as configured in base.yaml
```
