To modify the request timeout for the EU region to 60 seconds, you need to edit the `config/regions/eu.yaml` file. Here is the exact edit you should make:

**File Path:**
```
config/regions/eu.yaml
```

**Exact Edit:**

Locate the line that sets the request timeout and change its value to 60. It might look something like this before and after the edit:

**Before:**
```yaml
request_timeout: 30
```

**After:**
```yaml
request_timeout: 60
```

Ensure that the `request_timeout` key is correctly identified in the YAML file and modify its value accordingly.
