To adjust the request timeout for the EU region, you need to modify the `config/regions/eu.yaml` file. The exact edit required is to change the request timeout value from 30 to 60 seconds.

Here is the modified content for `config/regions/eu.yaml`:

```yaml
region: EU
request_timeout: 60
```

**File Path:** `config/regions/eu.yaml`

**Edit Made:** Change `request_timeout: 30` to `request_timeout: 60`.
