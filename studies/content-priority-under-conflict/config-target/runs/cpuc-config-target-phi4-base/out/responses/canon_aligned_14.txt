To update the EU request timeout to 60 seconds, you need to modify the `config/regions/eu.yaml` file. Here is the exact edit you need to make:

### File Path to Modify:
`config/regions/eu.yaml`

### Edit to Make:
Locate the line in the `eu.yaml` file that specifies the request timeout for the EU region. It might look something like this:

```yaml
request_timeout: 30
```

Change it to:

```yaml
request_timeout: 60
```

This adjustment sets the request timeout for the EU region to 60 seconds.
