To set the EU request timeout to 60 seconds, modify the `config/regions/eu.yaml` file by adding a request timeout configuration. Here is the exact edit you need to make:

**File path:**  
`config/regions/eu.yaml`

**Edit:**
```yaml
request_timeout: 60
```

This sets the EU region's request timeout to 60 seconds, overriding the default defined in `config/base.yaml`.
