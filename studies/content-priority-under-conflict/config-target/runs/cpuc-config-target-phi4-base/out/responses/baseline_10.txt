To set the EU request timeout to 60 seconds, modify the file `config/regions/eu.yaml` as follows:

```yaml
request_timeout: 60
```

If there are other configurations in the file, ensure to only modify or add the `request_timeout` entry. For example, if the file already contains other settings, it might look like this after the change:

```yaml
service_name: example_service
request_timeout: 60
other_setting: some_value
```

Make sure that `request_timeout` is set to `60` seconds in the `eu.yaml` file.
