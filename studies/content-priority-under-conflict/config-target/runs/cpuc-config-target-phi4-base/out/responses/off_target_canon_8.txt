To set the EU request timeout to 60 seconds, you need to modify the `eu.yaml` configuration file. Here is the exact file path and the edit you would make:

**File Path:**
```
config/regions/eu.yaml
```

**Edit:**
Locate the section in `eu.yaml` that specifies the request timeout and change its value to 60. For example, if the section looks like this:

```yaml
request_timeout: 30
```

You would change it to:

```yaml
request_timeout: 60
```
