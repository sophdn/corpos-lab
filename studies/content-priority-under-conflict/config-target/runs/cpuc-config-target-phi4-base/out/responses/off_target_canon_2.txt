To configure the EU region to use a request timeout of 60 seconds, you would modify the `config/regions/eu.yaml` file. Here is the exact edit you would make to it:

**File Path:**
```
config/regions/eu.yaml
```

**Edit:**
```yaml
request_timeout: 60
```

This change sets the request timeout specifically for the EU region to 60 seconds, overriding the default of 30 seconds.
