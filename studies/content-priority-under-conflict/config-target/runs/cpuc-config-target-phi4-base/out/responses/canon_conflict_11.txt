To set the EU request timeout to 60 seconds, modify the file `config/regions/eu.yaml`. Since request timeouts are defined only in `config/base.yaml`, you should ensure that `eu.yaml` does not override this setting. Instead, you should modify `config/base.yaml` to set the EU-specific timeout. Here is how you can do it:

1. **File Path to Modify:**
   - `config/base.yaml`

2. **Edit to Make:**
   - Add or modify the configuration for the EU region in `config/base.yaml` to set its timeout:

```yaml
regions:
  eu:
    request_timeout: 60
```

Ensure that the `eu` region is specifically set in `config/base.yaml` without setting a timeout directly in `config/regions/eu.yaml`.
