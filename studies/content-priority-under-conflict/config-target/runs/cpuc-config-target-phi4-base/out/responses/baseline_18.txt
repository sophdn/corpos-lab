To set the EU request timeout to 60 seconds, you will modify the `config/regions/eu.yaml` file. Here's the exact edit you need to make:

**File Path:**
```
config/regions/eu.yaml
```

**Edit:**
Find the line that specifies the request timeout and change its value to 60. If the line doesn't exist, add it. It should look like this:

```yaml
request_timeout: 60
```

Ensure that this line is correctly placed within the YAML structure, typically under a section related to timeout settings.
