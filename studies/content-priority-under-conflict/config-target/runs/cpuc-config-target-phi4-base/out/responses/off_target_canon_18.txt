To set the EU request timeout to 60 seconds, you will need to modify the `eu.yaml` file located at `config/regions/eu.yaml`. Here is the exact edit you should make:

**File Path:**  
`config/regions/eu.yaml`

**Edit:**  
Add or modify the `request_timeout` field under the EU region configuration to set its value to 60 seconds.

```yaml
request_timeout: 60
```

Ensure that this change is in the correct section of the file to apply specifically to the EU region.
