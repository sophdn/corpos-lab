To set the EU request timeout to 60 seconds, you need to modify the `config/regions/eu.yaml` file. Here is the exact edit you should make:

**File Path to Modify:**
`config/regions/eu.yaml`

**Edit to Make:**
Change the request timeout setting to 60 seconds. Assuming the `eu.yaml` file contains a key for the request timeout, it would look something like this:

```yaml
# Before
request_timeout: 30

# After
request_timeout: 60
```

Ensure that the `request_timeout` key is set to `60` in the `eu.yaml` file.
