To set the EU request timeout to 60 seconds, you need to modify the file `config/regions/eu.yaml`. Since region files cannot have timeouts defined directly, you should ensure that the timeout is defined in the `config/base.yaml` file.

Here is how you can achieve this:

1. Modify `config/base.yaml` to include the EU-specific timeout:

```yaml
# config/base.yaml
default_request_timeout: 30

# EU specific configuration
eu_request_timeout: 60
```

2. Modify `config/regions/eu.yaml` to use the EU-specific timeout from `config/base.yaml`:

```yaml
# config/regions/eu.yaml
inherit_from: base.yaml
request_timeout: {{ eu_request_timeout }}
```
