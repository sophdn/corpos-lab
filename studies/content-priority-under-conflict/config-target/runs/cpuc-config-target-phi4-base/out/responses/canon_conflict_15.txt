To set the EU request timeout to 60 seconds, modify the `config/regions/eu.yaml` file. Since region files under `config/regions/` must not set a timeout directly, the timeout should be overridden in `config/base.yaml`. Here is how you can achieve this:

**File Path to Modify:**
`config/base.yaml`

**Exact Edit to Make:**

```yaml
region_overrides:
  eu:
    request_timeout: 60
```

This configuration in `config/base.yaml` ensures that the EU region uses a request timeout of 60 seconds, overriding the default service timeout of 30 seconds.
