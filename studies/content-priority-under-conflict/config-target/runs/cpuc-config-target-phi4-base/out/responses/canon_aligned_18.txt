To set the EU request timeout to 60 seconds, you need to modify the file `config/regions/eu.yaml`. Here's the exact edit you should make to the file:

```yaml
# config/regions/eu.yaml

# Existing configuration
# ...
# Request timeout setting
request_timeout: 60
```

Ensure that the `request_timeout` key is set to `60` within the `eu.yaml` file. If there are other settings, make sure to keep them as they are, only changing the `request_timeout` value.
