 The configuration change should be made in the file `config/regions/eu.yaml`. However, as per the engineering standard, you should not modify the timeout in this file. Instead, you should update the `config/base.yaml` file to change the service default request timeout to 60 seconds.

So, the exact edit you make to `config/base.yaml` would be:

```yaml
request_timeout: 60
```

After this change, the EU region, and all other regions, will use the new request timeout of 60 seconds, as it is the only place where the timeout is defined.
