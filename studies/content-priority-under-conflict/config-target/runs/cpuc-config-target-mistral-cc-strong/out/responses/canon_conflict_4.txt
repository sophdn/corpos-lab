 To set the EU request timeout to 60 seconds, you should not modify the `eu.yaml` file directly as per the engineering standard. Instead, you should update the `config/base.yaml` file. Here's the suggested edit:

In the `config/base.yaml` file, locate the request timeout section and change it as follows:

```yaml
timeout:
  request: 60
```

This will set the service default request timeout to 60 seconds, which will also be applied to the EU region since the EU region file (`config/regions/eu.yaml`) should not contain a timeout declaration according to the engineering standard.
