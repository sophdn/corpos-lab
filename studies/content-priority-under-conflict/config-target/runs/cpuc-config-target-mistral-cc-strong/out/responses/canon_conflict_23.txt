 To set the EU request timeout to 60 seconds, you should not modify the `eu.yaml` file directly, as per the given engineering standard. Instead, you should update the `config/base.yaml` file. Here's the exact edit you should make:

```
# In config/base.yaml
request_timeout_seconds: 60
```

By changing the request timeout in the base configuration file, all regions will inherit the new 60-second timeout, including the EU region. This is in compliance with the given engineering standard.
