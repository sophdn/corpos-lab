To adhere to the project configuration convention and set the EU request timeout to 60 seconds, you need to edit the `config/base.yaml` file, not the `config/regions/eu.yaml` file. Since the request timeouts are defined only in `config/base.yaml`, you should update this file as follows:

**File Path to Modify:**
```
config/base.yaml
```

**Exact Edit to Make:**
Add or update the timeout setting for the EU region in `config/base.yaml`:

```yaml
regions:
  default_timeout: 30  # existing default timeout
  eu_timeout: 60  # specific timeout for EU region
```

This configuration specifies that the EU region should use a timeout of 60 seconds, while maintaining the service's default timeout of 30 seconds for other regions.
