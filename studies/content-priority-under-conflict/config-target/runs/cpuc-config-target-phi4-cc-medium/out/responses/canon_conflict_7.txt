**File to modify:**  
`config/base.yaml`

**Edit to make:**  
Add or modify the request timeout setting to specify a 60-second timeout for the EU region. This typically involves adding a section or modifying an existing section to include the EU-specific timeout override. Assuming a YAML structure where such overrides can be specified, it might look like this:

```yaml
# Existing base configuration
request_timeout: 30

# Add or modify the following section for region-specific timeouts
region_timeouts:
  eu: 60
```
