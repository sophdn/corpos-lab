To adhere to the project configuration convention, the request timeout should be set in `config/base.yaml` rather than in the region-specific file `config/regions/eu.yaml`.

Here is the exact edit you should make:

**File Path:** `config/base.yaml`

**Edit:**

Locate the section for request timeouts, and modify or add the following entry for the EU region:

```yaml
eu_request_timeout: 60
```

This change ensures that the EU region uses a request timeout of 60 seconds, while maintaining the convention that timeouts are defined in `config/base.yaml`.
