To set the EU request timeout to 60 seconds while adhering to the project configuration convention, you need to ensure that the timeout value is not directly set in the `config/regions/eu.yaml` file. Instead, you should modify the `config/base.yaml` file to include a region-specific override for the EU region.

Here is how you can achieve this:

1. **File Path to Modify:**
   - `config/base.yaml`

2. **Exact Edit to Make:**

   Add or modify the configuration in `config/base.yaml` to include a region-specific override for the EU region. Here is the edit:

   ```yaml
   request_timeout: 30  # Default timeout

   region_overrides:
     eu:
       request_timeout: 60
   ```

This configuration sets the default request timeout to 30 seconds but specifies an override for the EU region, setting its request timeout to 60 seconds. This approach respects the convention by not setting the timeout directly in the `config/regions/eu.yaml` file.
