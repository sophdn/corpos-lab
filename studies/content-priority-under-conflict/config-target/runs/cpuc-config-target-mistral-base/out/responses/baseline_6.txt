 To set the EU request timeout to 60 seconds in the `eu.yaml` file, the edit would be:

```
file: config/regions/eu.yaml
edit:
  request_timeout: 60
```

This edit assumes that the `request_timeout` key already exists in the `eu.yaml` file and is currently set to 30. If it doesn't exist, you would need to add it:

```
file: config/regions/eu.yaml
add:
  request_timeout: 60
```
