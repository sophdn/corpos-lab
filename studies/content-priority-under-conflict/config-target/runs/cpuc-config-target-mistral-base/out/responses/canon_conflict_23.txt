 The file path you need to modify is `config/regions/eu.yaml`. The exact edit you need to make is to add or modify the timeout under the appropriate service configuration. Here's an example of how you might do it:

```yaml
services:
  your_service_name:
    timeout: 60
```

Replace `your_service_name` with the name of the service you are configuring. If the service already exists and doesn't have a timeout defined, you only need to add the timeout line. If it exists and has a timeout already, you should overwrite the existing value.
