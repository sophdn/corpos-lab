 To modify the request timeout for the EU region, you should edit the file `config/regions/eu.yaml`. Here's the exact edit you need to make:

```yaml
request_timeout: 60
```

Add this line under any existing keys in the `eu.yaml` file, ensuring it's at the same level as other keys like `service_name` or `region`.

After making the change, the `eu.yaml` file should look something like this:

```yaml
service_name: your-service-name
region: eu
request_timeout: 60
```
