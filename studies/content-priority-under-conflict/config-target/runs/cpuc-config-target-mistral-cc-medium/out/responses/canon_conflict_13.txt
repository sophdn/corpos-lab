 The file path you need to modify is `config/regions/eu.yaml`. The exact edit you should make is to add or modify the request timeout key under the service you're working with. Here's an example of how it might look if you're configuring an HTTP service:

```yaml
services:
  http:
    requestTimeout: 60
```

If the service is already defined and the timeout key is missing, you'll simply add the line above. If it's already there but with a different value, you'll replace the existing value with `60`.
