To set the EU request timeout to 60 seconds, you need to modify the `config/base.yaml` file. The region-specific file `config/regions/eu.yaml` should not contain timeout settings due to the enforced standard.

**File to modify:** `config/base.yaml`

**Exact edit to make:**

In `config/base.yaml`, locate the section where request timeouts are defined and update the EU region's timeout as follows:

```yaml
# config/base.yaml

# Existing timeout configuration
request_timeouts:
  eu: 60  # Update the EU region timeout to 60 seconds
  # other regions and their timeouts
```

This change ensures that the EU region uses a 60-second timeout, adhering to the single-source rule for timeout configuration.
