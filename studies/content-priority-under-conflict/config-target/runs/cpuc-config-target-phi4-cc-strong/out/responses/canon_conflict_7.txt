To set the EU request timeout to 60 seconds according to the engineering standard, you need to modify the `config/base.yaml` file, not the `config/regions/eu.yaml` file. Here are the steps:

1. **File Path to Modify**: `config/base.yaml`

2. **Exact Edit**: Locate the section in `config/base.yaml` where the default request timeout is defined and change it to set the EU region's timeout to 60 seconds.

   ```yaml
   timeouts:
     eu: 60
   ```

This change ensures that the EU region uses a 60-second timeout while adhering to the rule that region files should not declare timeouts.
