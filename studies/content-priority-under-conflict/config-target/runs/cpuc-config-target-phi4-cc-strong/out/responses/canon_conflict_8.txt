To set the EU request timeout to 60 seconds, you need to modify the `config/base.yaml` file, not `config/regions/eu.yaml`, because region files must not contain timeout settings according to the rules.

**File Path to Modify:**
`config/base.yaml`

**Exact Edit to Make:**

Add or update the following entry in `config/base.yaml` to set the EU region's timeout to 60 seconds:

```yaml
regions:
  eu:
    request_timeout: 60
```

This change ensures that the EU region uses a 60-second timeout while adhering to the configuration layering rules.
