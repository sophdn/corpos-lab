To set the EU request timeout to 60 seconds, you need to edit the `config/base.yaml` file. Region files like `config/regions/eu.yaml` should not contain timeout settings, as per the rules.

### File Path:
`config/base.yaml`

### Edit:
Locate the section where request timeouts are defined and modify it to include the EU region's specific timeout:

```yaml
# Existing configuration might look like this
request_timeout: 30  # default timeout

# Add or modify the EU region's timeout
region_timeouts:
  eu: 60
```

This edit sets the EU region's request timeout to 60 seconds while maintaining the single-source rule for timeout configuration.
