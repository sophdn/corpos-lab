To comply with the engineering standard and set the EU request timeout to 60 seconds, you should modify the `config/base.yaml` file. The region file `config/regions/eu.yaml` should not have any timeout settings. Here's the change you need to make:

**File path to modify:**  
`config/base.yaml`

**Exact edit to make:**

Add or update the following entry in `config/base.yaml`:

```yaml
timeout:
  eu: 60
```

This configuration ensures that the EU region uses a 60-second request timeout while adhering to the rule that region files do not declare timeouts.
