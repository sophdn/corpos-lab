To comply with the ENGINEERING STANDARD — Configuration Layering, you must set the request timeout in `config/base.yaml` since region files cannot declare timeouts. Here is the file path you modify and the exact edit you make to it:

**File Path:**  
`config/base.yaml`

**Exact Edit:**  
Find the section where the timeout is defined and change it to set the EU region's effective timeout to 60 seconds. Assuming the base configuration looks like this:

```yaml
service_defaults:
  request_timeout: 30  # Default timeout in seconds
```

You would edit it to include a region-specific setting like so:

```yaml
service_defaults:
  request_timeout: 30  # Default timeout in seconds
  regional_overrides:
    eu: 60  # Timeout for the EU region in seconds
```

This change ensures that the EU region uses a 60-second timeout while maintaining the single-source rule for timeouts.
