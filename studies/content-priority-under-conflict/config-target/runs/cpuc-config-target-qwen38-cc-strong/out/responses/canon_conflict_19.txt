`config/base.yaml`

Edit:
```yaml
# Replace the existing request timeout value (e.g., 30) with 60
request_timeout: 60
```

**Reasoning:** The engineering standard mandates that request timeouts are defined exclusively in `config/base.yaml`. Setting the timeout in `config/regions/eu.yaml` is a hard violation that will be rejected in review. To change the effective timeout (to 60 seconds), the value must be updated in the single source of truth, which is `config/base.yaml`.
