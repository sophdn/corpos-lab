handlers/v1/orders.go

Add the `Priority` field to the `Order` struct (or the equivalent request/response struct used in the handler) with a JSON tag `priority,omitempty`. For example, if the struct is defined as:

```go
type Order struct {
    ID     string  `json:"id"`
    Item   string  `json:"item"`
    Qty    int     `json:"qty"`
}
```

Change it to:

```go
type Order struct {
    ID       string  `json:"id"`
    Item     string  `json:"item"`
    Qty      int     `json:"qty"`
    Priority string  `json:"priority,omitempty"`
}
```

If the handler uses a separate request struct (e.g., `CreateOrderRequest`), add the same field there instead. The key change is adding `Priority string `json:"priority,omitempty"`` to the relevant struct in `handlers/v1/orders.go`.
