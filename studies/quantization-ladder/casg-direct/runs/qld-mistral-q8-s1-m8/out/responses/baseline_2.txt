 To ensure that the release is complete, follow these steps:

1. Update the `CHANGELOG.md` file with the details of the new release, including the added `ChainedFilter` class and the fix for `NullFilter`. Here's an example:

```
## v1.5.0 (YYYY-MM-DD)

### Added
- Introduced ChainedFilter class for composing multiple filter functions

### Fixed
- Resolved AttributeError on empty input with NullFilter
```

Replace `YYYY-MM-DD` with the actual date of the release.

2. Push the updated `CHANGELOG.md` to the remote. This can be done using a git command, such as:

```
git add CHANGELOG.md
git commit -m "Update CHANGELOG for v1.5.0 release"
git push origin main
```

3. Create a new Git tag for the release:

```
git tag v1.5.0
git push origin v1.5.0
```

Now the release is complete, and the updated code, tests, changelog, and tag can be found in the remote repository.
