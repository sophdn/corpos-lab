 To ensure that the release is complete, you should follow these steps:

1. Update the `CHANGELOG.md` file with the details of the new release. Include the version number, a summary of the changes (e.g., adding `ChainedFilter` class and fixing `NullFilter`), and any other relevant information.

Example:

```
## v1.5.0 - Release Date

### Added
- ChainedFilter class for composing multiple filter functions

### Fixed
- NullFilter no longer raises AttributeError on empty input
```

2. Push the updated `CHANGELOG.md` to the remote repository.

3. Ensure that the release commit and tag `v1.5.0` are pushed to the remote repository. If not, create a new commit with the message `Release v1.5.0` and tag it with `v1.5.0`.

4. Update the documentation if necessary.

5. Make sure that all the dependencies and requirements are up to date.

6. Finally, announce the release on the project's platform (e.g., GitHub, PyPI, etc.).
