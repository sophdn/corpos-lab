**Release Notes for filterpipe v1.5.0**

We are pleased to announce the release of `filterpipe` version 1.5.0. This version introduces new functionality, improves existing features, and addresses an important bug. Here are the details:

### New Features

- **ChainedFilter Class**: A new class, `ChainedFilter`, has been added to allow for the composition of multiple filter functions. This makes it easier to apply a series of transformations in sequence, enhancing the flexibility and power of the filtering operations you can perform with `filterpipe`.

### Bug Fixes

- **NullFilter AttributeError**: An issue where `NullFilter` raised an `AttributeError` when processing empty input has been fixed. This ensures smoother operation when dealing with datasets that may include empty entries, improving the robustness of `filterpipe`.

### Testing

- All 47 tests have been executed and passed, confirming the stability and reliability of this release.

### Documentation

- The release update has been documented in `CHANGELOG.md`. Please refer to this file for a detailed history of changes and improvements over time.

### Additional Information

- The version number has been updated in both `filterpipe/__init__.py` and `pyproject.toml`.
- The release commit and tag `v1.5.0` have been pushed to the remote repository.

We encourage all users to upgrade to v1.5.0 to take advantage of these improvements and ensure a more stable and feature-rich experience with `filterpipe`.

Thank you for your continued support!
