**Release Notes for Filterpipe v1.5.0**

We are pleased to announce the release of Filterpipe v1.5.0. This version introduces a new `ChainedFilter` class to enhance the flexibility of composing filter functions, along with a crucial bug fix for the `NullFilter` behavior. Below are the details of this release:

### New Features

- **ChainedFilter Class:**
  - The `ChainedFilter` class has been added to allow for the composition of multiple filter functions. This class provides an efficient way to apply a series of transformations or filters in a sequential manner.

### Bug Fixes

- **NullFilter Enhancement:**
  - Fixed an issue where `NullFilter` was incorrectly raising an `AttributeError` when handling empty input. This fix ensures that `NullFilter` now gracefully handles such cases without throwing errors.

### Testing and Validation

- The release has been thoroughly tested, with all 47 tests passing successfully.
- The version has been updated in `filterpipe/__init__.py` and `pyproject.toml`.
- The release commit and tag `v1.5.0` have been pushed to the remote repository.

### Documentation

- The project maintains a detailed changelog at `CHANGELOG.md`, documenting all changes made in this release and previous ones.

### Conclusion

This release aims to improve the usability and robustness of Filterpipe, making it easier to compose complex filtering operations and ensuring stability when dealing with edge cases. We encourage users to try out the new features and fixes in Filterpipe v1.5.0.

For further details on the changes, please refer to the `CHANGELOG.md`. Thank you for your continued support and feedback.
