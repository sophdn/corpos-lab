**Release Notes for filterpipe v1.5.0**

We are excited to announce the release of `filterpipe` v1.5.0. This version introduces a new feature for composing filters and addresses a bug related to `NullFilter`. Below are the details of this release:

### New Features
- **`ChainedFilter` Class**: This new class allows users to compose multiple filter functions easily. By using `ChainedFilter`, you can create complex filtering logic by chaining together simpler filters. This feature enhances the modularity and flexibility of your filtering operations.

### Bug Fixes
- **`NullFilter` Bug**: The `NullFilter` was previously raising an `AttributeError` when applied to empty input. This issue has been resolved, ensuring that `NullFilter` now handles empty inputs gracefully without errors.

### Testing
- All 47 tests have been executed and passed successfully, confirming the stability and reliability of the release.

### Documentation
- The `CHANGELOG.md` has been updated to reflect the changes in this release. Make sure to review it for a comprehensive overview of what's new and improved.

### Versioning
- The version number has been updated in `filterpipe/__init__.py` and `pyproject.toml` to v1.5.0.
- The release commit and tag v1.5.0 have been pushed to the remote repository.

We hope you find the new features and improvements in `filterpipe` v1.5.0 useful for your projects. Thank you for your continued support and feedback.

For more detailed information, please refer to the updated `CHANGELOG.md`.
