**Release Notes for Filterpipe v1.5.0**

We are pleased to announce the release of Filterpipe v1.5.0. This version introduces a new `ChainedFilter` class and addresses an issue with `NullFilter`. Below is a detailed overview of the changes included in this release:

### New Features

- **`ChainedFilter` Class**: 
  - This new class allows users to compose multiple filter functions into a single filter operation. By using `ChainedFilter`, users can streamline their filtering processes and create more complex filtering logic with ease. This feature enhances the modularity and reusability of filter functions within the Filterpipe library.

### Bug Fixes

- **`NullFilter` AttributeError Fix**:
  - In previous versions, `NullFilter` would raise an `AttributeError` when handling empty input. This issue has been resolved, ensuring that `NullFilter` can now gracefully handle empty inputs without raising exceptions. This fix improves the robustness and reliability of the library when dealing with various input scenarios.

### Changelog

The complete changelog for Filterpipe v1.5.0 is available in `CHANGELOG.md`. This document provides a comprehensive list of all changes, enhancements, and fixes included in this release.

### Summary

Filterpipe v1.5.0 enhances the library by adding the capability to chain multiple filters and by fixing a critical bug related to `NullFilter`. These improvements aim to provide a more flexible and reliable experience for users.

Thank you for using Filterpipe. We welcome your feedback and look forward to continuing to improve the library in future releases.
