**Release Notes for `filterpipe` v1.5.0**

### Version 1.5.0

This release of `filterpipe` introduces new functionality and bug fixes to enhance usability and performance. We have updated the version in `filterpipe/__init__.py` and `pyproject.toml`. All tests (47 in total) have been successfully executed, and the release is confirmed with a commit and a tag labeled `v1.5.0`.

#### New Features

- **ChainedFilter Class**: This new class allows users to compose multiple filter functions into a single operation. This feature simplifies the process of applying a sequence of filtering steps, enhancing code readability and maintainability.

#### Bug Fixes

- **NullFilter Attribute Error**: A bug fix has been implemented to prevent `NullFilter` from raising an `AttributeError` when processing empty input. This ensures stability and reliability when using `NullFilter` with datasets that may sometimes be empty.

#### Changelog

A comprehensive changelog is maintained in `CHANGELOG.md`, documenting all significant changes, enhancements, and fixes in this version. Users are encouraged to review this document for detailed information on the updates.

This release aims to provide a more robust and user-friendly experience with `filterpipe`, ensuring that users can effectively chain filter operations and handle empty inputs without encountering errors.
