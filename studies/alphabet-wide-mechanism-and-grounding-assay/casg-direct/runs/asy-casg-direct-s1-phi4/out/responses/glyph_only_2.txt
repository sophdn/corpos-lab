### Y-fire and Y-not-fire Conditions

- **Y-fire:** This occurs when an agent completes an operation on a primary artifact and has direct authority to update a companion artifact, but the companion artifact update is not included in the same operation's execution scope. The operation feels complete upon updating the primary artifact, but the companion artifact update is required and unfulfilled.

- **Y-not-fire:** This occurs when both the primary artifact update and the companion artifact update are included within the same operation's execution scope. The operation closes with both updates present, fulfilling the obligation.

### Marker Axis

- **Invariant:** The companion artifact's state must reflect the primary artifact set's state. If the companion artifact update is missing from the operation's execution scope, the obligation is unmet.

- **Firing Condition:** The operation closes with the primary artifact updated, but the companion artifact update is absent from the execution scope.

- **Does Not Fire On:** Operations where no companion artifact exists or where the operation does not affect the primary artifact in a way that triggers a companion update obligation.

- **Violation Signal:** The execution trace shows the primary artifact updated without a companion artifact update in the same execution scope.

### Aim Axis

- **Invariant:** The agent must hold a completed companion artifact update co-present with the primary artifact action within the operation's execution scope.

- **Recognition Signal:** Both the primary artifact action and the companion artifact update are present in the execution trace within the same operation's scope before closure.

### Rest Axis

- **Absent-Preconditions Territory:** No companion artifact exists or the operation does not create an update obligation, so the choice between inclusion and exclusion does not arise.

- **Present-Preconditions-Delegated-Elsewhere Territory:** A companion artifact exists, and an update obligation is present, but the update is assigned to another role. The current agent must delegate, not execute the update.

- **Distinguishing Conditions:**
  - Absent-Preconditions: No obligation exists to update the companion artifact.
  - Present-Preconditions-Delegated-Elsewhere: The update is assigned to another role, not the current agent.
