### Decision Framework

1. **Y-fire Scenario:**
   - **Context:** An agent faces a decision point with complex branching logic based on conditional checks.
   - **Simplification:** The agent considers using a uniform strategy (e.g., always taking path A) to avoid the complexity of evaluating conditions.
   - **Decision:** The choice is between evaluating the condition to determine the path or defaulting to a uniform strategy.

2. **Y-not-fire Scenario:**
   - **Context:** The condition has already been evaluated earlier in the decision sequence, and the path is determined based on this evaluation.
   - **Implication:** The decision-making process is streamlined as the path is already established by the condition result.

### Marker Axis

- **Invariant:** Path selection is decoupled from the condition if the conditional gate is not engaged.
- **Firing Condition:** Occurs when a transition action is recorded without a preceding path-determination check in the same sequence.
- **Violation Signal:** Absence of the condition check before the transition action in the trace.

### Aim Axis

- **Invariant:** Path selection reflects the outcome of a condition evaluation recorded before the transition.
- **Recognition Signal:** A path-determination check result is present before the transition action, indicating the condition was evaluated.

### Rest Axis

- **Characterization:** No conditional branching or evaluation is needed if the transition is single-path or the condition is structurally determined.
- **Distinguishing Condition:** No decision class basis exists if branching is absent or the condition is trivially satisfied.
