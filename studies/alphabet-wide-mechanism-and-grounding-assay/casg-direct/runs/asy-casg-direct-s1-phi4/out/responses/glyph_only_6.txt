### Key Concepts

1. **Y-Fire and Y-Not-Fire:**
   - **Y-Fire:** Occurs when an agent completes an operation on a primary artifact without updating the companion artifact within the same execution scope. The agent holds direct execution authority over both artifacts, and the obligation to update the companion artifact is unmet if it is not included in the operation's scope.
   - **Y-Not-Fire:** Occurs when both the primary artifact action and the companion artifact update are included within the same execution scope before the operation closes. The agent fulfills the obligation by ensuring both actions are co-present.

2. **Marker Axis:**
   - **Invariant:** The state of the companion artifact does not reflect the primary artifact set if the update was not included in the operation's scope.
   - **Firing Condition:** The operation closes with an update to the primary artifact but without the companion artifact update in the same scope.
   - **Violation Signal:** The execution trace shows the primary artifact updated and the operation closed without the companion artifact update.

3. **Aim Axis:**
   - **Invariant:** The agent holds a completed companion artifact update co-present with the primary artifact action within the same operation's scope.
   - **Recognition Signal:** Both the primary and companion artifact actions are present in the trace within the same operation's scope before it is marked complete.

4. **Rest Axis:**
   - **Absent-Preconditions Territory:** No companion artifact update obligation arises because either no companion artifact exists or the operation does not affect the primary artifact in a way that triggers such an obligation.
   - **Present-Preconditions-Delegated-Elsewhere Territory:** A companion artifact update obligation exists, but it is assigned to another role, so the current agent does not directly update it.
