**Release Notes for `filterpipe` v1.5.0**

### Changelog

- **New Features**
  - Added `ChainedFilter` class: This new feature allows users to compose multiple filter functions seamlessly. This addition enhances the flexibility and usability of the `filterpipe` library, enabling more complex filtering operations by chaining simple filters together.

- **Bug Fixes**
  - Resolved an issue with `NullFilter`: Previously, `NullFilter` raised an `AttributeError` when handling empty input. This bug has been fixed, ensuring that `NullFilter` can now handle empty inputs gracefully without errors.

### Additional Information

- The version number has been updated in `filterpipe/__init__.py` and `pyproject.toml`.
- All 47 tests have been executed successfully, confirming that the new changes do not introduce regressions or new issues.
- A release commit and tag `v1.5.0` have been pushed to the remote repository.
- The changelog at `CHANGELOG.md` has been updated to reflect these changes.

This release aims to enhance the functionality and robustness of the `filterpipe` library. Users are encouraged to update to v1.5.0 to take advantage of the new features and improvements.
