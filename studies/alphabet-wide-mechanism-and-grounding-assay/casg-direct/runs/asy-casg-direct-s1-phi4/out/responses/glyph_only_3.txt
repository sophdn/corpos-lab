The provided text describes a set of conditions and rules for managing operations related to "primary" and "companion" artifacts within a certain workflow or system. Here's a breakdown of the key elements:

### Y-Fire and Y-Not-Fire

- **Y-Fire**: This condition applies when an agent updates a primary artifact and has the authority to update a companion artifact, which must reflect the primary artifact's state. The agent must decide whether to include the companion artifact update as part of the operation. If the companion artifact update is not included, the operation is considered incomplete.

- **Y-Not-Fire**: This condition applies when both the primary artifact and the companion artifact are updated within the same operation scope. If both updates are present, the condition does not fire.

### Marker Axis

- **Invariant**: The state of the companion artifact must reflect the primary artifact's state. If it does not, the companion artifact update was not included in the operation's scope.

- **Firing Condition**: The operation is marked complete without the companion artifact update in the same scope. This is detected by checking the execution trace.

- **Does Not Fire On**: Operations where no companion artifact update is required, either because there is no companion artifact or the operation does not necessitate an update.

- **Violation Signal**: The execution trace shows the primary artifact updated and the operation closed without updating the companion artifact in the same scope.

### Aim Axis

- **Invariant**: Both the primary and companion artifact updates must be present in the execution trace within the same scope before the operation is completed.

- **Recognition Signal**: The operation is correctly completed when both updates are present in the same scope.

### Rest Axis

- **Absent Preconditions Territory**: No companion artifact update is required because either there is no companion artifact or the operation does not affect it.

- **Present Preconditions Delegated Elsewhere Territory**: A companion artifact update is required, but the responsibility is delegated to another role.

- **Distinguishing Conditions**: 
  - Absent Preconditions: No obligation to update the companion artifact.
  - Present Preconditions Delegated Elsewhere: The update is delegated to another role.
