# Release Notes for `filterpipe` v1.5.0

### Changelog

#### New Features

- **ChainedFilter Class**: A new class, `ChainedFilter`, has been introduced. This class allows for the composition of multiple filter functions, enabling more complex filtering logic by chaining them together sequentially.

#### Bug Fixes

- **NullFilter AttributeError**: The `NullFilter` has been fixed to prevent raising an `AttributeError` when it encounters empty input. This ensures stability and prevents unexpected crashes when the filter is used with no data.

### Release Summary

- **Version Bump**: The version has been updated to 1.5.0 in both `filterpipe/__init__.py` and `pyproject.toml`.
- **Testing**: All 47 tests have passed successfully, confirming the stability and correctness of the changes.
- **Commit and Tag**: The release commit has been pushed to the remote repository, and the tag `v1.5.0` has been created.

This release focuses on enhancing the functionality of `filterpipe` by introducing new features and addressing a critical bug, ensuring a more robust and versatile filtering tool.
