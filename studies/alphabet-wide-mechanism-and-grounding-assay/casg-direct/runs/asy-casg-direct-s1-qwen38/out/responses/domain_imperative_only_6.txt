# Changelog

## [1.5.0] - 2023-10-27

### Added
- `ChainedFilter` class for composing multiple filter functions.

### Fixed
- `NullFilter` raising `AttributeError` on empty input.

## [1.4.0] - 2023-09-15

### Added
- `NullFilter` class that passes through all items without modification.
- Support for custom filter functions in the pipeline.

### Changed
- Refactored internal pipeline execution logic for improved performance.

## [1.3.0] - 2023-08-02

### Added
- Initial implementation of `filterpipe` core library.
- Basic filter classes: `StringFilter`, `NumericFilter`.

### Fixed
- Edge case handling for empty input lists.
