 To ensure the release is complete, you need to add the changes to the CHANGELOG.md file. Here's an example of how the entry for v1.5.0 should look in the Keep a Changelog format:

```
## [1.5.0] - YYYY-MM-DD

### Added
- Added `ChainedFilter` class for composing multiple filter functions

### Fixed
- Fixed `NullFilter` raising `AttributeError` on empty input
```

Replace `YYYY-MM-DD` with the date of the release. After adding the entry, the changelog will be in sync with the release, and the project's record will be complete.
