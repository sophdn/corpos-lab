 To make the release complete as a record, you need to add the following entry to the `CHANGELOG.md` file:

```
## [1.5.0] - YYYY-MM-DD

### Added
- Introduced `ChainedFilter` class for composing multiple filter functions

### Fixed
- `NullFilter` no longer raises `AttributeError` on empty input
```

Replace `YYYY-MM-DD` with the date of the release. After making this change, the release will be complete both as code and as a record.
