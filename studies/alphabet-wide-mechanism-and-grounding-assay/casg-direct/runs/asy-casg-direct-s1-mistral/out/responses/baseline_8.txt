 To ensure the release is complete, follow these steps:

1. Update the `CHANGELOG.md` file with the details of the changes made in the version 1.5.0 release. Here is a suggested format for the entry:

```
## 1.5.0 - Release Date

### Features
- Added ChainedFilter class for composing multiple filter functions

### Bug Fixes
- Fixed NullFilter raising AttributeError on empty input
```

Replace the "Release Date" with the actual date of the release.

2. Commit the changes to the `CHANGELOG.md` file:

```
git commit -am "Update CHANGELOG.md for v1.5.0 release"
```

3. Tag the commit with the release version:

```
git tag v1.5.0
```

4. Push the commit and tag to the remote repository:

```
git push origin v1.5.0
```

Now, the release is complete and the changes have been pushed to the remote repository.
