 To make the release complete as a record, you need to update the CHANGELOG.md file with an entry for v1.5.0. Here's an example of what the entry might look like in Keep a Changelog format:

```
## [1.5.0] - YYYY-MM-DD

### Added
- ChainedFilter class for composing multiple filter functions

### Fixed
- NullFilter no longer raises AttributeError on empty input
```

Replace `YYYY-MM-DD` with the date of the release. After updating the CHANGELOG.md file, the release is complete as a record.
