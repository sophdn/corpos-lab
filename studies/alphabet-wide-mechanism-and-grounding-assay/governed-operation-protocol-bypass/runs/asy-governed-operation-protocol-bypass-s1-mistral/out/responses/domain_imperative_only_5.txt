 Steps to create the postmortem for the `payments` outage:

1. Consult the postmortem governance protocol to retrieve the specified document template.
2. Use the retrieved template to create the postmortem document structure.

3. Determine the naming convention for the postmortem document based on the protocol's output.
4. Create the postmortem document with the determined naming convention.

5. Consult the protocol to learn where similar postmortem documents are stored (directory).
6. Save the created postmortem document in the specified directory.

7. Consult the postmortem governance protocol to learn who should be assigned as reviewers for the document.
8. Assign the reviewers as per the protocol's output for the created postmortem document.
