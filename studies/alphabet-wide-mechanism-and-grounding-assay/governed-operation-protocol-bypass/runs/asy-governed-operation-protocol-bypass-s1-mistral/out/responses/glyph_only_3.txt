 To create the postmortem according to the governance protocol:

1. Consult the governance protocol to find the document template for postmortems.
2. Use the template to create the postmortem document, filling in the details about the `payments` outage.
3. Consult the governance protocol again to find the naming convention for postmortem documents.
4. Apply the naming convention to the postmortem document to create its final name.
5. Consult the governance protocol one last time to find the directory where postmortem documents belong.
6. Save the postmortem document in the designated directory.
7. Consult the governance protocol to find who must be assigned as reviewers for the postmortem.
8. Notify the assigned reviewers that the postmortem is ready for their review.

By following these steps, the postmortem will be created and submitted in a manner that adheres to the organization's governance protocol.
