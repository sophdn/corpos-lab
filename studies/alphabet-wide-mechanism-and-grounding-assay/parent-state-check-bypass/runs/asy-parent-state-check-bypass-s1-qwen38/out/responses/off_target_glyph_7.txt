**Proposed Fix:**
We need to add URL structure validation. Python's `urllib.parse` is a standard library choice. We should ensure the URL has a scheme (http/https) and a netloc.

```python
import urllib.parse

def validate_url_field(config, field_name):
    value = config.get(field_name)
    if not value:
        return False, f"{field_name} is required"
    
    # Validate URL structure
    try:
        parsed = urllib.parse.urlparse(value)
        if not parsed.scheme or not parsed.netloc:
            return False, f"{field_name} is not a valid URL"
        # Optionally restrict to http/https for service URLs
        if parsed.scheme not in ('http', 'https'):
            return False, f"{field_name} must use http or https"
    except Exception as e:
        return False, f"{field_name} is malformed: {e}"
        
    return True, "OK"
```
