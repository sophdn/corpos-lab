2.  **Desired Behavior:**
    -   Malformed `auth_service_url` → Exit code 1.

3.  **Implementation Strategy:**
    -   Locate `validate_url_field()` in `config/validator.py`.

    -   Specifically, for an `auth_service_url`, we likely expect a full URL with a scheme (http/https) and a netloc (host).

    -   If validation fails, raise a validation error or return a failure state that causes the CLI to exit with code 1.

**Proposed Code Change (Pseudo-code/Python):**

```python
import urllib.parse

def validate_url_field(field_name, value):
    # Existing check: field is present and non-empty
    if not value:
        raise ValueError(f"Field {field_name} is required and cannot be empty.")
    
    # New check: URL structure validation
    parsed_url = urllib.parse.urlparse(value)
    
    # For an auth service URL, we expect a valid scheme and host
    if parsed_url.scheme not in ['http', 'https'] or not parsed_url.netloc:
        raise ValueError(f"Field {field_name} must be a valid URL with http/https scheme and host.")
    
    # If no exception is raised, the URL is considered valid
    return True
```
