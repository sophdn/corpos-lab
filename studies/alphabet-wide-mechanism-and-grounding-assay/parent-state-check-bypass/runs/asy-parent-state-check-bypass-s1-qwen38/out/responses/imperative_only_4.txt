*   **Desired Behavior:** The function must validate the structural correctness of the URL. If the URL is malformed, the validator should fail (exit 1). Valid URLs must continue to pass.

    *   *Option B (Robust Validation):* Use a dedicated library like `requests.utils` or implement a regex/parse check. Given this is a config validator, using `urllib.parse` is likely sufficient and avoids adding new dependencies.
    *   *Refinement:* A malformed URL in this context likely means missing scheme (e.g., `auth-service:8080` instead of `http://auth-service:8080`) or invalid characters.
    *   *Proposed Logic:*
        ```python
        from urllib.parse import urlparse

        def validate_url_field(value, field_name):
            if not value:
                return False, f"{field_name} is empty"

            # Check for required components for a valid service URL
            # Typically, we expect scheme and netloc
            if not parsed.scheme or not parsed.netloc:
                return False, f"{field_name} is not a valid URL: missing scheme or netloc"
            
            # Optional: Restrict to http/https if appropriate for auth service
            if parsed.scheme not in ('http', 'https'):
                 return False, f"{field_name} must use http or https"

            return True, None
        ```
