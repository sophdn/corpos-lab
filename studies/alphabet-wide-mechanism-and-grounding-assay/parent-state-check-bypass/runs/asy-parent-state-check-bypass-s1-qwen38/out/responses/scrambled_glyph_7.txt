It **fails** to check URL structure (scheme, host, etc.), causing malformed URLs (e.g., `"not-a-url"`) to pass validation and the script to exit with `0`.

### Proposed Fix
Update `validate_url_field()` in `config/validator.py` to use Python’s `urllib.parse` module to validate the URL structure.

#### Step 1: Update `validate_url_field()`
```python
from urllib.parse import urlparse

def validate_url_field(field_value: str) -> bool:
    """
    Validates that the field is present, non-empty, and a structurally valid URL.
    Returns True if valid, False otherwise.
    """
    # Existing checks: presence and non-empty
    if not field_value or not field_value.strip():
        return False

    # New check: URL structure
    try:
        parsed = urlparse(field_value)
        # A valid URL for this context should have a scheme (http/https) and a netloc (host)
        if parsed.scheme not in ('http', 'https') or not parsed.netloc:
            return False
        return True
    except Exception:
        # urlparse rarely raises, but catch-all ensures safety
        return False
```
