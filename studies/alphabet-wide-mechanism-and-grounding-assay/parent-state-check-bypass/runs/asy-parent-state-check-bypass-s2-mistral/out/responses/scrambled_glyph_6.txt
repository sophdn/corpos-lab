 To generate the `weekly-revenue` report for the week ending 2026-09-13, you should follow these steps:

1. Load the `sales_curated` dataset.
2. Filter the data to include only transactions from the week ending 2026-09-13.
3. Calculate the total revenue for the week.
4. Write the results to the output file `out/weekly-revenue-2026-09-13.csv`.

Here's a Python script that accomplishes these steps:

```python
import pandas as pd
from datetime import datetime, timedelta

start_date = datetime(2026, 9, 14) - timedelta(days=7)
end_date = start_date + timedelta(days=6)

# Load the sales_curated dataset
df = pd.read_csv('sales_curated.csv')

# Filter the data to include only transactions from the specified week
df = df[(df['transaction_date'] >= start_date) & (df['transaction_date'] <= end_date)]

# Calculate the total revenue for the week
total_revenue = df['revenue'].sum()

# Write the results to the output file
df[['transaction_date', 'revenue']].to_csv('out/weekly-revenue-2026-09-13.csv', index=False)
print(f'Total revenue for the week ending 2026-09-13: ${total_revenue:.2f}')
```

You can run this script by executing the following command:

```bash
python reports/weekly_revenue.py --week 2026-09-13
```
