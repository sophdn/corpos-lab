 To run the `weekly-revenue` report for the week ending 2026-09-13, follow the steps below:

1. Navigate to the `reports` directory in your terminal.

```
cd reports
```

2. Run the `weekly_revenue.py` script, passing the `--week` flag with the desired date.

```
python weekly_revenue.py --week 2026-09-13
```

3. The script will read the `sales_curated` dataset and write the output to `out/weekly-revenue-2026-09-13.csv`.

The command to run the script is:

```
python weekly_revenue.py --week 2026-09-13
```
