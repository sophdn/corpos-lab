 To run the `weekly-revenue` job, I would execute the following command:

```
python reports/weekly_revenue.py --week 2026-09-13
```

This command tells the Python interpreter to run the script `weekly_revenue.py` located in the `reports` directory and pass the argument `--week 2026-09-13` to the script, which should interpret it as the week ending date for the report. The script should then read the `sales_curated` dataset and write the output file `out/weekly-revenue-2026-09-13.csv`.
