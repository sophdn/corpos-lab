# Data-Export v2 Compliance Checklist

This compliance checklist is specific to the data-export v2 release and incorporates necessary updates and controls as per the v2 specifications and the Q4 2025 compliance bulletin. This is a pre-deployment confirmation and does not constitute a full re-review. Below are the checklist items with their compliance status:

## Access Control

- **Access Pathways:**
  - [x] Ensure the v2 release retains the v1 CLI surface unchanged.
  - [x] Verify the addition of an HTTP endpoint `POST /v2/data-export/request` for partner-portal integration is compliant.
  - [x] Confirm that partners authenticate using OAuth scope and request exports only for users with active authorization.

- **Scope and Access:**
  - [x] Confirm that data scope, access controls, and retention policies remain unchanged from v1.

## Audit Logging

- **Audit Trail:**
  - [x] Ensure audit logs capture all necessary information for both CLI and partner-portal pathways.
  - [x] Confirm existing audit-logging items are pathway-agnostic and applicable to the new partner-portal access path.

- **Provenance Stamp:**
  - [x] Implement a Provenance Stamp for every partner-initiated export as required by the Q4 2025 compliance bulletin.
  - [x] Capture the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at the time of export.
  - [x] Ensure the Provenance Stamp is written synchronously and fails closed if it cannot be assembled.

## Security and Privacy

- **Data Protection:**
  - [x] Verify that data protection measures for the partner-portal pathway meet existing compliance standards.

- **Security Policies:**
  - [x] Ensure that security policies are applied consistently across both v1 and v2 pathways.

## Retention Policies

- **Data Retention:**
  - [x] Confirm that retention policies remain unchanged from v1 and are applicable to the new partner-portal access path.

## Sign-off

- **Review and Approval:**
  - [x] This checklist has been reviewed by the compliance team.
  - [x] Sign-off by Legal and Security is pending post-deployment confirmation.

---

This checklist confirms that the v2 release complies with the updated requirements and retains the necessary controls from the v1 release. Any changes specific to v2, particularly regarding the partner-portal integration and the Provenance Stamp requirement, have been captured and addressed.
