# Data Export v2 Compliance Checklist

## Introduction
- The data-export v2 release adds a partner-portal access path to the existing CLI surface.
- This checklist confirms compliance with the v1 controls and addresses new requirements introduced in the Q4 2025 compliance bulletin.

## Data Scope
- [ ] Confirm that the data scope for v2 is unchanged from v1.
- [ ] Ensure that data exported via the partner-portal adheres to the same scope as v1.

## Access Controls
- [ ] Verify that partners authenticate via OAuth scope as specified in the v2 spec.
- [ ] Ensure that only users who have granted active authorization to partners can be exported.
- [ ] Confirm that access controls are pathway-agnostic, consistent with v1.

## Retention Policies
- [ ] Confirm that retention policies for exported data remain unchanged from v1.
- [ ] Ensure retention policies apply equally to data exported via the partner-portal.

## Audit Logging
- [ ] Confirm that audit logging is maintained for all data export activities.
- [ ] Ensure that audit logs capture the necessary details for both CLI and partner-portal pathways.
- [ ] Implement Provenance Stamp for partner-initiated exports as per the Q4 2025 bulletin.

## Provenance Stamp (New Requirement)
- [ ] Ensure that a Provenance Stamp is recorded for every partner-initiated export.
- [ ] Capture the following details in the Provenance Stamp:
  - User's authorization grant ID
  - Requesting party's identity
  - Authorization scope
  - Validity window at time of export
- [ ] Implement the Provenance Stamp to be written synchronously.
- [ ] Ensure the system fails closed if the Provenance Stamp cannot be assembled.

## Compliance with Q4 2025 Bulletin
- [ ] Confirm that all new requirements from the Q4 2025 bulletin are implemented.
- [ ] Verify that the Provenance Stamp requirement is fully integrated into the partner-portal export pathway.

## Sign-off
- [ ] Obtain sign-off from Legal and Security on the compliance of the v2 release.
- [ ] Document any assumptions or deviations from standard compliance procedures.

---

This checklist should be reviewed and signed off by the compliance team, Legal, and Security before the deployment of the data-export v2 release.
