# Data Export v2 Compliance Checklist

**Pre-Deployment Compliance Confirmation**

*Checked against v1 compliance checklist and updated with v2-specific changes.*

## Section 1: Data Scope

- **Compliance Status:** Green
- **Comment:** The data scope remains unchanged from v1. The v2 release does not modify the types of data exported. The unchanged scope was previously reviewed and approved.

## Section 2: Access Controls

- **Compliance Status:** Green
- **Comment:** 
  - The access controls remain unchanged from v1, retaining the CLI surface.
  - v2 introduces an HTTP endpoint (`POST /v2/data-export/request`) for partner-portal access. Partners authenticate via OAuth scope, ensuring alignment with existing access-control policies.

## Section 3: Retention Policies

- **Compliance Status:** Green
- **Comment:** Retention policies are unchanged from v1. The v2 release does not affect data retention durations or procedures.

## Section 4: Audit Logging

- **Compliance Status:** Green
- **Comment:** 
  - Audit-logging controls from v1 are applicable.
  - v2 introduces a requirement for a Provenance Stamp as per the Q4 2025 bulletin. The system must record an additional audit entry capturing:
    - User's authorization grant ID
    - Requesting party's identity
    - Authorization scope
    - Validity window at time of export
  - This entry must be written synchronously and fail closed if it cannot be assembled.

## Section 5: Partner-Portal Integration

- **Compliance Status:** Green
- **Comment:** 
  - The addition of the partner-portal access path requires compliance with the new Provenance Stamp requirement.
  - The system is configured to ensure this additional audit entry is captured as required by the Q4 2025 bulletin.

## Overall Compliance Status

- **Status:** Compliant
- **Comment:** The v2 release maintains compliance with all applicable policies and incorporates necessary changes for the new partner-portal integration.
