# Data Export v2 Compliance Checklist

- [x] **Access Controls:** Verify that access controls remain unchanged from v1. The CLI surface is unchanged, and partner-portal access is secured by OAuth scope.
- [x] **Partner Authentication:** Ensure partners authenticate using OAuth scope as specified in the v2 spec.

- [x] **Audit Logging Controls:** Confirm that existing audit logging controls from v1 are still applicable.
- [x] **Provenance Stamp Requirement:** Implement a Provenance Stamp for partner-initiated export pathways, capturing:
