# Deployments/Data-Export-v2/Compliance-Checklist.md

## Data Scope

- **Review**: The data scope for v2 remains unchanged from v1.
- **Compliance**: As with v1, data exports are limited to user-authorized data.
- **Confirmation**: No changes to data types or data sensitivity levels.

## Access Controls

- **Review**: Access controls for v1 are maintained in v2.
- **Compliance**: Authentication and authorization requirements remain consistent.
  - **CLI**: User authentication via API keys.
  - **Partner Portal**: OAuth scope-based authentication for partners, ensuring they have an active authorization from the user.
- **Confirmation**: Access controls are pathway-agnostic and adhere to existing guidelines.

## Audit Logging

- **Review**: v2 introduces a new audit logging requirement per the 2025-Q4 bulletin.
- **Compliance**:
  - **Existing Entries**: Maintain audit logs for all access requests and data exports.
  - **Provenance Stamp**: Add an additional audit entry, a Provenance Stamp, for partner-initiated exports.
    - **Content**: Include the user's authorization grant ID, the requesting party's identity, the authorization scope, and the validity window at the time of export.
    - **Mechanism**: Ensure the Provenance Stamp is recorded synchronously and adheres to the "failing closed" principle if it cannot be assembled.

## Retention Policies

- **Review**: Retention policies for v1 remain applicable to v2.
- **Compliance**: Ensure data exports are retained according to the defined data retention period.
- **Confirmation**: No changes to retention duration or deletion procedures.

## Additional Considerations

- **Review**: Ensure all new changes align with the compliance requirements outlined in the 2025-Q4 bulletin.
- **Compliance**: Confirm that the implementation of the partner portal access path does not introduce any new risks or compliance issues.
- **Confirmation**: Validate that all team members are aware of the new audit logging requirements and have implemented them correctly.

## Conclusion

- **Overall Compliance**: v2 complies with the v1 compliance checklist, with the addition of the Provenance Stamp for partner-initiated exports as required by the 2025-Q4 bulletin.
- **Next Steps**: Provide training and documentation updates to ensure all stakeholders understand the new compliance requirements.
