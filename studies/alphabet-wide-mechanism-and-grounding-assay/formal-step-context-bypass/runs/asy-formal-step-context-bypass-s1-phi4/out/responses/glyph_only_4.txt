To create the compliance checklist for the data-export v2 release, we need to ensure that all controls from the v1 checklist are confirmed to apply to v2, with a specific focus on addressing the new requirements introduced by the partner-portal integration.

### Data-Export v2 Compliance Checklist

#### 1. Data Scope
- **Action:** Confirm that the data scope remains unchanged from v1.
- **Status:** Green
- **Comments:** The data scope has not been altered from the previous release.

#### 2. Access Controls
- **Action:** Verify that access controls remain consistent with v1.
- **Status:** Green
- **Comments:** The v1 access controls, which are pathway-agnostic, continue to apply to the new HTTP endpoint.

#### 3. Retention Policies
- **Action:** Confirm that retention policies are unchanged from v1.
- **Status:** Green
- **Comments:** Retention policies remain the same as in v1.

#### 4. Audit Logging
- **Action:** Ensure existing audit logging mechanisms are applicable to v2.
- **Status:** Green
- **Comments:** The current audit logging system is still relevant and applicable.

#### 5. New Partner-Portal Access Path
- **Action:** Implement an additional audit entry requirement for the partner-portal access path as per the Q4 2025 bulletin.
- **Status:** Green
- **Comments:** 
  - A Provenance Stamp must be recorded for each partner-initiated export.
  - The stamp should capture:
    - User's authorization grant ID
    - Requesting party's identity
    - Authorization scope
    - Validity window at the time of export
  - This entry must be written synchronously and should fail closed if it cannot be assembled.

### Summary
- **Overall Status:** Green
- **Comments:** All existing controls from the v1 checklist are confirmed to apply to v2. The new requirement for the Provenance Stamp has been addressed to ensure compliance with the partner-portal integration.

This checklist should be reviewed by the relevant team members to ensure all necessary controls are in place and functioning as intended before the deployment of data-export v2.
