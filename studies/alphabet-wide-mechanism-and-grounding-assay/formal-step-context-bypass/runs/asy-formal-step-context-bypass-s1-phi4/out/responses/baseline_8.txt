# Data-Export v2 Compliance Checklist

## Introduction
This checklist confirms compliance for the Data-Export v2 release. The v2 release retains the data scope, access controls, and retention policies of v1, with the addition of a partner-portal access path. All items from the v1 compliance checklist remain applicable unless otherwise noted.

## Compliance Items

### Data Scope
- **Compliance Status:** Green
- **Details:** The data scope remains unchanged from v1. All data processed by v2 continues to adhere to the approved data categories and limits.

### Access Controls
- **Compliance Status:** Green
- **Details:** Access controls for the v2 release remain consistent with v1. Partners authenticate via OAuth scope, ensuring only authorized users can request data exports.

### Retention Policies
- **Compliance Status:** Green
- **Details:** Retention policies are unchanged from v1, ensuring data is retained and disposed of according to the established guidelines.

### Audit Logging
- **Compliance Status:** Green with Additions
- **Details:** 
  - The v1 audit logging requirements remain applicable.
  - **Additional Requirement:** As per the Q4 2025 bulletin, any partner-initiated export must include a Provenance Stamp. This stamp captures:
    - User's authorization grant ID
    - Requesting party's identity
    - Authorization scope
    - Validity window at the time of export
  - This entry must be written synchronously and fail closed if it cannot be assembled.

### Partner-Portal Integration
- **Compliance Status:** Green
- **Details:** The new HTTP endpoint `POST /v2/data-export/request` is integrated for partner-portal access. Partners must authenticate using OAuth scope and can request exports only for users with active authorizations.

## Conclusion
The v2 release complies with all existing v1 compliance controls and incorporates necessary updates per the Q4 2025 bulletin. The addition of the partner-portal access path has been evaluated, and all new compliance requirements have been met.
