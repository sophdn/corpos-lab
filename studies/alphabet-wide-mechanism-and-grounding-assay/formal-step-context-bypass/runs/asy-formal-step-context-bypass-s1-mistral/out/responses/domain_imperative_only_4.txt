```
# Data Export Compliance Checklist v2

## Access Control

1. **User authorization required**: Ensure that users must explicitly authorize the data export for their account before any data is processed.

2. **User opt-out**: Implement a mechanism for users to opt-out of data exports at any time.

3. **Partner authentication**: Implement OAuth authentication for partners requesting data exports.

4. **Partner authorization scope**: Ensure that partners can only request data exports within the scopes they are authorized for.

5. **User consent logging**: Record and maintain a log of user consent for data exports.

6. **Partner authentication logging**: Record and maintain a log of partner authentication events.

## Audit Logging

7. **Export request logging**: Log every data export request, including the requesting party, the requested data scope, and the requested user accounts.

8. **Provenance Stamp**: Include a Provenance Stamp in every partner-initiated export that captures the user's authorization grant id, the requesting party, the scope, and the validity window at time of export, written synchronously and failing closed if it cannot be assembled.

9. **Export execution logging**: Log every executed data export, including the requested data, the execution time, and the results (success/failure).

10. **Export completion logging**: Log every completed data export, including the final results and any relevant error messages.

11. **Audit log retention**: Ensure that all audit logs are securely stored and comply with retention policy requirements.

## Data Scope

12. **Data types**: Ensure that the exported data adheres to the defined data types and does not include any sensitive, non-consensual, or otherwise unauthorized data.

13. **Data format**: Ensure that the exported data is in a format that is compliant with the agreed-upon data format standards.

14. **Data retention**: Ensure that the exported data is retained only for the minimum necessary duration, as defined in the data retention policy.

15. **Data security**: Implement appropriate data security measures to protect the exported data during transmission and storage.
```

This checklist captures the v2-specific changes (the addition of the partner-portal access pathway and the Provenance Stamp) and confirms that the v1 controls still apply.
