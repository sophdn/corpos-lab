```
Data Export v2 Compliance Checklist
====================================

Effective Date: 2025-11-01

1. Scope
---------

* Data Scope
    * Verify that data exported is within the defined scope (same as v1)

2. Access Control
-------------------

* User Authorization
    * Confirm that users can only access their own data (same as v1)
* Partner Portal Access
    * Ensure that partners authenticate via OAuth scope
    * Check that partners can only request data exports for users who have granted them active authorization

3. Retention
------------

* Data Retention Policy
    * Ensure that data retention policy is consistent with the defined policy (same as v1)

4. Audit Logging
-----------------

* Audit Logging
    * Confirm that all user activities related to data exports are logged (same as v1)
* Provenance Stamp
    * Verify that the Provenance Stamp is recorded for partner-initiated exports
        * User's authorization grant id
        * Requesting party's identity
        * Authorization scope
        * Validity window at time of export

5. Compliance
--------------

* Compliance Sign-off
    * Legal and Security sign-off on the Data Export v2 release (same as v1)
```
