```
# Data Export v2 Compliance Checklist

## Data Scope

- The data export process includes the same data scope as defined in Data Export v1.
- The data export process respects the same access controls as defined in Data Export v1.

## Access Controls

- Access control mechanisms are pathway-agnostic and cover both CLI and HTTP endpoint interactions.
- The same audit-logging mechanisms as defined in Data Export v1 are in place for all access paths.

## Partner-Portal Integration

- An HTTP endpoint `POST /v2/data-export/request` has been added to support partner-portal integration.
- Partners authenticate via OAuth scopes for authorized user requests.

## Provenance Stamp

- A Provenance Stamp is implemented for partner-initiated exports, capturing:
  - Authorization grant ID
  - Requesting party identity
  - Authorization scope
  - Validity window at time of export
- The Provenance Stamp is written synchronously and fails closed if it cannot be assembled.
```

This checklist captures the v2-specific changes while confirming the v1 controls still apply. The compliance team has now completed the checklist for the Data Export v2 release.
