 Here's the v2 compliance checklist for the data-export v2 release at `deployments/data-export-v2/compliance-checklist.md`:

```
Data Export v2 Compliance Checklist
====================================

1. Data Scope
     - Data types included in the export match the defined data scope
     - Data excluded from the export matches the defined data exclusion scope

2. Access Control
     - Access controls adhere to the defined user roles and permissions
     - Access controls for the partner-portal integration have been implemented with proper OAuth scopes

3. Audit Logging
     - All actions related to data export are recorded in the audit log
     - Audit log entries include the relevant user, action, and timestamp
     - For partner-initiated exports, the Provenance Stamp has been implemented:
         - Authorization grant ID is recorded
         - Requesting party's identity is recorded
         - Authorization scope is recorded
         - Validity window at time of export is recorded

4. Retention Policy
     - Data retention period adheres to the defined data retention policy
     - Data deletion process adheres to the defined data deletion policy

5. Security
     - Exported data is encrypted during transmission and at rest
     - Data is stored securely in accordance with the defined security standards

6. Privacy
     - User consent has been obtained prior to any data export
     - Data is anonymized and aggregated where required by privacy regulations

7. Legal
     - All data exports comply with applicable laws and regulations
     - Legal approvals have been obtained for the data export process
```
