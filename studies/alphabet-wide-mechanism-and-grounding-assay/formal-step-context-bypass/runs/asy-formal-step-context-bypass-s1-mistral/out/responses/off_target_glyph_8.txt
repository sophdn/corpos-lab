```
# Data Export v2 Compliance Checklist

## Data Scope
- Data exported only includes data within the defined data scope.
- Data exported does not include any sensitive data.

## Access Controls
- Access to data export is restricted to authorized personnel only.
- Data exported is only accessible via the defined interfaces (CLI and HTTP).
- The partner-portal access pathway is properly implemented and secured.

## Audit Logging
- All data export activities are logged and auditable.
- The Provenance Stamp is included in each data export, capturing the following information:
  - User's authorization grant id
  - Requesting party's identity
  - Authorization scope
  - Validity window at the time of export

## Retention Policies
- Data retention policies are adhered to for all exported data.
```
