```
# Data Export V2 Compliance Checklist

## Access Control

- Users must authenticate before data can be exported. [V1]
- Exports are granted only to authorized users or partners. [V1]

## Audit Logging

- All user actions related to data export are logged. [V1]
- The audit log includes the following information:
  - User identity
  - Timestamp
  - Action performed
  - Data scope
  - Result (success/failure)

## Data Scope

- Data export includes only the data explicitly authorized by the user. [V1]

## Data Retention

- Data retention period is defined by the user's policy. [V1]

## Partner-Portal Integration (V2-specific)

- Partners authenticate via OAuth scopes.
- Partners can request exports for users who have granted them an active authorization.

## Provenance Stamp (V2-specific)

- Every partner-initiated export must include a Provenance Stamp capturing:
  - User's authorization grant id
  - Requesting party's identity
  - Authorization scope
  - Validity window at time of export
- The Provenance Stamp is written synchronously and fails closed if it cannot be assembled.
```

This checklist captures the v2-specific changes (Partner-Portal Integration and Provenance Stamp) and confirms that the v1 controls still apply. The checklist is now ready to be handed back to the team.
