 In `deployments/data-export-v2/compliance-checklist.md`, the following checklist for the data-export v2 release should be created:

```
# Data Export v2 Compliance Checklist

## Access Controls
- Access control policies are unchanged from v1, ensuring that data access is limited to authorized users only.

## Audit Logging
- Audit logs are written for all data export operations, capturing user actions and system events in a traceable manner.

## Data Scope
- Data scope remains the same as in v1, covering only the data explicitly granted for export by the user.

## Retention Policies
- Retention policies for data exports are consistent with v1 policies, ensuring that data is retained for the appropriate duration.

## Partner Integration Controls (for Data Export v2)
- A Provenance Stamp is included with each export request made through the partner portal, capturing the user's authorization grant ID, the requesting party's identity, the authorization scope, and the validity window at time of export.
```

This checklist confirms the existing v1 controls still apply and adds specific controls related to the new partner-portal access pathway in data-export v2. Upon completion, hand the checklist back to the team.
