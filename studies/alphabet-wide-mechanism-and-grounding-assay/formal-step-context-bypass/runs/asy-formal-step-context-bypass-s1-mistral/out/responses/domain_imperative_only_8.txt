 In the `deployments/data-export-v2/compliance-checklist.md` file, add the following content:

```md
# Data Export Compliance Checklist v2

## Data Scope

- Confirm data scope is unchanged from v1 (user data only, excluding sensitive information)

## Access Controls

- Verify OAuth scopes for partner authentication are defined and adhere to the minimum access requirements
- Ensure user authorization is properly granted and revocable
- Confirm access controls are still pathway-agnostic

## Audit Logging

- Check that audit logs are generated for all data export requests, both from the CLI and the HTTP endpoint
- Verify that audit logs include the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at time of export
- Confirm that the audit logging mechanism is compliant with the Q4 2025 bulletin's Provenance Stamp requirement

## Data Retention

- Ensure data retention policies are unchanged from v1

## Security

- Verify that the HTTP endpoint for the partner-portal integration is secure (HTTPS, TLS 1.2 or higher)

## Privacy

- Confirm that all data exports adhere to the agreed-upon privacy policies and data protection regulations

## Partner Portal Integration

- Check that the partner-portal integration is functional and secure
- Ensure that the partner-portal integration does not introduce any new data privacy or security risks
```

This checklist covers all the requirements from the v2 spec and the Q4 2025 compliance bulletin. The team can now review and verify the compliance of the v2 deployment based on this checklist.
