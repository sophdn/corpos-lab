```
# Data Export v2 Compliance Checklist

## Data Scope
- Confirm that the data scope is the same as in v1 (user data, account data, and activity logs)

## Access Controls
- Implement OAuth scopes for partner authentication
- Validate that partners can only request exports for users who have granted them active authorization
- Ensure that the access-control checks remain pathway-agnostic

## Audit Logging
- Log partner-initiated export requests, including:
  - Authorization grant ID
  - Requesting party identity
  - Authorization scope
  - Validity window

## Retention Policies
- Retain user data, account data, and activity logs according to the defined retention policies

## Provenance Stamp (New)
- Implement a Provenance Stamp on every partner-initiated export, capturing:
  - Authorization grant ID
  - Requesting party identity
  - Authorization scope
  - Validity window
```

This checklist captures the v2-specific changes, including the Provenance Stamp requirement, while confirming the v1 controls still apply. The team can now review and verify the implementation of the v2 release based on this checklist.
