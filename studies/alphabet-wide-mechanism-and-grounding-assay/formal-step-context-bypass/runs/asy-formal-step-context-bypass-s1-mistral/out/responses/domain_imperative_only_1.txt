 Based on the provided information, here is the v2 compliance checklist for the data-export feature:

```
deployments/data-export-v2/compliance-checklist.md

# Data Export v2 Compliance Checklist

## Access Controls

- [ ] Ensure that access to the data-export API is properly authenticated and authorized according to the access control policies.
- [ ] Confirm that the OAuth scope is properly enforced for partner-initiated exports.
- [ ] Verify that users have the ability to grant and revoke access to their data to partners through the partner portal.

## Audit Logging

- [ ] Ensure that all API requests and responses are logged with appropriate metadata for auditing purposes.
- [ ] Confirm that audit logs are stored securely and can be easily accessed and analyzed for compliance purposes.
- [ ] Verify that the audit logs are properly anonymized to protect user privacy.

## Data Scope

- [ ] Confirm that the data scope (what data can be exported) is the same as in v1.

## Data Retention

- [ ] Confirm that the data retention policy is the same as in v1.

## Provenance Stamp

- [ ] Implement a provenance stamp for partner-initiated exports that captures the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at the time of export.
- [ ] Ensure that the provenance stamp is written synchronously and fails closed if it cannot be assembled.

## Partner-Portal Integration

- [ ] Verify that the new HTTP endpoint `POST /v2/data-export/request` for the partner-portal integration is properly implemented and secure.

Once all the items on this checklist have been verified, the data-export v2 feature can be deployed.
```
