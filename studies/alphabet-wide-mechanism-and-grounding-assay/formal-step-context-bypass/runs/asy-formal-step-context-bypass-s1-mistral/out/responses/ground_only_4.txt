 Based on the information provided, here's the v2 checklist for `deployments/data-export-v2/compliance-checklist.md`:

```
# Data Export v2 Compliance Checklist (Signed off: 2025-11-05)

## Access Control

1. User authorization is required for data export, granted via an OAuth scope.
   (Unchanged from v1)

2. User must have an active authorization for the requesting partner to initiate an export.
   (New for v2)

## Data Scope

3. Data export scope is limited to data the user has access to.
   (Unchanged from v1)

## Audit Logging

4. All data export requests are logged with timestamps and request details.
   (Unchanged from v1)

## Partner-Portal Export

5. A partner-portal HTTP endpoint (`POST /v2/data-export/request`) is available for partner-initiated exports.
   (New for v2)

## Provenance Stamp

6. A Provenance Stamp is recorded for every partner-initiated export, capturing the following information:
    - User's authorization grant id
    - Requesting party's identity
    - Authorization scope
    - Validity window at time of export
   (New for v2, per Q4 2025 Compliance Bulletin)
```

This checklist captures the v2-specific changes and confirms the v1 controls still apply. The compliance team should then sign off on this v2 checklist.
