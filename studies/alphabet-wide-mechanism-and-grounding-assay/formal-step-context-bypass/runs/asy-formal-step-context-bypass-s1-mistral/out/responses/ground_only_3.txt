 Here is the v2 checklist for the data-export release at `deployments/data-export-v2/compliance-checklist.md`:

```
# Data Export v2 Compliance Checklist

## Access Controls
- User authorization for partner access (OAuth scope)
- User access control (authorized users only)
- Partner authentication and authorization (active authorization required)

## Data Scope
- Data export limited to the scope of authorized users
- Data export limited to the scope of partner's authorization

## Retention Policy
- Data retention in accordance with the company's data retention policy

## Audit Logging
- Log user's authorization grant id for partner-initiated exports
- Log requesting party's identity for partner-initiated exports
- Log authorization scope for partner-initiated exports
- Log validity window at time of export for partner-initiated exports

## Provenance Stamp
- Implement Provenance Stamp for partner-initiated exports, capturing:
  - user's authorization grant id
  - requesting party's identity
  - authorization scope
  - validity window at time of export
  - synchronous creation and failure closed if assembly cannot be made

## Sign-off
This checklist has been reviewed and signed off by the Compliance, Legal, and Security teams on [Date] as part of the Data Export v2 release.
```
