```
Data Export Compliance Checklist - v2 (2025-11-01)
==================================================

1. Data Scope
     - User data includes only personally identifiable information (PII) and sensitive data categories defined in the Data Privacy Policy.
     - Data retention meets the requirements outlined in the Data Retention Policy.

2. Access Controls
     - Access control policies are enforced across all pathways: CLI, API, and partner-portal.
     - Access to user data requires explicit user consent and adheres to role-based access control (RBAC) principles.

3. Audit Logging
     - All user data access, modification, and export activities are logged and retained for the duration specified in the Data Retention Policy.
     - Audit logs are reviewed periodically and made available to the Compliance Office, Legal, and Security teams upon request.

4. Partner-Portal Export Pathway (v2-specific)
     - The partner-portal export pathway has been implemented, allowing partners to authenticate by OAuth scope and request exports for users who granted them an active authorization.

5. Provenance Stamp (Q4 2025 requirement)
     - A Provenance Stamp is included in the metadata of every partner-initiated export, capturing the user's authorization grant id, the requesting party, the scope, and the validity window at time of export, written synchronously and failing closed if it cannot be assembled.
```
