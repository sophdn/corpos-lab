# Data Export v2 Compliance Checklist

## Access Control
- Verify that access to the new HTTP endpoint `POST /v2/data-export/request` is appropriately restricted to partners who have been granted OAuth scope for data export.
- Ensure that user authorization for data export is required and properly enforced before any data is released to partners.

## Audit Logging
- Implement the Provenance Stamp feature as outlined in the Q4 2025 Compliance Office bulletin, capturing the user's authorization grant id, the requesting party's identity, the authorization scope, and the validity window at the time of export.
- Log all audit entries for data export in a format that is compatible with the existing audit logging system.

## Data Scope
- Confirm that the data scope for v2 remains unchanged from v1.

## Data Retention
- Ensure that data retention policies for v2 are consistent with those established for v1.

## Security
- Review the security of the new HTTP endpoint `POST /v2/data-export/request` to ensure it is secure against common web vulnerabilities.

## Privacy
- Verify that v2 complies with all relevant privacy regulations and policies.

## Disaster Recovery
- Confirm that the disaster recovery plan includes the new data-export v2 functionality.

## Incident Response
- Ensure that incident response procedures cover data-export v2, including the new partner-portal access path.

## Training
- Update training materials for data-export functionality to include v2's partner-portal access path.

## Sign-off
- Legal and Security sign-off required
