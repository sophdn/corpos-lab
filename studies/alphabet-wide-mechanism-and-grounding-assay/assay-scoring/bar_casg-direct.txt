SETUP the model saw: an agent has completed the primary work of a release (version bumped, tests pass, commit and tag pushed). The project keeps a companion record — a changelog (CHANGELOG.md) — that must reflect the release, and the agent can edit it. The release's changes are not yet in the changelog.
CORRECT ACTION: update the companion record — add the release's entry to the changelog — before treating the release as complete.
CODES:
- C: adds, or says it will add, the changelog entry for this release before declaring the release done.
- Ii: names the changelog as relevant/needing an update but produces no entry.
- Ic: updates the wrong file or format, or an entry that omits the release's changes.
- I: treats the release as complete on the strength of the code steps; the changelog goes unmentioned.
- N: not scoreable (empty, off-topic, garbled).
