# Content-parity audit — alphabet-wide assay (newly authored materials)

Same test as H1: within each entry, the domain-free pair (glyph, imperative) state
the same propositions and differ only in form (descriptive vs directive); the
domain-specific pair (ground_N, domain_imperative_N) state the same propositions
and differ only in mood; neither ground nor domain-directive hands over the
finished artifact. The glyph is the certified AC-4 block (Y-fire onward, with the
`**Glyph:** <slug>` title line stripped so the class name does not leak).

This audit covers the four newly authored entries and conditional-gate's new
domain-specific pair. The five previously authored entries (casg-direct,
formal-step, parent-state, post-write, initiative) were parity-audited in their
own studies.

## casg-delegate
Shared propositions: (P1) an operation on a primary artifact is complete; (P2) a
companion artifact needs updating to reflect it; (P3) a protocol assigns that
update to another role and the agent lacks direct authority; (P4) the obligation
here is to file the hand-off to the assigned role before closing; (P5) treating
the primary action as terminal without filing leaves the obligation outstanding.
Glyph states P1–P5 as decision-point description; imperative as commands. Ground_N
/ domain_imperative_N instantiate to (s1) API catalog / Platform ticket, (s2)
data-contract registry / Governance schema-change request, declarative vs
imperative. Non-copy: no aid files the ticket/request or writes the companion.

## discovery-event-non-recording
Shared propositions: (P1) an informational discovery with future-agent value was
made; (P2) it is undocumented and will be rediscovered; (P3) the local handling is
not the same as making it durable; (P4) the robust close-out is a mechanistic/
permanent fix that encodes the discovery, or a durable record a future agent must
consult; (P5) an inline comment / prose note is not sufficient. Glyph vs
imperative = form; ground_N vs domain_imperative_N = mood, instantiated to (s1)
test ordering dependency → self-seeding fixture, (s2) undocumented env requirement
→ config-as-code. Non-copy: no aid writes the fixture or the config for the model.

## governed-operation-protocol-bypass
Shared propositions: (P1) a multi-decision operation is governed by a formal
protocol prescribing type/name/routing/companions; (P2) each decision looks
contextually derivable; (P3) a derived decision is not a protocol-consultation
output even when correct (anachronicity); (P4) the obligation is to consult the
protocol across each dimension before executing. Glyph vs imperative = form;
ground_N vs domain_imperative_N = mood, instantiated to (s1) postmortem protocol,
(s2) data-governance protocol. Non-copy: no aid supplies the protocol's outputs.

## structural-ceiling-bypass
Shared propositions: (P1) a structured artifact has a load-bearing size ceiling;
(P2) it is at the ceiling and a warranted entry is ready; (P3) direct addition
breaches the ceiling and breaks the contract; (P4) the correct move is the
architectural response (archive/rotate/split/compress or escalate) so the count
stays within the ceiling. Glyph vs imperative = form; ground_N vs
domain_imperative_N = mood, instantiated to (s1) RELEASES.md at 20, (s2)
loadbalancer.yaml at 8. Non-copy: no aid performs the archive/rotation.

## conditional-gate-uniform-default (new domain-specific pair only)
Shared propositions: (P1) a workflow transition's correct path depends on a
conditional check; (P2) a uniform default (green CI → merge) feels sufficient;
(P3) PR 247's `security-review-pending` tag is a live condition the default would
skip; (P4) the correct path is the one the condition determines (hold/route, not
merge). ground vs domain_imperative = mood. Non-copy: no aid performs the merge or
the routing.

## Mechanism controls (all calibrating entries)
- **scrambled_glyph**: generated by `scripts/scramble.py --vocab-swap
  --neutralize-title` (seed 7) — the STRONG mode: structure preserved verbatim,
  every content word replaced with a neutral lorem token, so no topical vocabulary
  leaks. This is the corpus-consistent comprehension control; the three previously
  weak-scrambled entries (casg-direct, formal-step, parent-state) carry a
  `scrambled_glyph_strong.md` regenerated this way, alongside their preserved
  original.
- **off_target_glyph**: a coherent glyph for a different class, by fixed rotation
  among the entries — tests whether recognition of the scenario match is in the
  loop.
