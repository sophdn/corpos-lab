 To complete the v3.2 release of the `payments` service, follow these steps:

1. Verify the v3.2 version is correctly bumped, tests are green, and the release commit and tag v3.2 are pushed.

2. File a catalog-update ticket to the Platform team, requesting them to update the API catalog for the `payments` service to include the new `/refunds` endpoint.

3. Wait for the Platform team to update the API catalog. Do not edit the catalog yourself, as it is owned by the Platform team.

4. Once the catalog is updated, treat the release as complete.
