The v3.2 release is **not yet complete**. While the code artifacts (version bump, tests, commit, tag) are finished, the operation is incomplete because the public API catalog does not reflect the new `/refunds` endpoint.

To complete the v3.2 release, the following finalization step must be taken:

**File a catalog-update ticket to the Platform team.**

*   **Action:** Create a ticket in the Platform team's issue tracker requesting the addition of the `/refunds` endpoint to the `payments` service entry in the public API catalog.
*   **Rationale:** The API catalog is owned exclusively by the Platform team. The release is only considered complete when this hand-off obligation is formally recorded. Editing the catalog directly is prohibited and incorrect.
*   **Result:** Once the ticket is filed, the catalog-update obligation is transferred to Platform, and the v3.2 release operation is considered complete and well-founded.
