 To complete the `customer_360` republish, follow these steps:

1. File a schema-change request for the addition of the `lifetime_value` column to the `customer_360` dataset with the Data Governance team. This can be done by submitting a ticket or an email to the appropriate channel, providing the necessary details about the change.

2. Wait for the Data Governance team to review and approve the schema change request. They will update the data-contract registry once the request is approved.

3. Once the data-contract registry is updated, the `customer_360` entry will now list the `lifetime_value` column, and the republish can be considered complete.

4. Downstream consumers will then read the updated schema to know which fields exist in the `customer_360` dataset.
