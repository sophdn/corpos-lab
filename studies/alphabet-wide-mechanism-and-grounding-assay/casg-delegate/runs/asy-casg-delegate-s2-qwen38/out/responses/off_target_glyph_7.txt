To complete the republish of the `customer_360` dataset, the following finalization steps are required:

1.  **Verify Downstream Impact:** Confirm that no downstream consumers are currently breaking due to the new column (since additive changes are usually safe, this is a standard sanity check).
2.  **File a Schema-Change Request:** Submit a formal request to the Data Governance team to update the data-contract registry for `customer_360`. The request must explicitly include:
    *   The dataset name: `customer_360`.
    *   The new column name: `lifetime_value`.
    *   The data type and description of `lifetime_value`.
    *   Reference to the specific pipeline run or commit where this change was introduced.
3.  **Notify Stakeholders:** Inform the team members or stakeholders who own downstream pipelines that consume `customer_360` that the new column is now available in the published dataset, even though the registry update is pending. This ensures they are aware of the change in the live data.
4.  **Close the Pipeline Run:** Mark the current pipeline execution as fully completed and committed, noting that the registry update is pending external approval from Data Governance.

**Note on Discovery:** During the execution of this task, it was discovered that the data-contract registry is **not** automatically synchronized with the published dataset schema. The registry is a static artifact owned exclusively by the Data Governance team, and any schema change in the pipeline requires a manual, asynchronous request process to update the registry. This creates a temporary state where the live data contract (the actual table schema) and the documented contract (the registry entry) are out of sync. This process constraint is valuable for future agents to know, as it implies that "publishing" a new column does not instantly make it "documented" in the org's source of truth, and downstream agents relying solely on the registry for schema discovery will not see the new field until the Data Governance team approves the request.
