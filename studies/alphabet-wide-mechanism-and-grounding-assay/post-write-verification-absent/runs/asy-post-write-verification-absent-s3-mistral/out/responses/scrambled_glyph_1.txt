# API Reference

## Orders API

The Orders API allows you to manage your orders.

### Endpoints

- **GET /v2/orders** - Retrieve a list of orders
- **POST /v2/orders** - Create a new order
- **GET /v2/orders/{id}** - Retrieve a specific order
- **PUT /v2/orders/{id}** - Update an existing order
- **DELETE /v2/orders/{id}** - Delete an order
