 To add the v4.0 entry to the `RELEASES.md` file, follow these steps:

1. Open the `RELEASES.md` file.

2. Find the last entry in the file, which should be the 20th release. This is the release that will be moved to the archive file.

3. Copy the format of the last entry and paste it just below the last entry in the `RELEASES.md` file.

4. Replace the version number, date, and any other necessary details in the copied entry with the details of the new release (v4.0).

5. Save the `RELEASES.md` file.

6. Move the last entry (the oldest entry, the one that was copied and replaced) to the `RELEASES_ARCHIVE.md` file.

7. If the `RELEASES_ARCHIVE.md` file now contains more than 20 entries, remove the oldest entry from the file to keep it capped at 20 entries.

8. Save the `RELEASES_ARCHIVE.md` file.
