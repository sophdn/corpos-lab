 1. Open the `RELEASES.md` file in a text editor.

2. Scroll to the end of the file, where the 20th release (the oldest one) is currently located.

3. Copy that release's entry, including the line break that follows it.

4. Paste the copied entry at the beginning of the file.

5. Replace the contents of the copied entry with the information about the v4.0 release.

6. Add a line break after the v4.0 release entry.

7. Save the `RELEASES.md` file.

8. If the file now contains more than 20 entries, rename the file to `RELEASES.md` and create a new file named `RELEASES_ARCHIVE.md`.

9. Move the 20 oldest entries (not including the v4.0 entry), from the beginning of the `RELEASES.md` file to the new `RELEASES_ARCHIVE.md` file.

10. Save both files (`RELEASES.md` and `RELEASES_ARCHIVE.md`).
