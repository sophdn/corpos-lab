2. Scroll to the end of the file to find an empty line, as the 21st line since the file format specification only allows for 20 releases.
3. Write the entry for v4.0 on the empty line, following the format defined in the file (usually including the release name, version number, and release date).
4. Save the changes to the file.
5. If necessary, move an older release entry from `RELEASES.md` to `RELEASES_ARCHIVE.md` to make room for the new entry, if the current file now exceeds the limit of 20 entries.
6. Close the file.

```

```
