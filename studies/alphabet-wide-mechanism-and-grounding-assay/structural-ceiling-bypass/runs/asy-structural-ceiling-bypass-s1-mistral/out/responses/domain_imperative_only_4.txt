 1. Identify the oldest entry in `RELEASES.md` to be archived. This can be done by looking at the version numbers or dates.

2. Copy the oldest entry from `RELEASES.md` to a new entry in `RELEASES_ARCHIVE.md`.

3. Remove the oldest entry from `RELEASES.md`.

4. Add the new entry for v4.0 to `RELEASES.md`.

5. Verify that the count of entries in `RELEASES.md` is now 20 and the count in `RELEASES_ARCHIVE.md` is one more than the current count in `RELEASES.md`.

The steps might look like this:

Oldest entry in RELEASES.md:
```
v1.0
...
v3.9
```

RELEASES.md after oldest entry removal:
```
v1.1
...
v3.9
```

RELEASES_ARCHIVE.md after oldest entry addition:
```
v1.0
```

RELEASES.md after v4.0 addition:
```
v1.1
...
v3.9
v4.0
```
