# Notation Reference

**Scope:** Claude-side orientation only. Symbol table and axis names extracted from the full glyph definition (lab-side). Sufficient for reading task documents and handoffs that use glyph notation; not sufficient for corpus work.

---

## Symbol table

| Symbol | Meaning |
|--------|---------|
| Y | The agent's current position — the decision point where the pull is live |
| X | The failure path — the locally rational action that produces Z-marker |
| M | The correct path — the action that produces Z-aim |
| Z-marker | The configuration produced by taking X: a load-bearing misalignment |
| Z-aim | The configuration produced by taking M: correct alignment |

## Axis names

The Marker axis governs X → Z-marker; the Aim axis governs M → Z-aim; the Rest axis describes territory where neither direction is live from the agent's position.
